      Simplify: \(x^3 \cdot x^5\).

      Solution:

      Solution:

      D) 2^7 = 49
      Correct Answer: C
      
      Solution:
      Use log_a(c) = b ⇔ a^b = c. Here a = 7, b = 2, c = 49, so 7^2 = 49.
      
      Explanation:
      The base of the logarithm becomes the base of the exponential, and the logarithm value becomes the exponent.
      
      Common mistake note:
      A common mistake is to treat the log argument (49) as the exponent and write 7^49 = 2; that does not match the definition of logarithms.
      ------------------------------------------------------------------------------
      
      Problem 6 (Q6):
      Convert the exponential equation (1/3)^(-2) = 9 to logarithmic form.
      A) log_(1/3)(9) = -2
      B) log_9(1/3) = -2
      C) log_(1/3)(-2) = 9
      D) log_(-2)(1/3) = 9
      Correct Answer: A
      
      Solution:
      Use a^b = c ⇔ log_a(c) = b. Here a = 1/3, b = -2, c = 9, so log_(1/3)(9) = -2.
      
      Explanation:
      Even with fractions and negative exponents, the conversion rule is the same: the log base is 1/3, the log argument is 9, and the log equals -2.
      
      Common mistake note:
      A common mistake is to swap base and argument (log_9(1/3) = -2). That would mean 9^(-2) = 1/3, but 9^(-2) = 1/81.
      ------------------------------------------------------------------------------
      
      Problem 7 (Q7):
      A student writes: log_4(64) = 4. Which exponential equation matches the student's statement?
      A) 4^64 = 4
      B) 4^4 = 64
      C) 64^4 = 4
      D) 64^4 = 16
      Correct Answer: B
      
      Solution:
      Use log_a(c) = b ⇔ a^b = c. Here a = 4, c = 64, b = 4, so 4^4 = 64.
      
      Explanation:
      The logarithmic equation says the exponent needed on base 4 to get 64 is 4; that translates directly to 4^4 = 64.
      
      Common mistake note:
      A common mistake is to put the argument as the exponent (4^64 = 4), confusing c with b. In log form, the argument is the result, not the exponent.

      1.1.3.6 Solve logarithmic equations
      ------------------------------------------------------------------------------
      Problem 1 (Q1):
      Solve for x:  log_2(x) = 5
      A) x = 10
      B) x = 32
      C) x = 7
      D) x = 25
      Correct Answer: B
      
      Solution:
      Rewrite in exponential form: x = 2^5 = 32.
      
      Explanation:
      A logarithmic equation log_b(x)=c is equivalent to x=b^c (with x>0 and b>0, b≠1). Here b=2 and c=5, so x=32.
      
      Common mistake note:
      A common mistake is to multiply 2·5 and claim x=10. Logs convert to exponentials; they do not turn into multiplication.
      ------------------------------------------------------------------------------
      
      Problem 2 (Q2):
      Solve for x:  ln(x) = 3
      A) x = e^3
      B) x = 3e
      C) x = \ln(3)
      D) x = e/3
      Correct Answer: A
      
      Solution:
      Exponentiate both sides with base e: x = e^3.
      
      Explanation:
      Since ln is log base e, ln(x)=3 means x is the number whose natural log is 3, i.e., x=e^3.
      
      Common mistake note:
      A common mistake is to think ln(x)=3 implies x=3. ln is not the identity function; you must exponentiate to undo it.
      ------------------------------------------------------------------------------
      
      Problem 3 (Q3):
      Solve for x:  log_10(x) + log_10(4) = 2
      A) x = 50
      B) x = 25
      C) x = 100
      D) x = 4
      Correct Answer: B
      
      Solution:
      Use log addition: log_10(x)+log_10(4)=log_10(4x).
      So log_10(4x)=2.
      Convert to exponential form: 4x=10^2=100.
      Thus x=25.
      
      Explanation:
      Combine logs with the same base using log(a)+log(b)=log(ab), then rewrite as an exponential equation and solve.
      
      Common mistake note:
      A common mistake is to add inside the log: log(x)+log(4)=log(x+4). That property is false; logs combine by multiplication, not addition.
      ------------------------------------------------------------------------------
      
      Problem 4 (Q4):
      Solve for x:  log_3(x - 1) = log_3(2x - 7)
      A) x = 4
      B) x = 6
      C) x = 3
      D) x = 2
      Correct Answer: B
      
      Solution:
      Set arguments equal (and enforce domains): x-1 = 2x-7.
      Solve: x = 6.
      Domain check: x-1>0 ⇒ x>1; 2x-7>0 ⇒ x>3.5. x=6 is valid.
      
      Explanation:
      For b>0, b≠1, log_b(A)=log_b(B) implies A=B provided A>0 and B>0. Solve the resulting linear equation and verify the domain.
      
      Common mistake note:
      A common mistake is to forget domain restrictions and accept an extraneous solution when an argument is ≤0. Always check that each log’s argument is positive.
      ------------------------------------------------------------------------------
      
      Problem 5 (Q5):
      Solve for x:  log_5(x) = -2
      A) x = -25
      B) x = 1/25
      C) x = -1/25
      D) x = 25
      Correct Answer: B
      
      Solution:
      Rewrite in exponential form: x = 5^{-2} = 1/5^2 = 1/25.
      
      Explanation:
      A negative logarithm value means the argument is a positive fraction. Converting to exponential form gives x=5^{-2}.
      
      Common mistake note:
      A common mistake is to think a negative log output means x is negative (e.g., x=-25). Log arguments must be positive, so x cannot be negative.
      ------------------------------------------------------------------------------
      
      Problem 6 (Q6):
      Solve for x:  log_2(x) + log_2(x - 2) = 3
      A) x = 4
      B) x = -2
      C) x = 2 + \sqrt{12}
      D) x = 6
      Correct Answer: A
      
      Solution:
      Domain: x>0 and x-2>0 ⇒ x>2.
      Combine logs: log_2(x) + log_2(x-2) = log_2(x(x-2)) = 3.
      Convert to exponential form: x(x-2)=2^3=8.
      Solve: x^2-2x-8=0 ⇒ (x-4)(x+2)=0.
      So x=4 or x=-2. Domain x>2 ⇒ x=4.
      
      Explanation:
      Use log addition to combine into one logarithm, rewrite as an exponential equation, solve the quadratic, then discard any root that makes a log argument nonpositive.
      
      Common mistake note:
      A common mistake is to keep both quadratic roots without checking the domain. Here x=-2 must be rejected because log_2(x) is undefined for x≤0 and also x-2 must be positive.
      ------------------------------------------------------------------------------
      
      Problem 7 (Q7):
      Solve for x:  log_3(x + 4) - log_3(x - 2) = 1
      A) x = 1
      B) x = 2
      C) x = 5
      D) x = 7
      Correct Answer: C
      
      Solution:
      Domain: x+4>0 and x-2>0 ⇒ x>2.
      Use subtraction rule: log_3((x+4)/(x-2))=1.
      Convert to exponential form: (x+4)/(x-2)=3.
      Solve: x+4=3x-6 ⇒ 10=2x ⇒ x=5.
      Check domain: 5>2, valid.
      
      Explanation:
      Use log(a)-log(b)=log(a/b) for the same base, convert to exponential form, solve the resulting linear equation, and verify the domain.
      
      Common mistake note:
      A common mistake is to subtract inside incorrectly as log(x+4-(x-2)). Logs do not distribute over subtraction; you must form a quotient.

      1.1.3.7 Apply the change-of-base formula
      ------------------------------------------------------------------------------
      Problem 1 (Q1):
      Use the change-of-base formula to evaluate \(\log_2(32)\) using common logarithms (base 10).
      A) 5
      B) 4
      C) \(\dfrac{\log 32}{\log 2}\) and it equals 6
      D) \(\dfrac{\log 2}{\log 32}\) and it equals 5
      Correct Answer: A
      
      Solution:
      \(\log_2(32)=\dfrac{\log(32)}{\log(2)}\). Since \(32=2^5\), \(\log_2(32)=5\).
      
      Explanation:
      By change of base, \(\log_b(a)=\dfrac{\log(a)}{\log(b)}\). Here, \(\log_2(32)=\dfrac{\log(32)}{\log(2)}\), and because \(32=2^5\), the logarithm equals 5.
      
      Common mistake note:
      Flipping the fraction gives \(\dfrac{\log 2}{\log 32}=\log_{32}(2)\), not \(\log_2(32)\).
      ------------------------------------------------------------------------------
      
      Problem 2 (Q2):
      Write \(\log_5(12)\) using natural logarithms (\(\ln\)) via change of base.
      A) \(\dfrac{\ln 12}{\ln 5}\)
      B) \(\dfrac{\ln 5}{\ln 12}\)
      C) \(\ln(12\cdot 5)\)
      D) \(\ln(12-5)\)
      Correct Answer: A
      
      Solution:
      \(\log_5(12)=\dfrac{\ln 12}{\ln 5}\).
      
      Explanation:
      The change-of-base formula rewrites \(\log_b(a)\) as \(\dfrac{\ln a}{\ln b}\). Substituting \(a=12\), \(b=5\) gives \(\dfrac{\ln 12}{\ln 5}\).
      
      Common mistake note:
      \(\dfrac{\ln 5}{\ln 12}\) equals \(\log_{12}(5)\), not \(\log_5(12)\).
      ------------------------------------------------------------------------------
      
      Problem 3 (Q3):
      Given \(\log_{10}(2)\approx 0.3010\), approximate \(\log_2(10)\) using change of base. Round to 3 decimal places.
      A) 3.322
      B) 0.301
      C) 2.000
      D) 0.500
      Correct Answer: A
      
      Solution:
      \(\log_2(10)=\dfrac{\log_{10}(10)}{\log_{10}(2)}=\dfrac{1}{0.3010}\approx 3.322\).
      
      Explanation:
      Using base-10 change of base, \(\log_2(10)=\dfrac{\log(10)}{\log(2)}\). Since \(\log(10)=1\), compute \(1/0.3010\approx 3.322\).
      
      Common mistake note:
      Using \(\dfrac{\log(2)}{\log(10)}\) gives \(\log_{10}(2)\), not \(\log_2(10)\).
      ------------------------------------------------------------------------------
      
      Problem 4 (Q4):
      Solve for \(x\): \(\log_3(x)=4\). Use change of base to justify your steps.
      A) 81
      B) 64
      C) 12
      D) 16
      Correct Answer: A
      
      Solution:
      \(\log_3(x)=\dfrac{\ln x}{\ln 3}=4\Rightarrow \ln x=4\ln 3\Rightarrow x=e^{4\ln 3}=3^4=81\).
      
      Explanation:
      Change of base converts \(\log_3(x)\) to \(\dfrac{\ln x}{\ln 3}\). Multiply both sides by \(\ln 3\): \(\ln x=4\ln 3\). Exponentiate to get \(x=e^{4\ln 3}=3^4=81\).
      
      Common mistake note:
      Don’t treat \(\log_3(x)=4\) as linear (e.g., \(x=4\cdot 3\)). It means \(x\) is the value of \(3^4\).
      ------------------------------------------------------------------------------
      
      Problem 5 (Q5):
      Which expression is obtained by applying ONLY the change-of-base formula to rewrite \(\log_7(\sqrt{5})\) in terms of common logarithms (base 10)? (Do not apply any other log properties.)
      A) \(\dfrac{\log(\sqrt{5})}{\log 7}\)
      B) \(\dfrac{\log 7}{\log(\sqrt{5})}\)
      C) \(\dfrac{\log(5^{1/2})}{\log 7}\)
      D) \(\dfrac{\log 5}{\log 49}\)
      Correct Answer: A
      
      Solution:
      \(\log_7(\sqrt{5})=\dfrac{\log(\sqrt{5})}{\log 7}\).
      
      Explanation:
      Using change of base with common logs: \(\log_b(a)=\dfrac{\log(a)}{\log(b)}\). With \(a=\sqrt{5}\) and \(b=7\), this becomes \(\dfrac{\log(\sqrt{5})}{\log 7}\).
      
      Common mistake note:
      Choice B is the reciprocal (\(\log_{\sqrt{5}}(7)\)). Choices C and D rewrite the argument/base beyond a direct single application of change of base as stated.
      ------------------------------------------------------------------------------
      
      Problem 6 (Q6):
      Use change of base to solve for \(x\): \(\log_4(x)=\dfrac{1}{2}\).
      A) 2
      B) 8
      C) 16
      D) 4
      Correct Answer: A
      
      Solution:
      \(\log_4(x)=\dfrac{\ln x}{\ln 4}=\dfrac{1}{2}\Rightarrow \ln x=\dfrac{1}{2}\ln 4\Rightarrow x=e^{(1/2)\ln 4}=4^{1/2}=2\).
      
      Explanation:
      Rewrite with change of base: \(\log_4(x)=\dfrac{\ln x}{\ln 4}\). Solve for \(\ln x\) and exponentiate to obtain \(x\).
      
      Common mistake note:
      A common error is to treat \(\log_4(x)=\tfrac12\) as \(x=4/2\). It instead means \(x=4^{1/2}\).
      ------------------------------------------------------------------------------
      
      Problem 7 (Q7):
      A student writes: \(\log_3(7)=\dfrac{\ln 3}{\ln 7}\). Which statement best describes the error?
      A) The numerator and denominator are reversed; it should be \(\dfrac{\ln 7}{\ln 3}\).
      B) Natural logs cannot be used in change of base; only base 10 logs work.
      C) Change of base requires multiplying: \(\log_3(7)=\ln 3\cdot \ln 7\).
      D) The expression is correct as written.
      Correct Answer: A
      
      Solution:
      Correct change-of-base: \(\log_3(7)=\dfrac{\ln 7}{\ln 3}\). The student inverted the fraction.
      
      Explanation:
      By change of base, \(\log_b(a)=\dfrac{\ln a}{\ln b}\). Here \(a=7\), \(b=3\), so it must be \(\dfrac{\ln 7}{\ln 3}\). The student wrote the reciprocal, which equals \(\log_7(3)\).
      
      Common mistake note:
      Swapping numerator and denominator changes the value to a different logarithm (base and argument swapped), not the original.

      1.1.3.8 Graph exponential functions
      ------------------------------------------------------------------------------
      Problem 1 (Q1):
      Which graph best represents the function f(x)=2^x ?
      A) Passes through (0,1), increases as x increases, and has horizontal asymptote y=0.
      B) Passes through (0,0), increases as x increases, and has vertical asymptote x=0.
      C) Passes through (0,1), decreases as x increases, and has horizontal asymptote y=0.
      D) Passes through (1,0), increases as x increases, and has horizontal asymptote y=1.
      Correct Answer: A
      
      Solution:
      For f(x)=2^x: f(0)=2^0=1 so it passes through (0,1). Since base 2>1, it is increasing. As x→−∞, 2^x→0, so the horizontal asymptote is y=0. Therefore choice A.
      
      Explanation:
      An exponential with base greater than 1 grows to the right, crosses the y-axis at 1, and approaches 0 on the left, giving asymptote y=0.
      
      Common mistake note:
      Choosing C by thinking all exponentials “decay.” Decay happens when 0<b<1, not when b>1.
      ------------------------------------------------------------------------------
      
      Problem 2 (Q2):
      A graph is decreasing, has y-intercept 1, and approaches y=0 as x increases. Which function matches this graph?
      A) f(x)=2^x
      B) f(x)=(1/2)^x
      C) f(x)=2^x+1
      D) f(x)=(1/2)^x+3
      Correct Answer: B
      
      Solution:
      A decreasing exponential with y-intercept 1 and horizontal asymptote y=0 must be of the form b^x with 0<b<1 and no vertical shift. (1/2)^x fits: f(0)=1 and it decreases to 0 as x→∞. So B.
      
      Explanation:
      For b^x, the y-intercept is always 1 (since b^0=1). Decreasing behavior indicates 0<b<1; no vertical shift keeps asymptote at y=0.
      
      Common mistake note:
      Picking C because it still has y-intercept 2^0+1=2 (not 1) and asymptote y=1 (not 0).
      ------------------------------------------------------------------------------
      
      Problem 3 (Q3):
      Graph g(x)=3^(x−2). Which statement is correct?
      A) It is the graph of 3^x shifted 2 units left.
      B) It is the graph of 3^x shifted 2 units right.
      C) It is the graph of 3^x shifted 2 units up.
      D) It is the graph of 3^x reflected across the x-axis.
      Correct Answer: B
      
      Solution:
      Replacing x by (x−2) shifts the graph right 2 units. Thus g(x)=3^(x−2) is 3^x shifted 2 units right → B.
      
      Explanation:
      Horizontal shifts: f(x−h) moves right by h; f(x+h) moves left by h. Here h=2.
      
      Common mistake note:
      Choosing A by confusing the sign inside the input. The minus sign causes a shift to the right, not left.
      ------------------------------------------------------------------------------
      
      Problem 4 (Q4):
      For the function h(x)=2^x+5, what is the horizontal asymptote?
      A) y=0
      B) y=5
      C) x=0
      D) x=5
      Correct Answer: B
      
      Solution:
      The parent function 2^x has horizontal asymptote y=0. Adding +5 shifts the graph up 5 units, so the asymptote becomes y=5. Answer: B.
      
      Explanation:
      A vertical shift f(x)+k moves all y-values (including the asymptote) up by k.
      
      Common mistake note:
      Choosing A because you remember 2^x has asymptote y=0, but forgetting that the +5 shifts the entire graph upward.

      Problem 5 (Q5):
      A function has horizontal asymptote y=−3 and passes through the point (0,−2). It is an increasing exponential. Which function could it be?
      A) f(x)=2^x−3
      B) f(x)=(1/2)^x−3
      C) f(x)=2^x+3
      D) f(x)=−2^x−3
      Correct Answer: A
      
      Solution:
      Asymptote y=−3 suggests a vertical shift down 3: f(x)=b^x−3. Passing through (0,−2) gives f(0)=1−3=−2, which works. Increasing requires b>1, so choose b=2. Thus A.
      
      Explanation:
      An exponential of the form b^x+k has asymptote y=k and y-intercept 1+k. With k=−3, the y-intercept is −2, matching the point.
      
      Common mistake note:
      Choosing B because it matches the asymptote and point, but (1/2)^x is decreasing (since 0<b<1), contradicting “increasing.”

      Problem 6 (Q6):
      Which table of values could come from an exponential function of the form f(x)=a·b^x with a>0 and b>1?
      A) x: 0,1,2,3  | f(x): 2,4,6,8
      B) x: 0,1,2,3  | f(x): 3,6,12,24
      C) x: 0,1,2,3  | f(x): 5,4,3,2
      D) x: 0,1,2,3  | f(x): 1,1,1,1
      Correct Answer: B
      
      Solution:
      For f(x)=a·b^x, the ratio f(x+1)/f(x) is constant and equals b. In B, ratios are 6/3=2, 12/6=2, 24/12=2, constant with b=2>1 and a=f(0)=3>0. So B.
      
      Explanation:
      Exponential growth shows a constant multiplicative factor between consecutive outputs. Linear patterns (constant difference) are not exponential.
      
      Common mistake note:
      Choosing A because it “increases,” but A has constant differences (+2) rather than constant ratios, so it’s linear, not exponential.

      Problem 7 (Q7):
      Graph y=−(1/3)^x. Which description is correct?
      A) Always positive, decreasing, with asymptote y=0.
      B) Always negative, increasing, with asymptote y=0.
      C) Always negative, decreasing, with asymptote y=1.
      D) Crosses the x-axis at x=0 and has asymptote y=0.
      Correct Answer: B
      
      Solution:
      (1/3)^x is always positive and decreasing (since 0<b<1). Multiplying by −1 makes all values negative and reflects across the x-axis, which turns a decreasing curve into an increasing one. The horizontal asymptote remains y=0. Therefore: always negative, increasing, asymptote y=0 → B.
      
      Explanation:
      Reflection across the x-axis changes the sign of y-values and reverses monotonicity: if a positive function decreases, its negative increases.
      
      Common mistake note:
      Choosing A by ignoring the leading negative sign. The negative makes the entire graph lie below the x-axis (never positive).

      1.1.3.9 Graph logarithmic functions
      ------------------------------------------------------------------------------
      Problem 1 (Q1):
      Which statement correctly describes the graph of \(y=\log_2(x)\)?
      A) Vertical asymptote at \(x=0\); passes through \((1,0)\); increasing for \(x>0\).
      B) Horizontal asymptote at \(y=0\); passes through \((0,1)\); increasing for all real \(x\).
      C) Vertical asymptote at \(x=1\); passes through \((0,0)\); decreasing for \(x>0\).
      D) Horizontal asymptote at \(y=1\); passes through \((2,0)\); decreasing for \(x>0\).
      Correct Answer: A
      
      Solution:
      For \(y=\log_2(x)\): the domain is \(x>0\), so there is a vertical asymptote at \(x=0\). Also \(\log_2(1)=0\), so it passes through \((1,0)\). Since the base \(2>1\), the function is increasing on \((0,\infty)\).
      
      Explanation:
      A basic logarithm \(y=\log_b(x)\) has vertical asymptote \(x=0\), x-intercept at \((1,0)\), and is increasing when \(b>1\) (decreasing when \(0<b<1\)).
      
      Common mistake note:
      Mixing up logarithms with exponentials: choosing a horizontal asymptote at \(y=0\) (that’s typical for \(b^x\), not \(\log_b x\)).

      Problem 2 (Q2):
      Consider \(f(x)=\ln(x-3)+2\). Which option gives the vertical asymptote and the domain?
      A) Asymptote: \(x=3\); Domain: \((3,\infty)\).
      B) Asymptote: \(y=2\); Domain: \(( -\infty,\infty)\).
      C) Asymptote: \(x=-3\); Domain: \((-3,\infty)\).
      D) Asymptote: \(x=0\); Domain: \((0,\infty)\).
      Correct Answer: A
      
      Solution:
      Require the log argument to be positive: \(x-3>0\Rightarrow x>3\). So the domain is \((3,\infty)\). The vertical asymptote occurs where the argument is 0: \(x-3=0\Rightarrow x=3\).
      
      Explanation:
      For \(\ln(x-h)+k\), shifting right by \(h\) moves the vertical asymptote from \(x=0\) to \(x=h\), and the domain becomes \((h,\infty)\). The \(+2\) shifts the graph up but does not create a horizontal asymptote.
      
      Common mistake note:
      Confusing the vertical shift \(+2\) with an asymptote location. Logarithmic graphs have vertical asymptotes where the argument is 0, not horizontal asymptotes.
      ------------------------------------------------------------------------------
      
      Problem 3 (Q3):
      Which point lies on the graph of \(y=\log_3(x)+1\)?
      A) \((3,2)\)
      B) \((1,2)\)
      C) \((0,1)\)
      D) \((9,1)\)
      Correct Answer: A
      
      Solution:
      Test \((3,2)\): \(y=\log_3(3)+1=1+1=2\), which matches the given y-value. So \((3,2)\) lies on the graph.
      
      Explanation:
      To check a point \((x,y)\), substitute into the function. Here, adding 1 shifts the basic \(\log_3(x)\) graph up by 1, so points like \((3,1)\) become \((3,2)\).
      
      Common mistake note:
      Forgetting the +1 vertical shift and choosing outputs as if \(y=\log_3(x)\) (e.g., thinking \(\log_3(3)=1\) is the final y-value).

      Problem 4 (Q4):
      Which transformation describes the change from \(y=\log_{10}(x)\) to \(y=\log_{10}(x+5)\)?
      A) Shift left 5 units.
      B) Shift right 5 units.
      C) Shift up 5 units.
      D) Shift down 5 units.
      Correct Answer: A
      
      Solution:
      Replacing \(x\) by \(x+5\) shifts the graph left by 5 units. Therefore the correct transformation is a left shift of 5 units.
      
      Explanation:
      In general, \(f(x+c)\) shifts the graph of \(f\) left by \(c\). Thus \(\log_{10}(x+5)\) moves the vertical asymptote from \(x=0\) to \(x=-5\).
      
      Common mistake note:
      Reversing the direction of horizontal shifts: many mistakenly say “right 5” because they see +5, but inside-the-function shifts go opposite the sign.

      Problem 5 (Q5):
      For \(g(x)=-\log_2(x)\), which description is correct?
      A) Vertical reflection of \(y=\log_2(x)\); decreasing on \((0,\infty)\).
      B) Horizontal reflection of \(y=\log_2(x)\); increasing on \((0,\infty)\).
      C) Shift of \(y=\log_2(x)\) up by 2; increasing on \((0,\infty)\).
      D) Shift of \(y=\log_2(x)\) right by 2; decreasing on \((0,\infty)\).
      Correct Answer: A
      
      Solution:
      Multiplying a function by \(-1\) reflects its graph across the x-axis. Since \(\log_2(x)\) is increasing on \((0,\infty)\), \(-\log_2(x)\) is decreasing on \((0,\infty)\).
      
      Explanation:
      A negative sign in front of a function, \(-f(x)\), is a vertical reflection. For logarithms with base \(>1\), the original is increasing; the reflection becomes decreasing while keeping the same domain and asymptote at \(x=0\).
      
      Common mistake note:
      Confusing vertical vs. horizontal reflection: reflection across the y-axis would be \(f(-x)\), not \(-f(x)\).

      Problem 6 (Q6):
      Find the x-intercept of \(y=\log_5(x-4)\).
      A) \((5,0)\)
      B) \((4,0)\)
      C) \((9,0)\)
      D) \((0,9)\)
      Correct Answer: A
      
      Solution:
      Set \(y=0\): \(0=\log_5(x-4)\Rightarrow x-4=5^0=1\Rightarrow x=5\). Therefore the x-intercept is \((5,0)\).
      
      Explanation:
      The x-intercept occurs where \(y=0\). For any base \(b\), \(\log_b(1)=0\). So set the inside equal to 1: \(x-4=1\Rightarrow x=5\), giving \((5,0)\).
      
      Common mistake note:
      Setting the log argument to 0 (which finds the vertical asymptote \(x=4\)) instead of setting the function value to 0.

      Problem 7 (Q7):
      A logarithmic function has the form \(y=\log_3(x+2)-1\). Which option correctly gives (i) the vertical asymptote, (ii) the point obtained from the parent point \((1,0)\) after transformations, and (iii) whether the function is increasing or decreasing?
      A) (i) \(x=-2\); (ii) \((-1,-1)\); (iii) increasing.
      B) (i) \(x=2\); (ii) \((3,-1)\); (iii) increasing.
      C) (i) \(x=-2\); (ii) \((1,-1)\); (iii) decreasing.
      D) (i) \(x=0\); (ii) \((-1,1)\); (iii) decreasing.
      Correct Answer: A
      
      Solution:
      (i) The vertical asymptote occurs when the log argument is 0: \(x+2=0\Rightarrow x=-2\).
      (ii) Start from the parent point \((1,0)\) on \(y=\log_3(x)\). The \(x+2\) shifts left 2: \((1,0)\to(-1,0)\). Then \(-1\) shifts down 1: \((-1,0)\to(-1,-1)\).
      (iii) Since base \(3>1\), the function is increasing.
      
      Explanation:
      Horizontal shifts change x-values and move the vertical asymptote; vertical shifts change y-values. The monotonicity of \(\log_b(x)\) depends on the base: increasing for \(b>1\), decreasing for \(0<b<1\).
      
      Common mistake note:
      Applying the +2 shift as a right shift instead of left, which would incorrectly place the asymptote at \(x=2\) and move points in the wrong direction.

      1.1.3.15 Solve logarithmic inequalities
      ------------------------------------------------------------------------------
      Problem 1 (Q1):
      Solve the inequality: \(\log_2(x) \ge 3\).
      A) \(x \ge 6\)
      B) \(x \ge 8\)
      C) \(0 < x \le 8\)
      D) \(x > 8\)
      Correct Answer: B
      
      Solution:
      Domain: \(x>0\). Since base \(2>1\), \(\log_2(x)\) is increasing, so exponentiating preserves the inequality:
      \[\log_2(x) \ge 3 \iff x \ge 2^3 = 8.\]
      Thus \(x\ge 8\).
      
      Explanation:
      For logarithms with base greater than 1, the function is increasing, so \(\log_b(x)\ge c\) is equivalent to \(x\ge b^c\), provided \(x>0\).
      
      Common mistake note:
      Forgetting the domain restriction \(x>0\), or using \(x>8\) instead of \(x\ge 8\).
      ------------------------------------------------------------------------------
      
      Problem 2 (Q2):
      Solve the inequality: \(\log_{1/3}(x) < 2\).
      A) \(0<x<\tfrac{1}{9}\)
      B) \(x>\tfrac{1}{9}\)
      C) \(x\ge \tfrac{1}{9}\)
      D) \(0<x<9\)
      Correct Answer: B
      
      Solution:
      Domain: \(x>0\). Because the base satisfies \(0<\tfrac13<1\), \(\log_{1/3}(x)\) is decreasing, so the inequality reverses when converting to exponential form:
      \[\log_{1/3}(x) < 2 \iff x > \left(\tfrac13\right)^2 = \tfrac19.\]
      Therefore, \(x>\tfrac19\).
      
      Explanation:
      When \(0<b<1\), \(\log_b(x)\) is decreasing. Applying \(b^{(\cdot)}\) to both sides flips the inequality sign.
      
      Common mistake note:
      Not reversing the inequality (leading to \(0<x<1/9\)), or including the endpoint \(x=1/9\) even though the inequality is strict.
      ------------------------------------------------------------------------------
      
      Problem 3 (Q3):
      Solve the inequality: \(\ln(x-1) \le 0\).
      A) \(x \le 2\)
      B) \(1 < x \le 2\)
      C) \(x \ge 2\)
      D) \(0 < x \le 2\)
      Correct Answer: B
      
      Solution:
      Domain: \(x-1>0\Rightarrow x>1\).
      Since \(\ln\) is increasing,
      \[\ln(x-1)\le 0 \iff x-1 \le e^0=1.\]
      So \(x\le 2\). Intersect with the domain gives \(1<x\le 2\).
      
      Explanation:
      First enforce the log domain (argument positive). Then use monotonicity of \(\ln\) (increasing) to move from a log inequality to an inequality in the argument.
      
      Common mistake note:
      Including \(x=1\) (where \(\ln(0)\) is undefined) or forgetting to apply the domain restriction.
      ------------------------------------------------------------------------------
      
      Problem 4 (Q4):
      Solve the inequality: \(\log_{5}(2x+1) > \log_{5}(x+4)\).
      A) \(x > 3\)
      B) \(-\tfrac{1}{2} < x \le 3\)
      C) \(x < -\tfrac{1}{2}\)
      D) \(x > -\tfrac{1}{2}\)
      Correct Answer: A
      
      Solution:
      Domain: \(2x+1>0\Rightarrow x>-\tfrac12\) and \(x+4>0\Rightarrow x>-4\). Combined domain: \(x>-\tfrac12\).
      Because base \(5>1\), \(\log_5\) is increasing, so compare arguments:
      \[2x+1 > x+4 \Rightarrow x>3.\]
      Intersecting with the domain leaves \(x>3\).
      
      Explanation:
      With the same base \(b>1\), \(\log_b(A) > \log_b(B)\) is equivalent to \(A>B\) as long as both arguments are positive.
      
      Common mistake note:
      Ignoring domain restrictions or trying to subtract logs without ensuring both arguments are valid.
      ------------------------------------------------------------------------------
      
      Problem 5 (Q5):
      Solve the inequality: \(\log_2(x+3) + \log_2(x-1) \ge 3\).
      A) \(x \ge 1\)
      B) \(x \ge 3\)
      C) \(x \ge -1+2\sqrt{3}\)
      D) \(x \le -1-2\sqrt{3}\)
      Correct Answer: C
      
      Solution:
      Domain: \(x+3>0\Rightarrow x>-3\) and \(x-1>0\Rightarrow x>1\). So domain: \(x>1\).
      Combine logs:
      \[\log_2((x+3)(x-1))\ge 3.\]
      Since base \(2>1\), exponentiate:
      \[(x+3)(x-1)\ge 8.\]
      Expand and solve:
      \[x^2+2x-3\ge 8 \Rightarrow x^2+2x-11\ge 0.\]
      Roots: \(x=\frac{-2\pm\sqrt{48}}{2}=-1\pm 2\sqrt3\).
      Thus \(x\le -1-2\sqrt3\) or \(x\ge -1+2\sqrt3\).
      Intersect with \(x>1\) gives \(x\ge -1+2\sqrt3\).
      
      Explanation:
      Use the product rule \(\log_b A+\log_b B=\log_b(AB)\) (valid only when both arguments are positive), then solve the resulting quadratic inequality and apply the domain.
      
      Common mistake note:
      Combining logs without enforcing \(x>1\), which can lead to incorrectly including the left-branch solution \(x\le -1-2\sqrt3\).
      ------------------------------------------------------------------------------
      
      Problem 6 (Q6):
      Solve the inequality: \(\log_3(x^2-4) \le 1\).
      A) \(-\sqrt{7} \le x \le \sqrt{7}\)
      B) \(-\sqrt{7} \le x < -2\) or \(2 < x \le \sqrt{7}\)
      C) \(x < -\sqrt{7}\) or \(x > \sqrt{7}\)
      D) \(-2 < x < 2\)
      Correct Answer: B
      
      Solution:
      Domain: \(x^2-4>0\Rightarrow x^2>4\Rightarrow x<-2\) or \(x>2\).
      Since base \(3>1\), exponentiate without flipping:
      \[x^2-4 \le 3^1=3 \Rightarrow x^2 \le 7.\]
      So \(-\sqrt7 \le x \le \sqrt7\). Intersect with the domain gives
      \[[-\sqrt7,\sqrt7]\cap\big(( -\infty,-2)\cup(2,\infty)\big)= [-\sqrt7,-2)\cup(2,\sqrt7].\]
      Thus \(-\sqrt7 \le x < -2\) or \(2 < x \le \sqrt7\).
      
      Explanation:
      Solve the inequality from exponentiating (since the base is >1) and intersect with the necessary domain condition that the log argument is positive.
      
      Common mistake note:
      Including \(x=\pm2\) (argument becomes 0, log undefined) or forgetting to intersect with the domain \(|x|>2\).
      ------------------------------------------------------------------------------
      
      Problem 7 (Q7):
      Solve the inequality: \(\log_2(x) - \log_2(x-2) \ge 1\).
      A) \(x \ge 4\)
      B) \(2 < x \le 4\)
      C) \(x>2\)
      D) \(0<x\le 4\)
      Correct Answer: B
      
      Solution:
      Domain: \(x>0\) and \(x-2>0\Rightarrow x>2\). So domain: \(x>2\).
      Combine logs:
      \[\log_2\left(\frac{x}{x-2}\right)\ge 1.\]
      Since base \(2>1\), exponentiate:
      \[\frac{x}{x-2} \ge 2.\]
      On the domain, \(x-2>0\), so multiply both sides by \(x-2\) without flipping:
      \[x \ge 2(x-2)=2x-4 \Rightarrow x\le 4.\]
      Intersect with \(x>2\) gives \(2<x\le 4\).
      
      Explanation:
      After combining logs into a single log, exponentiate (base >1) and solve the resulting rational inequality, using the domain to determine the sign of \(x-2\).
      
      Common mistake note:
      Multiplying by \(x-2\) without noting it must be positive (from the domain), or allowing \(x\le 2\) where the expression is undefined.
