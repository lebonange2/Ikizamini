Problem 1 (not_true_output):
What is the output of the NOT operator when the input is True?
A) True
B) False
C) Unknown
D) Depends on other inputs
Correct Answer: B

Solution:
The NOT operator inverts the truth value of its input. If the input is True, the output will be False.

Explanation:
In a truth table for a single NOT operator, there are two rows: one with the input as True and another with the input as False. For the row with True input, the NOT operator produces False as the output.

Common mistake note:
A common mistake is to assume that the NOT operator always produces the opposite of any input, but it only inverts the truth value.
------------------------------------------------------------------------------

Problem 2 (and_both_true_output):
What is the output of the AND operator when both inputs are True?
A) True
B) False
C) Unknown
D) Depends on other inputs
Correct Answer: A

Solution:
The AND operator produces True only if both its inputs are True.

Explanation:
In a truth table for a single AND operator, there are four rows: one with both inputs as True, another with both inputs as False, and two with one input as True and the other as False. For the row with both inputs as True, the AND operator produces True as the output.

Common mistake note:
A common mistake is to think that the AND operator simply combines the inputs without considering their truth values.
------------------------------------------------------------------------------

Problem 3 (or_one_true_output):
What is the output of the OR operator when one input is True and the other is False?
A) True
B) False
C) Unknown
D) Depends on other inputs
Correct Answer: A

Solution:
The OR operator produces True if at least one of its inputs is True.

Explanation:
In a truth table for a single OR operator, there are four rows: one with both inputs as True, another with both inputs as False, and two with one input as True and the other as False. For the row with one input as True and the other as False, the OR operator produces True as the output.

Common mistake note:
A common mistake is to think that the OR operator requires both inputs to be True for a True output.

Problem 4 (xor_both_true_ouput):
What is the output of the XOR (exclusive OR) operator when both inputs are True?
A) True
B) False
C) Unknown
D) Depends on other inputs
Correct Answer: B

Solution:
The XOR operator produces True if exactly one of its inputs is True.

Explanation:
In a truth table for a single XOR operator, there are four rows: one with both inputs as True, another with both inputs as False, and two with one input as True and the other as False. For the row with both inputs as True, the XOR operator produces False as the output.

Common mistake note:
A common mistake is to confuse XOR with OR, thinking that if any input is True, the output will be True.

Problem 5 (not_and_expression):
What is the truth value of the expression NOT (A AND B) when A is False and B is True?
A) True
B) False
C) Unknown
D) Depends on other inputs
Correct Answer: A

Solution:
The NOT operator inverts the truth value of its input. Since A AND B is False, NOT (A AND B) is True.

Explanation:
First, evaluate the AND operator: A is False and B is True, so A AND B is False. Then apply the NOT operator to the result: NOT False is True.

Common mistake note:
A common mistake is to forget to evaluate the expression inside the NOT operator before applying the NOT operation.
------------------------------------------------------------------------------

Problem 6 (or_and_not_expression):
What is the truth value of the expression (A OR B) AND NOT A when A is True and B is False?
A) True
B) False
C) Unknown
D) Depends on other inputs
Correct Answer: B

Solution:
First, evaluate the OR operator: A is True, so A OR B is True. Then apply the NOT operator to A: NOT A is False. Finally, evaluate the AND operator: True AND False is False.

Explanation:
The order of operations requires evaluating parentheses first, then applying operators from left to right. In this case, A OR B is evaluated first, followed by NOT A, and finally the AND operation.

Common mistake note:
A common mistake is to evaluate the expressions in the wrong order or to forget about operator precedence.

Problem 7 (not_and_or_expression):
What is the truth value of the expression (NOT A) OR (B AND C) when A is False, B is True, and C is False?
A) True
B) False
C) Unknown
D) Depends on other inputs
Correct Answer: A

Solution:
First, evaluate the NOT operator: A is False, so NOT A is True. Then evaluate the AND operator: B is True and C is False, so B AND C is False. Finally, evaluate the OR operator: True OR False is True.

Explanation:
The order of operations requires evaluating parentheses first, then applying operators from left to right. In this case, NOT A is evaluated first, followed by B AND C, and finally the OR operation.

Common mistake note:
A common mistake is to evaluate the expressions in the wrong order or to forget about operator precedence.
