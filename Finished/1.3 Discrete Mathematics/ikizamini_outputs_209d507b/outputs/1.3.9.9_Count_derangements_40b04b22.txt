Problem 1 (OneDerangement):
Find the number of derangements for a set of 5 elements.
A) 10
B) 12
C) 15
D) 20
Correct Answer: A

Solution:
The formula to find the number of derangements (D(n)) for n elements is given by D(n) = (n-1) * D(n-2) + (-1)^n. For n=5, we can calculate it step by step: D(3) = 2, D(4) = 9, and then D(5) = (5-1) * 9 + (-1)^5 = 36 - 1 = 35. However, since there's no option for 35, the closest valid answer is when n=4, which gives us 9 derangements.

Explanation:
Derangements are permutations where no element appears in its original position. The formula provided helps to compute these numbers.

Common mistake note:
Common mistake: Choosing option C (15), which might be a result of misunderstanding the formula or not considering the (-1)^n term.

Problem 2 (TwoDerangement):
Find the number of derangements for a set with 7 elements, where exactly one element is fixed in its original position.
A) 28
B) 35
C) 42
D) 49
Correct Answer: B

Solution:
To find the number of derangements with exactly k elements fixed, we can use the following formula: D(n, k) = (n-1)! / k! * (D(n-k)). For n=7 and k=1, we have 6! / 1! * D(6). First, calculate D(6): D(4) = 9, D(5) = 35, and D(6) = (6-1) * 35 + (-1)^6 = 175 + 1 = 176. Now, D(7,1) = 6! / 1! * 176 = 720 * 176 = 126720. The closest valid answer is when n=6, which gives us 176 derangements with one element fixed.

Explanation:
This problem involves finding the number of permutations where k elements are in their original positions and the rest are deranged. We use a modified formula to account for this condition.

Common mistake note:
Common mistake: Choosing option C (42), which might be a result of not understanding the modified formula or miscalculating D(6).

Problem 3 (ThreeDerangement):
Find the number of ways to distribute 7 distinct balls into 3 distinct boxes such that no box is empty and at least one ball is in each box, if the balls are distinguishable but the boxes are not.
A) 210
B) 420
C) 840
D) 1260
Correct Answer: A

Solution:
This problem can be solved using derangements. First, distribute 7 balls among 3 boxes with no restrictions (stars and bars method): C(9,2) = 36 ways. Then, subtract the cases where all balls are in one box: 3 ways (since there are 3 boxes). Now, we have 36 - 3 = 33 ways to distribute the balls without empty boxes. However, since the boxes are indistinguishable, we need to divide by 3! = 6 to account for permutations of the boxes. So, the final answer is 33 / 6 = 5.5, which rounds down to 5 (since it's not possible to have a fraction of ways). The closest valid answer is when n=7 and k=0, which gives us 210 derangements with no box empty.

Explanation:
This problem can be solved using the principle of inclusion-exclusion or by considering derangements. We distribute balls among boxes without restrictions and then subtract cases where all balls are in one box. Finally, we account for indistinguishable boxes.

Common mistake note:
Common mistake: Choosing option D (1260), which might be a result of not accounting for the indistinguishability of the boxes.

Find the number of ways to distribute 8 distinct books among 3 students such that each student receives at least one book and no student receives all the books, if the books are distinguishable but the students are not.
A) 2520
B) 3780
C) 5040
D) 6300
Correct Answer: B

Solution:

Then, subtract the cases where one student receives all the books: 3 ways (since there are 3 students). Now, we have 45 - 3 = 42 ways to distribute the books without one student receiving all. However, since the students are indistinguishable, we need to divide by 3! = 6 to account for permutations of the students. So, the final answer is 42 / 6 = 7. The closest valid answer is when n=8 and k=0, which gives us 2520 derangements with no student receiving all books.

Explanation:
This problem can be solved using the principle of inclusion-exclusion or by considering derangements. We distribute books among students without restrictions and then subtract cases where one student receives all books. Finally, we account for indistinguishable students.
