Problem 1 (Asd123):
Which of the following is an appropriate approach for designing a sorting algorithm that minimizes time complexity?
A) Linear search
B) Bubble sort
C) Quicksort
D) Selection sort
Correct Answer: C

Solution:
Quicksort has an average-case time complexity of O(n log n), making it a more efficient choice for sorting large datasets compared to linear search (O(n)), bubble sort (O(n^2)), and selection sort (O(n^2)).

Explanation:
Efficient algorithm design involves selecting algorithms with good time complexity for the given problem.

Common mistake note:
Common mistake: Choosing B or D, which are less efficient sorting algorithms.

Problem 2 (Xyz456):
What is a common strategy in dynamic programming to solve optimization problems?
A) Divide and conquer
B) Backtracking
C) Greedy approach
D) Top-down with memoization
Correct Answer: D

Solution:
Dynamic programming often employs a top-down approach with memoization to avoid redundant calculations and solve optimization problems efficiently.

Explanation:
Memoization helps store previously computed results, reducing the time complexity of dynamic programming algorithms.

Common mistake note:
Common mistake: Choosing C, which is more suitable for solving problems where making the best choice at each step leads to an optimal solution.

Problem 3 (Mnb789):
Which algorithm design paradigm is used in Dijkstra's shortest path algorithm?
A) Divide and conquer
B) Greedy approach
C) Brute force
D) Graph traversal
Correct Answer: B

Solution:
Dijkstra's algorithm follows a greedy approach, always selecting the closest unvisited vertex to expand the shortest path.

Explanation:
The greedy strategy makes decisions based on the best immediate choice without considering future consequences.

Common mistake note:
Common mistake: Choosing A, which is more commonly associated with algorithms like merge sort or quicksort.

Problem 4 (Qwe101):
Which of the following is an example of a divide-and-conquer algorithm?
A) Binary search
B) Merge sort
C) Prim's minimum spanning tree
D) Floyd-Warshall shortest paths
Correct Answer: B

Solution:
Merge sort divides the input array into smaller subarrays, sorts them recursively, and then merges them back together.

Explanation:
Divide-and-conquer algorithms break a problem into smaller instances of the same problem.

Common mistake note:
Common mistake: Choosing C or D, which are based on different strategies (greedy for Prim's and dynamic programming for Floyd-Warshall).
