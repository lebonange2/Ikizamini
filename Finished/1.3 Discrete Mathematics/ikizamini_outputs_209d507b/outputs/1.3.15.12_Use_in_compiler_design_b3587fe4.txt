Problem 1 (Assemble):
What is the primary function of an assembler in compiler design?
A) Compiles high-level code into machine code
B) Interprets assembly language instructions
C) Translates source code into assembly language
D) Optimizes machine code for better performance
Correct Answer: B

Solution:
An assembler translates assembly language instructions into machine code. It is responsible for interpreting the assembly language and generating the corresponding binary code.

Explanation:
Option A refers to a compiler, option C refers to a parser or lexical analyzer, and option D refers to an optimizer  – all of which are different components in a compiler system.

Common mistake note:
Common mistake is selecting A (compiler) instead of B (assembler), as some learners may混淆 the roles of these two components.

Problem 2 (Parser):
Which component of a compiler takes source code and generates an abstract syntax tree  (AST)?
A) Scanner
B) Parser
C) Code generator
D) Optimizer
Correct Answer: B

Solution:
A parser is responsible for taking the source code and breaking it down into an abstract syntax tree, which represents the structure of the program.

Explanation:
Option A  (Scanner) lexically analyzes the input, option C  (Code generator) translates the AST into machine code, and option D  (Optimizer) improves the generated code' efficiency.

Common mistake note:
Common mistake is selecting A (scanner), as learners might confuse tokenization with parsing.
