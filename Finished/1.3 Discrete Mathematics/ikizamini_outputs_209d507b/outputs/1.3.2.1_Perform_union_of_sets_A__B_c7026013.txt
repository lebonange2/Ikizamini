Problem 1 (AsdFgHjKlMnO):
Given set A = {1, 2, 3} and set B = {3, 4, 5}, what is the union of sets A and B (A ∪ B)?
A) {1, 2}
B) {3, 4, 5}
C) {1, 2, 3, 4, 5}
D) {1, 2, 3} or {3, 4, 5}
Correct Answer: C

Solution:
The union of sets A and B (A ∪ B) includes all elements that are in either set A or set B. So the union is {1, 2, 3, 4, 5}.

Explanation:
Union operation combines all unique elements from both sets without repetition.

Common mistake note:
Common mistake: Choosing 'A' or 'B', which are subsets of the correct answer and do not include all elements. The union should contain all unique elements from both sets.
