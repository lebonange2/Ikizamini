Problem 1 (InverseMatrix_1):
Find the inverse of matrix A using the characteristic equation method:
A = [2, 5; -3, 1]
A) [1/7, -5/7; 3/7, 2/7]
B) [-1/7, 5/7; 3/7, -2/7]
C) [1/7, 5/7; -3/7, 2/7]
D) [-1/7, -5/7; 3/7, 2/7]
Correct Answer: C

Solution:
The characteristic equation for matrix A is given by det(A - λI) = 0, where I is the identity matrix and λ are eigenvalues. For A = [2, 5; -3, 1], we get:
(2-λ)(1-λ) + 15 ≠ 0
λ^2 - 3λ - 7 = 0
Solving for λ gives us λ1 = (3 + √45)/2 and λ2 = (3 - √45)/2.
The eigenvectors corresponding to these eigenvalues are used to form the matrix P, where each column is an eigenvector. For this problem, we can find that P = [1, 7/√45; 1, -3/√45].
Next, we calculate P^-1 by finding the adjoint of P and dividing by its determinant (which is non-zero). The inverse of A is then given by A^-1 = P * inv(D) * P^-1, where D is a diagonal matrix with λ1 and λ2 on the diagonal.
After calculating these values, we get A^-1 = [1/7, 5/7; -3/7, 2/7].

Explanation:
The characteristic equation method involves finding eigenvalues and eigenvectors to compute the inverse of a matrix. The correct answer is found by following this process.

Common mistake note:
A common mistake is to forget to calculate the inverse of D (the diagonal matrix of eigenvalues) or to incorrectly find the eigenvectors, leading to an incorrect result.

Problem 4 (Eigenbasis_4):
Find the eigenbasis for matrix D:
D = [0, 1; -2, 3]
A) [[-1], [2]]
B) [[1], [-2]]
C) [[-1, 2], [2, -4]]
D) [[-1, 1], [2, -2]]
Correct Answer: A

Solution:
The eigenbasis for matrix D consists of eigenvectors corresponding to its eigenvalues. The eigenvalues are found by solving det(D - λI) = 0, which gives us λ1 = 1 and λ2 = 2.
For λ1 = 1, we solve (D - λI)[x] = [0], which results in the eigenvector [-1].
For λ2 = 2, we solve (D - λI)[y] = [0], which results in the eigenvector [2].
The eigenbasis is thus given by [[-1], [2]].

Explanation:
The eigenbasis is formed by the eigenvectors of a matrix. The correct answer is found by correctly finding the eigenvectors for each eigenvalue.

Common mistake note:
A common mistake is to incorrectly solve the system of equations (D - λI)[v] = [0], leading to incorrect eigenvectors.

Problem 5 (DiagonalMatrix_5):
Convert matrix E to a diagonal matrix using the characteristic equation method:
E = [1, 2; 3, 4]
A) [[-5, 0]; [0, 7]]
B) [[-5, 0]; [0, -7]]
C) [[5, 0]; [0, 7]]
D) [[5, 0]; [0, -7]]
Correct Answer: C

Solution:
To convert matrix E to a diagonal matrix using the characteristic equation method, we first find its eigenvalues and eigenvectors. The eigenvalues are found by solving det(E - λI) = 0, which gives us λ1 = 5 and λ2 = -1.
The eigenvectors for λ1 = 5 are found by solving (E - λI)[x] = [0], resulting in the eigenvector [-2].
The eigenvectors for λ2 = -1 are found by solving (E - λI)[y] = [0], resulting in the eigenvector [3].
We form a matrix P with these eigenvectors as columns and calculate its inverse, P^-1. Then we find the diagonal matrix D by multiplying E with P^-1 on the left and P on the right: D = P^-1 * E * P.
The resulting diagonal matrix is [[5, 0]; [0, 7]].

Explanation:
The characteristic equation method involves finding eigenvalues and eigenvectors to convert a matrix into a diagonal form. The correct answer is found by following this process.

Common mistake note:
A common mistake is to incorrectly calculate the inverse of P or to mix up the eigenvectors, leading to an incorrect diagonal matrix.
