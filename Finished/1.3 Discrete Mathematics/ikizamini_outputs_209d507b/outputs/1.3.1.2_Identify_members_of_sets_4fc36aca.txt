Problem 1 (:1):
Which number is a member of the set {2, 4, 6, 8}?
A) 1
B) 3
C) 5
D) 6
Correct Answer: D

Solution:
The set consists of even numbers. Only '6' is an even number and part of the set.

Explanation:
To identify members of a set, compare each element in the set to the options provided.

Common mistake note:
A common mistake would be selecting odd numbers like '1', '3', which are not in the given even number set.
------------------------------------------------------------------------------

Problem 2 (2):
Which letter is a member of the set {'A', 'E', 'I', 'O', 'U'}?
A) B
B) C
C) D
D) E
Correct Answer: D

Solution:
The set consists of vowels. Only 'E' is a vowel and part of the set.

Explanation:
Match each element in the set to the given options, focusing on vowels.

Common mistake note:
A common mistake would be selecting consonants like 'B', 'C', or 'D', which are not included in the vowel set.
