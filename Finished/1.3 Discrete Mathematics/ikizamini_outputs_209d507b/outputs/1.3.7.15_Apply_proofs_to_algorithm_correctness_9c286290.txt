Problem 1 (One):
Consider the following algorithm for finding the maximum value in an array of integers:

```python
def find_ max(arr):
    max_val = arr[0]
    for i in range(1, len(arr)):
        if arr[i] > max_val:
            max_val = arr[i]
    return max_val
```

Prove the algorithm's correctness by providing a loop invariant that holds before and after each iteration of the `for` loop. Which of the following statements is a correct loop invariant for this algorithm?
A) The maximum value in the array is always stored in `max_val`.
B) The first element of the array, `arr[0]`, is greater than or equal to all other elements.
C) The sum of the elements in the array is less than or equal to the product of their counts.
D) The maximum value in the array is always stored in the last element of the array.
Correct Answer: A

Solution:
A loop invariant must be true before and after each iteration of the loop. In this case, the invariant that `max_val` holds the maximum value seen so far is correct because it's initially true (when `max_val` is set to `arr[0]`) and remains true after each comparison in the loop.

Explanation:
The other choices are either not true for all cases or do not relate to the algorithm's purpose of finding the maximum value.

Common mistake note:
A common mistake would be to choose B, which is only true before the loop starts but not necessarily after each iteration.

Problem 2 (Two):
Prove the correctness of the following insertion sort algorithm by providing a loop invariant:

```python
def insertion_sort(arr):
    for i in range(1, len(arr)):
        key = arr[i]
        j = i - 1
        while j >= 0 and arr[j] > key:
            arr[j + 1] = arr[j]
            j -= 1
        arr[j + 1] = key
```

Which of the following statements is a correct loop invariant for this algorithm?
A) The elements in `arr[0:i]` are sorted.
B) The last element in the array, `arr[-1]`, is always the smallest value seen so far.
C) The sum of all elements in the array is less than or equal to their product.
D) All elements in the array are in non-decreasing order.
Correct Answer: A

Solution:
A loop invariant must be true before and after each iteration of the loop. In this case, the invariant that `arr[0:i]` is sorted is correct because it's initially true (when i = 1) and remains true after each inner loop operation.

Explanation:
The other choices are either not true for all cases or do not relate to the algorithm's purpose of sorting the array in non-decreasing order.

Common mistake note:
A common mistake would be to choose D, which is only true when the entire sort is complete, not necessarily after each iteration.

Problem 5 (Five):
Prove that the following algorithm correctly computes the factorial of a non-negative integer n:

```python
def factorial(n):
    if n == 0:
        return 1
    else:
        return n * factorial(n-1)
```

Which of the following is a proof by induction for this algorithm's correctness?
A) Base case: `factorial(0) = 1`. Inductive step: Assume `factorial(k) = k!`, then `factorial(k+1) = (k+1) * k!`.
B) Base case: `factorial(-1) = -1`. Inductive step: Assume `factorial(k-1) = (k-1)!`, then `factorial(k) = k * (k-1)!`.
C) Base case: `factorial(1) = 0`. Inductive step: Assume `factorial(k) = k!`, then `factorial(k+1) = k * k!`.
D) Base case: `factorial(2) = 3`. Inductive step: Assume `factorial(k-2) = (k-2)!`, then `factorial(k) = k * (k-2)!`.
Correct Answer: A

Solution:
Proof by induction starts with a base case and an inductive step. For the factorial function, the base case is when n = 0, where the result is 1. The inductive step assumes `factorial(k) = k!` and shows that `factorial(k+1) = (k+1) * k!`.

Explanation:
The other choices either have incorrect base cases or incorrect inductive steps.

Common mistake note:
A common mistake would be to choose B, which has an incorrect base case.

Problem 6 (Six):
Prove that the following algorithm correctly computes the greatest common divisor (GCD) of two integers a and b:

```python
def gcd(a, b):
    while b != 0:
        temp = a % b
        a = b
        b = temp
    return a
```

Which property of the Euclidean algorithm is used in this proof?
A) The GCD of two integers is less than or equal to either integer.
B) The GCD of two integers is the same as the GCD of the smaller integer and the remainder when the larger is divided by the smaller.
C) The GCD of two integers is the product of their prime factors.
D) The GCD of two integers is always 1.
Correct Answer: B

Solution:
The algorithm uses the property that the GCD of two integers a and b is equal to the GCD of b and the remainder when a is divided by b. This property allows the algorithm to repeatedly update a and b until b becomes zero, at which point a is the GCD.

Explanation:
The other choices either describe different properties or are incorrect statements about the GCD.

Common mistake note:
A common mistake would be to choose A, which is a property of the GCD but not directly used in this algorithm.

```python
        i += 1
        j -= 1
    return True
```

D) The length of the string is always odd.
Correct Answer: A

Solution:
A loop invariant must be true before and after each iteration of the loop. In this case, the invariant that the characters at indices i and j are always equal is correct because it's initially true (when i = 0 and j = len(s) - 1) and remains true after each comparison in the loop.

Explanation:
The other choices are either not true for all cases or do not relate to the algorithm's purpose of checking if a string is a palindrome.

Common mistake note:
A common mistake would be to choose B, which is only true for some cases but not a sufficient invariant for proving correctness.
