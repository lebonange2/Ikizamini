Problem 1 (:1):
Which of the following statements represents a valid use of the existential quantifier (∃)?
A) For all x, x is a prime number.
B) There exists an x such that x is both even and odd.
C) There exists a real number x such that x^2 = 1.
D) No integers x satisfy the equation x + 5 = 0.
Correct Answer: C

Solution:
The correct statement using the existential quantifier (∃) is 'There exists a real number x such that x^2 = 1.' This means there is at least one real number (for example, x = 1 or x = -1) that satisfies the equation. Answer A uses 'for all' which is an universal quantifier, B is false because no number can be both even and odd, and D is negation of a true statement, so it's not existential.

Explanation:
Existential quantification asserts that there exists at least one element in a set that satisfies a given property. In this case, we're looking for an example where the property (x^2 = 1) has at least one solution.

Common mistake note:
A common mistake is to confuse existential quantifier (∃) with universal quantifier (∀). Answer A uses the universal quantifier, which is not what the question asks for.

Problem 2 (2):
Which of the following statements can be represented using the existential quantifier (∃)?
A) All circles have a diameter.
B) Every person on Earth has at least one sibling.
C) There is a number that is both prime and even.
D) No two parallel lines intersect.
Correct Answer: C

Solution:
The statement 'There is a number that is both prime and even' can be represented using the existential quantifier (∃) because it asserts that there exists at least one number (2) with the given property. The other statements do not require an existential quantifier as they describe general truths or universal properties.

Explanation:
Existential quantification is used when we want to say that there exists at least one element in a set that satisfies a certain condition. In this case, option C asserts that there's at least one number (2) which is both prime and even, making it the correct existential statement.

Common mistake note:
A common mistake would be to choose A or B, as they describe general truths using 'all' or 'every', which are universal quantifiers rather than existential.

Problem 3 (3):
Which of the following logical expressions is equivalent to ∃x (P(x))?
A) ¬∀x ¬P(x)
B) ¬∃x ¬P(x)
C) ∀x P(x)
D) ¬∀x P(x)
Correct Answer: A

Solution:
The logical expression equivalent to ∃x (P(x)) is ¬∀x ¬P(x). This is because the negation of 'for all x, not P(x)' means that there must be at least one x for which P(x) is true.

Explanation:
De Morgan's laws state that ¬(∀x P(x)) is equivalent to ∃x ¬P(x), and ¬¬A is equivalent to A. So, ¬¬(∀x P(x)) becomes ∀x P(x). By applying De Morgan's law again, we get ¬∀x ¬P(x) which means there exists at least one x for which P(x) holds true.

Common mistake note:
A common mistake would be to choose B, as it represents the negation of ∃x ¬P(x), which is not equivalent to ∃x (P(x)).

The statement 'At least one integer is not even' uses the existential quantifier (∃) correctly because it asserts that there exists at least one integer (like 1 or 3) that does not have the property of being even.

Explanation:
Existential quantification is used when we want to say that there is at least one element in a set with a given property. In this case, option B correctly uses ∃ to assert that there's at least one integer that is not even.

Common mistake note:
A common mistake would be to choose A or C, as they use universal quantifiers (∀) and describe general truths rather than existential statements.

Problem 5 (5):
Which of the following sentences can be translated into a mathematical statement using the existential quantifier (∃)?
A) Every day is a new opportunity.
B) Some people never change.
C) All birds can fly.
D) No two snowflakes are alike.
Correct Answer: B

Solution:
The sentence 'Some people never change' can be translated into a mathematical statement using the existential quantifier (∃) as ∃x (Person(x) ∧ NeverChanges(x)). This means there exists at least one person who never changes.

Explanation:
Existential quantification is used when we want to say that there is at least one element in a set with a given property. In this case, option B correctly represents an existential statement about people who never change.

Problem 6 (6):
Which of the following logical expressions is equivalent to ∃x (P(x) ∧ Q(x))?
A) ¬∀x ¬(P(x) ∧ Q(x))
B) ¬∃x ¬(P(x) ∧ Q(x))
C) ∀x (P(x) ∧ Q(x))
D) ¬∀x (P(x) ∧ Q(x))
Correct Answer: A

Solution:
The logical expression equivalent to ∃x (P(x) ∧ Q(x)) is ¬∀x ¬(P(x) ∧ Q(x)). This is because the negation of 'for all x, not (P(x) and Q(x))' means that there must be at least one x for which both P(x) and Q(x) are true.

Explanation:
De Morgan's laws state that ¬(∀x (P(x) ∧ Q(x))) is equivalent to ∃x ¬(P(x) ∧ Q(x)), and ¬¬A is equivalent to A. So, ¬¬(∀x (P(x) ∧ Q(x))) becomes ∀x (P(x) ∧ Q(x)). By applying De Morgan's law again, we get ¬∀x ¬(P(x) ∧ Q(x)) which means there exists at least one x for which both P(x) and Q(x) hold true.

Common mistake note:
A common mistake would be to choose B, as it represents the negation of ∃x ¬(P(x) ∧ Q(x)), which is not equivalent to ∃x (P(x) ∧ Q(x)).
