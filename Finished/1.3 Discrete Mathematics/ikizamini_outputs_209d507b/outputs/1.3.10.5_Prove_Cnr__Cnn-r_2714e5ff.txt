Problem 1 (One):
Calculate C(6, 3) and show that it matches the given value.
A) 10
B) 20
C) 30
D) 40
Correct Answer: C

Solution:
C(6, 3) = 6! / (3!(6-3)!) = 720 / (6 * 2) = 30

Explanation:
This question tests the understanding of combinations and their calculation.

Common mistake note:
A common mistake would be to divide by only one factor of 3 instead of both 3 and 2.

Problem 2 (Two):
Prove that C(5, 2) = C(5, 3). Show your work.
A) False
B) True (10)
C) True (20)
D) Insufficient information
Correct Answer: B

Solution:
C(5, 2) = 5! / (2!(5-2)!) = 120 / (2 * 3) = 10
C(5, 3) = 5! / (3!(5-3)!) = 120 / (6 * 2) = 10

Explanation:
This question tests the understanding of the identity C(n, r) = C( n, n-r).

Common mistake note:
A common mistake would be to assume that since the values are different when calculated directly, they are not equal according to the identity.

Problem 3 (Three):
Calculate C(8, 4) + C(8, 5). Show your work and simplify if possible.
A) 20
B) 35
C) 56
D) 70
Correct Answer: D

Solution:
C(8, 4) = 8! / (4!(8-4)!) = 1680 / (24 * 4) = 70
C(8, 5) = C(8, 3) = 8! / (5!(8-5)!) = 1680 / (120 * 3) = 70
Total: 70 + 70 = 140

Explanation:
This question tests the understanding of combinations and their calculation, along with the identity C( n, r) = C( n, n-r).

Common mistake note:
A common mistake would be to add the values without considering that C(8, 5) is equal to C(8, 3), which simplifies the problem.

Problem 4 (Four):
Prove that C(n, r) = C(n-1, r-1) + C(n-1, r). Show your work.
A) False
B) True (specific cases)
C) True (general identity)
D) Insufficient information
Correct Answer: C

Solution:
C(n, r) = n! / (r!(n-r)!) 
C(n-1, r-1) + C(n-1, r) = (n-1)! / ((r-1)!((n-1)-(r-1))!) + (n-1)! / (r!((n-1)-r)!) 
= 2( (n-1)! ) / (r!(n-r-1)!) 
= n! / (r!(n-r)!)

Explanation:
This question tests the understanding of a different identity related to combinations.

Common mistake note:
A common mistake would be to assume that the two expressions are not equivalent without expanding and simplifying them.

Problem 6 (Six):
Prove that C(n, r) = C(n-1, r) + C(n-1, r-1) using the formula for combinations. Show your work.
A) False
B) True (specific cases)
C) True (general identity)
D) Insufficient information
Correct Answer: C

Solution:
C(n, r) = n! / (r!(n-r)!) 
C(n-1, r) + C(n-1, r-1) = (n-1)! / (r!((n-1)-r)!) + (n-1)! / ((r-1)!((n-1)-(r-1))!) 
= n! / (r!(n-r)!)  * (1 + 1/(n- r)) 
= n! / (r!(n-r)!)

Explanation:
This question tests the understanding of a different identity related to combinations.

Common mistake note:
A common mistake would be to assume that the two expressions are not equivalent without expanding and simplifying them.
