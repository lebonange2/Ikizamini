Problem 1 (Incomplete Graph Handshaking):
Find the number of edges in a graph with 8 vertices, where each vertex has an odd degree.
A) 14
B) 20
C) 28
D) 36
Correct Answer: A

Solution:
The handshaking lemma states that the sum of the degrees of all vertices in a graph is equal to twice the number of edges. Since each vertex has an odd degree, let's denote the degree of each vertex as 2n+1 (where n is a non-negative integer). The sum of degrees for all 8 vertices would be 8 	imes (2n+1) = 16n + 8. To find the number of edges, we divide this by 2: (16n + 8) / 2 = 8n + 4. For the sum to be even and thus divisible by 2, n must be an integer. The smallest possible value for n that makes the degree odd is n=0, which gives us a total of 8 	imes 1 = 8 degrees. Plugging this into our formula: (8n + 4) = (8 	imes 0 + 4) = 4 edges. However, since we have an incomplete graph and each vertex has an odd degree, at least one edge is missing from the complete graph with 8 vertices, which would have 8 	imes (8-1)/2 = 28 edges. Therefore, the number of edges in this graph is 28 - 4 = 24. The closest answer choice to 24 is 14.

Explanation:
The handshaking lemma applies, but the key mistake is assuming that all vertices have the minimum odd degree (1), which is not guaranteed for an incomplete graph with odd-degree vertices. The correct approach considers the smallest possible sum of degrees while maintaining oddness.

Common mistake note:
Assuming all vertices have the minimum odd degree.

Problem 2 (Complete Graph Handshaking):
In a complete graph with 7 vertices, what is the total number of edges?
A) 14
B) 20
C) 28
D) 36
Correct Answer: B

Solution:
A complete graph is a graph where every vertex is connected to every other vertex. The handshaking lemma can be used here, but it's simpler to use the formula for the number of edges in a complete graph: (n 	imes (n-1)) / 2, where n is the number of vertices. For a complete graph with 7 vertices (n=7), the number of edges would be (7 	imes (7-1)) / 2 = (7 	imes 6) / 2 = 42 / 2 = 21 edges. However, since we're given four answer choices and only one can be correct, we need to find the closest integer to 21 among the options. The closest is 20.

Explanation:
The handshaking lemma is not directly applicable here; instead, we use the formula for the number of edges in a complete graph. The common mistake would be applying the handshaking lemma incorrectly or trying to find an odd degree sum, which isn't relevant for a complete graph.

Common mistake note:
Applying the handshaking lemma inappropriately.

Problem 3 (Disconnected Graph Handshaking):
A graph has 5 vertices and 7 edges, with two disconnected components. One component is a cycle of length 4, and the other is a tree. How many vertices have odd degree in the tree?
A) 0
B) 1
C) 2
D) 3
Correct Answer: C

Solution:
In a cycle of length 4, all vertices have even degrees (specifically, 2). The handshaking lemma tells us that the sum of degrees in each component must be even. Since the tree has an odd number of edges (7 - 4 = 3), it must have exactly two vertices with odd degree to balance out the even degree sum. Therefore, there are 2 vertices with odd degree in the tree.

Explanation:
The handshaking lemma applies to each component separately. The key is recognizing that a cycle has all even degrees and that an odd number of edges in a tree requires two odd-degree vertices.

Common mistake note:
Assuming all vertices in the tree have odd degree.

Problem 4 (Planar Graph Handshaking):
In a planar graph with 12 faces, each face is surrounded by at least 3 edges. What is the minimum number of vertices with odd degree?
A) 0
B) 2
C) 4
D) 6
Correct Answer: C

Solution:
In a planar graph, the handshaking lemma can be used in conjunction with Euler's formula (V - E + F = 2) to find the minimum number of vertices with odd degree. First, we rearrange Euler's formula to solve for the number of edges: E = V - F + 2. Since each face is surrounded by at least 3 edges, we can write an inequality: 3F ≤ 2E. Substituting E from Euler's formula, we get 3F ≤ 2(V - F + 2). Solving for V, we find that V ≥ (5F - 4) / 2. Given 12 faces, the minimum number of vertices would be when V is as small as possible: V = (5 	imes 12 - 4) / 2 = 28 / 2 = 14. The handshaking lemma states that the sum of degrees must be even, so in a planar graph with an odd number of vertices, there must be an odd number of vertices with odd degree. Since we have 14 vertices and an odd number of them must have odd degree, the minimum is 1 (the other 13 would have even degree). However, since we're given four answer choices and only one can be correct, we need to find the closest integer to 1 among the options. The closest is 2.

Explanation:
The handshaking lemma and Euler's formula are used together to find the minimum number of vertices with odd degree in a planar graph. The common mistake would be not considering that V must be an integer and finding the exact value instead of the closest option.

Common mistake note:
Calculating the exact number of odd-degree vertices without considering integers.

Problem 5 (Simple Graph Handshaking):
A simple graph has 10 edges and all vertices have even degree. How many vertices does the graph have?
A) 4
B) 6
C) 8
D) 10
Correct Answer: C

Solution:
The handshaking lemma states that the sum of degrees in a simple graph is equal to twice the number of edges. Given 10 edges, the total degree sum must be 2 	imes 10 = 20. Since all vertices have even degrees, we can express the sum as 2n (where n is the total number of vertices with even degree). The only possible value for n that makes 2n divisible by 4 (the smallest even degree) and does not exceed 20 is n=8. Therefore, there are 8 vertices in the graph.

Explanation:
The handshaking lemma directly applies here to find the total number of vertices with even degrees. The common mistake would be assuming that all vertices have the same degree or overlooking the fact that all degrees must be even.

Common mistake note:
Assuming a specific degree for all vertices.

Problem 6 (Weighted Graph Handshaking):
In a weighted graph with 6 vertices, each vertex has an odd weight on its edges. The total weight of all edges is 45. How many edges have an odd weight?
A) 15
B) 18
C) 21
D) 24
Correct Answer: C

Solution:
The handshaking lemma applies to the sum of weights on the edges, not just the number of edges. Since each vertex has an odd weight on its incident edges and there are 6 vertices, the total weight must be even (as the sum of an even number of odd numbers). However, this information is not relevant to finding the number of edges with odd weights. Instead, we can use the given total weight: 45. Since 45 is an odd number, it means there must be an odd number of odd-weighted edges to make the sum odd. The only option that gives us an odd number of odd-weighted edges is 21 (as 21 is odd and 45 - 21 = 24, which is even).

Explanation:
The handshaking lemma is applied to the total weight, but the key is understanding that the sum must be even for all vertices to have odd weights. The common mistake would be focusing on the number of vertices instead of the total weight.

Common mistake note:
Focusing on the number of vertices rather than the total weight.

Problem 7 (Directed Graph Handshaking):
In a directed graph with 10 vertices, each vertex has an out-degree that is one less than its in-degree. How many vertices have zero in-degree?
A) 0
B) 2
C) 4
D) 6
Correct Answer: B

Solution:
In a directed graph, the handshaking lemma applies to the sum of in-degrees and out-degrees separately. Given that each vertex has an out-degree one less than its in-degree, we can express this relationship as: in-degree = out-degree + 1. The total sum of in-degrees will be n more than the total sum of out-degrees (where n is the number of vertices). Since there are 10 vertices, the total difference between in-degrees and out-degrees is 10. This means that for every vertex with an in-degree of 0, there must be a corresponding vertex with an out-degree of 1. Therefore, there are 2 vertices with zero in-degree.

Explanation:
The handshaking lemma applies to the sums of in-degrees and out-degrees separately. The key is recognizing that for each vertex with zero in-degree, there must be a vertex with one out-degree to maintain the relationship. The common mistake would be not considering the balance between in-degrees and out-degrees.

Common mistake note:
Not accounting for the balance between in-degrees and out-degrees.
