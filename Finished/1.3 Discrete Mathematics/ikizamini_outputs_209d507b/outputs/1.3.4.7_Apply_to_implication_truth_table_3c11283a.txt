Problem 1 (:1):
If P represents 'It is raining' and Q represents 'I will stay at home', which truth value corresponds to the statement 'If it is not raining, then I will not stay at home'? Use the implication truth table.
A) T
B) F
C) 1
D) 0
Correct Answer: B

Solution:
The given statement can be written in symbolic form as P → ¬Q. Using the implication truth table, we find that when P is F (it is not raining) and Q is T (I stay at home), the truth value of P → ¬Q is F. Therefore, the correct answer is B: F.

Explanation:
The implication truth table shows that for an implication to be false, the antecedent must be true and the consequent must be false. In this case, since it's not raining (P is F), but I still stay at home (Q is T), the implication is false.

Common mistake note:
A common mistake would be to choose A: T, assuming that if it's not raining, then the statement is true. However, the truth table shows that only when it's raining and I don't stay at home is the implication true.

Problem 2 (:2):
Given P represents 'I will go for a walk' and Q represents 'It is sunny', which truth value corresponds to the statement 'If I won't go for a walk, then it isn't sunny'? Use the implication truth table.
A) 1
B) 0
C) T
D) F
Correct Answer: A

Solution:
The given statement can be written as ¬P → ¬Q. Using the implication truth table, we find that when P is F (I won't go for a walk) and Q is T (it is sunny), the truth value of ¬P → ¬Q is 1 (true). Therefore, the correct answer is A: 1.

Explanation:
The implication is true when either the antecedent is false or both the antecedent and consequent are true. In this case, since I won't go for a walk (P is F), the statement is considered true regardless of whether it's sunny or not (Q).

Common mistake note:
A common mistake would be to choose D: F, assuming that if I don't go for a walk, then the statement must be false. However, as per the truth table, when the antecedent is false, the implication is considered true.
