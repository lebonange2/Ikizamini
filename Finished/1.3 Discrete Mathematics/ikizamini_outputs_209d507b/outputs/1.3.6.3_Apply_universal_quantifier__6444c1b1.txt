Problem 1 (:1):
Which of the following statements represents a valid use of the universal quantifier (∀)?
A) All dogs can fly.
B) There exists a cat that does not like fish.
C) For every integer x, x + 2 > x.
D) Some numbers are not divisible by themselves.
Correct Answer: C

Solution:
The correct statement using the universal quantifier (∀) is 'For every integer x, x + 2 > x.' This states that the property holds true for all integers. Choice A is false because dogs cannot fly in reality. Choice B uses the existential quantifier (∃), not the universal one. Choice D involves a negation and thus implies the existential quantifier.

Explanation:
The universal quantifier (∀) asserts that a property holds for all members of a set or domain. In this case, choice C correctly applies the universal quantifier to the statement about integers.

Common mistake note:
Common mistake: Confusing the universal quantifier (∀) with the existential quantifier (∃). The latter is used when stating that there exists at least one element in a set satisfying a property.

Problem 2 (:2):
Which of the following statements uses the universal quantifier (∀) correctly to describe all real numbers?
A) There exists a number x such that x^2 = 0.
B) For every x, there is y with y > x.
C) All real numbers have an even integer multiple.
D) No real number is both rational and irrational.
Correct Answer: D

Solution:
The correct statement using the universal quantifier (∀) is 'No real number is both rational and irrational.' This asserts that no member of the set of real numbers can be both rational and irrational at the same time. Choice A uses the existential quantifier, choice B does not involve a negation, and choice C is false since there are real numbers without an even integer multiple.

Explanation:
The universal quantifier (∀) describes properties that hold for all elements in a set. In this case, choice D correctly applies the universal quantifier to exclude a specific property from holding for any real number.

Common mistake note:
Common mistake: Not recognizing that the negation of 'some numbers are both rational and irrational' is a valid use of the universal quantifier.

Problem 3 (:3):
Which of the following statements uses the universal quantifier (∀) to express that all circles have a specific property?
A) There exists a circle with no center.
B) For every circle, there is a line tangent to it.
C) All circles have a circumference-to-diameter ratio of π.
D) Some circles are not perfectly round.
Correct Answer: C

Solution:
The correct statement using the universal quantifier (∀) is 'All circles have a circumference-to-diameter ratio of π.' This property holds true for every circle. Choice A and D use existential quantifiers, and choice B does not express a negation or a specific property shared by all circles.

Explanation:
The universal quantifier (∀) can be used to describe properties that are universally true for a class of objects, like circles in this case. Choice C correctly applies the universal quantifier to the circumference-to-diameter ratio.

Common mistake note:
Common mistake: Not recognizing that the property 'circumference- to-diameter ratio is π' applies to all circles.

Problem 4 (:4):
Which of the following statements uses the universal quantifier (∀) to express a true fact about integers?
A) All even numbers are prime.
B) For every integer x, there exists an integer y such that x + y = 0.
C) No integer is both positive and negative.
D) Some integers have more than two factors.
Correct Answer: B

Solution:
The correct statement using the universal quantifier (∀) is 'For every integer x, there exists an integer y such that x + y = 0.' This is true because for any integer x, its negative (-x) will add up to zero. Choice A is false (2 is even and prime), choice C does not use a quantifier, and choice D uses the existential quantifier.

Explanation:
The universal quantifier (∀) can be used to express properties that hold for all elements in a set. In this case, choice B correctly applies the universal quantifier to state that every integer has an additive inverse.

Common mistake note:
Common mistake: Not recognizing that the property 'every integer has an additive inverse' is true for all integers.
