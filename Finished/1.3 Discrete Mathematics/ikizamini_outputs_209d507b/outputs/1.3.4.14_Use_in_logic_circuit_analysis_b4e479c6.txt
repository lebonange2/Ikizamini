Problem 1 (Inverter):
What is the output of an inverter gate when the input is 1?
A) 0
B) 1
C) No Output
D) Invalid Choice
Correct Answer: A

Solution:
An inverter gate flips the input. If the input is 1, the output will be 0.

Explanation:
In logic gates, an inverter gate (NOT gate) inverts its input. When the input is high (1), the output is low (0).

Common mistake note:
Common mistake: Choosing B, assuming that a 1 remains unchanged. Remember, an inverter always flips the input.
------------------------------------------------------------------------------

Problem 2 (AND Gate):
What is the output of an AND gate when both inputs are 1?
A) 0
B) 1
C) No Output
D) Invalid Choice
Correct Answer: B

Solution:
An AND gate produces a high output (1) only when all its inputs are high.

Explanation:
In logic gates, an AND gate produces an output of 1 if both input signals are 1; otherwise, it produces an output of 0.

Common mistake note:
Common mistake: Choosing A, assuming that at least one input needs to be 1. Both inputs must be 1 for the output to be 1.
------------------------------------------------------------------------------

Problem 3 (OR Gate):
What is the output of an OR gate when one input is 0 and the other is 1?
A) 0
B) 1
C) No Output
D) Invalid Choice
Correct Answer: B

Solution:
An OR gate produces a high output (1) if at least one input is high.

Explanation:
In logic gates, an OR gate produces an output of 1 if at least one input signal is 1; otherwise, it produces an output of 0.

Common mistake note:
Common mistake: Choosing A, assuming that both inputs need to be 1. Only one input needs to be 1 for the output to be 1.
------------------------------------------------------------------------------

Problem 4 (NAND Gate):
What is the output of a NAND gate when both inputs are 1?
A) 0
B) 1
C) No Output
D) Invalid Choice
Correct Answer: A

Solution:
A NAND gate is an AND gate followed by an inverter. If both inputs are 1, the output of the AND gate is 1, which is then inverted to 0.

Explanation:
In logic gates, a NAND gate produces an output opposite to that of an AND gate; it outputs 0 when both inputs are 1 and 1 otherwise.

Common mistake note:
Common mistake: Choosing B, assuming that the output remains unchanged. A NAND gate inverts the AND gate's output.
------------------------------------------------------------------------------

Problem 6 (XOR Gate):
What is the output of an XOR gate when one input is 1 and the other is 0?
A) 0
B) 1
C) No Output
D) Invalid Choice
Correct Answer: B

Solution:
An XOR gate produces a high output (1) if the inputs are different; otherwise, it produces an output of 0.

Explanation:
In logic gates, an XOR gate outputs 1 when the number of high input signals is odd and 0 when it is even.

Common mistake note:
Common mistake: Choosing A, assuming that both inputs need to be different. The XOR gate only cares if one input is different from the other.
