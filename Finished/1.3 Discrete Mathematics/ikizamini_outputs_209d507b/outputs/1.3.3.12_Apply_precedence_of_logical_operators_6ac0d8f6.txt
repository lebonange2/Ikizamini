Problem 1 (InfixOrder1):
What is the result of the expression `true && false || true`?
A) false
B) true
C) null
D) undefined
Correct Answer: B

Solution:
The logical AND operator (`&&`) has higher precedence than the logical OR operator (`||`). First, `true && false` evaluates to `false`, then `false || true` evaluates to `true`. So the result is `true`.

Explanation:
Precedence rules determine the order of evaluation in an expression. In this case, the AND operation is performed before the OR operation.

Common mistake note:
A common mistake would be to evaluate left-to-right without considering operator precedence, which would lead to selecting 'A: false'.

Problem 2 (InfixOrder2):
What is the result of the expression `false || true && false`?
A) true
B) false
C) null
D) undefined
Correct Answer: B

Solution:
The logical OR operator (`||`) has lower precedence than the logical AND operator (`&&`). First, `true && false` evaluates to `false`, then `false || false` evaluates to `false`. So the result is `false`.

Explanation:
Operator precedence governs the sequence of operations. In this case, the OR operation happens after the AND operation.

Common mistake note:
A common mistake would be to evaluate right-to-left without considering operator precedence, which would lead to selecting 'A: true'.

Problem 3 (ParenthesesOrder):
What is the result of the expression `(true && false) || true`?
A) false
B) true
C) null
D) undefined
Correct Answer: B

Solution:
The parentheses group the `true && false` part, so it's evaluated first as `false`. Then `false || true` evaluates to `true`. So the result is `true`.

Explanation:
Parentheses can be used to override operator precedence and force specific parts of an expression to be evaluated first.

Common mistake note:
A common mistake would be to assume that the parentheses don't change the order of evaluation, which would lead to selecting 'A: false'.

Problem 4 (PrefixOrder1):
What is the result of the expression `!true && !false`?
A) true
B) false
C) null
D) undefined
Correct Answer: B

Solution:
The logical NOT operator (`!`) has higher precedence than the logical AND operator (`&&`). First, `!true` evaluates to `false`, then `false && !false` evaluates to `false`. So the result is `false`.

Explanation:
Operator precedence applies to both prefix and infix operators. In this case, the NOT operation happens before the AND operation.

Common mistake note:
A common mistake would be to evaluate left-to-right without considering operator precedence, which would lead to selecting 'A: true'.

Problem 6 (MixedOrder):
What is the result of the expression `!true && (false || true)`?
A) true
B) false
C) null
D) undefined
Correct Answer: B

Solution:
The logical NOT operator (`!`) has higher precedence than the logical AND operator (`&&`). First, `!true` evaluates to `false`. The parentheses group the `false || true` part, which evaluates to `true`. Then `false && true` evaluates to `false`. So the result is `false`.

Explanation:
Operator precedence and parentheses can be combined in expressions. In this case, the NOT operation happens first, followed by the OR within parentheses, and finally the AND operation.

Common mistake note:
A common mistake would be to evaluate without considering operator precedence or the effect of parentheses, which could lead to selecting 'A: true'.

Problem 7 (MixedOrder2):
What is the result of the expression `(true && !false) || (false && !true)`?
A) true
B) false
C) null
D) undefined
Correct Answer: A

Solution:
The parentheses group the expressions, and within each group, the NOT operator has higher precedence than the AND operator. The first group evaluates to `true`, and the second group evaluates to `false`. Then `true || false` evaluates to `true`. So the result is `true`.

Explanation:
Operator precedence and parentheses can be combined in expressions. In this case, each set of parentheses contains a NOT operation followed by an AND operation, with the OR operation happening last.

Common mistake note:
A common mistake would be to evaluate without considering operator precedence or the effect of parentheses, which could lead to selecting 'B: false'.
