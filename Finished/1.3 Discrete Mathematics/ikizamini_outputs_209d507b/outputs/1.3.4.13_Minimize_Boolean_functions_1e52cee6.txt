Problem 1 (:1):
Minimize the Boolean function F(A, B, C) = Σ(0, 2, 4, 5, 6, 7)
A) (A'+B'C')(A'BC')
B) (A'+C)(B+C')
C) (A+BC')(A'+B'C')
D) (A'+C')(B+C)
Correct Answer: C

Solution:
The given function F(A, B, C) = Σ(0, 2, 4, 5, 6, 7) can be minimized using Karnaugh Maps or the Quine-McCluskey algorithm. After minimizing, we get the simplified form as (A+BC')(A'+B'C') which corresponds to choice C.

Explanation:
The process of minimizing a Boolean function involves grouping similar terms in a truth table or using graphical methods like Karnaugh Maps to simplify the expression.

Common mistake note:
One common mistake is forgetting to include 'don't care' states when simplifying, which can lead to an incorrect simplified form. In this case, there are no 'don't care' states, so all combinations of A, B, and C must be considered.

Problem 2 (:2):
Minimize the Boolean function F(X, Y, Z) = Σ(0, 1, 3, 7)
A) (X+Y'+Z')(X+YZ)
B) (X'+Y+Z)(X+Y'+Z')
C) (X+Y+Z')(X'+YZ)
D) (X+Y+Z)(X'+YZ')
Correct Answer: B

Solution:
The given function F(X, Y, Z) = Σ(0, 1, 3, 7) can be minimized using Karnaugh Maps or the Quine-McCluskey algorithm. After minimizing, we get the simplified form as (X'+Y+Z)(X+Y'+Z') which corresponds to choice B.

Explanation:
When simplifying a Boolean function, it's essential to consider all possible input combinations and group them based on their output values. In this case, grouping 0, 1, 3, and 7 in a Karnaugh Map leads to the simplified form.

Common mistake note:
A common mistake is misidentifying groups of 1s in the truth table or Karnaugh Map, which can result in an incorrect minimized function. Double-checking the grouping and verifying with a truth table helps avoid this error.
