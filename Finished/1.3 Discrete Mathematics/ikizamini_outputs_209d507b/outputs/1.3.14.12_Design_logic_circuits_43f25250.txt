Problem 1 (:1):
What is the output of an OR gate when A = 0 and B = 1?
A) 0
B) 1
C) A
D) B
Correct Answer: B

Solution:
The output of an OR gate is high (1) if either or both inputs are high. Since A = 0 and B = 1, the output will be 1.

Explanation:
An OR gate produces a high output when one or both inputs are high.

Common mistake note:
A common mistake is to choose 'C' if the test-taker assumes the gate is an AND gate. An AND gate requires both inputs to be high for the output to be high.
------------------------------------------------------------------------------

Problem 2 (:2):
What is the truth table entry for a NOT gate with input A = 1?
A) 0
B) 1
C) A
D) B and A
Correct Answer: A

Solution:
The output of a NOT gate is the opposite of its input. If A = 1, the output will be 0.

Explanation:
A NOT gate has only one input and inverts its output.

Common mistake note:
A common mistake is to choose 'B' if the test-taker forgets that NOT gates invert their inputs.
------------------------------------------------------------------------------

Problem 3 (:3):
Which combination of basic gates can be used to create a NAND gate?
A) AND and NOT
B) OR and NOT
C) AND and OR
D) NAND and XOR
Correct Answer: A

Solution:
A NAND gate can be created by combining an AND gate with a NOT gate. The output of the AND gate is inverted to produce the NAND gate's output.

Explanation:
The NAND gate is a universal gate, meaning it can be used to create any other logic gate.

Common mistake note:
A common mistake is to choose 'B' if the test-taker混淆s the function of an OR gate with that of a NAND gate.
------------------------------------------------------------------------------

Problem 4 (:4):
What is the output of a 2-input XOR gate when A = 0 and B = 1?
A) 0
B) 1
C) A
D) B
Correct Answer: B

Solution:
An XOR gate produces an output of 1 if the inputs have different values. With A = 0 and B = 1, the output will be 1.

Explanation:
The XOR gate gives a high output when the inputs are different from each other.

Common mistake note:
A common mistake is to choose 'C' if the test-taker assumes the XOR gate behaves like an AND or OR gate.
------------------------------------------------------------------------------

Problem 5 (:5):
What is the truth table entry for a 3-input AND gate with inputs A = 1, B = 0, and C = 1?
A) 0
B) 1
C) A
D) B and A and C
Correct Answer: A

Solution:
An AND gate produces a high output only when all inputs are high. With A = 1, B = 0, and C = 1, the output will be 0 because not all inputs are high.

Explanation:
The AND gate requires all inputs to be high for the output to be high.

Common mistake note:
A common mistake is to choose 'B' if the test-taker overlooks one of the low inputs.
------------------------------------------------------------------------------

Problem 6 (:6):
What logic circuit can be used to create a 4-input OR gate using only 2-input OR gates?
A) Connect all inputs directly to a single 4-input OR gate.
B) Connect two 2-input OR gates in series, then connect the outputs of those gates to another 2-input OR gate.
C) Connect four 2-input OR gates in parallel, with each input connected to one of the 4-inputs.
D) Connect two 2-input OR gates in parallel, then connect the outputs of those gates to a single 2-input OR gate.
Correct Answer: C

Solution:
To create a 4-input OR gate using only 2-input OR gates, you can connect four 2-input OR gates in parallel, with each input connected to one of the 4-inputs. The outputs of these gates are then combined with another 2-input OR gate.

Explanation:
Parallel connection allows each input to be processed independently by a separate 2-input OR gate.

Common mistake note:
A common mistake is to choose 'B' if the test-taker misunderstands how to combine multiple OR gates.

Problem 7 (:7):
What is the output of a 3-input XOR gate when A = 1, B = 1, and C = 0?
A) 0
B) 1
C) A
D) B and A and C
Correct Answer: B

Solution:
An XOR gate produces an output of 1 if the number of high inputs is odd. With A = 1, B = 1, and C = 0, there are two high inputs (A and B), so the output will be 1.

Explanation:
The XOR gate gives a high output when the inputs are different from each other.

Common mistake note:
A common mistake is to choose 'A' if the test-taker overlooks that two of the inputs are high.
