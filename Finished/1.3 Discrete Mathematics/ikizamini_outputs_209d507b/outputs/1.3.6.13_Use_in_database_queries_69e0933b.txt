Problem 1 (:Q1):
Which SQL statement correctly selects all customers from the 'customers' table who live in either 'New York' or 'Los Angeles'?
A) SELECT * FROM customers WHERE city = 'New York' OR city = 'Los Angeles'
B) SELECT * FROM customers WHERE city IN ('New York', 'Los Angeles')
C) SELECT * FROM customers WHERE city LIKE '%York%' OR LIKE '% Angeles'
D) SELECT * FROM customers WHERE city = 'New York'; SELECT * FROM customers WHERE city = 'Los Angeles'
Correct Answer: B

Solution:
The correct SQL statement uses the IN operator to select multiple values within a single condition. Answer B is correct because it uses the IN operator with parentheses around the list of cities.

Explanation:
The IN operator allows for matching one value against a list of values in a WHERE clause. Option A uses OR, which would match either city independently. Option C uses LIKE with wildcards, which would not be specific enough to only match 'New York' and 'Los Angeles'. Option D executes two separate queries, which is not the same as selecting all customers from both cities within a single query.

Common mistake note:
Common mistake: Using OR instead of IN. This would return customers who live in either city but not necessarily those living in both.

Problem 3 (:Q3):
Which SQL statement correctly selects all products from the 'products' table that have a price greater than $50 or less than $25?
A) SELECT * FROM products WHERE price > 50 OR < 25
B) SELECT * FROM products WHERE price BETWEEN 25 AND 50
C) SELECT * FROM products WHERE price IN (50, 25)
D) SELECT * FROM products WHERE price > 50; SELECT * FROM products WHERE price < 25
Correct Answer: A

Solution:
The correct SQL statement uses the OR operator to select records that meet either condition. Answer A is correct because it correctly applies the greater than and less than operators with OR.

Explanation:
The OR operator combines two conditions, returning rows that match either one. Option B uses BETWEEN, which would return products priced between $25 and $50 (inclusive). Option C uses IN with a single price range, which is not correct for this scenario. Option D executes two separate queries, which is not the same as selecting all products within the specified price ranges within a single query.

Common mistake note:
Common mistake: Using BETWEEN instead of OR. This would return products priced between $25 and $50, not those priced above or below this range.

Problem 6 (:Q6):
Which SQL statement correctly selects all users with the email domain 'gmail.com' or 'yahoo.com' from the 'users' table?

C) SELECT * FROM users WHERE email IN ('%gmail.com', '%yahoo.com')
D) SELECT * FROM users WHERE email = 'gmail.com'; SELECT * FROM users WHERE email = 'yahoo.com'
Correct Answer: A

Solution:
The correct SQL statement uses the LIKE operator with wildcards to match email domains. Answer A is correct because it correctly applies wildcards to match both email domains.

Explanation:
The LIKE operator allows for pattern matching within a string value in a WHERE clause. Option B compares email addresses directly, which would not match any records. Option C uses IN with wildcards, which is incorrect syntax. Option D executes two separate queries, which is not the same as selecting all users with either email domain within a single query.

Common mistake note:
Common mistake: Using = instead of LIKE. This would not return any results because it compares entire email addresses directly.
