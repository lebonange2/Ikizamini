Problem 1 (Just a number):
Which roster notation represents the set containing only the number 5?
A) [6]
B) {5}
C) [5, 7]
D) {3, 5}
Correct Answer: B

Solution:
The roster notation for a set with a single element is to enclose the element in curly braces. Thus, {5} represents the set containing only the number 5.

Explanation:
Sets are represented using curly braces {} and elements are separated by commas. Roster notation lists all elements of the set.

Common mistake note:
Common mistake: Using square brackets [] which denote a list or array, not a set.
------------------------------------------------------------------------------

Problem 2 (Two numbers):
Which roster notation represents the set containing the numbers 2 and 4?
A) [2, 4]
B) {2, 4}
C) {2, 2, 4}
D) {3, 5}
Correct Answer: B

Solution:
The roster notation for a set with multiple elements is to enclose the elements in curly braces and separate them by commas. Thus, {2, 4} represents the set containing numbers 2 and 4.

Explanation:
Sets cannot have duplicate elements. Curly braces ensure uniqueness.

Common mistake note:
Common mistake: Including duplicates like {2, 2, 4}, which is not valid for a set.

A) [-3, -5]
B) {-3, -5}
C) [3, 5]

Correct Answer: B

Solution:
The roster notation for a set with negative numbers is to enclose the elements in curly braces and separate them by commas. Thus, {-3, -5} represents the set containing negative numbers -3 and -5.

Explanation:
Sets can contain any type of element, including negative numbers. Curly braces denote sets regardless of values.

Common mistake note:
Common mistake: Using square brackets [] or including non-negative numbers like [3, 5].

Problem 6 (Set with an empty set):
Which roster notation represents the set containing only the empty set?
A) [{}]
B) {[]}
C) [{,}]
D) {∅}
Correct Answer: D

Solution:
The roster notation for a set with only the empty set is to enclose the empty set symbol (∅) in curly braces. Thus, {∅} represents the set containing only the empty set.

Explanation:
Sets can contain other sets as elements, including the empty set represented by ∅.

Common mistake note:
Common mistake: Using square brackets [] or incorrect notations like [{,}] or {[]}.

Problem 7 (Set with a range of numbers):
Which roster notation represents the set containing all even numbers from 2 to 10?
A) [2, 4, 6, 8, 10]
B) {2, 4, 6, 8, 10}
C) [1, 3, 5, 7, 9]
D) {1, 2, 3}
Correct Answer: B

Solution:
The roster notation for a set with a range of numbers is to enclose the elements in curly braces and separate them by commas. Thus, {2, 4, 6, 8, 10} represents the set containing all even numbers from 2 to 10.

Explanation:
Sets can represent number ranges as long as each element is distinct. Curly braces denote sets regardless of values.

Common mistake note:
Common mistake: Using square brackets [] or including odd numbers like [1, 3, 5, 7, 9].
