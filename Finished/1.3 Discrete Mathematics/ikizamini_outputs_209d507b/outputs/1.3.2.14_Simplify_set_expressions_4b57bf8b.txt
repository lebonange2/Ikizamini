Problem 1 (Asd1):
Given the sets A = {1, 2, 3} and B = {2, 3, 4}, what is the simplified form of (A ∪ B) - A?
A) {1}
B) {2, 3}
C) {4}
D) Ø
Correct Answer: C

Solution:
The union of sets A and B (A ∪ B) is {1, 2, 3, 4}. When we subtract set A from this union ((A ∪ B) - A), we remove all elements that are in both A and the union. Since all elements of A are also in the union, we are left with just the element that is in the union but not in A, which is {4}.

Explanation:
The key here is understanding that subtracting a set from its own union results in removing only the elements that are exclusively from the original set.

Common mistake note:
A common mistake would be to choose B, thinking that it's the intersection of A and B. However, we're looking for elements in the union but not in A.

Problem 2 (Asd2):
Simplify the expression (B ∩ C) ∪ (C ∪ D), where B = {1, 2}, C = {2, 3}, and D = {3, 4}.
A) {2, 3}
B) {1, 2, 3}
C) {2, 3, 4}
D) {1, 2, 3, 4}
Correct Answer: C

Solution:
First, find the intersection of B and C (B ∩ C), which is {2}. Then, find the union of C and D (C ∪ D), which is {2, 3, 4}. Finally, combine these two sets by taking their union ((B ∩ C) ∪ (C ∪ D)). The result is {2, 3, 4}.

Explanation:
The intersection gives us the common elements of B and C, while the second union expands the set. Combining them with another union results in all unique elements from both sets.

Common mistake note:
A common mistake would be to choose A or B, assuming that the intersection is enough. However, we need to consider the expanded set after taking the second union.

Problem 3 (Asd3):
Simplify the expression (X ∪ Y) - (X ∩ Y), where X = {1, 2, 3} and Y = {2, 3, 4}.
A) {1}
B) {1, 2, 3, 4}
C) {2, 3}
D) {4}
Correct Answer: B

Solution:
The union of X and Y (X ∪ Y) is {1, 2, 3, 4}. The intersection of X and Y (X ∩ Y) is {2, 3}. Subtracting the intersection from the union removes all elements that are common to both sets. Since there are no elements in X and Y that are not in both, we retain all elements in the original union, which results in {1, 2, 3, 4}.

Explanation:
Subtracting the intersection of two sets from their union leaves only the unique elements from each set.

Common mistake note:
A common mistake would be to choose A or C, assuming that we are removing all elements in both sets. However, since there is no element exclusive to X or Y, we retain all elements.

Problem 4 (Asd4):

D) Ø
Correct Answer: B

Solution:
The set P consists of prime numbers less than 10, which are {2, 3, 5, 7}. The union of P and Q (P ∪ Q) is {2, 3, 5, 7}. Subtracting Q from this union ((P ∪ Q) - Q) removes all elements that are in both P and Q. This leaves us with the prime number 7, which is {7, 9}.

Explanation:
We're looking for numbers that are prime and less than 10 but not in set Q.

Common mistake note:
A common mistake would be to choose A or C, thinking that we should retain all elements from the union. However, we need to remove elements that are exclusively from set Q.

Problem 5 (Asd5):
Simplify the expression (U ∩ V) ∪ (V ∩ W), where U = {1, 2, 3}, V = {2, 3, 4}, and W = {3, 4, 5}.
A) {2, 3}
B) {2, 3, 4}
C) {2, 3, 4, 5}
D) {1, 2, 3, 4, 5}
Correct Answer: B

Solution:
The intersection of U and V (U ∩ V) is {2, 3}. The intersection of V and W (V ∩ W) is {3, 4}. Taking the union of these two intersections gives us {2, 3, 4}.

Explanation:
We're finding common elements between pairs of sets and then combining those common elements.

Common mistake note:
A common mistake would be to choose A or D, assuming that we are considering all elements from the original sets. However, we are only considering elements that are common in both intersections.

Common mistake note:

Problem 7 (Asd7):

D) Ø
Correct Answer: A

Solution:
The set Z consists of even numbers less than 6, which are {2, 4}. The union of Z and W (Z ∪ W) is {1, 2, 3, 4, 5}. Subtracting Z from this union ((Z ∪ W) - Z) removes all elements that are in both Z and the union. This leaves us with the odd numbers from set W, which is {1, 3, 5}.

Explanation:
We're looking for numbers that are in set W but not even.

Common mistake note:
A common mistake would be to choose B or C, thinking that we should retain all elements from the union. However, we need to remove elements that are exclusively from set Z.
