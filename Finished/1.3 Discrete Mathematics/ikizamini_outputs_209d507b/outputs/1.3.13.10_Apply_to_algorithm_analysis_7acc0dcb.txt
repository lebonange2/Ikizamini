Problem 1 (:1):
What is the time complexity of calculating the sum of numbers in a list using Python?
A) O(1)
B) O(n)
C) O(n^2)
D) O(log n)
Correct Answer: B

Solution:
The time complexity is O(n) because the code iterates through each element in the list once. Option A (O(1)) is incorrect as it doesn't grow with the input size. Option C (O(n^2)) is wrong since there's no nested loop. Option D (O(log n)) is incorrect as it doesn't involve a logarithmic operation.

Explanation:
The code snippet calculates the sum of numbers in a list by iterating through each element once. Therefore, the time complexity is linear with respect to the size of the input list.

Common mistake note:
A common mistake would be to assume that a simple loop has a lower complexity than O(n), but basic loops contribute linearly to the overall time complexity.

Problem 3 (:3):
What is the time complexity of sorting an array using Bubble Sort?
A) O(n)
B) O(n log n)
C) O(n^2)
D) O(log n)
Correct Answer: C

Solution:
The time complexity of Bubble Sort is O(n^2) due to the nested loops that compare and swap elements. Option A (O(n)) and D (O(log n)) are incorrect as they represent faster sorting algorithms. Option B (O(n log n)) refers to more efficient sorting algorithms like Merge Sort or Quick Sort.

Explanation:
Bubble Sort repeatedly steps through the list, compares adjacent elements, and swaps them if needed. In the worst case, when the input is reverse sorted, it has quadratic time complexity.

Common mistake note:
A common mistake would be to confuse Bubble Sort's time complexity with that of other sorting algorithms like Merge Sort or Quick Sort.

Problem 4 (:4):
What is the time complexity of searching for an element in a sorted array using Binary Search?
A) O(n)
B) O(n log n)
C) O(log n)
D) O(1)
Correct Answer: C

Solution:
The time complexity of Binary Search is O(log n) as it repeatedly divides the search space in half. Option A (O(n)) and B (O(n log n)) are incorrect for slower searching algorithms. Option D (O(1)) is wrong since constant-time search only applies to certain data structures like hash tables.

Explanation:
Binary Search starts by comparing the target value with the middle element of a sorted array. If found, it's returned; if not, the half containing the target is searched further. This process continues recursively until the target is found or the search space is empty. The algorithm halves the search space in each step, resulting in logarithmic time complexity.

Common mistake note:
A common mistake would be to assume Binary Search has linear time complexity like a simple sequential search, which is not the case due to its divide- and-conquer approach.

Problem 6 (:6):
What is the time complexity of multiplying two n x n matrices using a naive algorithm?
A) O(n)
B) O(n log n)
C) O(n^2)
D) O(n^3)
Correct Answer: D

Solution:
The time complexity of multiplying two matrices using a naive algorithm is O(n^3) as it involves multiplying each element in one matrix with the corresponding elements in the other. Option A (O(n)) and B (O(n log n)) are incorrect for faster algorithms. Option C (O(n^2)) refers to operations like matrix addition, not multiplication.

Explanation:
Naive matrix multiplication requires multiplying each element of one matrix with the corresponding elements in the other matrix, resulting in a new matrix. This process requires n x n operations for each element in the output matrix, leading to cubic time complexity.

Common mistake note:
A common mistake would be to underestimate the number of multiplications required for matrix multiplication and assume it has quadratic time complexity like simpler operations.

Problem 7 (:7):
What is the time complexity of finding the maximum value in an unsorted array using a linear search?
A) O(n)
B) O(n log n)
C) O(log n)
D) O(1)
Correct Answer: A

Solution:
The time complexity of finding the maximum value in an unsorted array using a linear search is O(n) as it needs to traverse all elements. Option B (O(n log n)) and C (O(log n)) are incorrect for faster algorithms or sorted data. Option D (O(1)) is wrong since constant-time search only applies to certain situations like having a precomputed maximum value.

Explanation:
Linear search compares each element in the array with the current maximum value found so far. It must examine every element to ensure no larger value was missed, resulting in linear time complexity.

Common mistake note:
A common mistake would be to assume that finding the maximum value in an unsorted array can be done faster than a simple sequential search, which is not the case without additional information or structure.
