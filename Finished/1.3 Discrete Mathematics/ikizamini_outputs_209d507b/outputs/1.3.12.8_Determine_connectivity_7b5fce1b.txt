Problem 1 (AssembleNetwork):
Given the following nodes and edges, determine if there is a path from node A to node E.
A) [A]-[B]-[C]-[D]-[E]
B) [A]-[B]-[C]-[E]
C) [A]-[D]-[E]
D) [A]-[C]-[E]
Correct Answer: A

Solution:
The path [A]-[B]-[C]-[D]-[E] exists, so there is a connection from node A to node E.

Explanation:
Connectivity means determining if there's a route between two nodes in a graph. In this case, the presence of a direct edge from C to D allows for a continuous path from A to E.

Common mistake note:
A common mistake is choosing option B or D, which omits the edge [C]-[D], resulting in a disconnected path.

Problem 2 (BridgeNode):
In the following graph, which node, when removed, would disconnect nodes A and E?
A) B
B) C
C) D
D) F
Correct Answer: C

Solution:
Removing node C would disconnect nodes A and E since it is the only path connecting them.

Explanation:
To determine connectivity, we must find a node that, when removed, breaks the connection between two other nodes. In this case, removing node C separates A and E.

Common mistake note:
A common mistake is choosing B or F, which are not on the direct path between A and E, or D, which still allows for alternative paths.

Problem 3 (CycleDetected):
Identify if there is a cycle (a closed loop) in the following graph.
A) Yes
B) No
C) Cannot determine without more information
D) The graph is not provided
Correct Answer: A

Solution:
There is a cycle because node C connects back to itself: [C]→[D]→[E]→[C].

Explanation:
A cycle in a graph is a sequence of edges that form a closed loop. In this case, the edge from E to C creates a cycle.

Common mistake note:
A common mistake is choosing B or C, not recognizing the self-loop created by the edge [E]-[C].

Problem 4 (DisconnectedComponents):
How many disconnected components are in the following graph?
A) 0
B) 1
C) 2
D) 3
Correct Answer: C

Solution:
There are 2 disconnected components: [A]-[B] and [C]-[D].

Explanation:
Disconnected components refer to separate groups of nodes that are not connected by any path. In this graph, A and B are one component, and C and D are another.

Common mistake note:
A common mistake is choosing 1 or 3, either overlooking the disconnected nodes or incorrectly counting the single edge between them as a connection.

Problem 5 (IslandGraph):
In the following graph, which of the following statements about connectivity is true?
A) All nodes are connected to every other node.
B) There is an island (a group of nodes not connected to the rest of the graph) with 3 nodes.
C) No nodes are disconnected from the main graph.
D) The graph is a tree (every node is connected by exactly one path).
Correct Answer: B

Solution:
There is an island consisting of nodes C, D, and E.

Explanation:
An island in a graph refers to a group of nodes that are disconnected from the rest of the graph. In this case, nodes C, D, and E form an island separate from node A.

Common mistake note:
A common mistake is choosing A or C, not recognizing the isolated group of nodes (C, D, and E), or D, which would require all nodes to be connected by a single path.

Problem 6 (TreeConnectivity):
In a tree structure, how many paths are there between node X and node Y?
A) 0
B) 1
C) 2 or more
D) Depends on the number of nodes in the tree
Correct Answer: B

Solution:
There is only one path between any two nodes in a tree structure.

Explanation:
In a tree, every node is connected by exactly one path. Therefore, there is always a single path between any two nodes X and Y.

Common mistake note:
A common mistake is choosing C or D, thinking that multiple paths may exist in a tree, which contradicts the definition of a tree.

Problem 7 (WeightedConnectivity):
In a weighted graph, how do you determine the shortest path between two nodes?
A) Find the path with the highest total weight.
B) Choose any random path connecting the two nodes.
C) Use Dijkstra's algorithm or similar method to find the minimum total weight.
D) The graph must be unweighted to determine the shortest path.
Correct Answer: C

Solution:
Use Dijkstra's algorithm or a similar method to find the minimum total weight.

Explanation:
In a weighted graph, determining the shortest path involves finding the minimum sum of edge weights between two nodes. Dijkstra's algorithm is commonly used for this purpose.

Common mistake note:
A common mistake is choosing A, which would result in finding the longest path instead of the shortest, or B, which does not guarantee the shortest route.
