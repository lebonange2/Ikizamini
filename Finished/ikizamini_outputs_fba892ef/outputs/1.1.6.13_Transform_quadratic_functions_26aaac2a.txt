Problem 1 (One):
Given the function f(x) = x^2 + 4x + 3, shift the graph to the right by 2 units. What is the new equation?
A) (x - 2)^2 + 4(x - 2) + 3
B) (x + 2)^2 + 4(x + 2) + 3
C) x^2 + 4x + 6
D) x^2 + 8x + 15
Correct Answer: A

Solution:
When shifting a quadratic function to the right, we subtract the desired number of units from x inside the function. So, if we want to shift it by 2 units to the right, we replace x with (x - 2). The new equation is f(x - 2) = (x - 2)^2 + 4(x - 2) + 3.

Explanation:
The correct answer shifts the vertex of the parabola to the right by 2 units. Choice B shifts it to the left, choice C does not shift the function at all, and choice D shifts it incorrectly.

Common mistake note:
Common mistake is to add the shift value instead of subtracting it when shifting to the right.

Problem 2 (Two):
Given the function g(x) = 2(x - 1)^2 + 5, reflect the graph over the x-axis. What is the new equation?
A) -2(x - 1)^2 + 5
B) -2x^2 + 4x - 3
C) 2(x + 1)^2 + 5
D) 2(x - 1)^2 - 5
Correct Answer: A

Solution:
Reflecting a quadratic function over the x-axis involves multiplying the entire function by -1. So, the new equation is -g(x) = -2(x - 1)^2 + 5.

Explanation:
The correct answer flips the parabola upside down. Choice B reflects incorrectly around y-axis, choice C shifts the vertex, and choice D changes the vertex coordinates without reflecting.

Common mistake note:
Common mistake is to forget that only the function values change when reflecting over the x-axis, not the input variable.

Problem 3 (Three):
Given the function h(x) = -(x + 3)^2 - 1, shift the graph down by 4 units and then left by 2 units. What is the new equation?
A) -((x + 5)^2 - 5)
B) -((x - 1)^2 - 5)
C) -(x + 5)^2 + 3
D) -(x - 1)^2 + 7
Correct Answer: A

Solution:
First, shift the function down by subtracting the desired number from inside the function. Then, shift it left by adding to x. The new equation is h(x + 2) - 4 = -(x + 5)^2 - 1.

Explanation:
The correct answer shifts both vertically and horizontally correctly. Choice B shifts vertically but not horizontally, choice C does not shift vertically enough, and choice D shifts incorrectly in both directions.

Common mistake note:
Common mistake is to mix up the order of shifting operations or apply them to the wrong parts of the function.

Problem 4 (Four):
Given the function j(x) = 3x^2 + 6x, stretch the graph vertically by a factor of 4. What is the new equation?
A) 12x^2 + 24x
B) 12x^2 + 6x
C) 12(x - 1)^2 + 6(x - 1)
D) 3(4x)^2 + 6(4x)
Correct Answer: A

Solution:
To stretch a quadratic function vertically, multiply the entire function by the desired factor. So, the new equation is 4j(x) = 12x^2 + 24x.

Explanation:
The correct answer multiplies every term by 4. Choice B does not stretch enough, choice C shifts the vertex, and choice D uses the wrong variable substitution.

Common mistake note:
Common mistake is to multiply only one part of the function or apply the stretching factor incorrectly.

Problem 5 (Five):
Given the function k(x) = x^2 - 4x + 5, reflect the graph over both axes. What is the new equation?
A) -(x + 2)^2 - 1
B) (x - 2)^2 - 1
C) -(x - 2)^2 + 9
D) (x + 2)^2 + 9
Correct Answer: C

Solution:
Reflecting a quadratic function over both axes means multiplying the entire function by -1 and then changing the signs of the linear term coefficients. The new equation is -(k(x)) = -(x - 2)^2 + 9.

Explanation:
The correct answer reflects both horizontally and vertically correctly. Choice A only reflects vertically, choice B does not reflect at all, and choice D reflects incorrectly.

Common mistake note:
Common mistake is to forget that the signs of the linear term coefficients change when reflecting over both axes.

Problem 6 (Six):
Given the function l(x) = 4(x - 2)^2 + 1, compress the graph horizontally by a factor of 2. What is the new equation?
A) 8( x - 4)^2 + 1
B) 2( x - 2)^2 + 1
C) 4(2x - 4)^2 + 1
D) 4(x/2 - 2)^2 + 1
Correct Answer: D

Solution:
To compress a quadratic function horizontally, multiply x by the desired factor. So, the new equation is l(2x) = 4((x/2) - 2)^2 + 1.

Explanation:
The correct answer compresses correctly using the variable substitution. Choice A multiplies the wrong term, choice B does not compress enough, and choice C uses the wrong variable substitution.

Common mistake note:
Common mistake is to multiply x by the factor directly instead of applying it to the input.

Problem 7 (Seven):
Given the function m(x) = -2(x + 1)^2 - 3, shift the graph right by 3 units and stretch horizontally by a factor of 5. What is the new equation?
A) -10( x + 4)^2 - 8
B) -(x/5 + 1)^2 - 3
C) -10(x - 2)^2 - 3
D) -(5x + 5)^2 - 3
Correct Answer: A

Solution:
First, shift the function right by subtracting the desired number from inside the function. Then, stretch it horizontally by dividing x by the factor. The new equation is m((x - 3)/5) = -2((x - 3)/5 + 1)^2 - 3.

Explanation:
The correct answer shifts and stretches correctly using variable substitution. Choice B does not shift enough, choice C uses the wrong stretching method, and choice D shifts incorrectly.

Common mistake note:
Common mistake is to mix up the order of shifting and stretching operations or apply them to the wrong parts of the function.
