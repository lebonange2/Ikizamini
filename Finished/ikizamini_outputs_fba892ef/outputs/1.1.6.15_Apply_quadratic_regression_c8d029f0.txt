Problem 1 (One):
A dataset shows the relationship between hours of studying and test scores for a group of students. Which type of regression model would be appropriate to analyze this data?
A) Linear Regression
B) Quadratic Regression
C) Logistic Regression
D) Exponential Regression
Correct Answer: B

Solution:
The relationship between hours of studying and test scores is expected to exhibit curvature, suggesting a non-linear pattern. Quadratic regression models this relationship using a second-degree polynomial, making it suitable for this scenario.

Explanation:
Linear regression assumes a straight-line relationship, logistic regression is used for binary classification problems, and exponential regression models growth or decay over time.

Common mistake note:
A common mistake would be to choose A (Linear Regression), as it's simpler and more straightforward. However, it might not accurately capture the curvature in the data.

Problem 2 (Two):
A dataset contains the distance traveled by a car versus the time taken. Which type of regression should be used to analyze this relationship?
A) Polynomial Regression (degree 3)
B) Linear Regression
C) Quadratic Regression
D) Cubic Regression
Correct Answer: B

Solution:
The relationship between distance and time is expected to be linear, as distance increases at a constant rate with time. Linear regression models this type of relationship.

Explanation:
Polynomial (degree 3) and cubic regression introduce unnecessary complexity for a straight-line relationship. Quadratic regression models curvature, which is not present in this case.

Common mistake note:
A common mistake might be to choose C (Quadratic Regression) or D (Cubic Regression), assuming that higher-degree polynomials would fit the data better. However, simplicity and interpretability are crucial in regression analysis.

Problem 4 (Four):
A dataset contains information about the number of hours spent on a project and the cost incurred. Which type of regression should be used to analyze the relationship?
A) Polynomial Regression (degree 2)
B) Linear Regression
C) Quadratic Regression
D) Cubic Regression
Correct Answer: A

Solution:
The relationship between hours and cost might not be linear, as costs could increase at a faster rate as more hours are spent. A polynomial regression (degree 2) can capture this curvature.

Explanation:
Linear regression assumes a straight-line relationship, quadratic regression is suitable for a parabolic curve, and cubic regression models a curved relationship with three turning points. Polynomial regression of degree 2 is the most appropriate choice here.

Common mistake note:
A common mistake would be to choose B (Linear Regression), assuming that cost increases linearly with time. However, in many cases, costs increase at a faster rate as more hours are spent.
