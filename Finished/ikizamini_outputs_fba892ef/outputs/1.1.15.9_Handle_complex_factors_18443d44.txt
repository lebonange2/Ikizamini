Problem 1 (Inequality with Complex Factors):
Solve for x: (2x + 3)(x - 4) > 0
A) x > -1.5 or x < 4
B) x > 4 or x < -3
C) x > -3 or x < 1.5
D) x > 1.5 or x < -4
Correct Answer: A

Solution:
(2x + 3)(x - 4) > 0
分解因式：
(x + 1.5)(x - 4) > 0
解不等式得：
x > -1.5 或 x < 4

Explanation:
要找到不等式的解，首先需要分解因式，然后确定每个因子的符号变化点，根据符号判断不等式的解集。

Common mistake note:
常见的错误是直接尝试求根，而不是先分解因式。这会导致无法正确识别不等式的解集。

Problem 2 (Fractional Equation with Complex Factors):
Solve for x: rac{(x + 2)(x - 3)}{(x - 1)(x + 4)} = 0
A) x = -2 or x = 3
B) x = 1 or x = -4
C) x = -2 or x = -4
D) No solution
Correct Answer: D

Solution:
rac{(x + 2)(x - 3)}{(x - 1)(x + 4)} = 0
令分子为零：
(x + 2)(x - 3) = 0
解得：x = -2 或 x = 3
但分母不能为零，因此排除 x = -2 和 x = 3。
无解

Explanation:
解决分数方程时，不仅要找到分子的根，还要确保分母不为零。在这个例子中，x = -2 和 x = 3 都会导致分母为零，因此都不是有效解。

Common mistake note:
常见的错误是只考虑分子为零的情况，而忽视了分母不能为零的要求。

Problem 3 (Quadratic Inequality with Complex Factors):
Solve for x: (x - 1)(2x + 3) < 0
A) x > 1 or x < -1.5
B) x < 1 or x > -1.5
C) -1.5 < x < 1
D) No solution
Correct Answer: C

Solution:
(x - 1)(2x + 3) < 0
分解因式：
(2x + 3)(x - 1) < 0
解不等式得：-1.5 < x < 1

Explanation:
首先分解因式，然后确定每个因子的符号变化点，根据符号判断不等式的解集。在这个例子中，两个因子的符号在 x = -1.5 和 x = 1 处改变。

Common mistake note:
常见的错误是误判了因子的符号，导致选择错误的解集范围。

Problem 4 (System of Equations with Complex Factors):
Solve the system of equations: 
(x + 2)(y - 3) = 5
(x - 1)(y + 4) = 7
A) x = 2, y = 0
B) x = -1, y = 2
C) x = 1, y = -1
D) x = -2, y = 3
Correct Answer: C

Solution:
(x + 2)(y - 3) = 5
(x - 1)(y + 4) = 7
分别解得：
x = 1, y = -1

Explanation:
先将方程组中的每个方程展开，然后用代入法或消元法求解。在这个例子中，可以使用代入法来找到 x 和 y 的值。

Common mistake note:
常见的错误是误操作导致计算错误，或者在解方程时没有注意到因式结构。

Problem 5 (Complex Factor in a Limit):
Find the limit as x approaches 0: 
lim (x → 0) rac{(x + 1)^2(x - 2)}{x(x + 3)}
A) undefined
B) 0
C) 1
D) -2
Correct Answer: C

Solution:
lim (x → 0) rac{(x + 1)^2(x - 2)}{x(x + 3)}
先简化分子和分母：
lim (x → 0) rac{x^2 + 2x + 1}{x + 3}
将 x = 0 代入简化后的表达式：
1 / 3

Explanation:
In calculating the limit, first try to simplify the expression and then directly substitute x's value. In this example, both the numerator and denominator have common factors that can be simplified.

Common mistake note:
Common mistakes include not correctly simplifying the expression or not simplifying before substituting x = 0.

Problem 6 (Complex Factor in a Function):
Find the domain of the function: f(x) = rac{1}{(x + 2)(x - 3)}
A) All real numbers
B) x ≠ -2, x ≠ 3
C) x < -2 or x > 3
D) x > -2 and x < 3
Correct Answer: B

Solution:
f(x) = rac{1}{(x + 2)(x - 3)}
The denominator cannot be zero, so: x ≠ -2, x ≠ 3

Explanation:
The domain of the function is all x values that do not make the denominator zero. In this example, there are two factors, each of which restricts the x value.

Common mistake note:
Common mistakes include considering only one factor's restriction and ignoring the other factor's impact.

Problem 7 (Complex Factor in a Complex Number):
Find the conjugate of the complex number: z = (1 + 2i)(3 - 4i)
A) (1 + 2i)(3 + 4i)
B) (1 - 2i)(3 - 4i)
C) (1 - 2i)(3 + 4i)
D) (1 + 2i)(-3 + 4i)
Correct Answer: C

Solution:
z = (1 + 2i)(3 - 4i)
Expand and find the conjugate:
z = 5 - 2i
The conjugate is: (1 - 2i)(3 + 4i)

Explanation:
To find the conjugate of a complex number, negate the imaginary part. In this example, first expand the expression and then perform the conjugation operation.

Common mistake note:
Common mistakes include calculation errors or not following the rules for conjugating complex numbers.
