Problem 1 (OneStepSubstitutionEasy1):
Solve the system of equations:
 y = 3x - 4
 y = 2x + 5
A) x = 9, y = 17
B) x = -9, y = -31
C) x = 1, y = -1
D) x = 1, y = 2
Correct Answer: C

Solution:
Substitute the first equation into the second:
 3x - 4 = 2x + 5
 Solve for x:
 x = 9
 Substitute x back into either equation to find y:
 y = 3(1) - 4
 y = 1 - 4
 y = -3
 The correct answer is (x, y) = (1, -3).

Explanation:
The substitution method involves solving one of the equations for one variable and then plugging that expression into the other equation to solve for the second variable.

Common mistake note:
A common mistake is to substitute the wrong equation or forget to plug the value back into an equation.

Problem 2 (OneStepSubstitutionEasy2):
Solve the system of equations:
 4x - y = 10
 x = 3y - 5
A) x = 3, y = 2
B) x = 2, y = 3
C) x = 5, y = 5
D) x = 7, y = 4
Correct Answer: D

Solution:
Substitute the second equation into the first:
 4(3y - 5) - y = 10
 Solve for y:
 12y - 20 - y = 10
 11y = 30
 y = 30 / 11
 y ≈ 2.73
 Since x = 3y - 5, we can substitute the value of y back in:
 x = 3(2.73) - 5
 x ≈ 8.19 - 5
 x ≈ 3.19
 The correct answer is (x, y) ≈ (3.19, 2.73).

Explanation:
In this problem, we can substitute the value of x directly into the first equation since it's already solved for x.

Common mistake note:
A common mistake is to forget to round the decimal values or use approximate solutions.

Problem 3 (OneStepSubstitutionMedium1):
Solve the system of equations:
 2x + 3y = 7
 5x - 4y = 8
A) x = 2, y = 1
B) x = -2, y = 3
C) x = 1, y = 2
D) x = 3, y = -1
Correct Answer: A

Solution:
Solve the first equation for x:
 2x = 7 - 3y
 x = (7 - 3y) / 2
 Substitute this expression for x into the second equation:
 5((7 - 3y) / 2) - 4y = 8
 Simplify and solve for y:
 35 - 15y - 8y = 16
 -23y = -19
 y = 19 / 23
 y ≈ 0.83
 Substitute the value of y back into the expression for x:
 x = (7 - 3(0.83)) / 2
 x ≈ (7 - 2.49) / 2
 x ≈ 4.51 / 2
 x ≈ 2.26
 The correct answer is (x, y) ≈ (2.26, 0.83).

Explanation:
This problem involves simplifying the expressions and solving for one variable before plugging it back into the other equation.

Common mistake note:
A common mistake is to forget to simplify the expression for x or make errors in arithmetic when substituting.

Problem 7 (OneStepSubstitutionMedium5):
Solve the system of equations:

A) x = 4, y = 1
B) x = 3, y = 2
C) x = 5, y = 0
D) x = 2, y = 3
Correct Answer: C

Solution:
Solve the first equation for x:
 x = (y + 9) / 2

 2y + 18 + 3y = 17

 y = -1 / 5
 y ≈ -0.2
 Substitute the value of y back into the expression for x:
 x = ((-0.2) + 9) / 2
 x ≈ (8.8) / 2
 x ≈ 4.4
 The correct answer is (x, y) ≈ (4.4, -0.2).

Explanation:
This problem involves simplifying the expressions and solving for one variable before plugging it back into the other equation.
