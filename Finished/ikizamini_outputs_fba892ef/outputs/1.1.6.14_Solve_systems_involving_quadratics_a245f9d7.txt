Problem 1 (One-Variable-QuadraticSubstitution):
Solve the system of equations:

y = x^2 + 3x - 4
2x + y = 10

What is the value of x that satisfies both equations?
A) -5
B) 2
C) 1
D) 4
Correct Answer: B

Solution:
Substitute the expression for y from the first equation into the second equation:

2x + (x^2 + 3x - 4) = 10
Combine like terms and solve for x:

x^2 + 5x - 14 = 0
Factor:

(x + 7)(x - 2) = 0
So, x = -7 or x = 2. However, we discard x = -7 because it does not satisfy the first equation.
Thus, x = 2 is the correct solution.

Explanation:
This question tests solving a system of equations where one equation can be easily solved for one variable and then substituted into the other equation to solve for the second variable.

Common mistake note:
A common mistake would be to assume that x = -7 is also a valid solution, but it does not satisfy both equations.

Problem 2 (Two-Variable-QuadraticFactoring):
Solve the system of equations:

x^2 + y^2 = 13
x + y = 5

What is the sum of the x and y values that satisfy both equations?
A) 6
B) 8
C) 4
D) 10
Correct Answer: C

Solution:
First, solve for y in terms of x from the second equation: 

y = 5 - x
Substitute this expression for y into the first equation:

x^2 + (5 - x)^2 = 13
Expand and simplify:

x^2 + 25 - 10x + x^2 = 13
Combine like terms:

2x^2 - 10x + 12 = 0
Divide by 2 for simplicity:

x^2 - 5x + 6 = 0
Factor:

(x - 3)(x - 2) = 0
So, x = 3 or x = 2. For each value of x, we find the corresponding y value from y = 5 - x:

If x = 3, then y = 2
If x = 2, then y = 3
The sum for both cases is x + y = 3 + 2 = 5 or x + y = 2 + 3 = 5. Since the question asks for the sum only, the answer is 5.

Explanation:
This question tests solving a system of equations where one variable can be eliminated directly from both equations and then factoring to solve for the remaining variable.

Common mistake note:
A common mistake would be to add the x and y values from each equation separately, which would lead to an incorrect sum.

Problem 3 (Two-Variable-QuadraticElimination):
Solve the system of equations:

2x + 3y = 15
4x - 9y = 3

What is the value of x when y = 2?
A) 6
B) 3
C) 9
D) 1
Correct Answer: B

Solution:
First, check if one equation can be multiplied by a constant to eliminate one variable. Multiply the first equation by 3: 

6x + 9y = 45
Now subtract the second equation from this new equation:

(6x + 9y) - (4x - 9y) = 45 - 3
2x + 18y = 42
Divide both sides by 2 for simplicity:

x + 9y = 21
Now, substitute y = 2 into this equation to solve for x:

x + 9(2) = 21
x + 18 = 21
x = 3

Explanation:
This question tests solving a system of equations where one variable can be eliminated by multiplying one equation and then substituting the given value for the other variable to find the solution.

Common mistake note:
A common mistake would be to multiply both equations by different constants, which would not lead to elimination of one variable.

Problem 4 (Two-Variable-QuadraticSystem):
Solve the system of equations:

x^2 + y = 5
y^2 - x = 3

What is the value of x^2 + y^2?
A) 6
B) 8
C) 10
D) 4
Correct Answer: C

Solution:
First, solve for y in terms of x from the second equation: 

y = x + 3
Substitute this expression for y into the first equation:

x^2 + (x + 3) = 5
Simplify and solve for x:

x^2 + x - 2 = 0
Factor:

(x + 2)(x - 1) = 0
So, x = -2 or x = 1. For each value of x, we find the corresponding y value from y = x + 3:

If x = -2, then y = 1
If x = 1, then y = 4
Now calculate x^2 + y^2 for both cases and choose the common value:

x^2 + y^2 = (-2)^2 + 1^2 = 4 + 1 = 5
x^2 + y^2 = (1)^2 + 4^2 = 1 + 16 = 17
Since x = -2, y = 1 is the solution that also satisfies the second equation, we use this value for our calculation:

x^2 + y^2 = (-2)^2 + 1^2 = 4 + 1 = 5

Explanation:
This question tests solving a system of equations where both variables are quadratic and finding the sum of their squares for the correct solution.

Common mistake note:
A common mistake would be to choose the wrong x and y values, leading to an incorrect calculation of x^2 + y^2.

Problem 5 (QuadraticSystemCompletingSquare):
Solve the system of equations:

x^2 - 4xy + 3y^2 = 0
x + y = 5

What is the value of x when y = 1?
A) 6
B) 4
C) 2
D) 8
Correct Answer: B

Solution:
First, complete the square for the quadratic equation: 

x^2 - 4xy + 3y^2 = 0
(x^2 - 4xy + 4y^2) - y^2 = 0
(x - 2y)^2 - y^2 = 0
Factor as a difference of squares:

(x - 2y - y)(x - 2y + y) = 0
(x - 3y)(x - y) = 0
So, x = 3y or x = y. Now substitute y = 1 into these equations to find the corresponding x values:

If x = 3y, then x = 3(1) = 3
If x = y, then x = 1
Since x + y = 5, we discard x = 3 because it does not satisfy the second equation. Thus, x = 1 is the correct solution when y = 1.

Explanation:
This question tests solving a system of equations where one equation involves completing the square and finding the value of x for a given y.

Common mistake note:
A common mistake would be to choose the wrong x value that does not satisfy both equations.

Problem 6 (QuadraticSystemIntersection):
The graphs of the equations y = x^2 - 4x + 3 and y = 2x - 1 intersect at two points. What is the sum of the x-coordinates of these intersection points?
A) 6
B) 8
C) 4
D) 2
Correct Answer: C

Solution:
To find the intersection points, set the two equations equal to each other: 

x^2 - 4x + 3 = 2x - 1
Rearrange and solve for x:

x^2 - 6x + 4 = 0
Factor:

(x - 2)(x - 2) = 0
So, x = 2 (twice). Since the question asks for the sum of the x-coordinates, we add them: x + x = 2 + 2 = 4.

Explanation:
This question tests finding the intersection points of two quadratic equations and calculating the sum of their x-coordinates.

Common mistake note:
A common mistake would be to assume that there is only one intersection point or to forget to add the x-coordinates together.

Problem 7 (QuadraticSystemIntersectionGraph):
The graphs of the equations y = x^2 - 3x + 2 and y = x^2 + 2x - 8 intersect at two points. Which of the following is NOT a possible value for the sum of the y-coordinates of these intersection points?
A) -5
B) 0
C) 5
D) 10
Correct Answer: D

Solution:
To find the intersection points, set the two equations equal to each other: 

x^2 - 3x + 2 = x^2 + 2x - 8
Combine like terms and solve for x:

-5x = -10
x = 2
Now substitute x = 2 into either equation to find the corresponding y values. Using y = x^2 - 3x + 2: 

y = (2)^2 - 3(2) + 2 = 4 - 6 + 2 = 0
Since we have two intersection points with the same x-coordinate, the sum of their y-coordinates will be twice this value: 0 + 0 = 0. Therefore, the sum cannot be 10.

Explanation:
This question tests finding the intersection points of two quadratic equations and recognizing that the sum of their y-coordinates is not necessarily a specific value.

Common mistake note:
A common mistake would be to assume that all sums of y-coordinates are possible, without considering the fact that there may be multiple intersection points with the same x-coordinate.
