Problem 1 (Q1):
What is the difference between a consistent, inconsistent, and dependent system?
A) Consistent systems have exactly one solution. Inconsistent systems have no solutions. Dependent systems have infinitely many solutions.
B) Dependent systems have exactly one solution. Inconsistent systems have no solutions. Consistent systems have infinitely many solutions.
C) Inconsistent systems have no solutions. Consistent systems have exactly one solution. Dependent systems have infinitely many solutions.
D) Consistent systems have at least one solution. Inconsistent systems have no solutions. Dependent systems have exactly one solution.
Correct Answer: C

Solution:
A consistent system has exactly one solution, an inconsistent system has no solutions, and a dependent system has infinitely many solutions because the equations are redundant.

Explanation:
The key to understanding this concept is recognizing that dependent systems behave like consistent systems when solving for one variable, but they actually represent the same line and thus have infinitely many solutions.

Common mistake note:
Common mistake: Confusing dependent systems with consistent systems. Dependent systems are not consistent because they represent the same line.

Problem 2 (Q2):
[1]: 2x + 3y = 7
[2]: 4x + 6y = 14
A) [1] only
B) [2] only
C) Both [1] and [2]
D) None of the systems are consistent.
Correct Answer: A

Solution:
System [1] has a unique solution (x = 1, y = 1), while system [2] is just twice equation [1], making it dependent. Therefore, only system [1] is consistent.

Explanation:
To check for consistency, we can try to solve the systems. System [1] has a unique solution, while system [2] is dependent because it represents the same line as [1].

Common mistake note:
Common mistake: Assuming that having similar equations means they are either both consistent or both inconsistent. It's possible for one to be consistent and the other dependent.

Problem 3 (Q3):
[1]: 3x - 2y = 5
[2]: 6x - 4y = 10
A) [1] only
B) [2] only
C) Both [1] and [2]
D) None of the systems are inconsistent.
Correct Answer: C

Solution:
Both equations in the system represent parallel lines, so they have no solutions. Thus, the system is inconsistent.

Explanation:
To identify an inconsistent system, we can check if the lines represented by the equations are parallel. In this case, the slopes of both lines are equal but the y-intercepts differ, making them parallel and having no intersection point.

Common mistake note:
Common mistake: Assuming that having different constants means the system is independent. The key is to check if the lines are parallel or not.

Problem 4 (Q4):
[1]: 5x - 3y = 7
[2]: 10x - 6y = 14
A) [1] only
B) [2] only
C) Both [1] and [2]
D) None of the systems are dependent.
Correct Answer: C

Solution:
Both equations in the system represent the same line, so they are dependent (infinitely many solutions).

Explanation:
To identify a dependent system, we can check if one equation is a multiple of the other. In this case, [2] is twice equation [1], making them dependent.

Common mistake note:
Common mistake: Assuming that having different constants means the system is independent. The key is to check for linear dependence between the equations.

Problem 5 (Q5):
What does it mean when a system of linear equations has no solution?
A) The system is inconsistent
B) The system is consistent
C) The system is dependent
D) There is not enough information to determine
Correct Answer: A

Solution:
A system with no solution is called inconsistent, meaning the lines represented by the equations do not intersect.

Explanation:
An inconsistent system occurs when the lines are parallel and never intersect. This results in no common point of intersection, hence no solution.

Common mistake note:
Common mistake: Confusing dependent systems with inconsistent ones. Dependent systems have infinitely many solutions, while inconsistent systems have none.
------------------------------------------------------------------------------

Problem 6 (Q6):
If a system of linear equations has infinitely many solutions, what does this indicate?
A) The system is inconsistent
B) The system is consistent
C) The system is dependent
D) There is not enough information to determine
Correct Answer: C

Solution:
A system with infinitely many solutions is called dependent, meaning the lines represented by the equations are identical or overlap.

Explanation:
Dependent systems occur when one equation can be derived from another, resulting in multiple points of intersection (infinitely many).

Common mistake note:
Common mistake: Confusing consistent systems with dependent ones. Consistent systems have exactly one solution, while dependent systems have infinitely many.
------------------------------------------------------------------------------

Problem 7 (Q7):
What does it mean when a system of linear equations has exactly one solution?
A) The system is inconsistent
B) The system is consistent
C) The system is dependent
D) There is not enough information to determine
Correct Answer: B

Solution:
A system with exactly one solution is called consistent, meaning the lines represented by the equations intersect at a single point.

Explanation:
Consistent systems occur when the lines represented by the equations intersect at a single point, resulting in a unique solution for x and y.

Common mistake note:
Common mistake: Confusing dependent systems with consistent ones. Dependent systems have infinitely many solutions, while consistent systems have exactly one.
