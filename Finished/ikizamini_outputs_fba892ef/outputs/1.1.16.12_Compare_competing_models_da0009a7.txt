Problem 1 (IncrementalCostBenefit):
Which method compares two competing models based on their incremental costs and benefits?
A) Confidence Interval Analysis
B) Root Mean Squared Error (RMSE)
C) Mean Absolute Percentage Error (MAPE)
D) Incremental Cost-Benefit Analysis (ICBA)
Correct Answer: D

Solution:
Incremental Cost-Benefit Analysis (ICBA) compares models by evaluating the difference in costs and benefits. It helps select the model with the best value.

Explanation:
Confidence Interval Analysis measures uncertainty, RMSE and MAPE assess model performance, not cost-benefit. ICBA is for comparing models based on costs and benefits.

Common mistake note:
Mistakes include choosing error metrics (RMSE, MAPE) which evaluate model performance but not cost-benefit.

Problem 2 (ModelSelectionCriteria):
What primary criterion guides selecting one machine learning model over another?
A) Accuracy
B) Complexity
C) Interpretability
D) Model Selection Criteria (e.g., AIC, BIC)
Correct Answer: D

Solution:
Model Selection Criteria like AIC or BIC balance model fit and complexity, guiding the selection process.

Explanation:
Accuracy, complexity, and interpretability are important but not primary. Model selection criteria objectively compare models' performance and simplicity.

Common mistake note:
Common error is to choose accuracy alone, which may lead to overfitting if a complex model is selected based on training data.

Problem 3 (CrossValidation):
Which technique fairly assesses the predictive power of two different models?
A) Grid Search
B) Ensemble Learning
C) Cross-Validation
D) Early Stopping
Correct Answer: C

Solution:
Cross-validation compares models by evaluating their performance on various subsets of data, providing an unbiased assessment.

Explanation:
Grid Search and Early Stopping improve model performance, while Ensemble Learning combines models. Cross-validation assesses generalization ability.

Common mistake note:
Common error is to choose Grid Search or Ensemble Learning, which enhance model performance rather than compare them.

Problem 4 (AUCROC):
Which metric differentiates the discriminatory power of two classification models?
A) Mean Squared Error (MSE)
B) Receiver Operating Characteristic (ROC) Curve & AUC
C) F1 Score
D) Log Loss
Correct Answer: B

Solution:
ROC Curve and its AUC measure the discriminatory power of classification models, comparing their ability to distinguish classes.

Explanation:
MSE, F1 Score, and Log Loss evaluate model performance but do not focus on the trade-off between true positives and false positives like ROC-AUC.

Common mistake note:
Common mistake is to choose a metric (e.g., MSE) that focuses on error rates rather than the balance of true positive and false positive rates.
------------------------------------------------------------------------------

Problem 5 (R2Score):
When evaluating two regression models, which metric assesses their overall performance?
A) Mean Absolute Error (MAE)
B) Root Mean Squared Error (RMSE)
C) R-squared (R²)
D) Mean Squared Logarithmic Error (MSLE)
Correct Answer: C

Solution:
R-squared (R²) measures the proportion of variance in the dependent variable explained by a regression model, assessing overall performance.

Explanation:
MAE, RMSE, and MSLE measure prediction error but do not show the proportion of variance explained like R² does.

Common mistake note:
Common mistake is to choose an error metric (e.g., MAE) that only considers average difference without showing variance explained.
------------------------------------------------------------------------------

Problem 6 (HyperparameterTuning):
What method optimizes hyperparameters for different models to compare their performance?
A) Random Search
B) Grid Search
C) Bayesian Optimization
D) All of the above
Correct Answer: D

Solution:
Random Search, Grid Search, and Bayesian Optimization optimize model hyperparameters, allowing for fair comparison based on optimized performance.

Explanation:
Each method has strengths and weaknesses but helps find the best combination of hyperparameters for comparison.

Common mistake note:
Common error is to choose only one method (e.g., Grid Search) thinking it's the sole way to compare models. Multiple methods can provide a more comprehensive comparison.

Problem 7 (ModelEnsembling):
Which technique combines multiple models to improve performance and create a better overall model?
A) Bagging
B) Boosting
C) Stacking
D) All of the above
Correct Answer: D

Solution:
Bagging, Boosting, and Stacking ensemble techniques combine models to enhance performance, potentially creating a superior overall model.

Explanation:
Each technique has its approach but aims to leverage multiple models' strengths for better predictive power.

Common mistake note:
Common error is to choose only one ensemble method, thinking it's the exclusive way to combine models. Using multiple methods can lead to improved results.
