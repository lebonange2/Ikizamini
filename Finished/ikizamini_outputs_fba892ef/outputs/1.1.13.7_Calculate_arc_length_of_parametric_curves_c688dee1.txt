Problem 1 (:Q1):
Find the arc length of the curve given by r(t) = <2t, t^2, 3t>, where 0 ≤ t ≤ 2.
A) 8π/3
B) 4π
C) 16π/3
D) 8π
Correct Answer: C

Solution:
The arc length L of a parametric curve given by r(t) = <x(t), y(t), z(t)> from t=0 to t=2 is calculated using the formula: L  = ∫[0, 2] sqrt[(dx/dt)^2 + (dy/dt)^2 + (dz/dt)^2] dt. For the curve r(t) = <2t, t^2, 3t>, we have x'(t) = 2, y'(t) = 2t, and z'(t) = 3. Let's calculate the integrand: sqrt[(2)^2 + (2t)^2 + (3)^2] = sqrt[4 + 4t^2 + 9] = sqrt[13 + 4t^2]. Now integrate from t=0 to t=2: L  = ∫[0, 2] sqrt(13 + 4t^2) dt. To solve this integral, we use a substitution: let u = 2t, so du/dt = 2 and dt = du/2. The limits of integration change accordingly: when t=0, u=0; when t=2, u=4. The integral becomes: L  = (1/2) ∫[0, 4] sqrt(13 + u^2) du. This is a standard form for an elliptic integral, which can be evaluated using numerical methods or tables. However, we can estimate the value by comparing it to known integrals. The integral of sqrt(1 + u^2) from 0 to 4 is related to the complete elliptic integral of the second kind, which has a closed-form approximation for certain values. Since our integral has an additional constant (sqrt(13)), we can compare the area under the curve y = sqrt(13 + u^2) to that of y = sqrt(u^2), which is just the square root function. The area under the latter from 0 to 4 is π, so our integral will be slightly larger due to the constant 13. Among the given choices, only C (16π/3) is close to this estimate. Therefore, the correct answer is approximately 16π/3.

Explanation:
The arc length calculation involves integrating a square root function with respect to t. The integral can be challenging to solve analytically, but by comparing it to known integrals and considering the effect of the constant term, we can narrow down the choices and select the correct answer.

Common mistake note:
A common mistake is attempting to integrate sqrt(13 + 4t^2) without making a substitution. This leads to an integral that does not have a simple closed-form solution, making it difficult to evaluate. Another mistake might be selecting choice A (8π/3), which is too small, or D (8π), which is too large, due to underestimating or overestimating the effect of the constant 13.

Problem 2 (:Q2):
Find the arc length of the curve given by r(t) = <cos(t), sin(t), t>, where π/2 ≤ t ≤ 5π/2.
A) 4√2
B) 2√2
C) 8√2
D) 6√2
Correct Answer: A

Solution:
The arc length L of a parametric curve given by r(t) = <x(t), y(t), z(t)> from t=π/2 to t=5π/2 is calculated using the formula: L  = ∫[π/2, 5π/2] sqrt[(dx/dt)^2 + (dy/dt)^2 + (dz/dt)^2] dt. For the curve r(t) = <cos(t), sin(t), t>, we have x'(t) = -sin(t), y'(t) = cos(t), and z'(t) = 1. Let's calculate the integrand: sqrt[(-sin(t))^2 + (cos(t))^2 + (1)^2] = sqrt[sin^2(t) + cos^2(t) + 1] = sqrt[2]. Since the integrand is a constant, the integral simplifies to: L  = ∫[π/2, 5π/2] sqrt(2) dt. Integrating a constant results in the constant times the change of variable: L  = sqrt(2) * (5π/2 - π/2) = sqrt(2) * 2π = 4√2. Therefore, the correct answer is A (4√2).

Explanation:
The integrand simplifies to a constant because sin^2(t) + cos^2(t) = 1 for all t. This allows us to integrate directly and find a simple closed-form solution.

Common mistake note:
A common mistake is forgetting that sin^2(t) + cos^2(t) = 1, which simplifies the integrand. Another mistake might be integrating the individual terms of the integrand separately, leading to an incorrect result.
