Problem 1 (:Q1):
Given the polar curve r = 2θ, what is the slope of the tangent line at θ = π/4?
A) -√2
B) 0
C) 1
D) √2
Correct Answer: D

Solution:
The slope of a tangent line to a polar curve can be found using the formula: m = (dr/dθ) / (r - r^2 * θ). For the given curve, r = 2θ, we have dr/dθ = 2. Plugging into the formula, we get m = 2 / (2θ - 4θ^2) at θ = π/4. Evaluating this at θ = π/4, we find m = √2.

Explanation:
The slope is found using the polar curve's derivative and evaluating it at the given angle.

Common mistake note:
A common mistake would be to forget to use the formula for the slope of a tangent line in polar coordinates or to incorrectly compute the derivative of r with respect to θ.

Problem 2 (:Q2):
Find the slope of the tangent line to the curve r = 4sin(3θ) at θ = π/6. Which answer choice is correct?
A) -1
B) 0
C) 1
D) √3
Correct Answer: D

Solution:
The slope of a tangent line to a polar curve can be found using the formula: m = (dr/dθ) / (r - r^2 * θ). For the given curve, r = 4sin(3θ), we have dr/dθ = 12cos(3θ). Plugging into the formula and evaluating at θ = π/6, we get m = 12cos(π/2) / (4sin(π/2) - 16sin^2(π/2)). Simplifying, we find m = √3.

Explanation:
The slope is found using the polar curve's derivative and evaluating it at the given angle.

Common mistake note:
A common mistake would be to use the wrong formula for the derivative of r with respect to θ or to incorrectly evaluate the trigonometric functions.

Solution:

Plugging into the formula and evaluating at θ = π/4, we get m = (2cos^2(π/4) - 2sin^2(π/4)) / (2sin(π/4)cos(π/4) - 4sin^2(π/4)cos^2(π/4)). Simplifying, we find m = 1.

Explanation:
The slope is found using the polar curve's derivative and evaluating it at the given angle.

Problem 7 (:Q7):
Given the polar curve r = e^(θ/2), what is the slope of the tangent line at θ = π?
A) -e^(π/2)
B) 0
C) e^(π/2)
D) e^π
Correct Answer: C

Solution:
The slope of a tangent line to a polar curve can be found using the formula: m = (dr/dθ) / (r - r^2 * θ). For the given curve, r = e^(θ/2), we have dr/dθ = 1/2e^(θ/2). Plugging into the formula and evaluating at θ = π, we get m = (1/2e^(π/2)) / (e^(π/2) - e^π * π/2). Simplifying, we find m = e^(π/2).

Explanation:
The slope is found using the polar curve's derivative and evaluating it at the given angle.

Common mistake note:
A common mistake would be to forget to multiply the derivative by 1/2 or to incorrectly evaluate the expression for r - r^2 * θ.
