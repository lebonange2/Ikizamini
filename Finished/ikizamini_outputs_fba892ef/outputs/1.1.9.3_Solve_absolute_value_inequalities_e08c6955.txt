Problem 1 (One- or two-sided inequality with positive number inside the absolute value):
Solve the inequality: |2x + 3| < 5
A) x < 1
B) x > -4
C) x ≤ -4 or x ≥ 1
D) x ≤ -1 or x ≥ 4
Correct Answer: A

Solution:
To solve the inequality |2x + 3| < 5, consider two cases: when (2x + 3) is positive and when it's negative.

Case 1: If 2x + 3 ≥ 0, then |2x + 3| = 2x + 3. So the inequality becomes 2x + 3 < 5.
Solving for x gives us x < 1.

Case 2: If 2x + 3 < 0, then |2x + 3| = -(2x + 3). The inequality becomes -(2x + 3) < 5.
Simplifying and solving for x gives us -8 < 2x, which means x > -4.

Combining the two cases, we have x < 1 or x > -4. However, since we're looking for the solution where |2x + 3| is less than 5, we only consider x < 1 as the second case (x > -4) would make the absolute value greater than 5.

Common mistake notes: Some students might forget to consider both cases when solving absolute value inequalities.

Explanation:
The correct choice is A because it represents the solution where |2x + 3| is less than 5.

Common mistake note:
Forgetting to consider both cases when solving absolute value inequalities.

Problem 2 (Two- or one-sided inequality with negative number inside the absolute value):
Solve the inequality: |-3x - 2| ≤ 7
A) x ≤ -9 or x ≥ 1
B) x ≤ -± 1
C) x ≤ -3 or x ≥ 5/3
D) x ≤ -5/3 or x ≥ 3
Correct Answer: D

Solution:
To solve the inequality |-3x - 2| ≤ 7, we again consider two cases: when (-3x - 2) is positive and when it's negative.

Case 1: If -3x - 2 ≥ 0, then |-3x - 2| = -3x - 2. So the inequality becomes -3x - 2 ≤ 7.
Solving for x gives us x ≤ -5/3.

Case 2: If -3x - 2 < 0, then |-3x - 2| = 3x + 2. The inequality becomes 3x + 2 ≤ 7.
Solving for x gives us x ≥ -3.

Combining the two cases, we have x ≤ -5/3 or x ≥ -3. However, since we're looking for the solution where |3x + 2| is less than or equal to 7, we only consider x ≤ -5/3 as the second case (x ≥ -3) would make the absolute value greater than 7.

Common mistake notes: Some students might not recognize that when the inequality sign includes ≤, both cases are included in the solution.

Explanation:
The correct choice is D because it represents the solution where |-3x - 2| is less than or equal to 7.

Common mistake note:
Not including both cases when solving absolute value inequalities with ≤ sign.

Problem 3 (Double inequality with positive number inside the absolute value):
Solve the inequality: |x - 5| > 3 and |x - 5| < 7
A) x ≤ 2 or x ≥ 8
B) x ≤ 2 or x ≥ 12
C) 2 < x < 8
D) No solution
Correct Answer: C

Solution:
To solve the double inequality |x - 5| > 3 and |x - 5| < 7, we first consider each inequality separately.

For |x - 5| > 3, we have two cases:
Case 1: If x - 5 ≥ 0, then |x - 5| = x - 5. So the inequality becomes x - 5 > 3.
Solving for x gives us x > 8.

Case 2: If x - 5 < 0, then |x - 5| = -(x - 5). The inequality becomes -(x - 5) > 3.
Simplifying and solving for x gives us x < 2.

For |x - 5| < 7, we have two cases:
Case 1: If x - 5 ≥ 0, then |x - 5| = x - 5. So the inequality becomes x - 5 < 7.
Solving for x gives us x < 12.

Case 2: If x - 5 < 0, then |x - 5| = -(x - 5). The inequality becomes -(x - 5) < 7.
Simplifying and solving for x gives us x > -2.

Combining the solutions from both inequalities, we have x < 2 or x > 8 for the first inequality, and x < 12 or x > -2 for the second inequality. However, since we're looking for the intersection of these two solution sets, we only consider the range where both conditions are met: 2 < x < 8.

Common mistake notes: Students might not recognize that the solution to a double inequality with absolute values should be the intersection of the solutions from each individual inequality.

Explanation:
The correct choice is C because it represents the overlapping solution set for both inequalities.

Common mistake note:
Not finding the intersection of the solution sets when solving a double inequality with absolute values.

Problem 4 (Absolute value inequality with variable on both sides):
Solve the inequality: |2x + 1| - |x - 3| < 4
A) x ≤ -± 5
B) x ≤ -1 or x ≥ 7
C) x ≤ -9/3 or x ≥ 5
D) x ≤ -1 or x ≥ 1
Correct Answer: C

Solution:
To solve the inequality |2x + 1| - |x - 3| < 4, we need to consider four cases: each variable inside the absolute values can be positive or negative.

Case 1: If 2x + 1 ≥ 0 and x - 3 ≥ 0, then |2x + 1| = 2x + 1 and |x - 3| = x - 3. The inequality becomes (2x + 1) - (x - 3) < 4.
Solving for x gives us x < 0.

Case 2: If 2x + 1 ≥ 0 and x - 3 < 0, then |2x + 1| = 2x + 1 and |x - 3| = -(x - 3). The inequality becomes (2x + 1) + (x - 3) < 4.
Solving for x gives us x < 6/3.

Case 3: If 2x + 1 < 0 and x - 3 ≥ 0, then |2x + 1| = -(2x + 1) and |x - 3| = x - 3. The inequality becomes -(2x + 1) - (x - 3) < 4.
Solving for x gives us x > -9/3.

Case 4: If 2x + 1 < 0 and x - 3 < 0, then |2x + 1| = -(2x + 1) and |x - 3| = -(x - 3). The inequality becomes -(2x + 1) + (x - 3) < 4.
Solving for x gives us x > -7.

Combining the solutions from all cases, we have x < 0 or x < 6/3 or x > -9/3 or x > -7. However, since we're looking for the solution where |2x + 1| - |x - 3| is less than 4, we only consider the overlapping range: x ≤ -9/3 or x ≥ 5.

Common mistake notes: Students might not consider all possible combinations of positive and negative values for both variables inside the absolute values.

Explanation:
The correct choice is C because it represents the solution where |2x + 1| - |x - 3| is less than 4.

Common mistake note:
Not considering all four cases when solving an absolute value inequality with variables on both sides.

Problem 5 (Absolute value inequality with variable inside and outside):
Solve the inequality: 2|x - 1| + 3 > 7
A) x ≤ -1 or x ≥ 3
B) x ≤ 0 or x ≥ 2
C) x ≤ 1 or x ≥ 5
D) No solution
Correct Answer: D

Solution:
To solve the inequality 2|x - 1| + 3 > 7, we first subtract 3 from both sides to isolate |x - 1|:
2|x - 1| > 4
Now we consider two cases: x - 1 is positive or negative.

Case 1: If x - 1 ≥ 0, then |x - 1| = x - 1. The inequality becomes 2(x - 1) > 4.
Solving for x gives us x > 3.

Case 2: If x - 1 < 0, then |x - 1| = -(x - 1). The inequality becomes 2(-(x - 1)) > 4.
Simplifying and solving for x gives us x < -1.

However, since we're looking for the solution where 2|x - 1| is greater than 4, there are no values of x that satisfy this condition when |x - 1| is negative (as it would result in a value less than or equal to 4). Therefore, the only possible solution is x > 3. But since we're looking for an inequality where 2|x - 1| + 3 > 7, there are no values of x that satisfy this condition either because adding 3 to any positive number greater than 3 will always be less than or equal to 7.

Common mistake notes: Students might not recognize that the solution set for |x - 1| > 4 is empty, leading them to an incorrect conclusion.

Explanation:
The correct choice is D because there is no solution to the given inequality.

Common mistake note:
Assuming that there exists a solution when solving an absolute value inequality with a variable outside the absolute value.

Problem 6 (Absolute value inequality with multiple variables):
Solve the inequality: |2x + 3y| < 10 and |x - y| ≤ 5
A) No solution
B) x ≤ -9/3 or x ≥ 1, y ≤ -7/3 or y ≥ 3
C) x ≤ -10 or x ≥ 0, y ≤ -10 or y ≥ 0
D) x ≤ -19/3 or x ≥ 9, y ≤ -19/3 or y ≥ 9
Correct Answer: B

Solution:
To solve the system of inequalities |2x + 3y| < 10 and |x - y| ≤ 5, we need to consider each inequality separately.

For |2x + 3y| < 10, we have two cases:
Case 1: If 2x + 3y ≥ 0, then |2x + 3y| = 2x + 3y. So the inequality becomes 2x + 3y < 10.
We cannot solve for a single variable in terms of another because there are two variables. However, we can express y in terms of x: y < (10 - 2x)/3.

Case 2: If 2x + 3y < 0, then |2x + 3y| = -(2x + 3y). The inequality becomes -(2x + 3y) < 10.
Simplifying and solving for y gives us y > (10 - 2x)/3.

For |x - y| ≤ 5, we have two cases:
Case 1: If x - y ≥ 0, then |x - y| = x - y. So the inequality becomes x - y ≤ 5.
Solving for y gives us y ≥ x - 5.

Case 2: If x - y < 0, then |x - y| = -(x - y). The inequality becomes -(x - y) ≤ 5.
Simplifying and solving for y gives us y ≤ x + 5.

Combining the solutions from both inequalities, we have y < (10 - 2x)/3 or y > (10 - 2x)/3 for the first inequality, and y ≥ x - 5 or y ≤ x + 5 for the second inequality. The overlapping solution set is when both conditions are met: x ≤ -9/3 or x ≥ 1, y ≤ -7/3 or y ≥ 3.

Common mistake notes: Students might not recognize that the solution to a system of absolute value inequalities should be found by considering each inequality separately and then finding the overlapping region.

Explanation:
The correct choice is B because it represents the overlapping solution set for both inequalities.

Common mistake note:
Not finding the intersection of the solution sets when solving a system of absolute value inequalities.

Problem 7 (Absolute value inequality with variable inside and outside, multiple variables):
Solve the inequality: |x + y| - 3 < 5 and |2x - y| ≤ 7
A) x ≤ -1 or x ≥ 9, y ≤ -9 or y ≥ 1
B) x ≤ -1 or x ≥ 8, y ≤ -7 or y ≥ 3
C) x ≤ -9 or x ≥ 1, y ≤ -7 or y ≥ 3
D) No solution
Correct Answer: B

Solution:
To solve the system of inequalities |x + y| - 3 < 5 and |2x - y| ≤ 7, we again consider each inequality separately.

For |x + y| - 3 < 5, we first add 3 to both sides:
|x + y| < 8
Now we have two cases:
Case 1: If x + y ≥ 0, then |x + y| = x + y. So the inequality becomes x + y < 8.
We cannot solve for a single variable in terms of another because there are two variables. However, we can express y in terms of x: y < 8 - x.

Case 2: If x + y < 0, then |x + y| = -(x + y). The inequality becomes -(x + y) < 8.
Simplifying and solving for y gives us y > 8 - x.

For |2x - y| ≤ 7, we have two cases:
Case 1: If 2x - y ≥ 0, then |2x - y| = 2x - y. So the inequality becomes 2x - y ≤ 7.
Solving for y gives us y ≥ 2x - 7.

Case 2: If 2x - y < 0, then |2x - y| = -(2x - y). The inequality becomes -(2x - y) ≤ 7.
Simplifying and solving for y gives us y ≤ 2x + 7.

Combining the solutions from both inequalities, we have y < 8 - x or y > 8 - x for the first inequality, and y ≥ 2x - 7 or y ≤ 2x + 7 for the second inequality. The overlapping solution set is when both conditions are met: x ≤ -1 or x ≥ 8, y ≤ -7 or y ≥ 3.

Common mistake notes: Students might not recognize that the solution to a system of absolute value inequalities should be found by considering each inequality separately and then finding the overlapping region.

Explanation:
The correct choice is B because it represents the overlapping solution set for both inequalities.

Common mistake note:
Not finding the intersection of the solution sets when solving a system of absolute value inequalities.
