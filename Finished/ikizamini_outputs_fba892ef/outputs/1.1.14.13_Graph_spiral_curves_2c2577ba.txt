Problem 1 (IncrementalSpiral):
Which equation represents a logarithmic spiral starting at the origin (0,0) and increasing by 1 unit for each clockwise rotation?
A) (x^2 + y^2)^{0.5} = x + 1
B) x = cos(t) * t, y = sin(t) * t
C) r = θ
D) x = 2θ * cos(θ), y = 2θ * sin(θ)
Correct Answer: B

Solution:
The equation that represents a logarithmic spiral starting at the origin and increasing by 1 unit for each clockwise rotation is B: x = cos(t) * t, y = sin(t) * t. This is known as an Archimedean spiral. The other options do not describe spirals with the specified properties.

Explanation:
Option A describes a circle centered at (0,0). Option C represents a straight line in polar coordinates, not a spiral. Option D describes a spiral but increases by 2 units for each rotation.

Common mistake note:
Common mistake is to confuse spiral types or misinterpret starting conditions.

Problem 2 (DecrementalSpiral):
Which equation represents a logarithmic spiral that starts at (5,0) and decreases by 1 unit for each counterclockwise rotation?
A) x = 5 + cos(θ), y = 5 - sin(θ)
B) r = θ - 5
C) x = 5 + e^(-t), y = 5 * t
D) x = 5 + 2θ * cos(θ - π/2), y = 5 + 2θ * sin(θ - π/2)
Correct Answer: D

Solution:
The equation that represents a logarithmic spiral starting at (5,0) and decreasing by 1 unit for each counterclockwise rotation is D: x = 5 + 2θ * cos(θ - π/2), y = 5 + 2θ * sin(θ - π/2). This is a modified Archimedean spiral. The other options do not describe spirals with the specified properties.

Explanation:
Option A represents an ellipse, not a spiral. Option B describes a polar equation that does not decrease by 1 unit for each rotation and starts at (0,5). Option C combines an exponential function with a linear function, not a spiral.

Common mistake note:
Common mistake is to confuse the starting point or direction of rotation.

Problem 3 (ParametricSpiral):
Which set of parametric equations represents a spiral that starts at (1,0) and grows exponentially as it rotates counterclockwise?
A) x = e^t, y = t
B) x = 1 + cos(t), y = sin(t)
C) x = 1 + e^(t^2), y = t * e^t
D) x = 1 + e^(-t), y = t
Correct Answer: C

Solution:
The set of parametric equations that represents a spiral starting at (1,0) and growing exponentially as it rotates counterclockwise is C: x = 1 + e^(t^2), y = t * e^t. The other options do not describe spirals with the specified properties.

Explanation:
Option A describes exponential growth along the x-axis without rotation. Option B represents a circle, not a spiral. Option D grows exponentially along the y-axis but does not start at (1,0).

Common mistake note:
Common mistake is to overlook the starting point or direction of growth.

Problem 6 (PolarSpiral):
Which polar equation represents a spiral that starts at (0, 0) and rotates clockwise with an angular velocity of π/2 radians per unit distance?
A) r = θ^π/2
B) θ = r * π/2
C) r = e^(π/2t)
D) θ = t * π/2
Correct Answer: D

Solution:
The polar equation that represents a spiral starting at (0, 0) and rotating clockwise with an angular velocity of π/2 radians per unit distance is D: θ = t * π/2. This describes a spiral where the angle increases by π/2 radians for each unit increase in radius. The other options do not describe spirals with the specified properties.

Explanation:
Option A and C represent exponential growth, not spirals with a constant angular velocity. Option B describes an equation that does not form a spiral but rather a straight line from the origin.

Common mistake note:
Common mistake is to confuse exponential growth with spiral motion.

Problem 7 (SpiralIntersection):
Which of the following equations represents a spiral that intersects itself at least once?
A) x = cos(θ), y = sin(θ)
B) r = θ^2
C) x = 2θ * cos(θ - π/4), y = 2θ * sin(θ - π/4)
D) x = e^(t) * cos(t), y = e^(t) * sin(t)
Correct Answer: C

Solution:
The equation that represents a spiral that intersects itself at least once is C: x = 2θ * cos(θ - π/4), y = 2θ * sin(θ - π/4). This is a modified Archimedean spiral that can intersect itself depending on the range of θ. The other options do not describe spirals that intersect themselves.

Explanation:
Option A represents a circle, not a self- intersecting spiral. Option B describes a polar equation that does not form a self-intersecting spiral. Option D is an exponential spiral that does not intersect itself.

Common mistake note:
Common mistake is to overlook the possibility of self- intersection in spiral curves.
