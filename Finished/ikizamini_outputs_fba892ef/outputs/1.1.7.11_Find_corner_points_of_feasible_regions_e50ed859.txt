Problem 1 (AssembleFeasibleRegionEasy01):
Given the system of inequalities:
- 2x + y ≤ 8
- x - y ≤ 3
What are the coordinates of one corner point of the feasible region?
A) (0, 0)
B) (4, 0)
C) (0, 6)
D) (4, 4)
Correct Answer: B

Solution:
To find a corner point, set equations equal to each other. For example, let's set the first inequality to equality: 2x + y = 8. Solve for y: y = 8 - 2x. Substitute into second inequality: x - (8 - 2x) ≤ 3. Solve for x: x ≤ 11/3 ≈ 3.67, so x = 3. Substitute x back into y equation: y = 2. Corner point is (3, 2). However, choice B represents a corner point where x = 4 and y = 0, which is also within the feasible region.

Explanation:
Test understanding of finding a corner point by setting equations equal. Choices A, C, D incorrect because they don't satisfy both inequalities or are not intersection points.

Common mistake note:
Mistakes may include assuming any integer solution is a corner point; remember, a corner point occurs where two constraints intersect.

Problem 2 (AssembleFeasibleRegionEasy02):
Given the system of inequalities:
- 3x + 4y ≤ 12
- x - y ≥ -2
What are the coordinates of one corner point of the feasible region?
A) (0, 3)
B) (4, 0)
C) (0, 4)
D) (3, 1)
Correct Answer: A

Solution:
Set equations equal: x - y = -2. Solve for y: y = x - 2. Substitute into first inequality: 3x + 4(x - 2) ≤ 12. Solve for x: x ≤ 20/7 ≈ 2.86, so x = 2. Substitute x back into y equation: y = 0. Corner point is (2, 0). Choice A represents a corner point where x = 0 and y = 3, also within the feasible region.

Explanation:

- 2x + 4y ≥ 8
What are the coordinates of one corner point of the feasible region?
A) (5, 0)

Solution:

Substitute y = 0 back into x equation: x = 4. Corner point is (4, 0). Choice C represents a corner point where x = 3 and y = 1, also within the feasible region.

Explanation:
