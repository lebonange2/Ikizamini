Problem 1 (?):
Which of the following functions is a one-to-one function?
A) f(x) = x^2
B) g(x) = |x|
C) h(x) = x + 1
D) j(x) = -x
Correct Answer: C

Solution:
A one-to-one function has a unique output for every input. Function h(x) = x + 1 satisfies this property since each distinct value of x results in a different value for h(x). Functions A, B, and D do not have this property: f(x) = x^2 and g(x) = |x| both map -1 and 1 to the same output (1), while j(x) = -x maps every input to its negative.

Explanation:
A one-to-one function has a unique output for each input. To be sure, check if any two different inputs produce the same output.

Common mistake note:
Common mistake: Choosing A or B because they are quadratic or absolute value functions. These functions do not have a unique output for every input.

Problem 2 (?):
Is the function f(x) = 2^x a one-to-one function?
A) Yes
B) No
C) Cannot be determined without more information
D) The function is not defined for all real numbers
Correct Answer: A

Solution:
A one-to-one function has a unique output for every input. The exponential function f(x) = 2^x assigns a distinct value to each input, making it a one-to-one function.

Explanation:
Exponential functions with positive bases are always one-to-one because they increase without bound in both directions and never intersect or cross the x-axis.

Common mistake note:
Common mistake: Choosing B due to misconceptions about exponential growth. However, since 2^x is strictly increasing, it maintains a unique output for each input.

Problem 3 (?):
Which of the following graphs represents a one-to-one function?
A) [graph A - a parabola]
B) [graph B - a straight line with positive slope]
C) [graph C - a straight line with negative slope]
D) [graph D - a circle]
Correct Answer: B

Solution:
A one-to-one function has a unique output for every input. Graph B represents a straight line with a positive slope, which means that each x-value corresponds to exactly one y-value. The other graphs do not have this property: graph A shows a parabola (quadratic function), graph C shows a negative slope, and graph D represents a circle which is periodic and thus does not pass the vertical line test.

Explanation:
To identify a one-to-one function from its graph, check if any vertical line intersects the curve at more than one point. If no such lines exist, it's a one-to-one function.

Common mistake note:
Common mistake: Choosing A because it is a familiar shape (parabola), but quadratic functions do not have unique outputs for all inputs.

A) Yes

Correct Answer: A

Solution:
A one-to-one function has a unique output for every input. The cubic function f(x) = x^3 - 2x assigns a distinct value to each input, making it a one-to-one function.

Problem 5 (?):
Which of the following functions is NOT a one-to-one function?
A) f(x) = x + sin(x)
B) g(x) = e^x
C) h(x) = 3x - 2
D) j(x) = x^3 - x
Correct Answer: D

Solution:
A one-to-one function has a unique output for every input. Function j(x) = x^3 - x does not have this property because it maps -1, 0, and 1 to the same output (0). The other functions do have a unique output for each input: f(x), g(x), and h(x) are all strictly increasing or linear.

Explanation:
To identify non- one-to-one functions, look for repeated outputs. If any two different inputs produce the same output, the function is not one-to-one.

Common mistake note:
Common mistake: Choosing A because of the sine term, but x + sin(x) still has a unique output for each input since the range of sine is [-1, 1] and does not overlap with the domain.

Problem 6 (?):
Which of the following graphs represents a non- one-to-one function?
A) [graph A - a straight line with positive slope]
B) [graph B - an exponential curve with base greater than 1]
C) [graph C - a parabola opening upwards]
D) [graph D - a logarithmic curve with base greater than 1]
Correct Answer: C

Solution:
A non- one-to-one function has multiple outputs for at least one input. Graph C represents a parabola (quadratic function), which does not have unique outputs for all inputs, as it maps -1 and 1 to the same output (0). The other graphs represent one-to-one functions: graph A shows a straight line with a positive slope, graph B shows an exponential curve, and graph D represents a logarithmic curve.

Explanation:
To identify non- one-to-one functions from their graphs, look for points where the curve intersects itself or fails the vertical line test. If any such lines exist, it's not a one-to-one function.

Common mistake note:
Common mistake: Choosing A because of the straight line, but linear functions are always one-to-one unless they have a slope of zero.

Problem 7 (?):
Is the function f(x) = x^4 - 2x^2 + 1 a one-to-one function?
A) Yes
B) No
C) Cannot be determined without more information
D) The function is not defined for all real numbers
Correct Answer: B

Solution:
A one-to-one function has a unique output for every input. The function f(x) = x^4 - 2x^2 + 1 is not one-to-one because it does not pass the horizontal line test: the curve intersects the x-axis at x = -1, 0, and 1, indicating that multiple inputs map to the same output (0).

Explanation:
To determine if a function is one-to-one, check for repeated roots or intersections with the x-axis. If any such points exist, the function is not one-to-one.

Common mistake note:
Common mistake: Choosing A because of the polynomial form, but f(x) = x^4 - 2x^2 + 1 has repeated roots at x = 0, making it non- one-to-one.
