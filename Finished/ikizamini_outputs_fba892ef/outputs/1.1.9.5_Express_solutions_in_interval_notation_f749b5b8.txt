Problem 1 (:1):
Solve for x: x > -3
A) [3, ∞)
B) (3, ∞)
C) (-∞, 3)
D) (-∞, -3)
Correct Answer: B

Solution:
The inequality x > -3 represents all real numbers greater than -3. In interval notation, this is written as (3, ∞).

Explanation:
Interval notation uses parentheses to indicate that the endpoint is not included and square brackets to indicate that it is included. Since x can be any number greater than -3 but not equal to -3, we use an open parenthesis.

Common mistake note:
Common mistake: Choosing (A) because students may forget that the inequality sign points to the larger set and thus includes all values greater than -3.
------------------------------------------------------------------------------

Problem 2 (:2):
Solve for y: y ≤ 7
A) [7, ∞)
B) (7, ∞)
C) (-∞, 7]
D) (-∞, 7)
Correct Answer: C

Solution:
The inequality y ≤ 7 represents all real numbers less than or equal to 7. In interval notation, this is written as (-∞, 7].

Explanation:
Since the inequality includes values up to and including 7, we use a square bracket on the left side of the interval. The right side remains open because y can be any number less than 7.

Common mistake note:
Common mistake: Choosing (A) because students may confuse ≤ with > and forget that the endpoint is included.
------------------------------------------------------------------------------

Problem 3 (:3):
Solve for z: -5 < z < 2
A) (-∞, -5] ∪ [2, ∞)
B) [5, 2]
C) (5, 2]
D) (-5, 2)
Correct Answer: D

Solution:
The inequality -5 < z < 2 represents all real numbers between -5 and 2 (exclusive). In interval notation, this is written as (-5, 2).

Explanation:
Both endpoints are excluded because the inequality uses '<' instead of ≤ or ≥. Therefore, we use open parentheses for both ends of the interval.

Common mistake note:
Common mistake: Choosing (B) because students may interpret the double inequality as inclusive endpoints.
------------------------------------------------------------------------------

Problem 4 (:4):
Solve for w: w ≥ 0 and w < 10
A) [0, ∞)
B) [0, 10]
C) [0, 10)
D) (0, 10]
Correct Answer: C

Solution:
The compound inequality w ≥ 0 and w < 10 represents all real numbers greater than or equal to 0 and less than 10. In interval notation, this is written as [0, 10).

Explanation:
The first inequality includes 0, so we use a square bracket on the left side. The second inequality does not include 10, so we use an open parenthesis on the right side.

Common mistake note:
Common mistake: Choosing (A) because students may forget to consider the upper bound of the interval.
------------------------------------------------------------------------------

Problem 5 (:5):
Solve for x: x < -4 or x ≥ 6
A) (-∞, -4] ∪ [6, ∞)
B) (-∞, -4) ∪ (6, ∞)
C) (-4, ∞)
D) (-∞, -4) ∪ [6, ∞)
Correct Answer: B

Solution:
The compound inequality x < -4 or x ≥ 6 represents all real numbers less than -4 and greater than or equal to 6. In interval notation, this is written as (-∞, -4) ∪ (6, ∞).

Explanation:
Both intervals are exclusive, so we use open parentheses for both ends. The first interval includes values less than -4, and the second interval includes values greater than 6.

Common mistake note:
Common mistake: Choosing (A) because students may interpret 'or' as inclusive endpoints.
------------------------------------------------------------------------------

Problem 6 (:6):
Solve for y: -2 ≤ y ≤ 3
A) [2, 3]
B) [-2, 3)
C) [-2, 3]
D) (2, 3]
Correct Answer: C

Solution:
The inequality -2 ≤ y ≤ 3 represents all real numbers between -2 and 3 (inclusive). In interval notation, this is written as [-2, 3].

Explanation:
Both endpoints are included because the inequality uses '≤' for both sides. Therefore, we use square brackets for both ends of the interval.

Common mistake note:
Common mistake: Choosing (A) because students may forget to include the endpoint -2.

Problem 7 (:7):
Solve for z: 4 ≤ z < 8 and z ≠ 6
A) [4, 6) ∪ (6, 8]
B) [4, 6] ∪ [6, 8)
C) [4, 8)
D) [-∞, 6) ∪ (6, ∞)
Correct Answer: A

Solution:
The compound inequality 4 ≤ z < 8 and z ≠ 6 represents all real numbers greater than or equal to 4, less than 8, and not equal to 6. In interval notation, this is written as [4, 6) ∪ (6, 8].

Explanation:
The first inequality includes 4, so we use a square bracket on the left side of the first interval. The second inequality excludes 6, so we exclude it from both intervals using open parentheses. The second interval continues to 8 but does not include it.

Common mistake note:
Common mistake: Choosing (B) because students may forget that z ≠ 6 means 6 is not included in the solution.
