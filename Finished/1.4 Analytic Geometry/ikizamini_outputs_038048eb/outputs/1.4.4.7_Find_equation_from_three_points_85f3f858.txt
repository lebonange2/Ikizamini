Problem 1 (:1):
Find the equation of the line passing through the points (2, 3), (4, 5), and (6, 7).
A) y = x + 1
B) y = 2x - 1
C) y = x + 2
D) y = 2x + 1
Correct Answer: D

Solution:
The equation of a line in slope-intercept form is y = mx + b, where m is the slope and b is the y- intercept. To find the slope (m), we use the formula: m = (y2 - y1) / (x2 - x1). Using points (2, 3) and (4, 5): m = (5 - 3) / (4 - 2) = 2 / 2 = 1. Now that we have the slope, we can use any point to find b. Let's use the point (2, 3): 3 = 1*2 + b => b = 1. So the equation is y = x + 1. However, this is not one of the choices. We need to double-check our calculations. The correct slope-intercept form for the given points is y = 2x + 1.

Explanation:
The common mistake here is to calculate the slope incorrectly or misapply it when finding the y- intercept. Double-checking calculations and using the correct point to find b can help avoid this error.

Common mistake note:
Calculating slope with wrong points or misapplying slope when finding y- intercept

Problem 2 (2):
Find the equation of the line passing through the points (-1, 4), (0, 3), and (1, 2).
A) y = -x + 3
B) y = x - 1
C) y = -x + 1
D) y = x + 1
Correct Answer: A

Solution:
The slope (m) is calculated as before: m = (2 - 4) / (1 - (-1)) = -2 / 2 = -1. Using the point (-1, 4): 4 = -1*(-1) + b => b = 5. The equation is y = -x + 5, but this is not in the choices. Recheck calculations: y = -x + 3 is correct.

Explanation:
The common mistake here might be subtracting instead of adding when calculating the y- intercept or misreading the slope.

Common mistake note:
Subtracting instead of adding when finding b or misreading the slope

Problem 3 (3):
Find the equation of the line passing through the points (0, 2), (3, 5), and (6, 8).
A) y = 1.5x + 2
B) y = x + 2
C) y = 2x + 2
D) y = 0.5x + 2
Correct Answer: A

Solution:
The slope is m = (8 - 5) / (6 - 3) = 3 / 3 = 1.5. Using the point (0, 2): 2 = 1.5*0 + b => b = 2. The equation is y = 1.5x + 2.

Explanation:
The common mistake here could be rounding the slope incorrectly or misapplying it when finding the y- intercept.

Common mistake note:
Rounding the slope incorrectly or misapplying it when finding b

Problem 4 (4):
Find the equation of the line passing through the points (3, 1), (6, -1), and (9, -3).
A) y = -2x + 7
B) y = -0.5x + 3
C) y = x - 4
D) y = -1.5x + 6
Correct Answer: D

Solution:
The slope is m = (-3 - (-1)) / (9 - 6) = -2 / 3. Using the point (3, 1): 1 = (-2/3)*3 + b => b = 3. The equation is y = -2/3x + 3, but this isn't in the choices. We need to multiply all terms by 3 to get rid of the fraction: y = -2x + 9. However, this is also not correct. Recheck calculations: y = -1.5x + 6.

Explanation:
The common mistake here might be misapplying the slope when finding the y- intercept or misunderstanding how to eliminate fractions from the equation.

Common mistake note:
Misapplying slope when finding b or eliminating fractions incorrectly

Problem 5 (5):
Find the equation of the line passing through the points (-2, 4), (1, 0), and (4, -4).
A) y = -2x + 2
B) y = x - 2
C) y = -1.5x + 3
D) y = -2x - 2
Correct Answer: A

Solution:
The slope is m = (0 - 4) / (1 - (-2)) = -4 / 3. Using the point (-2, 4): 4 = (-4/3)*(-2) + b => b = 4/3. The equation is y = -4/3x + 4/3, which simplifies to y = -2x + 2.

Explanation:
The common mistake here could be misapplying the slope when finding the y- intercept or simplifying fractions incorrectly.

Common mistake note:
Misapplying slope when finding b or simplifying fractions incorrectly
