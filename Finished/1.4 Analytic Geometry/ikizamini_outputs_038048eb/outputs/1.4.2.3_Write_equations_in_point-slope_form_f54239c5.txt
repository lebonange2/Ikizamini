Problem 1 (Asdf):
Find the equation of the line passing through the point (3, -5) with a slope of 2.
A) (y + 5) = 2(x - 3)
B) (x + 3) = 2(y - 5)
C) (y - 5) = rac{1}{2}(x - 3)
D) (x - 3) = rac{1}{2}(y + 5)
Correct Answer: A

Solution:
The point-slope form of a line is given by (y - y1) = m(x - x1), where m is the slope and (x1, y1) is a point on the line. Plugging in the given values, we get (y + 5) = 2(x - 3).

Explanation:
The correct equation uses the point-slope formula with the provided point and slope.

Common mistake note:
Common mistake: Using the wrong order for the coordinates in the formula. The correct order is (x1, y1), not (y1, x1).

Problem 3 (Asdf):
Write an equation in point-slope form for a line with a slope of 0 and passing through the point (5, 3).
A) (y - 3) = 0(x - 5)
B) (x - 5) = 0(y - 3)
C) (y - 3) = rac{1}{0}(x - 5)
D) (x - 5) = rac{1}{0}(y - 3)
Correct Answer: A

Solution:
For a line with slope 0, the equation simplifies to y = constant. Since it passes through (5, 3), we have y - 3 = 0(x - 5) or simply (y - 3) = 0.

Explanation:
The correct equation represents a horizontal line with no change in the y-coordinate.

Common mistake note:
Common mistake: Not understanding that a slope of 0 results in a horizontal line, where y remains constant.

Problem 5 (Asdf):
What is the equation of the line passing through (0, 6) and parallel to the line with equation y = -3x + 2?
A) (y - 6) = -3(x - 0)
B) (x - 0) = -3(y - 6)
C) (y - 6) = rac{1}{-3}(x - 0)
D) (x - 0) = rac{1}{-3}(y - 6)
Correct Answer: A

Solution:
Lines parallel to y = mx + b have the same slope m. The given line has a slope of -3, so our equation should be in the form (y - y1) = -3(x - x1). Plugging in (0, 6), we get (y - 6) = -3(x - 0).

Explanation:
The correct equation uses the same slope as the given parallel line and one of the provided points.

Common mistake note:
Common mistake: Not understanding that parallel lines have the same slope, leading to an incorrect slope in the point-slope form.

However, since we only need to write an equation in point-slope form, we can use the given point: (y + 2) = rac{1}{3}(x - 6).
