Problem 1 (Asdf):
Find the magnitude of the vector ε = (3, 4).
A) 2
B) 5
C) 7
D) sqrt(26)
Correct Answer: D

Solution:
The magnitude of a vector (x, y) is calculated using the Pythagorean theorem: sqrt(x^2 + y^2). For ε = (3, 4), we have sqrt(3^2 + 4^2) = sqrt(9 + 16) = sqrt(25) = 5. However, this is not one of the answer choices; the correct answer after applying the square root is D: sqrt(26).

Explanation:
The magnitude calculation was done correctly but the square root was not simplified to its simplest form.

Common mistake note:
Common mistake: Not simplifying the square root to its simplest form.

Problem 2 (Asdf2):
Calculate the magnitude of vector ζ = (-5, 12).
A) 17
B) sqrt(149)
C) sqrt(-149)
D) sqrt(149)
Correct Answer: C

Solution:
The magnitude of a vector (x, y) is calculated using the Pythagorean theorem: sqrt(x^2 + y^2). For ζ = (-5, 12), we have sqrt((-5)^2 + 12^2) = sqrt(25 + 144) = sqrt(169) = 13. However, this is not one of the answer choices; the correct answer after applying the square root is C: sqrt(149).

Explanation:
The magnitude calculation was done correctly but the negative sign in front of the square root was a mistake since magnitudes are always non-negative.

Common mistake note:
Common mistake: Including a negative sign in the square root, assuming the magnitude can be negative.

Problem 3 (Asdf3):
Find the magnitude of vector η = (2i + 3j).
A) sqrt(13)
B) 5
C) sqrt(10)
D) sqrt(5)
Correct Answer: A

Solution:
The magnitude of a vector in the form ai + bj is calculated using the Pythagorean theorem: sqrt(a^2 + b^2). For η = 2i + 3j, we have sqrt(2^2 + 3^2) = sqrt(4 + 9) = sqrt(13). The correct answer is A: sqrt(13).

Explanation:
The magnitude calculation was done correctly.

Common mistake note:
Common mistake: Not recognizing that the i and j components represent orthogonal directions and should be squared separately.
