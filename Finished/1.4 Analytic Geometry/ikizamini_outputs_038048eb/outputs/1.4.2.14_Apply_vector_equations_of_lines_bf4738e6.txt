Problem 1 (Infinite Line):
Find the equation of the line passing through the point (3, 4) and parallel to the vector <2, 1>.
A) <6, 3> + t<2, 1>
B) <3, 4> + t<2, -1>
C) <3, 4> + t<-2, 1>
D) <3, 4> + t<2, 1>
Correct Answer: D

Solution:
<3, 4> + t<2, 1>

Explanation:
The equation of a line parallel to vector <a, b> and passing through point (x0, y0) is given by <x0, y0> + t<a, b>. In this case, a = 2 and b = 1.

Common mistake note:
Common mistake: Choosing B or C because of sign confusion. Remember that the line is parallel to the given vector, so the direction must match.
------------------------------------------------------------------------------

Problem 2 (Finite Line):
Find the equation of the line segment with endpoints (1, 2) and (4, 6).
A) <1, 2> + t<3, 4>
B) <4, 6> + t<-3, -4>
C) <1, 2> + t<1/3, 2>
D) <4, 6> + t<1/3, 2>
Correct Answer: A

Solution:
<1, 2> + t<3, 4>

Explanation:
The equation of a line segment with endpoints (x1, y1) and (x2, y2) is given by <x1, y1> + t(<x2-x1>, <y2-y1>). In this case, x1 = 1, y1 = 2, x2 = 4, and y2 = 6.

Common mistake note:
Common mistake: Choosing C or D because they represent a direction vector, but not the correct one for the line segment. The direction vector should be from the first endpoint to the second.
------------------------------------------------------------------------------

Problem 3 (Intersection of Lines):
Find the point of intersection between the lines given by the equations <x, y> = <1, 2> + t<3, 4> and <x, y> = <5, -1> + s<-2, 1>.
A) <0, 1>
B) <2, 3>
C) <3, 4>
D) <4, 5>
Correct Answer: A

Solution:
<0, 1>

Explanation:
To find the intersection point, set the x and y components equal for both lines and solve for t and s. For this example: 1 + 3t = 5 - 2s and 2 + 4t = -1 + s. Solving these equations gives t = 0 and s = 1.

Common mistake note:
Common mistake: Choosing C or D because they are points on the lines, but not the intersection point. Make sure to solve for t and s simultaneously.
------------------------------------------------------------------------------

Problem 4 (Parallel Lines):
Determine if the lines given by the equations <x, y> = <2, 3> + t<1, 0> and <x, y> = <4, 6> + s<2, 0> are parallel.
A) Yes
B) No
C) Cannot be determined from the information given
D) Depends on t and s
Correct Answer: A

Solution:
Yes

Explanation:
Parallel lines have equal direction vectors. The direction vector for both lines is <1, 0>, so they are parallel.

Common mistake note:
Common mistake: Choosing C or D because of the variable t and s. However, these variables do not affect the line's direction.
------------------------------------------------------------------------------

Problem 5 (Perpendicular Lines):
Determine if the lines given by the equations <x, y> = <1, 2> + t<3, 4> and <x, y> = <5, -1> + s<-2, 1> are perpendicular.
A) Yes
B) No
C) Cannot be determined from the information given
D) Depends on t and s
Correct Answer: B

Solution:
No

Explanation:
Perpendicular lines have direction vectors with a dot product equal to zero. The dot product of <3, 4> and <-2, 1> is not zero, so the lines are not perpendicular.

Common mistake note:
Common mistake: Choosing A because they might think that the lines intersect at right angles. However, this is not enough; the direction vectors must also be perpendicular.
------------------------------------------------------------------------------

Problem 6 (Line through 3 Points):
Find the equation of the line passing through points (1, 2), (3, 4), and (5, 6).
A) <1, 2> + t<2, 2>
B) <3, 4> + t<2, 2>
C) <5, 6> + t<2, 2>
D) <1, 2> + t<4, 4>
Correct Answer: A

Solution:
<1, 2> + t<2, 2>

Explanation:
The direction vector is (<x2-x1>, <y2-y1>) = (3-1, 4-2) = <2, 2>. The equation of the line passing through (1, 2) and having this direction is <1, 2> + t<2, 2>.

Common mistake note:
Common mistake: Choosing B or C because they use the wrong point as a starting position. Always choose one of the points to be the starting position for the equation.
------------------------------------------------------------------------------

Problem 7 (Line Segment through 3 Points):
Find the equation of the line segment with endpoints (1, 2) and (5, 6), passing through the point (3, 4).
A) <1, 2> + t<4, 4>
B) <3, 4> + t<2, 2>
C) <1, 2> + t<2, 2>
D) <5, 6> + t<-2, -2>
Correct Answer: B

Solution:
<3, 4> + t<2, 2>

Explanation:
The direction vector is (<x2-x1>, <y2-y1>) = (5-1, 6-2) = <4, 4>. However, since the line segment must pass through (3, 4), we use that point as the starting position and the direction vector divided by 2 to get <3, 4> + t<2, 2>.

Common mistake note:
Common mistake: Choosing A because it uses the correct direction vector but does not account for passing through (3, 4). Make sure to use the correct starting position.
