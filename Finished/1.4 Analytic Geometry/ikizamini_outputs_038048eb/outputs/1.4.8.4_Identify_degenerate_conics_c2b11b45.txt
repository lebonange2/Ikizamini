Problem 1 (:1):
Which equation represents a degenerate conic?
A) (x - 2)^2 + (y - 3)^2 = 0
B) x^2 + y^2 - 4x + 6y = 9
C) 3x^2 + 3y^2 = 12
D) x^2 - xy + y^2 = 0
Correct Answer: A

Solution:
A degenerate conic is a conic section that has collapsed into a point, a straight line, or a pair of lines. Equation A represents a circle with zero radius, which is a single point and thus a degenerate conic.

Explanation:
Equations B and C represent non-degenerate conics: B is a circle, and C is an ellipse. Equation D represents a rotated ellipse, not a degenerate conic.

Common mistake note:
Students might mistake option D for a degenerate hyperbola due to the xy term, but the presence of x^2 and y^2 terms with the same coefficient indicates an ellipse.
------------------------------------------------------------------------------

Problem 2 (:2):
Which equation represents a degenerate parabola?
A) y = 2x^2 - 4x + 2
B) y = x^2
C) y = x^3
D) y = |x|
Correct Answer: C

Solution:
A degenerate parabola is a parabola that has collapsed into a single point or a straight line. Equation C represents a cubic function, which is not a parabola and does not represent a degenerate conic.

Explanation:
Equations A and B represent regular parabolas, while D represents an absolute value function, none of which are degenerate conics.

Common mistake note:
Students might mistake option D for a degenerate parabola due to its non-standard shape, but it's not a quadratic equation and thus not a parabola.
------------------------------------------------------------------------------

Problem 3 (:3):
Which equation represents a degenerate hyperbola?
A) xy = 1
B) (x - 1)^2 - (y + 2)^2 = 0
C) x^2 - y^2 = 4
D) x^2 - xy + y^2 = 1
Correct Answer: B

Solution:
A degenerate hyperbola is a pair of intersecting lines. Equation B represents two lines that intersect at the origin, making it a degenerate hyperbola.

Explanation:
Equations A and C represent non-degenerate hyperbolas, while D represents an ellipse, none of which are degenerate.

Common mistake note:
Students might choose option D due to the xy term, but the x^2 and y^2 terms with the same coefficient indicate an ellipse rather than a degenerate hyperbola.
------------------------------------------------------------------------------

Problem 4 (:4):
Which equation represents a degenerate straight line?
A) x + 2y = 3
B) x^2 + y^2 = 1
C) x^2 - y^2 = 0
D) xy = 0
Correct Answer: D

Solution:
A degenerate straight line is a line that collapses into a single point. Equation D represents the union of two axes, x=0 and y=0, which is a pair of intersecting lines at the origin.

Explanation:
Equation A represents a non-degenerate straight line, B represents a unit circle, and C represents a hyperbola, none of which are degenerate.

Common mistake note:
Students might think option A is degenerate because it's simple, but it represents a standard linear equation.

Equation D represents a cubic function, which is not a conic at all. Equation A represents a degenerate circle (a single point), B represents a hyperbola, and C represents two intersecting lines (the axes).

Problem 6 (:6):
Which equation represents a degenerate circle?
A) x^2 + y^2 = 1
B) x^2 + y^2 = 0
C) (x - 1)^2 + (y - 1)^2 = 4
D) x^2 + xy + y^2 = 0
Correct Answer: B

Solution:
A degenerate circle is a single point. Equation B represents a circle with zero radius, which is a single point and thus a degenerate conic.

Explanation:
Equations A and C represent non-degenerate circles, while D represents an ellipse, none of which are degenerate.

Common mistake note:
Students might mistake option D for a degenerate hyperbola due to the xy term, but it's an ellipse with x^2 and y^2 terms having the same coefficient.

Problem 7 (:7):
Which equation represents a degenerate parabola that collapses into a straight line?
A) y = x^2 + 2x + 1
B) y = |x|
C) y = x^3 - 3x^2 + 3x
D) y = x|x|
Correct Answer: C

Solution:
A degenerate parabola that collapses into a straight line has the form y = ax^2 + bx + c, where a = 0. Equation C represents a cubic function with no quadratic term (a=0), which is not a parabola but still not a degenerate conic.

Explanation:
Equations A and B represent non-degenerate curves: A is a regular parabola, and B is an absolute value function. Equation D represents a piecewise linear function, not a degenerate parabola.

Common mistake note:
Students might mistake option B for a degenerate parabola due to its shape, but it's not a quadratic equation and thus not a parabola.
