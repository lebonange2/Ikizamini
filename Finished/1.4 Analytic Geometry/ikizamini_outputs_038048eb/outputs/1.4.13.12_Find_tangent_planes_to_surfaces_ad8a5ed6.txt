Problem 1 (:1):
Find the equation of the tangent plane to the surface z = x^2 + y^2 at the point (1, 2, 5).
A) (x - 1) + 4(y - 2) + 2(z - 5) = 0
B) 2(x - 1) + (y - 2) + 5(z - 5) = 0
C) (x - 1) + 2(y - 2) + 4(z - 5) = 0
D) 4(x - 1) + 2(y - 2) + (z - 5) = 0
Correct Answer: D

Solution:
The gradient vector of the surface z = x^2 + y^2 is given by ∇f = <2x, 2y, -1>. At the point (1, 2, 5), the gradient vector becomes <2, 4, -1>. The equation of the tangent plane at a point (a, b, c) with normal vector n is given by: n·(P - A) = 0, where P = (x, y, z) and A = (a, b, c). Plugging in the values, we get <2, 4, -1>·<x - 1, y - 2, z - 5> = 0. Expanding this gives: 2(x - 1) + 4(y - 2) - (z - 5) = 0, which simplifies to 4(x - 1) + 2(y - 2) + (z - 5) = 0.

Explanation:
The gradient vector is used to find the normal vector of the tangent plane. The dot product of the normal vector and the difference between an arbitrary point on the plane and the given point should be zero.

Common mistake note:
A common mistake is to forget that the negative sign in front of z comes from ∂f/∂z, which gives -1. This leads to choosing answer A or B.

Problem 3 (:3):
Find the equation of the tangent plane to the surface xy + yz +zx = 6 at the point (1, 2, 3).
A) (x - 1) + 2(y - 2) + 3(z - 3) = 0
B) x(y - 2) + 2(y - 2)(z - 3) + 3(z - 3)(x - 1) = 6
C) (x - 1) + (y - 2) + (z - 3) = 0
D) 2(x - 1) + 3(y - 2) + 6(z - 3) = 0
Correct Answer: A

Solution:
The gradient vector of the surface xy + yz +zx = 6 is given by ∇f = <y + z, x + z, x + y>. At the point (1, 2, 3), the gradient vector becomes <5, 4, 3>. The equation of the tangent plane at a point (a, b, c) with normal vector n is given by: n·(P - A) = 0, where P = (x, y, z) and A = (a, b, c). Plugging in the values, we get <5, 4, 3>·<x - 1, y - 2, z - 3> = 0. Expanding this gives: 5(x - 1) + 4(y - 2) + 3(z - 3) = 0, which simplifies to (x - 1) + 2(y - 2) + 3(z - 3) = 0.

Explanation:
The gradient vector is used to find the normal vector of the tangent plane. The dot product of the normal vector and the difference between an arbitrary point on the plane and the given point should be zero.

Common mistake note:
A common mistake is to think that the equation of the tangent plane is just the original function evaluated at the given point, leading to choosing answer B.
