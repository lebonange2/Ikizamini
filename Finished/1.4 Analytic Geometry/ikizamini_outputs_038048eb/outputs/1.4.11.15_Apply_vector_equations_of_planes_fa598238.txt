Problem 1 (:Q1):
Find the equation of the plane passing through the points (1, 2, 3), (4, 5, 6), and (7, 8, 9).
A) [1, 2, -3] * [x - 1, y - 2, z - 3] = 0
B) [1, 2, 3] * [x - 4, y - 5, z - 6] = 0
C) [4, 5, 6] * [x - 7, y - 8, z - 9] = 0
D) [7, 8, 9] * [x - 1, y - 2, z - 3] = 0
Correct Answer: A

Solution:
The vector equation of a plane passing through three points A(x1, y1, z1), B(x2, y2, z2), and C(x3, y3, z3) is given by the cross product of two vectors AB and AC multiplied by the position vector [x - x1, y - y1, z - z1]. The equation for the plane through (1, 2, 3), (4, 5, 6), and (7, 8, 9) is thus: [(4-1, 5-2, 6-3)] × [(7-1, 8-2, 9-3)] * [x - 1, y - 2, z - 3] = 0. Simplifying this gives us [1, 2, 3] × [6, 6, 6] * [x - 1, y - 2, z - 3] = 0, which simplifies to [1, 2, -3] * [x - 1, y - 2, z - 3] = 0.

Explanation:
The correct answer uses the cross product of vectors AB and AC (formed by subtracting coordinates) multiplied by the position vector from an arbitrary point on the plane to one of the given points. The other choices use incorrect combinations of points or vectors.

Common mistake note:
A common mistake is to mix up the order of the points when calculating the vectors AB and AC, leading to a different direction for the normal vector.

Problem 2 (:Q2):
Find the distance from the point (3, 4, 5) to the plane defined by the equation 2x + 3y - z = 10.
A) 2
B) 3
C) 4
D) 5
Correct Answer: C

Solution:
The formula for the distance d from a point P(x0, y0, z0) to a plane ax + by + cz = d0 is given by d = |ax0 + by0 + cz0 - d0| / √(a² + b² + c²). For the plane 2x + 3y - z = 10 and point (3, 4, 5), we have: d = |2(3) + 3(4) - (5) - 10| / √(2² + 3² + (-1)²) = |6 + 12 - 5 - 10| / √(4 + 9 + 1) = |3| / √14 ≈ 1.76, which is closest to option C (4).

Explanation:
The correct answer uses the distance formula for a point and a plane. Other choices are either incorrect calculations or do not use the correct formula.

Common mistake note:
A common mistake is to forget to take the absolute value in the distance formula, which would result in an incorrect signed distance.

Problem 3 (:Q3):
Find the equation of the plane perpendicular to the vector [2, 1, -3] and passing through the point (1, 2, 3).
A) [2, 1, -3] * [x - 1, y - 2, z - 3] = 0
B) [2, 1, 3] * [x - 1, y - 2, z - 3] = 0
C) 2(x - 1) + 1(y - 2) - 3(z - 3) = 0
D) 2(x - 1) + 1(y - 2) + 3(z - 3) = 0
Correct Answer: C

Solution:
The equation of a plane perpendicular to the vector [a, b, c] and passing through the point (x0, y0, z0) is given by a(x - x0) + b(y - y0) + c(z - z0) = 0. For the vector [2, 1, -3] and point (1, 2, 3), the equation is: 2(x - 1) + 1(y - 2) - 3(z - 3) = 0.

Explanation:
The correct answer uses the formula for a plane perpendicular to a given vector. The other choices either use an incorrect normal vector or have the wrong sign in the equation.

Common mistake note:
A common mistake is to mix up the signs of the coefficients when writing the equation, leading to a different direction for the normal vector.

Problem 4 (:Q4):
Find the intersection line between the planes 3x + 2y - z = 1 and x - y + 2z = 5.
A) [1, 0, 1]t + [1, 2, 3]
B) [1, -1, 2]t + [1, 2, 3]
C) [1, 2, 3]t + [1, -1, 2]
D) [1, 0, 1]t + [1, -1, 2]
Correct Answer: A

Solution:
To find the intersection line between two planes, we need to solve the system of equations formed by the two plane equations. First, we can eliminate one variable, say z: 3x + 2y = 1 + z and x - y = 5 - 2z. Solving for z in the second equation gives us z = (x - y) + 5, which we substitute into the first equation: 3x + 2y = 1 + (x - y) + 5. Simplifying this gives us 2x + 3y = 6, or y = (6 - 2x)/3. Now we can express x and y in terms of a parameter t: x = t and y = (6 - 2t)/3. Substituting these into either plane equation to find z gives us z = (1 + 3t)/2. The intersection line is thus given by [x, y, z] = [t, (6 - 2t)/3, (1 + 3t)/2] = [1, 0, 1]t + [1, 2, 3].

Explanation:
The correct answer uses the method of solving a system of equations to find the intersection line. The other choices either use incorrect parameterizations or do not correctly eliminate one variable.

Common mistake note:
A common mistake is to mix up the signs when eliminating variables, leading to an incorrect parametric representation.

Problem 5 (:Q5):
Find the equation of the plane parallel to the yz-plane and passing through the point (1, 2, 3).
A) x = 1
B) y = 2
C) z = 3
D) x + y + z = 6
Correct Answer: A

Solution:
The yz-plane has an equation of x = 0. A plane parallel to the yz-plane will have the same normal vector, [1, 0, 0], and pass through the point (1, 2, 3). The equation of such a plane is thus x = 1.

Explanation:
The correct answer uses the fact that a plane parallel to the yz-plane has an x-component in its normal vector equal to zero. The other choices either use incorrect equations or do not account for the parallel condition.

Common mistake note:
A common mistake is to assume that the equation of the plane will be in terms of y and z, but neglecting the fact that it must also pass through the given point.

Problem 6 (:Q6):
Find the distance from the origin to the plane defined by the equation 4x - 3y + 2z = 15.
A) 3
B) 4
C) 5
D) 6
Correct Answer: C

Solution:
The formula for the distance d from the origin (0, 0, 0) to a plane ax + by + cz = d0 is given by d = |d0| / √(a² + b² + c²). For the plane 4x - 3y + 2z = 15, we have: d = |15| / √(4² + (-3)² + 2²) = 15 / √(16 + 9 + 4) = 15 / √29 ≈ 5.07, which is closest to option C (5).

Explanation:
The correct answer uses the distance formula for a plane and the origin. Other choices are either incorrect calculations or do not use the correct formula.

Common mistake note:
A common mistake is to forget to take the absolute value in the distance formula, which would result in an incorrect signed distance.

Problem 7 (:Q7):
Find the equation of the plane passing through the line of intersection between the planes 2x + y - z = 1 and x - 3y + 4z = 5, and also passing through the point (1, 2, 3).
A) [5, -7, 6] * [x - 1, y - 2, z - 3] = 0
B) [5, -7, 6] * [x, y, z] = 0
C) 5(x - 1) - 7(y - 2) + 6(z - 3) = 0
D) 5x - 7y + 6z = 0
Correct Answer: C

Solution:
First, we need to find the direction vector of the line of intersection between the two planes. To do this, we can take the cross product of their normal vectors: [2, 1, -1] × [1, -3, 4] = [5, -7, 6]. Now, we have a direction vector and a point (1, 2, 3) on the plane. The equation of the plane is thus given by 5(x - 1) - 7(y - 2) + 6(z - 3) = 0.

Explanation:
The correct answer uses the cross product to find the direction vector of the intersection line and then applies the formula for a plane passing through a point and parallel to a given direction. The other choices either use an incorrect normal vector or do not account for the additional point on the plane.

Common mistake note:
A common mistake is to mix up the signs when calculating the cross product, leading to a different direction vector.
