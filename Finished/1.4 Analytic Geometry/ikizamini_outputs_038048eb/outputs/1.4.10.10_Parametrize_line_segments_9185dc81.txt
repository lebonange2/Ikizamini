Problem 1 (Asdf):
Find the parametric equations for the line segment connecting points A(2, 3) and B(5, 7).
A) [x(t) = 2t + 2, y(t) = 4t + 3, 0 ≤ t ≤ 1]
B) [x(t) = 5 - 2t, y(t) = 7 - 4t, 0 ≤ t ≤ 1]
C) [x(t) = 3t + 2, y(t) = 3t + 7, 0 ≤ t ≤ 1]
D) [x(t) = 5t + 2, y(t) = 7t + 3, 0 ≤ t ≤ 1]
Correct Answer: A

Solution:
The parametric equations for a line segment connecting two points (x1, y1) and (x2, y2) can be found using the formula x(t) = x1 + (x2 - x1)t and y(t) = y1 + (y2 - y1)t. For A(2, 3) and B(5, 7), we have x(t) = 2 + (5 - 2)t = 2t + 2 and y(t) = 3 + (7 - 3)t = 4t + 3. The limits of t are from 0 to 1 because at t=0 the point is A, and at t=1 it's B.

Explanation:
The correct parametric equations maintain a linear relationship between t and the change in x and y coordinates between points A and B.

Common mistake note:
A common mistake would be to reverse the direction of the line by using (x2 - x1) as the coefficient for t, which would result in choice C. This fails because it traces the line from B back to A instead of from A to B.
