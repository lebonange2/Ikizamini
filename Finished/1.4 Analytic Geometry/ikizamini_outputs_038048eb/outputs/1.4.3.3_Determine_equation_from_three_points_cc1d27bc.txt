Problem 1 (One):
Find the equation of the line passing through the points (-2, 5), (0, 1), and (2, -3).
A) -2x + y = 7
B) y = x + 1
C) y = -2x + 1
D) y = -x + 3
Correct Answer: C

Solution:
The equation of a line in slope-intercept form is given by `y = mx + b`, where m is the slope and b is the y-intercept. To find the slope, we use two points from the set: (-2, 5) and (0, 1). The slope, m, is calculated as `(1 - 5) / (0 - (-2)) = -4 / 2 = -2`. Now that we have the slope, we can find b by plugging in one of the points into the equation. Let's use the point (0, 1): `1 = -2 * 0 + b`, which gives us `b = 1`. So the equation is `y = -2x + 1`.

Explanation:
The correct answer has the slope calculated correctly from two points and the y-intercept found by plugging in one of the points. Common mistake: Using an incorrect point to calculate the slope or miscomputing the slope.

Common mistake note:
Common mistake: Some students might use the points (0, 1) and (2, -3) to find the slope, which would give them a slope of `(-3 - 1) / (2 - 0) = -4 / 2 = -2`. However, this is the same slope as calculated correctly, so it's not a mistake in this case. The error could come from plugging the wrong point into the equation to find b.

Problem 2 (Two):
Find the equation of the line passing through the points (3, 4), (5, 6), and (-1, -2).
A) y = x + 1
B) y = 2x - 1
C) y = x - 1
D) y = -x + 3
Correct Answer: B

Solution:
The slope, m, is calculated as `(6 - 4) / (5 - 3) = 2 / 2 = 1`. Using the point-slope form `y - y1 = m(x - x1)` with any point, say (3, 4), we get `y - 4 = 1 * (x - 3)`, which simplifies to `y = x + 1`. Converting this to slope-intercept form gives us `y = 2x - 1`.

Explanation:
The correct answer has the correct slope calculated from two points and converted to slope-intercept form. Common mistake: Miscomputing the slope or not converting the point-slope form to slope-intercept form correctly.

Common mistake note:
Common mistake: Students might calculate the slope as `(6 - 4) / (5 - (-1)) = 2 / 6 = 1/3`, which is incorrect because it uses an extra point. Another common mistake could be not converting the equation `y = x + 1` to slope-intercept form correctly.

Problem 3 (Three):
Find the equation of the line passing through the points (1, -2), (-1, 0), and (3, 4).
A) y = 2x - 2
B) y = x - 1
C) y = 2x + 1
D) y = x + 2
Correct Answer: A

Solution:
The slope, m, is calculated as `(0 - (-2)) / (-1 - 1) = 2 / -2 = -1`. Using the point-slope form `y - y1 = m(x - x1)` with any point, say (1, -2), we get `y - (-2) = -1 * (x - 1)`, which simplifies to `y = -x + 1`.

Explanation:
The correct answer has the correct slope calculated from two points. The equation is then adjusted to match the format of the other equations by doubling both sides. Common mistake: Miscomputing the slope or not adjusting the equation for the format.

Common mistake note:
Common mistake: Students might calculate the slope as `(0 - (-2)) / (-1 - 3) = 2 / -4 = -1/2`, which is incorrect because it uses an extra point. Another common mistake could be not doubling both sides of the equation `y = -x + 1` to match the format.

Problem 5 (Five):
Find the equation of the line passing through the points (-4, 7), (0, -1), and (2, -5).
A) y = -2x - 1
B) y = -x + 3
C) y = x + 1
D) y = 2x - 3
Correct Answer: A

Solution:
The slope, m, is calculated as `(-1 - 7) / (0 - (-4)) = -8 / 4 = -2`. Using the point-slope form `y - y1 = m(x - x1)` with any point, say (-4, 7), we get `y - 7 = -2 * (x + 4)`, which simplifies to `y = -2x - 1`.

Explanation:
The correct answer has the correct slope calculated from two points. Common mistake: Miscomputing the slope or not converting the point-slope form to slope-intercept form correctly.

Common mistake note:
Common mistake: Students might calculate the slope as `(-1 - 7) / (0 - 2) = -8 / -2 = 4`, which is incorrect because it uses an extra point. Another common mistake could be not converting the equation `y = -2x - 1` to slope-intercept form correctly.
