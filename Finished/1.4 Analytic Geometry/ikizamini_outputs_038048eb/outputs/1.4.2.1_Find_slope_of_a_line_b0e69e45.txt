Problem 1 (:1):
What is the slope of the line passing through points (3, 5) and (7, 9)?
A) -2
B) 2
C) 4/5
D) 5/4
Correct Answer: D

Solution:
The slope (m) of a line passing through two points (x1, y1) and (x2, y2) can be calculated using the formula: m = (y2 - y1) / (x2 - x1). For the given points (3, 5) and (7, 9), we have m = (9 - 5) / (7 - 3) = 4 / 4 = 1. However, since the answer choices are not in slope-intercept form, we must convert the slope to a fraction: 1 as a fraction is 5/4.

Explanation:
The correct choice is D because it represents the slope of the line in its simplest fractional form.

Common mistake note:
A common mistake would be to directly calculate the difference between y values (9 - 5 = 4) and x values (7 - 3 = 4), dividing them without simplifying, which results in choice C (4/4). This is a correct decimal value for slope but not in the expected fractional form.

Problem 2 (2):
Find the slope of the line given by the equation y = 3x - 1.
A) -1
B) 0
C) 1/3
D) 3
Correct Answer: D

Solution:
The slope (m) of a line in slope-intercept form (y = mx + b) is the coefficient of x. For the equation y = 3x - 1, the slope m is 3.

Explanation:
The correct choice is D because it directly corresponds to the coefficient of x in the given linear equation.

Common mistake note:
A common mistake would be to confuse the constant term (-1) with the slope. Another possible error might be dividing both sides by y, which could lead to a misunderstanding that the slope is 1/3 (choice C), but this manipulation changes the form of the equation.
------------------------------------------------------------------------------

Problem 3 (3):
What is the slope of the line parallel to y = 2x + 7?
A) -2
B) 0
C) 1/2
D) 2
Correct Answer: D

Solution:
Lines that are parallel have equal slopes. The given equation is in slope-intercept form (y = mx + b), with m = 2. Therefore, any line parallel to it will also have a slope of 2.

Explanation:
The correct choice is D because parallel lines maintain the same slope.

Common mistake note:
A common mistake would be to assume that parallel lines have no slope (choice B) or to confuse them with perpendicular lines, which have slopes that are negative reciprocals (e.g., choice A).
------------------------------------------------------------------------------

Problem 4 (4):
Find the slope of the line passing through the origin and the point (-3, 6).
A) -2
B) 2
C) 1/2
D) 2/3
Correct Answer: A

Solution:
The slope (m) of a line passing through the origin (0, 0) and a point (x, y) can be calculated using the formula: m = y / x. For the given points (0, 0) and (-3, 6), we have m = 6 / -3 = -2.

Explanation:
The correct choice is A because it represents the slope of the line passing through the origin and the specified point.

Common mistake note:
A common mistake would be to divide x by y instead of y by x, which would result in a positive slope (choice B). Another possible error might be to forget that the origin has coordinates (0, 0), leading to an incorrect calculation.
------------------------------------------------------------------------------

Problem 5 (5):
What is the slope of the line perpendicular to y = -4x + 2?
A) -1/4
B) 1/4
C) 4
D) -4
Correct Answer: A

Solution:
Lines that are perpendicular have slopes that are negative reciprocals of each other. The given equation is in slope-intercept form (y = mx + b), with m = -4. The slope of a line perpendicular to it will be the negative reciprocal, which is 1/4.

Explanation:
The correct choice is A because it represents the slope of a line perpendicular to the given line.

Common mistake note:
A common mistake would be to choose the reciprocal (4) instead of the negative reciprocal (choice C), or to assume that perpendicular lines have slopes that add up to zero, leading to choices B (-1/4) and D (-4).

Problem 6 (6):
Find the slope of a line with an angle of 30° measured counterclockwise from the positive x-axis.
A) -√3
B) 1
C) √3/3
D) √3
Correct Answer: C

Solution:
The slope (m) of a line with an angle θ in radians can be calculated using the formula: m = tan(θ). For 30°, we first convert it to radians: θ = π/6. The slope is then m = tan(π/6) = √3 / 3.

Explanation:
The correct choice is C because it represents the slope of a line with an angle of 30° in radians.

Common mistake note:
A common mistake would be to use degrees directly without converting them to radians, which could lead to incorrect calculations. Another possible error might be to choose the tangent value for 60° (choice D) instead of 30°.
------------------------------------------------------------------------------

Problem 7 (7):
Find the slope of a line that is horizontal.
A) 0
B) 1
C) undefined
D) any real number
Correct Answer: A

Solution:
A horizontal line has no change in y for any change in x, so its slope (m) is 0.

Explanation:
The correct choice is A because a horizontal line's slope is always zero.

Common mistake note:
A common mistake would be to choose 'undefined' (choice C), which typically refers to the slope of a vertical line. Another possible error might be to select 'any real number' (choice D), thinking that any value could be the slope, but this is not true for horizontal lines.
