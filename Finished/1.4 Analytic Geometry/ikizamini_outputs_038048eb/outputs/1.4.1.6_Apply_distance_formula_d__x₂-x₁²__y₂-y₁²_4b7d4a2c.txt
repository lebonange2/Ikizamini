Problem 1 (:1):
Find the distance between points A(3, 4) and B(-2, 6).
A) 5
B) √26
C) 7
D) 9
Correct Answer: B

Solution:
Using the distance formula: d = √[(x₂-x₁)² + (y₂-y₁)²]
d = √[(-2-3)² + (6-4)²]
d = √[(-5)² + (2)²]
d = √[25 + 4]
d ≈ √29
The distance is approximately √29.

Explanation:
The distance formula calculates the straight-line distance between two points in a coordinate plane. The correct answer is found by plugging the coordinates of A and B into the formula and simplifying.

Common mistake note:
Common mistake: Using the wrong order for subtraction in the formula (x₂-x₁ instead of x₁-x₂ or y₂-y₁ instead of y₁-y₂). This would result in a different value, leading to an incorrect distance.

Problem 2 (2):
What is the distance between point C(0, 0) and D(4, 3)?
A) 5
B) √16
C) √25
D) √5
Correct Answer: A

Solution:
Using the distance formula: d = √[(x₂-x₁)² + (y₂-y₁)²]
d = √[(4-0)² + (3-0)²]
d = √[4² + 3²]
d = √16
The square root of 16 is 4.

Explanation:
The distance formula can be applied to any two points, including the origin. The correct answer is found by plugging the coordinates into the formula and simplifying.

Common mistake note:
Common mistake: Forgetting that the point C(0, 0) is the origin, which makes x₁=0 and y₁=0. This may lead to unnecessary calculations or mistakes in the formula.

Problem 3 (3):
Find the distance between points E(-1, -2) and F(3, -5).
A) 4
B) √10
C) √13
D) √20
Correct Answer: C

Solution:
Using the distance formula: d = √[(x₂-x₁)² + (y₂-y₁)²]
d = √[(3-(-1))² + (-5-(-2))²]
d = √[4² + (-3)²]
d ≈ √25
The distance is approximately 5.

Explanation:
The distance formula works for any two points in the coordinate plane. The correct answer is found by plugging the coordinates into the formula and simplifying.

Common mistake note:
Common mistake: Mixing up the signs when subtracting negative values (e.g., -5-(-2) instead of -5+2). This would lead to a different value, resulting in an incorrect distance.
