Problem 1 (OneTranslation):
Given a point (x, y) and a translation matrix T = [[1, 0, 5], [0, 1, 3], [0, 0, 1]], what are the new coordinates after applying the transformation?
A) [x+5, y+3]
B) [x+3, y+5]
C) [x-5, y-3]
D) [x, y]
Correct Answer: A

Solution:
The translation matrix T shifts the point (x, y) by 5 units in the x-direction and 3 units in the y-direction. So, the new coordinates are (x+5, y+3).

Explanation:
An affine transformation preserves collinearity and ratios of distances; in this case, it only translates the point without rotation or scaling.

Common mistake note:
A common mistake is to mix up the translation values, applying them incorrectly. Make sure to apply the x-value change to the x-coordinate and the y-value change to the y-coordinate.

Problem 2 (TwoScaling):
Given a point (x, y) and a scaling matrix S = [[2, 0, 0], [0, 3, 0], [0, 0, 1]], what are the new coordinates after applying the transformation?
A) [2x, 3y]
B) [x/2, y/3]
C) [x+2, y+3]
D) [2x+3y, x+y]
Correct Answer: A

Solution:
The scaling matrix S scales the point (x, y) by a factor of 2 in the x-direction and 3 in the y-direction. So, the new coordinates are (2x, 3y).

Explanation:
An affine transformation preserves collinearity and ratios of distances; in this case, it only scales the point without rotation or translation.

Common mistake note:
A common mistake is to forget that scaling multiplies each coordinate by a factor, not adding or subtracting. Make sure to multiply the original coordinates by the corresponding scale factors.

Problem 3 (ThreeRotation):
Given a point (x, y) and a rotation matrix R = [[cos(π/4), -sin(π/4), 0], [sin(π/4), cos(π/4), 0], [0, 0, 1]], what are the new coordinates after applying the transformation?
A) [x√2/2 - y√2/2, x√2/2 + y√2/2]
B) [x√2/2 + y√2/2, x√2/2 - y√2/2]
C) [x+y, x-y]
D) [x, y]
Correct Answer: B

Solution:
The rotation matrix R rotates the point (x, y) by π/4 radians counterclockwise. Using trigonometry, we get the new coordinates as (x√2/2 + y√2/2, x√2/2 - y√2/2).

Explanation:
An affine transformation preserves collinearity and ratios of distances; in this case, it only rotates the point without scaling or translation.

Common mistake note:
A common mistake is to forget that rotation changes both coordinates simultaneously. Make sure to use trigonometry to find the new coordinates after rotation.

Problem 4 (FourShear):
Given a point (x, y) and a shear matrix S = [[1, 2, 0], [0, 1, 0], [0, 0, 1]], what are the new coordinates after applying the transformation?
A) [x+2y, y]
B) [x-2y, y]
C) [x, y+2x]
D) [x, y]
Correct Answer: A

Solution:
The shear matrix S shears the point (x, y) in the x-direction by a factor of 2. So, the new coordinates are (x + 2y, y).

Explanation:
An affine transformation preserves collinearity and ratios of distances; in this case, it only shears the point without rotation or scaling.

Common mistake note:
A common mistake is to misunderstand how shear affects the coordinates. Make sure to apply the shear factor to the x-coordinate while keeping the y-coordinate unchanged.

Problem 5 (FiveReflection):
Given a point (x, y) and a reflection matrix R = [[-1, 0, 0], [0, 1, 0], [0, 0, 1]], what are the new coordinates after applying the transformation?
A) [-x, y]
B) [x, -y]
C) [x+y, x-y]
D) [x, y]
Correct Answer: A

Solution:
The reflection matrix R reflects the point (x, y) about the y-axis. So, the new coordinates are (-x, y).

Explanation:
An affine transformation preserves collinearity and ratios of distances; in this case, it only reflects the point across a line without scaling or rotation.

Common mistake note:
A common mistake is to forget that reflection changes only one coordinate. Make sure to reflect the x-coordinate while keeping the y-coordinate unchanged.

Problem 6 (SixCompositionTranslationScaling):
Given a point (x, y) and two matrices T = [[1, 0, 5], [0, 1, 3], [0, 0, 1]] for translation and S = [[2, 0, 0], [0, 3, 0], [0, 0, 1]] for scaling, what are the new coordinates after applying T followed by S?
A) [2x+5, 3y+3]
B) [2x-5, 3y-3]
C) [x+2, y+3]
D) [x, y]
Correct Answer: A

Solution:
First apply the translation matrix T to get (x+5, y+3), then apply the scaling matrix S to get (2(x+5), 3(y+3)) or (2x+10, 3y+9). However, since we only need the result after applying both transformations in sequence, we have [2x+5, 3y+3].

Explanation:
When composing transformations, apply them from right to left. First translate, then scale.

Common mistake note:
A common mistake is to apply the scaling before translation or mixing up the order of operations. Remember to apply transformations in the correct sequence.

Problem 7 (SevenCompositionRotationShear):
Given a point (x, y) and two matrices R = [[cos(π/4), -sin(π/4), 0], [sin(π/4), cos(π/4), 0], [0, 0, 1]] for rotation and S = [[1, 2, 0], [0, 1, 0], [0, 0, 1]] for shear, what are the new coordinates after applying R followed by S?
A) [x√2/2 + y√2/2 + 2(x√2/2 - y√2/2), x√2/2 - y√2/2]
B) [x√2/2 + y√2/2, x√2/2 - y√2/2]
C) [x+2y, y]
D) [x, y]
Correct Answer: A

Solution:
First apply the rotation matrix R to get (x√2/2 + y√2/2, x√2/2 - y√2/2), then apply the shear matrix S to get [(x√2/2 + y√2/2) + 2(x√2/2 - y√2/2), x√2/2 - y√2/2] or [x+2y, y]. However, since we only need the result after applying both transformations in sequence, we have [x√2/2 + y√2/2 + 2(x√2/2 - y√2/2), x√2/2 - y√2/2].

Explanation:
When composing transformations, apply them from right to left. First rotate, then shear.

Common mistake note:
A common mistake is to apply the shear before rotation or mixing up the order of operations. Remember to apply transformations in the correct sequence.
