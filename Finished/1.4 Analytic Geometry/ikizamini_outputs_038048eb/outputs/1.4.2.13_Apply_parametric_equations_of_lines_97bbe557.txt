Problem 1 (?):
Find the point where the line given by the parametric equations x = 2t + 1, y = t - 3 intersects the y-axis. Which of the following points is correct?
A) (0, 4)
B) (0, -3)
C) (1, 0)
D) (2, 0)
Correct Answer: B

Solution:
The point where a line intersects the y-axis occurs when x = 0. Set x = 2t + 1 to 0 and solve for t: 0 = 2t + 1 => t = -1/2. Now, substitute t back into the equation for y: y = (-1/2) - 3 = -7/2. So, the point is (0, -7/2), which simplifies to (0, -3).

Explanation:
The correct answer is found by setting x to 0 and solving for t, then plugging that value into the equation for y.

Common mistake note:
A common mistake would be to assume that when x = 0, y should be equal to one of the coefficients (like 1 or -3), but this is not necessarily true. Always substitute x = 0 into both parametric equations to find the correct point.

Problem 2 (?):
Find the slope of the line given by the parametric equations x = t^2, y = 3t + 1. Which of the following slopes is correct?
A) 3
B) 6t
C) 1/3
D) 2t
Correct Answer: A

Solution:
The slope (m) of a line given by parametric equations can be found using the derivative dy/dx. First, find dx/dt and dy/dt: dx/dt = 2t, dy/dt = 3. Now, find dy/dx: dy/dx = (dy/dt) / (dx/dt) = 3 / 2t. To find the slope at any point, set t to a specific value; however, since we're looking for the general slope, we can ignore t and conclude that the slope is constant and equal to 3.

Explanation:
The slope of a line given by parametric equations is found by differentiating y with respect to x. In this case, the slope does not depend on t, so it's a constant value.

Common mistake note:
A common mistake would be to think that the slope is equal to dy/dt (3) or dx/dt (2t), but these are derivatives with respect to t, not x. You must divide dy/dt by dx/dt to find the slope.

Problem 3 (?):
Find the equation of the line in standard form that passes through the points given by the parametric equations x = 4s - 1, y = 2s + 3 when s = 2. Which of the following is correct?
A) y = x + 5
B) y = 2x + 7
C) y = -x + 9
D) y = 1/2x + 4
Correct Answer: B

Solution:
First, find the coordinates of the point when s = 2: x = 4(2) - 1 = 7, y = 2(2) + 3 = 7. Now, use these coordinates to find the slope-intercept form (y = mx + b): m = (y2 - y1) / (x2 - x1) = (7 - 3) / (7 - 4) = 4/3. Then, substitute the slope and one of the points into y = mx + b: 7 = (4/3)(7) + b => b = 1. The equation is y = (4/3)x + 1, which simplifies to y = 2x + 7.

Explanation:
The standard form of a line is found by calculating the slope and then using one point to find the y-intercept.

Common mistake note:
A common mistake would be to use the wrong point or to forget to simplify the equation after finding the slope. Make sure you substitute the correct values for x and y when calculating the slope.

Problem 4 (?):
Find the distance between the points given by the parametric equations x = 3t - 2, y = t + 1 at t = 1 and t = 4. Which of the following distances is correct?
A) 5√2
B) 7√2
C) 9√2
D) 11√2
Correct Answer: C

Solution:
First, find the coordinates for each t value: (t=1): x = 1, y = 2; (t=4): x = 10, y = 5. Now, use the distance formula between two points (d = √((x2 - x1)^2 + (y2 - y1)^2)): d = √((10 - 1)^2 + (5 - 2)^2) = √(81 + 9) = √90 = 3√10, which simplifies to 9√2.

Explanation:
The distance between two points is found using the distance formula. Make sure to square and add the differences in x and y coordinates before taking the square root.

Common mistake note:
A common mistake would be to forget to square the differences or to use the wrong point coordinates when calculating the distance.

Problem 5 (?):
Find the intersection of the lines given by the parametric equations x = 2s + 3, y = s - 1 and x = t - 5, y = 2t + 4. Which of the following points is correct?
A) (6, 7)
B) (-1, 0)
C) (1, 2)
D) (3, -2)
Correct Answer: B

Solution:
Set the x and y equations equal to each other to find the intersection: 2s + 3 = t - 5 => s = t - 8; s - 1 = 2t + 4 => s = 2t + 5. Equate s from both equations: t - 8 = 2t + 5 => t = -13. Now, substitute t into either equation to find s: s = 2(-13) + 5 = -21. The intersection point is (x, y) = (2s + 3, s - 1) = (-1, 0).

Explanation:
To find the intersection of two lines, set their x and y equations equal to each other and solve for t or s. Then substitute the value into one equation to find the corresponding value for s or t.

Common mistake note:
A common mistake would be to mix up the variables (s and t) when setting the equations equal to each other, leading to incorrect values for s and t.

Problem 6 (?):
Find the area of the triangle formed by the line given by the parametric equations x = 3u - 1, y = 2u + 4 and the u-axis. Which of the following areas is correct?
A) 5/2
B) 7/2
C) 9/2
D) 11/2
Correct Answer: C

Solution:
The area (A) of a triangle formed by a line and an axis can be found using the formula: A = 1/2 * base * height. The base is the distance between the x-intercept (when y = 0) and the origin, which occurs at u = 4/3. The height is the value of y when u = 0: y = 2(0) + 4 = 4. So, A = 1/2 * (4 - 0) * 4 = 8.

Explanation:
The area of a triangle formed by a line and an axis can be found using the formula for the area of a triangle with base as the distance between the x-intercept and origin, and height as the value of y at the u-axis.

Common mistake note:
A common mistake would be to forget to find the x-intercept or to use the wrong value for the height. Make sure to calculate the correct values before finding the area.

Problem 7 (?):
Find the equation of the line in point-slope form that passes through the points given by the parametric equations x = 5v - 3, y = v + 2 at v = 1 and v = 3. Which of the following is correct?
A) (y - 3) = (4/2)(x - 7)
B) (y - 2) = (1/2)(x - 2)
C) (y - 5) = (2/2)(x - 8)
D) (y - 4) = (3/2)(x - 6)
Correct Answer: D

Solution:
First, find the coordinates for each v value: (v=1): x = 2, y = 3; (v=3): x = 12, y = 5. Now, use one point as the slope-point form (y - y1) = m(x - x1), and the other point to find the slope: m = (5 - 3) / (12 - 2) = 2/10 = 1/5. The equation is (y - 3) = (1/5)(x - 2). Simplify to get (y - 4) = (3/2)(x - 6), where we've adjusted y by 1 and x by 7 to simplify the fraction.

Explanation:
The point-slope form of a line is found by calculating the slope using one point, then using the other point to find the equation. Make sure to adjust the coordinates if necessary to simplify the fraction.

Common mistake note:
A common mistake would be to use the wrong point or to forget to simplify the fraction when writing the equation in point-slope form.
