Problem 1 (One):
Find the derivative of f(x) = x^3 * e^x using the product rule.
A) 3x^2 * e^x + x^3 * e^x
B) x^2 * e^x + x^3 * e^x
C) 3x^2 * e^(2x)
D) x^3 * e^(x+1)
Correct Answer: A

Solution:
The product rule states that if you have a function f(x) = u(x)v(x), the derivative is f'(x) = u'(x)v(x) + u(x)v'(x). Here, u(x) = x^3 and v(x) = e^x. The derivatives are u'(x) = 3x^2 and v'(x) = e^x. Applying the product rule: f'(x) = (3x^2)(e^x) + (x^3)(e^x) = 3x^2 * e^x + x^3 * e^x.

Explanation:
The correct answer is A because it correctly applies the product rule by multiplying each derivative with the other function in the original expression.

Common mistake note:
A common mistake would be to forget to multiply one of the derivatives with the other function, resulting in an incorrect sum. For example, choosing B would be a mistake as it only includes one term from the product rule.

Problem 2 (Two):
Find the derivative of g(x) = sin(x) * cos(x) using the product rule.
A) cos^2(x) - sin^2(x)
B) sin(x) * cos(x)
C) cos(2x)
D) sin(2x)
Correct Answer: C

Solution:
The product rule states that if you have a function g(x) = u(x)v(x), the derivative is g'(x) = u'(x)v(x) + u(x)v'(x). Here, u(x) = sin(x) and v(x) = cos(x). The derivatives are u'(x) = cos(x) and v'(x) = -sin(x). Applying the product rule: g'(x) = (cos(x))(cos(x)) + (sin(x))(-sin(x)) = cos^2(x) - sin^2(x) = cos(2x).

Explanation:
The correct answer is C because it correctly applies the double angle identity for cosine, which simplifies the result from the product rule.

Common mistake note:
A common mistake would be to not recognize that cos^2(x) - sin^2(x) can be simplified using a trigonometric identity. Choosing A would be a mistake as it does not simplify the expression.
