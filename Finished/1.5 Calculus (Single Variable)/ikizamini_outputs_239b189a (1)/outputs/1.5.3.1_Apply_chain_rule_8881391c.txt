Problem 1 (Incremental Increase):
Find the derivative of f(x) = (2x + 1)^3 using the chain rule.
A) (6x^2 + 6x)(2x + 1)
B) 3(2x + 1)^2
C) 6(2x + 1)^2
D) 9(2x + 1)^2
Correct Answer: C

Solution:
The chain rule states that if you have a composite function like f(g(x)), the derivative is f'(g(x)) 	imes g'(x). Here, f(u) = u^3 and g(x) = 2x + 1. So, f'(u) = 3u^2 and g'(x) = 2. Applying the chain rule: f'(g(x)) = 3(2x + 1)^2 	imes 2 = 6(2x + 1)^2.

Explanation:
The derivative of (2x + 1)^3 is found by applying the chain rule with u = 2x + 1. The correct power rule for f'(u) is multiplied by g'(x).

Common mistake note:
A common mistake is to forget to multiply by the derivative of the inner function (g'(x)). Answer A has this error.

Problem 2 (Variable Inside Parentheses):
Find the derivative of h(x) = x(3x - 1)^2 using the chain rule.
A) (3x - 1)(6x - 1)
B) 3(3x - 1)^2 + 2x(3x - 1)
C) 6x(3x - 1) + (3x - 1)^2
D) 6x(3x - 1)
Correct Answer: B

Solution:
The chain rule applies to h(x) = x 	imes f(g(x)), where f(u) = u^2 and g(x) = 3x - 1. So, f'(u) = 2u and g'(x) = 3. The derivative is: h'(x) = f'(g(x)) 	imes g'(x) + x 	imes f'(g(x)). Thus, h'(x) = 2(3x - 1)(3) + x(2(3x - 1)) = 6(3x - 1) + 2x(3x - 1).

Explanation:
The derivative of x 	imes (3x - 1)^2 involves applying the product rule and the chain rule. The correct answer combines both rules.

Common mistake note:
A common mistake is to apply the chain rule only to one part of the product, neglecting the other part. Answer A has this error.

Problem 3 (Multiple Chain Rule):
Find the derivative of w(t) = (4t^2 + 3)^5(7t - 1)^3 using the chain rule.
A) 20(4t^2 + 3)^4 	imes 8t 	imes 7t - 1 + 9(7t - 1)^2 	imes 3
B) 5(4t^2 + 3)^4 	imes 8t 	imes (7t - 1)^3 + 3(4t^2 + 3)^5 	imes 7
C) 5(4t^2 + 3)^4 	imes 8t + 9(7t - 1)^2 	imes 3
D) (4t^2 + 3)^5 	imes (7t - 1)^2
Correct Answer: B

Solution:
The function w(t) has two parts, each requiring the chain rule. For the first part: f(u) = u^5 and g(t) = 4t^2 + 3; for the second part: h(v) = v^3 and j(t) = 7t - 1. The derivatives are f'(u) = 5u^4, g'(t) = 8t, h'(v) = 3v^2, and j'(t) = 7. Applying the chain rule: w'(t) = f'(g(t)) 	imes g'(t) 	imes h'(j( t)) 	imes j'(t). So, w'(t) = 5(4t^2 + 3)^4 	imes 8t 	imes 3(7t - 1)^2 	imes 7.

Explanation:
The derivative of a product with two composite functions requires applying the chain rule twice, once for each function.

Common mistake note:
A common mistake is to mix up the derivatives or apply them in the wrong order. Answer A has this error.

Problem 4 (Quotient Rule and Chain Rule):
Find the derivative of p(x) = (x^3 - 1)/(2x + 3)^2 using the chain rule and quotient rule.
A) (6x^2)(2x + 3)^2 - (x^3 - 1)(4(2x + 3)) / (2x + 3)^4
B) (3x^2)(2x + 3) - (x^3 - 1)(4) / (2x + 3)^3
C) 6x^2 - 4(x^3 - 1)/(2x + 3)
D) (x^3 - 1)(2x + 3) - 4(2x + 3)^2 / (x^3 - 1)^2
Correct Answer: A

Solution:
The function p(x) is a quotient, so we apply the quotient rule: p'(x) = [(u'v - uv') / v^2], where u = x^3 - 1 and v = (2x + 3)^2. The derivatives are u' = 3x^2 and v' = 4(2x + 3). Applying the chain rule: p'(x) = [(3x^2 	imes (2x + 3)^2 - (x^3 - 1) 	imes 4(2x + 3)) / (2x + 3)^4].

Explanation:
The derivative of a quotient involving composite functions requires applying both the chain rule and the quotient rule.

Common mistake note:
A common mistake is to apply the chain rule only to one part of the numerator or neglect the denominator's derivative. Answer B has this error.

Problem 5 (Trigonometric Chain Rule):
Find the derivative of q(theta) = sin(2theta)^3 using the chain rule.
A) 3sin(2theta)^2 	imes 2cos(2theta)
B) 6sin^2(2theta)cos(2theta)
C) 3cos(2theta)^2
D) 6sin(2theta)
Correct Answer: A

Solution:
The function q(theta) involves a composite of trigonometric functions. Let u = 2theta, so f(u) = sin^3(u). The derivatives are f'(u) = 3sin^2(u)cos(u) and g'(theta) = 2. Applying the chain rule: q'(theta) = f'(u) 	imes g'(theta) = 3sin^2(2theta)cos(2theta) 	imes 2 = 6sin^2(2theta)cos(2theta).

Explanation:
The derivative of a trigonometric composite function requires applying the chain rule with an appropriate substitution.

Common mistake note:
A common mistake is to forget to cube the sine term when differentiating. Answer C has this error.

Problem 6 (Exponential Chain Rule):
Find the derivative of r(x) = e^(3x^2 - 1) using the chain rule.
A) e^(3x^2 - 1)(6x)
B) 3e^(3x^2 - 1)
C) e^(3x^2 - 1)(9x^2 - 1)
D) e^(3x^2)
Correct Answer: A

Solution:
The function r(x) involves an exponential with a composite inside the exponent. Let u = 3x^2 - 1, so f(u) = e^u. The derivatives are f'(u) = e^u and g'(x) = 6x. Applying the chain rule: r'(x) = f'(u) 	imes g'(x) = e^(3x^2 - 1) 	imes 6x.

Explanation:
The derivative of an exponential with a composite inside requires applying the chain rule with an appropriate substitution.

Common mistake note:
A common mistake is to forget to multiply by the derivative of the inner function. Answer B has this error.

Problem 7 (Logarithmic Chain Rule):
Find the derivative of s(x) = ln(5x^2 + 1) using the chain rule.
A) (10x)/(5x^2 + 1)
B) (5x^2 + 1)/(10x)
C) ln(5x^2 + 1)(10x)
D) ln(5x^2)
Correct Answer: A

Solution:
The function s(x) involves a logarithm with a composite inside. Let u = 5x^2 + 1, so f(u) = ln(u). The derivatives are f'(u) = 1/u and g'(x) = 10x. Applying the chain rule: s'(x) = f'(u) 	imes g'(x) = (1/(5x^2 + 1)) 	imes 10x = (10x)/(5x^2 + 1).

Explanation:
The derivative of a logarithm with a composite inside requires applying the chain rule with an appropriate substitution.

Common mistake note:
A common mistake is to forget to multiply by the derivative of the inner function. Answer B has this error.
