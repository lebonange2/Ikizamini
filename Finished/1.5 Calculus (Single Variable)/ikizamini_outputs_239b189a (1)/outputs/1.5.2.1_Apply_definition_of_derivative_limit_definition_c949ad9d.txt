Problem 1 (:Q1):
Find the derivative of f(x) = x^2 at x=3 using the limit definition.
A) -6
B) 6
C) 9
D) 18
Correct Answer: B

Solution:
f'(x) = lim (h->0) [ f(x+h) - f(x) ] / h
f'(3) = lim (h->0) [ (3+h)^2 - 3^2 ] / h
= lim (h->0) [ 9 + 6h + h^2 - 9 ] / h
= lim (h->0) [ 6h + h^2 ] / h
= lim (h->0) [ h(6+h) ] / h
= lim (h->0) (6+h)
= 6

Explanation:
The limit definition of the derivative is used to find the slope of a tangent line at a specific point. In this case, we evaluate the limit as h approaches zero.

Common mistake note:
A common mistake would be forgetting to take the limit as h approaches zero or simplifying the expression incorrectly.

Problem 2 (:Q2):
Find the derivative of g(x) = 5x - 7 at x=4 using the limit definition.
A) -1
B) 3
C) 18
D) 23
Correct Answer: B

Solution:
g'(x) = lim (h->0) [ g(x+h) - g(x) ] / h
g'(4) = lim (h->0) [ 5(4+h) - 7 - (5*4 - 7) ] / h
= lim (h->0) [ 20 + 5h - 7 - 20 + 7 ] / h
= lim (h->0) [ 5h ] / h
= lim (h->0) [ 5 ]
= 5

Explanation:
Again, we use the limit definition of the derivative to find the slope of the tangent line at x=4. The function is linear, so the derivative is constant.

Common mistake note:
A common mistake might be forgetting to distribute the 5 in g(x+h) or misapplying the distributive property.

Problem 3 (:Q3):
Find the derivative of h(x) = x^3 - 2x at x=1 using the limit definition.
A) -1
B) 0
C) 1
D) 3
Correct Answer: D

Solution:
h'(x) = lim (h->0) [ h(x+h)^3 - 2(x+h) - (x^3 - 2x) ] / h
h'(1) = lim (h->0) [ (1+h)^3 - 2(1+h) - (1 - 2) ] / h
= lim (h->0) [ 1 + 3h + 3h^2 + h^3 - 2 - 2h - (-1) ] / h
= lim (h->0) [ h^3 + h^2 + h ] / h
= lim (h->0) [ h(h^2 + h + 1) ] / h
= lim (h->0) (h^2 + h + 1)
= 1+1+1
= 3

Explanation:
The function is a cubic, so we apply the limit definition to find the derivative at x=1. The simplification involves expanding and factoring.

Common mistake note:
A common mistake would be misapplying the power rule when expanding (h^2 + h + 1) or not simplifying correctly.

Problem 4 (:Q4):
Find the derivative of p(x) = x / (x+1) at x=2 using the limit definition.
A) 0.5
B) 1
C) 2
D) 3
Correct Answer: A

Solution:
p'(x) = lim (h->0) [ p(x+h) - p(x) ] / h
p'(2) = lim (h->0) [ (2+h)/(2+h+1) - 2/(2+1) ] / h
= lim (h->0) [ (2+h)/(3+h) - 2/3 ] / h
= lim (h->0) [ 6 + 3h - 2(3+h) ] / [ 3h + 3h^2 ]
= lim (h->0) [ 6 + 3h - 6 - 2h ] / [ 3h(1+h) ]
= lim (h->0) [ h ] / [ 3h(1+h) ]
= lim (h->0) [ 1/(3(1+h)) ]
= 1/6

Explanation:
The function is a rational function, so we apply the limit definition to find the derivative at x=2. The simplification involves multiplying by the conjugate.

Common mistake note:
A common mistake would be forgetting to multiply by the conjugate or simplifying incorrectly.

Problem 5 (:Q5):
Find the derivative of q(x) = e^x at x=0 using the limit definition.
A) 1
B) e
C) 2
D) e^2
Correct Answer: A

Solution:
q'(x) = lim (h->0) [ q(x+h) - q(x) ] / h
q'(0) = lim (h->0) [ e^(0+h) - e^0 ] / h
= lim (h->0) [ e^h - 1 ] / h
= 1

Explanation:
The derivative of the exponential function is itself. We use the limit definition to find the derivative at x=0.

Common mistake note:
A common mistake would be not recognizing that the derivative of e^x is e^x or applying the chain rule incorrectly.

Problem 6 (:Q6):
Find the derivative of r(x) = sin(x) at x=π/2 using the limit definition.
A) -1
B) 0
C) 1
D) π
Correct Answer: C

Solution:
r'(x) = lim (h->0) [ r(x+h) - r(x) ] / h
r'(π/2) = lim (h->0) [ sin(π/2+h) - sin(π/2) ] / h
= lim (h->0) [ cos(h) - 1 ] / h
= 0

Explanation:
The derivative of sine is cosine. We use the limit definition to find the derivative at x=π/2, where cos(h) approaches 0 as h approaches 0.

Common mistake note:
A common mistake would be forgetting that sin(π/2) = 1 or applying the sum/difference identities incorrectly.

Problem 7 (:Q7):
Find the derivative of s(x) = ln(x) at x=1 using the limit definition.
A) -1
B) 0
C) 1
D) e
Correct Answer: C

Solution:
s'(x) = lim (h->0) [ s(x+h) - s(x) ] / h
s'(1) = lim (h->0) [ ln(1+h) - ln(1) ] / h
= lim (h->0) [ ln(1+h) ] / h
= 1

Explanation:
The derivative of the natural logarithm is 1/x. We use the limit definition to find the derivative at x=1, where ln(1+h) approaches 0 as h approaches 0.

Common mistake note:
A common mistake would be forgetting that ln(1) = 0 or applying the change of base formula incorrectly.
