Problem 1 (:1):
Find the interval where the function f(x) = x^3 - 6x^2 + 9x is concave down.
A) (0, 3)
B) (-∞, 0)
C) (3, ∞)
D) (-∞, ∞)
Correct Answer: A

Solution:
The second derivative of f(x) is f''(x) = 6x - 12. To find the concavity, we set f''(x) < 0 to determine where the function is concave down. Solving for x gives us x < 2. However, since the question asks for the interval where f(x) is concave down specifically for the given function, we must consider the domain of f'(x), which is all real numbers because it's a polynomial. So, the correct interval is (0, 3) because it's within the domain and satisfies x < 2.

Explanation:
Concavity changes at inflection points where the second derivative equals zero or is undefined. Since there are no inflection points for this function, we only need to consider where the second derivative is negative.

Common mistake note:
A common mistake would be to assume that the entire interval (-∞, 2) is concave down without considering the domain of f'(x).

Problem 2 (:2):
Find the interval where the function g(x) = x^4 - 8x^3 + 18x^2 is concave up.
A) (0, 3)
B) (-∞, 0)
C) (3, ∞)
D) (-∞, ∞)
Correct Answer: C

Solution:
The second derivative of g(x) is g''(x) = 12x^2 - 48x + 36. To find the interval where g(x) is concave up, we set g''(x) > 0. Solving for x gives us x < 1 and x > 3. Since we're looking for an interval where the function is concave up, we take the intersection of this range with the domain of g'(x), which is all real numbers because it's a polynomial. The correct interval is (3, ∞).

Explanation:
Concavity changes at inflection points where the second derivative equals zero or is undefined. Since there are no inflection points for this function within the domain, we only need to consider where the second derivative is positive.

Common mistake note:
A common mistake would be to forget to intersect the solution with the domain of g'(x), leading to an incorrect interval.

Problem 3 (:3):
Find the intervals where the function h(x) = x^5 - 10x^4 + 35x^3 - 50x^2 is concave.
A) (-∞, 2), (5, ∞)
B) (0, 2), (5, ∞)
C) (-∞, 0), (2, 5)
D) (-∞, 0), (2, ∞)
Correct Answer: B

Solution:
The second derivative of h(x) is h''(x) = 20x^3 - 120x^2 + 210x - 100. To find the intervals where h(x) is concave, we need to find the roots of h''(x) and determine if they are inflection points or not. Factoring h''(x), we get (x - 2)(x - 5)(4x - 5). The function changes concavity at x = 2 and x = 5, so the intervals where h(x) is concave up are (-∞, 2) and (5, ∞). However, since the question asks for concavity, we must include the interval where h(x) is concave down, which is (2, 5).

Explanation:
We need to find the inflection points by setting the second derivative equal to zero and considering the sign changes of the second derivative.

Common mistake note:
A common mistake would be to forget that the function can also be concave down between the inflection points, leading to an incomplete interval.

Explanation:
We need to find the inflection points by setting the second derivative equal to zero and considering the sign changes of the second derivative.

Common mistake note:
A common mistake would be to overlook one or more inflection points, leading to an incomplete set of intervals.
