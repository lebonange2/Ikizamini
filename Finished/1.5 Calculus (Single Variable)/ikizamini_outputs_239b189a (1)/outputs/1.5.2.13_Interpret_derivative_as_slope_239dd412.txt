Problem 1 (IncreasingFunctionSlope):
The function f(x) = x^2 is increasing on the interval (1, 3). What is the approximate slope of the tangent line to f at x = 2?
A) -1
B) 0
C) 1
D) 2
Correct Answer: C

Solution:
The derivative of f(x) = x^2 is f'(x) = 2x. At x = 2, the slope of the tangent line is f'(2) = 2*2 = 4. Since the question asks for an approximate value and we want a positive slope (as the function is increasing), the closest option is C: 1.

Explanation:
The derivative represents the instantaneous rate of change of the function at a given point. Since f(x) is increasing, its derivative should be positive.

Common mistake note:
A common mistake would be to choose A (-1) or B (0), which represent decreasing or constant slopes respectively. This confusion arises from not recognizing that the function is increasing.

Problem 2 (DecreasingFunctionSlope):
The function g(x) = -x^3 is decreasing on the interval (-2, 0). What is the approximate slope of the tangent line to g at x = -1?
A) -3
B) -1
C) 0
D) 1
Correct Answer: A

Solution:
The derivative of g(x) = -x^3 is g'(x) = -3x^2. At x = -1, the slope of the tangent line is g'(-1) = -3*(-1)^2 = -3. The closest option is A: -3.

Explanation:
The derivative represents the instantaneous rate of change of the function at a given point. Since g(x) is decreasing, its derivative should be negative.

Common mistake note:
A common mistake would be to choose D (1), which represents an increasing slope. This confusion arises from not recognizing that the function is decreasing.

Problem 3 (HorizontalTangent):
The function h(x) = x^4 - 4x^3 has a horizontal tangent at x = c. What is the value of c?
A) 0
B) 1
C) 2
D) 3
Correct Answer: C

Solution:
The derivative of h(x) = x^4 - 4x^3 is h'(x) = 4x^3 - 12x^2. For a horizontal tangent, the slope must be 0, so we set h'(x) = 0 and solve for x: 4x^3 - 12x^2 = 0. Factoring out 4x^2 gives us 4x^2(x - 3) = 0, which means x = 0 or x = 3. Since we're looking for a horizontal tangent at x = c, and the question specifies that it occurs only once, c must be 3.

Explanation:
A horizontal tangent indicates that the slope of the function is 0 at that point. Setting the derivative equal to 0 and solving for x gives us the value of c where this occurs.

Common mistake note:
A common mistake would be to choose A (0) or B (1), which are also solutions to h'(x) = 0 but do not correspond to a horizontal tangent as they are not the only solution.

Problem 4 (ZeroSlope):
The function j(x) = x^2 - 4x has a zero slope at x = k. What is the value of k?
A) 0
B) 1
C) 2
D) 4
Correct Answer: C

Solution:
The derivative of j(x) = x^2 - 4x is j'(x) = 2x - 4. For a zero slope, the derivative must be 0, so we set j'(x) = 0 and solve for x: 2x - 4 = 0. Solving gives us x = 2, which means k = 2.

Explanation:
A zero slope indicates that the function's rate of change is momentarily constant at that point. Setting the derivative equal to 0 and solving for x gives us the value of k where this occurs.

Common mistake note:
A common mistake would be to choose A (0) or D (4), which are also points where j(x) changes concavity but do not have zero slope.

Problem 5 (PositiveSlopeExample):
The function k(x) = x^3 + 2x has a positive slope at x = m. Which of the following is true about m?
A) m < -1
B) m = 0
C) 0 < m < 1
D) m > 1
Correct Answer: D

Solution:
The derivative of k(x) = x^3 + 2x is k'(x) = 3x^2 + 2, which is always positive since it's a sum of squares. For the slope to be positive, we need m > 0. The most restrictive option that ensures this is D: m > 1.

Explanation:
Since the derivative is always positive, any value of x greater than 0 will result in a positive slope for k(x).

Common mistake note:
A common mistake would be to choose A (-1) or B (0), which would result in a non-positive slope. This confusion arises from not recognizing that the derivative is always positive.

Problem 6 (NegativeSlopeExample):
The function l(x) = -x^2 + 3x has a negative slope at x = n. Which of the following is true about n?
A) n < 0
B) 0 < n < 1
C) n = 1
D) n > 1
Correct Answer: B

Solution:
The derivative of l(x) = -x^2 + 3x is l'(x) = -2x + 3. For the slope to be negative, we need -2x + 3 < 0, which simplifies to x > 1.5/2 or x > 3/4. The most restrictive option that ensures this is B: 0 < n < 1.

Explanation:
Since l(x) has a negative slope at x = n, the derivative must be less than zero. Solving for this inequality gives us the range of values for n.

Common mistake note:
A common mistake would be to choose A (n < 0), which would result in a non-negative slope. This confusion arises from not recognizing that the derivative is negative only within a specific interval.

Problem 7 (IncreasingThenDecreasing):
The function m(x) = x^3 - 6x^2 + 9x has a slope that changes from positive to negative at x = p. What is the value of p?
A) 0
B) 1
C) 2
D) 3
Correct Answer: C

Solution:
The derivative of m(x) = x^3 - 6x^2 + 9x is m'(x) = 3x^2 - 12x + 9. The sign of the slope changes when the derivative changes from positive to negative or vice versa, which occurs at the roots of the derivative. Factoring m'(x) gives us 3(x - 1)(x - 3), so the roots are x = 1 and x = 3. Since we're looking for a change from increasing to decreasing, p must be the larger root, which is 3.

Explanation:
The slope changes sign when the function changes concavity. Setting the derivative equal to zero and finding the roots gives us the values of x where this occurs. We choose the one that corresponds to an increase in slope followed by a decrease.

Common mistake note:
A common mistake would be to choose A (0) or B (1), which are points where the function changes concavity but do not correspond to a change from positive to negative slope.
