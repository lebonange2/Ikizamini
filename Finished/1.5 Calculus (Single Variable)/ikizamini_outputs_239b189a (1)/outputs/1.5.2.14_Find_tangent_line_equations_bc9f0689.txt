Problem 1 (:1):
Find the equation of the tangent line to the curve f(x) = x^2 at the point (2, 4).
A) (x - 2) + 4 = 0
B) 2(x - 2)^2 + 4 = 0
C) 4(x - 2) + 8 = 0
D) 2(x - 2) + 4 = 0
Correct Answer: C

Solution:
The derivative of f(x) = x^2 is f'(x) = 2x. At the point (2, 4), the slope of the tangent line is f'(2) = 4. The equation of a line in point-slope form is y - y1 = m(x - x1). Plugging in the point (2, 4) and the slope 4 gives us y - 4 = 4(x - 2), which simplifies to 4x - 8 + y = 4, or 4(x - 2) + 4 = 0.

Explanation:
The tangent line equation is found by using the derivative at the given point to find the slope and then applying the point-slope form of a linear equation.

Common mistake note:
A common mistake would be to use f(2) instead of f'(2) for the slope, which would result in choice A. This fails because f(2) gives the y-value at the point but not the slope of the tangent line.

Problem 2 (:2):
Find the equation of the tangent line to the curve g(x) = 3ln(x) at x = e.
A) (x - e) + 3 = 0
B) 3(x - e)^2 + 1 = 0
C) 3(x - e) + 3 = 0
D) 3(x - e) - 3 = 0
Correct Answer: C

Solution:
The derivative of g(x) = 3ln(x) is g'(x) = 3/x. At x = e, the slope of the tangent line is g'(e) = 3/e. The equation of a line in point-slope form is y - y1 = m(x - x1). Since we don't have an explicit point, we can use any value for y1 and x1 as long as they satisfy the original function. Let's use (e, 3) since g(e) = 3ln(e) = 3. Plugging in the slope and this point gives us y - 3 = 3/(e)(x - e), which simplifies to 3(x - e) + 3 = 0.

Explanation:
The tangent line equation is found by using the derivative at the given x-value to find the slope and then applying the point-slope form of a linear equation, using any point on the curve that corresponds to the x-value.

Common mistake note:
A common mistake would be to forget to take the derivative or use the wrong function for finding the slope, which would result in choices A or B. This fails because the slope must come from the derivative of the function.

Problem 3 (:3):
Find the equation of the tangent line to the curve h(x) = x^3 - 2x at x = 1.
A) (x - 1)^2 + 1 = 0
B) 3(x - 1) + 1 = 0
C) 3(x - 1) - 1 = 0
D) 3(x - 1) + 2 = 0
Correct Answer: B

Solution:
The derivative of h(x) = x^3 - 2x is h'(x) = 3x^2 - 2. At x = 1, the slope of the tangent line is h'(1) = 3(1)^2 - 2 = 1. The equation of a line in point-slope form is y - y1 = m(x - x1). Let's use (1, -1) since h(1) = 1^3 - 2(1) = -1. Plugging in the slope and this point gives us y + 1 = 1( x - 1), which simplifies to 3(x - 1) + 1 = 0.

Explanation:
The tangent line equation is found by using the derivative at the given x-value to find the slope and then applying the point-slope form of a linear equation, using any point on the curve that corresponds to the x-value.

Common mistake note:
A common mistake would be to forget to subtract 2x when finding the derivative or use the wrong function for finding the slope, which would result in choices A, C, or D. This fails because the slope must come from the correct derivative of the function.

Problem 4 (:4):
Find the equation of the tangent line to the curve f(x) = x^3 - 6x^2 + 9x at x = 3.
A) (x - 3)^2 - 3 = 0
B) 3(x - 3) - 9 = 0
C) 3(x - 3) + 9 = 0
D) 6(x - 3) + 18 = 0
Correct Answer: B

Solution:
The derivative of f(x) = x^3 - 6x^2 + 9x is f'(x) = 3x^2 - 12x + 9. At x = 3, the slope of the tangent line is f'(3) = 3(3)^2 - 12(3) + 9 = 0. The equation of a line in point-slope form is y - y1 = m(x - x1). Let's use (3, 0) since f(3) = 3^3 - 6(3)^2 + 9(3) = 0. Plugging in the slope and this point gives us y - 0 = 0(x - 3), which simplifies to 3(x - 3) - 9 = 0.

Explanation:
The tangent line equation is found by using the derivative at the given x-value to find the slope and then applying the point-slope form of a linear equation, using any point on the curve that corresponds to the x-value.

Common mistake note:
A common mistake would be to forget to subtract 6x^2 when finding the derivative or use the wrong function for finding the slope, which would result in choices A, C, or D. This fails because the slope must come from the correct derivative of the function.

Problem 5 (:5):
Find the equation of the tangent line to the curve g(x) = 2sin(x) at x = π/2.
A) (x - π/2)^2 + 1 = 0
B) 2cos(π/2)(x - π/2) + 2 = 0
C) 2cos(π/2)(x - π/2) - 2 = 0
D) 2(x - π/2) + 2 = 0
Correct Answer: B

Solution:
The derivative of g(x) = 2sin(x) is g'(x) = 2cos(x). At x = π/2, the slope of the tangent line is g'(π/2) = 2cos(π/2) = 0. The equation of a line in point-slope form is y - y1 = m(x - x1). Let's use (π/2, 2) since g(π/2) = 2sin(π/2) = 2. Plugging in the slope and this point gives us y - 2 = 0(x - π/2), which simplifies to 2cos(π/2)(x - π/2) + 2 = 0.

Explanation:
The tangent line equation is found by using the derivative at the given x-value to find the slope and then applying the point-slope form of a linear equation, using any point on the curve that corresponds to the x-value. Since cos(π/2) = 0, the slope is 0.

Common mistake note:
A common mistake would be to forget to multiply by 2 when finding the derivative or use the wrong function for finding the slope, which would result in choices A, C, or D. This fails because the slope must come from the correct derivative of the function.

Problem 7 (:7):
Find the equation of the tangent line to the curve f(x) = 5cos(2x) at x = π/4.
A) (x - π/4)^2 + 1 = 0
B) -10sin(π/4)(x - π/4) + 5 = 0
C) -10sin(π/4)(x - π/4) - 5 = 0
D) 5(x - π/4) + 5 = 0
Correct Answer: B

Solution:
The derivative of f(x) = 5cos(2x) is f'(x) = -10sin(2x). At x = π/4, the slope of the tangent line is f'(π/4) = -10sin(2(π/4)) = -10sin(π/2) = -10. The equation of a line in point-slope form is y - y1 = m(x - x1). Let's use (π/4, 5cos(π/2)) since f(π/4) = 5cos(π/2) = 0. Plugging in the slope and this point gives us y - 0 = -10(x - π/4), which simplifies to -10sin(π/4)(x - π/4) + 5 = 0.

Explanation:
The tangent line equation is found by using the derivative at the given x-value to find the slope and then applying the point-slope form of a linear equation, using any point on the curve that corresponds to the x-value. Since sin(π/2) = 1, the slope is -10.

Common mistake note:
A common mistake would be to forget to multiply by -10 when finding the derivative or use the wrong function for finding the slope, which would result in choices A, C, or D. This fails because the slope must come from the correct derivative of the function.
