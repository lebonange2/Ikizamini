Problem 1 (What is the limit of (2^x - 4) / x as x approaches 0?):
(A) -4
(B) 0
(C) 2
(D) ∞
(E) Does not exist
A) -4
B) 0
C) 2
D) ∞ (infinity)
Correct Answer: C

Solution:
The limit can be evaluated by applying L'Hôpital's rule, which states that if the limit of the ratio of the derivatives is finite and non-zero, then the original limit is also equal to that value. The derivative of 2^x is ln(2) 	imes 2^x, and the derivative of x is 1. Thus, we have the following:

lim (x→0) [(2^x - 4) / x] = lim (x→0) [ln(2) 	imes 2^x / 1]
= ln(2) 	imes 2^0
= ln(2) 	imes 1
= ln(2)

Since ln(2) is a finite, non-zero value, the limit of (2^x - 4) / x as x approaches 0 is ln(2), which is approximately 0.69315.

Explanation:
The correct answer is C because L'Hôpital's rule simplifies the limit to a finite value.

Common mistake note:
A common mistake would be to assume that since 2^x approaches 1 and x approaches 0, the entire fraction approaches 0/0, which would lead to an indeterminate form. However, L'Hôpital's rule allows us to evaluate this limit by differentiating both the numerator and denominator.

Problem 3 (What is the limit of (e^x - 1) / x as x approaches 0?):
(A) 1
(B) 0.5
(C) 2
(D) ∞
(E) Does not exist
A) 1
B) 0.5
C) 2
D) ∞ (infinity)
Correct Answer: A

Solution:
This limit is a well-known limit that represents the derivative of e^x at x = 0, which is equal to the base e itself. By L'Hôpital's rule or by recognizing this special case, we know that:

lim (x→0) [(e^x - 1) / x] = e^(0) 	imes 1
= 1 	imes 1
= 1

Explanation:
The correct answer is A because the limit represents the derivative of e^x evaluated at x = 0.

Common mistake note:
A common mistake would be to try to use a numerical approach or graphing method, which might give an approximate value close to 1 but not the exact value. The limit is exact and can be found using L'Hôpital's rule or recognizing the special case.
