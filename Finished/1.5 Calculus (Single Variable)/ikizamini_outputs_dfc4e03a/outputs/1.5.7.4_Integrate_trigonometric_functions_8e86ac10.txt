Problem 1 (Asin(BC)+D):
Find the antiderivative of the function: f(x) = A\sin(Bx + C) + D
A) \(-A\cos(Bx + C) + Dx + E\)
B) \(A\cos(Bx + C) + Dx + E\)
C) \(-A\cos(Bx + C) + E\)
D) \(A\cos(Bx + C) + E\)
Correct Answer: B

Solution:
The antiderivative of A\sin(Bx + C) is -A\cos(Bx + C) because the derivative of \cos(Bx + C) is -B\sin(Bx + C), and multiplying by A gives us -A\cos(Bx + C). The constant D does not affect the integration process, so it remains as a constant term in the antiderivative: -A\cos(Bx + C) + Dx + E.

Explanation:
The integral of a sine function is the negative cosine function times the coefficient and加上一次常数项

Common mistake note:
Common mistake: Forgetting to multiply by the coefficient A. The correct answer should have -A instead of just -1.

B) \(B\sin(Cx + D) + Ex + F\)

Explanation:
The integral of a cosine function is the sine function times the coefficient and加上一次常数项

Common mistake note:
Common mistake: Forgetting to multiply by the coefficient B. The correct answer should have -B instead of just -1.

Problem 3 (sin(x)/x):
Find the antiderivative of the function: f(x) = \frac{\sin(x)}{x}
A) \(-\cos(x) + C\)
B) \(-\cos(x) + x + C\)
C) \(-\cos(x) + \\ln|x| + C\)
D) \(\cos(x) + \\ln|x| + C\)
Correct Answer: C

Solution:
The antiderivative of \frac{\sin(x)}{x} can be found using substitution, letting u = x and du/dx = 1. The integral becomes: \(rac{-θ(u)}{u}du\), which simplifies to -θ(u) + C. Substituting back in x for u gives us -θ(x) + C = -Κ(x) + C = -φ(1/x) + C = \\ln|x| + C.

Explanation:
Use substitution to find the antiderivative of sin(x)/x

Common mistake note:
Common mistake: Not recognizing that the integral requires a substitution or not correctly applying the substitution method.
