Problem 1 (x1):
Find the domain of the function f(x) = √(x+3)
A) (−∞, −3)
B) [−3, ∞)
C) (0, ∞)
D) R
Correct Answer: B

Solution:
The square root function is defined only for non-negative values. Thus, we need to find the values of x for which x+3 ≥ 0. Solving this inequality gives us x ≥ -3. Therefore, the domain of f(x) is [−3, ∞).

Explanation:
The domain includes all real numbers greater than or equal to -3 because the square root function requires non-negative inputs.

Common mistake note:
A common mistake would be to choose A (−∞, −3), which represents values where x+3 is negative, but that's not allowed for the square root function.

Problem 2 (x2):
Find the domain of the function g(x) = 1/(x^2 - 4)
A) R
B) (−∞, −2) ∪ (2, ∞)
C) [−2, 2]
D) ∅
Correct Answer: B

Solution:
The domain of a rational function is all real numbers except those that make the denominator equal to zero. For g(x), the denominator x^2 - 4 = (x-2)(x+2) must not be zero. Thus, we exclude x=2 and x=-2 from the domain. The domain is therefore (−∞, −2) ∪ (2, ∞).

Explanation:
The domain excludes values that would make the denominator equal to zero, which in this case are x=2 and x=-2.

Common mistake note:
A common mistake would be to choose A (R), thinking that all real numbers are allowed. However, we must exclude values that make the denominator zero.

Correct Answer: D

Solution:

Explanation:
The domain includes all real numbers greater than -1 because the natural logarithm function requires positive inputs.

Common mistake note:
A common mistake would be to choose B ([0, ∞)), which excludes x=0 but allows only non-negative values. However, we must exclude x=-1 as well.

Problem 4 (x4):
Find the domain of the function j(x) = csc(πx)
A) R
B) [0, 1] ∪ [1, 2] ∪ ... ∪ [n, n+1], where n is an integer
C) (−∞, 0) ∪ (0, ∞)
D) All real numbers except x = k/2, where k is an integer
Correct Answer: D

Solution:
The cosecant function is undefined at multiples of π because the sine function has zeros at these points. The sine function is zero when x = kπ, where k is an integer. Therefore, the domain of j(x) excludes x = k/2 (which corresponds to πx = kπ), where k is an integer.

Explanation:
The domain excludes values that would make the sine function equal to zero, which in this case are x = k/2 for any integer k.

Common mistake note:
A common mistake would be to choose A (R), thinking that all real numbers are allowed. However, we must exclude values where the sine function is zero.

C) [-1, 1]

Correct Answer: D

Solution:
The arctangent function is defined for all real numbers. There are no restrictions on the input of the tangent function, so there are no restrictions on the input of its inverse, the arctangent function. Therefore, the domain of k(x) is All real numbers.

Explanation:
The arctangent function has a domain of all real numbers because the tangent function is defined for all real numbers.

Common mistake note:
A common mistake would be to choose C ([-1, 1]), thinking that the range of the tangent function is limited. However, the arctangent function's domain is not restricted by the range of the tangent function.

Problem 6 (x6):
Find the domain of the function l(x) = √(2 - x^2)
A) [-√2, √2]
B) [0, √2]
C) (−∞, ∞)
D) (-1, 1)
Correct Answer: A

Solution:
The square root function is defined only for non-negative values. Thus, we need to find the values of x for which 2 - x^2 ≥ 0. Solving this inequality gives us -√2 ≤ x ≤ √2. Therefore, the domain of l(x) is [-√2, √2].

Explanation:
The domain includes all real numbers between -√2 and √2 because the square root function requires non-negative inputs.

Common mistake note:
A common mistake would be to choose D ((-1, 1)), which represents a smaller interval within the correct domain. However, we must include the endpoints -√2 and √2.

Problem 7 (x7):
Find the domain of the function m(x) = (3x + 1)^(-1/2)
A) (−∞, −1/3)
B) [-1/3, ∞)
C) (-1/3, ∞)
D) [0, ∞)
Correct Answer: C

Solution:
The function involves a square root in the denominator, so we must ensure that the expression inside the square root is non-negative. Thus, we need to find the values of x for which 3x + 1 > 0. Solving this inequality gives us x > -1/3. Therefore, the domain of m(x) is (-1/3, ∞).

Explanation:
The domain includes all real numbers greater than -1/3 because the square root in the denominator requires a positive value.

Common mistake note:
A common mistake would be to choose B ([-1/3, ∞)), which excludes x=-1/3 but allows non-negative values. However, we must exclude x=-1/3 as well.
