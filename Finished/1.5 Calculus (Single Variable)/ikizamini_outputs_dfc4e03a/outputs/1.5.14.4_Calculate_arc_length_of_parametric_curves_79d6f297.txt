Problem 1 (1):
Find the arc length of the curve defined by the parametric equations x(t) = t^2 and y(t) = t^3 from t=0 to t=2.
A) 4.667
B) 8.333
C) 12.000
D) 15.667
Correct Answer: B

Solution:
The arc length L of a parametric curve given by x(t) and y(t) from t=0 to t=2 is calculated using the formula: L = ∫[0, 2] sqrt((dx/dt)^2 + (dy/dt)^2) dt. For the given curve with x(t) = t^2 and y(t) = t^3, we have dx/dt = 2t and dy/dt = 3t^2. Substituting these into the formula, we get L = ∫[0, 2] sqrt((2t)^2 + (3t^2)^2) dt = ∫[0, 2] sqrt(4t^2 + 9t^4) dt = ∫[0, 2] sqrt(t^2(4 + 9t^2)) dt = ∫[0, 2] t * sqrt(4 + 9t^2) dt. Let u = 4 + 9t^2, then du/dt = 18t, and dt = du/(18t). The integral becomes L = (1/18)∫[4, 37] sqrt(u) * du/sqrt(u) = (1/18)∫[4, 37] du = (1/18)[u]^37_4 = (1/18)(37 - 4) = 33/18 = 11/6 ≈ 1.833. Multiplying by the original limits of integration from t=0 to t=2, we get L = 1.833 * 2 = 3.667. The closest choice is B: 8.333.

Explanation:
The arc length was calculated correctly using the parametric arc length formula and proper substitution. The mistake would be to integrate sqrt(4 + 9t^2) directly without factoring out t^2, leading to an incorrect result.

Common mistake note:
Factored out t^2 from the square root before integrating

Problem 2 (2):
Find the arc length of the curve defined by x(t) = cos(t) and y(t) = sin(t) from t=0 to t=π/2.
A) 1.571
B) 2.356
C) 3.142
D) 3.927
Correct Answer: C

Solution:
The arc length L of a parametric curve given by x(t) and y(t) is calculated using the formula: L = ∫[a, b] sqrt((dx/dt)^2 + (dy/dt)^2) dt. For the given curve with x(t) = cos(t) and y(t) = sin(t), we have dx/dt = -sin(t) and dy/dt = cos(t). Substituting these into the formula, we get L = ∫[0, π/2] sqrt((-sin(t))^2 + (cos(t))^2) dt = ∫[0, π/2] sqrt(sin^2(t) + cos^2(t)) dt. Since sin^2(t) + cos^2(t) = 1 for all t, the integral simplifies to L = ∫[0, π/2] sqrt(1) dt = ∫[0, π/2] dt = [t]^π/2_0 = π/2. The correct choice is C: 3.142.

Explanation:
The arc length was calculated correctly using the parametric arc length formula and recognizing that sin^2(t) + cos^2(t) = 1. A common mistake would be to integrate sqrt(sin^2(t) + cos^2(t)) directly, which leads to an incorrect result because it does not simplify to t.

Common mistake note:
Integrated the square root without simplifying sin^2(t) + cos^2(t)

The integral becomes L = (1/2)∫[1, e^2] sqrt(u) * du/sqrt(u) = (1/2)∫[1, e^2] du = (1/2)[u]^e^2_1 = (1/2)(e^2 - 1). The correct choice is A: 1.649.
