Problem 1 (Asdf):
Evaluate the integral ∫(2x)e^x dx using integration by parts. Which of the following is the correct answer?
A) (2x)e^x - 2∫e^xdx
B) (2x)e^x - 2e^x + C
C) x^2e^x - e^x + C
D) x^2e^x - 2e^x + C
Correct Answer: B

Solution:
Let u = 2x, dv = e^x dx. Then du = 2 dx and v = ∫e^x dx = e^x. Using the integration by parts formula: ∫udv = uv - ∫vdu, we get ∫(2x)e^x dx = (2x)e^x - ∫e^x * 2 dx = (2x)e^x - 2∫e^xdx = (2x)e^x - 2e^x + C

Explanation:
The correct choice is obtained by applying the integration by parts formula correctly. The common mistake would be to integrate e^x incorrectly, leading to option A.

Common mistake note:
Common mistake: Integrating e^x as xe^x instead of e^x.

Problem 3 (Asdf3):
Evaluate the integral ∫sin(x) * cos(x) dx using integration by parts. Which of the following is the correct answer?
A) -cos^2(x) + C
B) sin^2(x) + C
C) 1/2 sin(2x) + C
D) 1 - 1/2 sin(2x) + C
Correct Answer: C

Solution:
Let u = sin(x), dv = cos(x) dx. Then du = cos(x) dx and v = ∫cos(x) dx = sin(x). Using integration by parts: ∫udv = uv - ∫vdu, we get ∫sin(x) * cos(x) dx = sin(x) * sin(x) - ∫sin(x) * cos(x) dx. Solving for the integral, we have 2∫sin(x) * cos(x) dx = sin^2(x). Thus, ∫sin(x) * cos(x) dx = 1/2 sin^2(x) + C

Explanation:
The correct choice is obtained by applying the integration by parts formula correctly and solving for the integral. The common mistake would be to integrate sin(x) * cos(x) directly without using integration by parts, leading to option A.

Common mistake note:
Common mistake: Integrating sin(x) * cos(x) directly instead of using integration by parts.

Problem 5 (Asdf5):
Evaluate the integral ∫(2x + 1)^3 dx using integration by parts. Which of the following is the correct answer?
A) (2x + 1)^4/4 + C
B) (2x + 1)^4/8 + C
C) 1/2 (2x + 1)^4 + C
D) 1/4 (2x + 1)^4 + C
Correct Answer: B

Solution:
Let u = (2x + 1)^3, dv = dx. Then du = 6(2x + 1)^2 dx and v = ∫dx = x. Using integration by parts: ∫udv = uv - ∫vdu, we get ∫(2x + 1)^3 dx = (2x + 1)^3 * x - ∫x * 6(2x + 1)^2 dx. This is a complex integral that cannot be solved using integration by parts directly. Instead, expand (2x + 1)^3 and integrate term by term. The correct answer is obtained by expanding and integrating: ∫(8x^3 + 12x^2 + 6x + 1) dx = 8/4 x^4 + 12/3 x^3 + 6/2 x^2 + x + C = (2x + 1)^4/8 + C

Explanation:
The correct choice is obtained by expanding the integrand and integrating term by term, not by attempting to use integration by parts directly. The common mistake would be to try to integrate (2x + 1)^3 using integration by parts, which does not lead to a simple solution.

Problem 6 (Asdf6):
Evaluate the integral ∫sin(x) * tan(x) dx using integration by parts. Which of the following is the correct answer?
A) -cos^2(x) + C
B) sin^2(x) + C
C) 1 - cos(2x)/2 + C
D) cos^2(x)/2 + C
Correct Answer: D

Solution:
Let u = sin(x), dv = tan(x) dx. Then du = cos(x) dx and v = ∫tan(x) dx = -ln|cos(x)|. Using integration by parts: ∫udv = uv - ∫vdu, we get ∫sin(x) * tan(x) dx = -sin(x) * ln|cos(x)| - ∫-ln|cos(x)| * cos(x) dx = -sin(x) * ln|cos(x)| + ∫ln|cos(x)| * cos(x) dx. This is a complex integral that cannot be solved using integration by parts directly. Instead, use the substitution w = cos(x), dw = -sin(x) dx to simplify: ∫ln|w| * (-dw/w) = ∫-ln( w)/w dw = -∫ln(w)d(ln(w)) = [-ln^2(w)]/2 + C = [-ln^2(cos(x))] / 2 + C = cos^2(x)/2 + C

Explanation:
The correct choice is obtained by making a substitution and integrating the simplified form, not by attempting to use integration by parts directly. The common mistake would be to try to integrate sin(x) * tan(x) using integration by parts, which does not lead to a simple solution.

Common mistake note:
Common mistake: Attempting to use integration by parts on sin(x) * tan(x) without making a substitution.

Problem 7 (Asdf7):
