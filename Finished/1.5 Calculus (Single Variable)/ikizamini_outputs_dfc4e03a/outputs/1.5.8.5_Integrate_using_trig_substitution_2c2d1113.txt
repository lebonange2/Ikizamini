Problem 1 (Q1):
Evaluate the integral ∫(x² dx) / (x³ + 1) from 0 to 2.
A) π/3 - π/6
B) π/2
C) π
D) 2π
Correct Answer: B

Solution:
Using trig substitution with x = tan(θ), dx = sec²(θ)dθ, the integral becomes ∫(tan²(θ)sec²(θ)dθ) / (tan³(θ) + 1). This simplifies to ∫(sec⁴(θ)dθ) / (sec³(θ)). Integrating, we get ∫(sec(θ)dθ) from π/4 to arctan(2) = ln|sec(θ) + tan(θ)| evaluated from π/4 to arctan(2) = ln(sqrt(5) + 2) - ln(sqrt(2) + 1) = π/2.

Explanation:
The integral is solved using trigonometric substitution and evaluating the resulting integral with respect to θ or π.

Common mistake note:
A common mistake would be not recognizing that dx becomes sec²(θ)dθ, leading to an incorrect result.

Problem 2 (Q2):
Evaluate the integral ∫(sin(x) dx) / (1 + cos²(x)) from 0 to π.
A) π/4
B) π/2
C) 3π/4
D) π
Correct Answer: A

Solution:
Using trig substitution with x = 2arctan(t), dx = 2/(1 + t²)dt, the integral becomes ∫(sin(2arctan(t)) * 2/(1 + t²)dθ) / (1 + cos²(2arctan(t))). This simplifies to ∫(2t/(1 + t²)dθ) / (1 + (1 - t²)/(1 + t²)). Integrating, we get ∫(2tdθ) from 0 to 1 = π/4.

Explanation:
The integral is solved using trigonometric substitution and evaluating the resulting integral with respect to θ or π.

Common mistake note:
A common mistake would be not recognizing that dx becomes 2/(1 + t²)dt, leading to an incorrect result.

Problem 3 (Q3):
Evaluate the integral ∫(cos(x) dx) / (sin²(x) + 4) from -π/2 to π/2.
A) 0
B) π/2
C) π
D) 2π
Correct Answer: A

Solution:
Using trig substitution with x = arctan(2t), dx = 2/(1 + 4t²)dt, the integral becomes ∫(cos(arctan(2t)) * 2/(1 + 4t²)dθ) / ((sin(arctan(2t)))² + 4). This simplifies to ∫(2tdθ) from -1/√3 to 1/√3 = 0.

Explanation:
The integral is solved using trigonometric substitution and evaluating the resulting integral with respect to θ or π. The limits of integration yield an odd function, which results in a zero value.

Common mistake note:
A common mistake would be not recognizing that dx becomes 2/(1 + 4t²)dt, leading to an incorrect result.

Problem 6 (Q6):
Evaluate the integral ∫(sin(x)cos(x) dx) / (1 + cos(2x)) from 0 to π.
A) π/4
B) π/2
C) 3π/4
D) π
Correct Answer: B

Solution:
Using trig substitution with x = arctan(t), dx = dt/(1 + t²), the integral becomes ∫((sin(arctan(θ))cos(arctan(θ))) * dt/(1 + t²)) / (1 + cos(2arctan(θ))). This simplifies to ∫(t/2dt) from 0 to ∞ = π/2.

Explanation:
The integral is solved using trigonometric substitution and evaluating the resulting integral with respect to θ or π. The limits of integration yield an even function, which results in a non-zero value.

Common mistake note:
A common mistake would be not recognizing that dx becomes dt/(1 + t²), leading to an incorrect result.

Problem 7 (Q7):
Evaluate the integral ∫(sin(x)cos²(θ) dx) / (1 - cos³(θ)) from 0 to π/2.
A) π/6
B) π/3
C) π/2
D) π
Correct Answer: B

Solution:
Using trig substitution with x = arctan(t), dx = dt/(1 + t²), the integral becomes ∫((sin(arctan(θ))cos²(arctan(θ))) * dt/(1 + t²)) / (1 - cos³(arctan(θ))). This simplifies to ∫(t²/2dt) from 0 to 1 = π/3.

Explanation:
The integral is solved using trigonometric substitution and evaluating the resulting integral with respect to θ or π. The limits of integration yield a non-zero result.

Common mistake note:
A common mistake would be not recognizing that dx becomes dt/(1 + t²), leading to an incorrect result.
