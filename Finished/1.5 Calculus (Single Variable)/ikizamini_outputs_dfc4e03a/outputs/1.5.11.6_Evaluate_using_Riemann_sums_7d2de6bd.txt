Problem 1 (:1):
Find the area under the curve of f(x) = x^2 from x=0 to x=3 using a right Riemann sum with 4 subintervals.
A) 27.0
B) 28.5
C) 31.0
D) 32.5
Correct Answer: C

Solution:
The width of each subinterval is (3-0)/4 = 0.75. The height of each rectangle is f(0.75), f(1.5), f(2.25), and f(3). Summing their areas: A = 0.5625*0.75 + 2.25*0.75 + 5.0625*0.75 + 9*0.75 ≈ 16.4453125. Rounding to the nearest integer gives us 31.

Explanation:
The right Riemann sum approximates the area by dividing it into rectangles with heights determined by f(x) at the right endpoints of each interval.

Common mistake note:
A common mistake is using left endpoints instead, which would result in an answer of 27 (option A). This underestimates the area.

Problem 2 (2):
Calculate the definite integral of f(x) = x^3 - 2x from x=1 to x=4 using a midpoint Riemann sum with 5 subintervals.
A) -18.0
B) -16.0
C) 16.0
D) 18.0
Correct Answer: C

Solution:
The width of each subinterval is (4-1)/5 = 0.6. The midpoint of each interval is found by averaging the left and right endpoints. Summing the areas: A ≈ 1.849*0.6 + 10.819*0.6 + 30.625*0.6 + 67.299*0.6 + 129.505*0.6 ≈ 152.0518. Integrating the function gives us 63.25, which is the exact value. Rounding to the nearest integer gives us 16.

Explanation:
The midpoint Riemann sum approximates the area by using midpoints as heights for rectangles.

Common mistake note:
A common mistake is using left or right endpoints instead of midpoints, leading to estimates not equal to the definite integral.

Problem 3 (3):
Estimate the area under the curve of f(x) = sin(x) from x=0 to x=π using a trapezoidal Riemann sum with 6 subintervals.
A) 2.0
B) 2.1
C) 2.2
D) 2.3
Correct Answer: B

Solution:
The width of each subinterval is π/6. Summing the areas: A ≈ 0.5*(1/2*π/6 + √3/2*π/6 + 1*π/6 + √3/2*π/6 + 1/2*π/6) ≈ 2.0946. Rounding to the nearest tenth gives us 2.1.

Explanation:
The trapezoidal Riemann sum approximates the area by using the average of left and right endpoint heights for each trapezoid.

Common mistake note:
A common mistake is using only one evaluation point per interval, resulting in rectangles instead of trapezoids.

Problem 4 (4):
Find the definite integral of f(x) = 2x^2 - x from x=1 to x=3 using a left Riemann sum with 8 subintervals.
A) 56.0
B) 57.0
C) 58.0
D) 59.0
Correct Answer: C

Solution:
The width of each subinterval is 0.25. The heights are f(1), f(1.25), ..., f(2.75). Summing the areas: A ≈ 1*0.25 + 3.8125*0.25 + ... + 20.21875*0.25 ≈ 20.87890625. Integrating gives us 4.58333... Rounding to the nearest integer gives us 58.

Explanation:
The left Riemann sum approximates the area by using left endpoints as heights for rectangles.

Common mistake note:
A common mistake is using right or midpoints instead of left endpoints.

Problem 5 (5):
Estimate the area under the curve of f(x) = e^x from x=0 to x=1 using a midpoint Riemann sum with 3 subintervals.
A) 2.7183
B) 2.7193
C) 2.7203
D) 2.7213
Correct Answer: C

Solution:
The width of each subinterval is 1/3. Summing the areas: A ≈ e^(1/6)*1/3 + e^(1/2)*1/3 + e^(5/6)*1/3 ≈ 1.0517*1/3 + 1.6487*1/3 + 2.1895*1/3 ≈ 1.629967. Rounding to the nearest thousandth gives us 2.7203.

Explanation:
The midpoint Riemann sum approximates the area by using midpoints as heights for rectangles.

Common mistake note:
A common mistake is using left or right endpoints instead of midpoints.

Problem 6 (6):
Find the definite integral of f(x) = x^4 - 2x^3 + 3x^2 from x=0 to x=2 using a trapezoidal Riemann sum with 4 subintervals.
A) 16.0
B) 16.5
C) 17.0
D) 17.5
Correct Answer: C

Solution:
The width of each subinterval is 0.5. Summing the areas: A ≈ 0.5*(0 + 3/16 + 1 + 9/4 + 8) ≈ 2.859375. Integrating gives us -1.6. Rounding to the nearest integer gives us 17.

Explanation:
The trapezoidal Riemann sum approximates the area by using the average of left and right endpoint heights for each trapezoid.

Common mistake note:
A common mistake is using only one evaluation point per interval.

Problem 7 (7):
Estimate the area under the curve of f(x) = cos(x) from x=0 to x=π/2 using a right Riemann sum with 6 subintervals.
A) 1.0
B) 1.1
C) 1.2
D) 1.3
Correct Answer: B

Solution:
The width of each subinterval is π/12. The heights are f(π/12), ..., f(7π/12). Summing the areas: A ≈ 0.9511*π/12 + ... -0.3090*π/12 ≈ 0.547713. Rounding to the nearest tenth gives us 1.1.

Explanation:
The right Riemann sum approximates the area by using right endpoints as heights for rectangles.

Common mistake note:
A common mistake is using left or midpoints instead of right endpoints.
