Problem 1 ([1.5.8.3]Q1):
Find the derivative of f(x) = x^2 with respect to x.
A) 2x
B) x^2
C) 2
D) 1
Correct Answer: A

Solution:
The derivative of x^n is nx^(n-1). So, the derivative of f(x) = x^2 is 2x.

Explanation:
This question tests basic understanding of differentiation rules for simple polynomials.

Common mistake note:
Common mistake: Choosing B (x^2), which is the original function and not its derivative.

Problem 2 ([1.5.8.3]Q2):
Find du if u = 3sin(x) + 4cos(x).
A) 3cos(x) - 4sin(x)
B) 3sin(x) + 4cos(x)
C) 0
D) du/dx
Correct Answer: A

Solution:
The derivative of u = a*sin(x) + b*cos(x) is du/dx = a*cos(x) - b*sin(x). So, du/dx = 3cos(x) - 4sin(x).

Explanation:
This question tests the chain rule and differentiation of trigonometric functions.

Common mistake note:
Common mistake: Choosing B (3sin(x) + 4cos(x)), which is the original function u, not its derivative.
------------------------------------------------------------------------------

Problem 3 ([1.5.8.3]Q3):
Find du if u = e^(2x) - ln(3x).
A) 2e^(2x) - 1/(3x)
B) e^(2x) + 1/3x
C) e^(2x) - 3
D) ln(3x)
Correct Answer: A

Solution:
The derivative of u = a*e^(bx) is du/dx = ab*e^(bx), and the derivative of ln(ax) is du/dx = 1/(ax). So, du/dx = 2e^(2x) - 1/(3x).

Explanation:
This question tests differentiation rules for exponential and logarithmic functions.

Common mistake note:
Common mistake: Choosing B (e^(2x) + 1/3x), which combines the derivatives incorrectly.
------------------------------------------------------------------------------

Problem 4 ([1.5.8.3]Q4):
Find du if u = √(x^2 + 1).
A) (2x)/(2√(x^2 + 1))
B) x/(x^2 + 1)
C) 1/2
D) 1
Correct Answer: A

Solution:
The derivative of u = √(f(x)) is du/dx = (1/2) * f'(x) / √(f(x)). So, du/dx = (1/2) * 2x / √(x^2 + 1) = (2x)/(2√(x^2 + 1)).

Explanation:
This question tests the chain rule and differentiation of a composite function involving a square root.

Common mistake note:
Common mistake: Choosing B (x/(x^2 + 1)), which is the derivative of x inside the square root, not the entire function.
------------------------------------------------------------------------------

Problem 5 ([1.5.8.3]Q5):
Find du if u = sin(x)cos(x).
A) cos^2(x) - sin^2(x)
B) sin(x)cos(x)
C) sin(x)
D) cos(x)
Correct Answer: A

Solution:
The derivative of u = sin(x)cos(x) can be found using the product rule: du/dx = cos(x)d/dx(sin(x)) + sin(x)d/dx(cos(x)). This simplifies to cos^2(x) - sin^2(x).

Explanation:
This question tests the product rule and trigonometric identities.

Common mistake note:
Common mistake: Choosing B (sin(x)cos(x)), which is the original function, not its derivative.
------------------------------------------------------------------------------

Problem 6 ([1.5.8.3]Q6):
Find du if u = x^3e^(2x).
A) 3x^2e^(2x) + 2x^3e^(2x)
B) x^3e^(2x)
C) 3x^2e^(2x)
D) 2x^3e^(2x)
Correct Answer: A

Solution:
The derivative of u = a*x^n*e^(bx) is du/dx = na*x^(n-1)e^(bx) + bax^ne^(bx). So, du/dx = 3x^2e^(2x) + 2x^3e^(2x).

Explanation:
This question tests the product rule and differentiation of a composite function involving an exponential function.

Common mistake note:
Common mistake: Choosing B (x^3e^(2x)), which is the original function, not its derivative.

Problem 7 ([1.5.8.3]Q7):
Find du if u = ln(4x^2 + 1).
A) (8x)/(4x^2 + 1)
B) ln(4x^2 + 1)
C) 1/(4x^2 + 1)
D) 1
Correct Answer: A

Solution:
The derivative of u = ln(f(x)) is du/dx = f'(x) / f(x). So, du/dx = (8x)/(4x^2 + 1).

Explanation:
This question tests the chain rule and differentiation of a composite function involving a logarithm.

Common mistake note:
Common mistake: Choosing B (ln(4x^2 + 1)), which is the original function, not its derivative.
