Problem 1 (AsdFg6789):
Find the absolute minimum value of the function f(x) = x^3 - 3x^2 + 2 on the interval [-2, 4].
A) -16
B) 0
C) 2
D) 18
Correct Answer: B

Solution:
The extreme value theorem states that a continuous function on a closed interval attains its minimum and maximum values within the interval. To find the absolute minimum, we first find critical points by taking the derivative: f'(x) = 3x^2 - 6x. Setting this equal to zero gives x = 0 and x = 2. We also consider the endpoints: f(-2) = -18; f(0) = 2; f(2) = -2; and f(4) = 18. The absolute minimum occurs at x = 0, so the minimum value is f(0) = 2.

Explanation:


Common mistake note:
A common mistake is to forget to check the endpoints of the interval.

Problem 2 (BnmLk5678):
Find the absolute maximum value of f(x) = 2sin(x) + cos(x) on the interval [0, π].
A) 1
B) sqrt(5)
C) sqrt(3)
D) 2
Correct Answer: B

Solution:
The extreme value theorem applies. However, finding critical points analytically is challenging due to the trigonometric functions involved. We can use numerical methods or recognize that the maximum will occur at one of the endpoints or where the second derivative changes sign (since it's a trigonometric function with period 2π and we're looking at [0, π]). The second derivative is f''(x) = -2sin(x) - cos(x), which changes sign from negative to positive at x = π/4. Evaluating f(x): f(0) = 1; f(π/4) ≈ 1.8019; and f(π) = -1. The absolute maximum value occurs at x = π/4, but the closest exact answer within the choices is B (sqrt(5)).

Explanation:


Common mistake note:
A common mistake is to assume that the maximum will occur at x = π/2 (where sin(x) is at its maximum), but this isn't necessarily true for a sum or product of trigonometric functions.

Problem 3 (CklJh4567):
Find the absolute minimum value of f(x) = x^3 - 9x on the interval [-3, 3].
A) -27
B) 0
C) 18
D) 27
Correct Answer: A

Solution:
The extreme value theorem applies. We find critical points by taking the derivative: f'(x) = 3x^2 - 9. Setting this equal to zero gives x = ±sqrt(3). Evaluating f(x): f(-3) = 0; f(sqrt(3)) ≈ -1.4641; f(-sqrt(3)) ≈ 1.4641; and f(3) = 0. The absolute minimum occurs at x = sqrt(3), so the minimum value is approximately -1.4641, which is closest to A (-27).

Explanation:


Common mistake note:
A common mistake is to overlook one or both of the critical points.

Problem 4 (DlkJh4567):
Find the absolute maximum value of f(x) = 2x^2 - 8x + 9 on the interval [-1, 4].
A) 1
B) 3
C) 9
D) 17
Correct Answer: D

Solution:
The extreme value theorem applies. We find a single critical point by taking the derivative: f'(x) = 4x - 8. Setting it equal to zero gives x = 2. Evaluating f(x): f(-1) = 17; f(2) = 9; and f(4) = 9. The absolute maximum value occurs at x = -1, so the maximum value is 17.

Explanation:


Common mistake note:
A common mistake is to overlook the endpoint x = -1.
