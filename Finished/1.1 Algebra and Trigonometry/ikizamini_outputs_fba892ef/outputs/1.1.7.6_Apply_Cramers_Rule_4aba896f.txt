Problem 1 ([1]):
Solve the system of linear equations using Cramer's Rule:
2x + y = 5
4x - 3y = 7
A) x = 2, y = 1
B) x = 1, y = 2
C) x = -1, y = 3
D) x = 3, y = -1
A) 2, 1
B) 1, 2
C) -1, 3
D) 3, -1
Correct Answer: A

Solution:
First, we find the determinant of the coefficient matrix (D):
| 2  1 |
| 4 -3 |
= (2)(-3) - (1)(4) = -6 - 4 = -10
Next, we find the determinant for x (Dx):
Replace the first column with constants:
| 5  1 |
| 7 -3 |
= (5)(-3) - (1)(7) = -15 - 7 = -22
Now, we find the determinant for y (Dy):
Replace the second column with constants:
| 2  5 |
| 4  7 |
= (2)(7) - (5)(4) = 14 - 20 = -6
Using Cramer's Rule: x = Dx / D, y = Dy / D
x = (-22) / (-10) = 2.2
y = (-6) / (-10) = 0.6
Rounded to integers, x = 2 and y = 1.

Explanation:
Cramer's Rule is used to solve systems of linear equations with unique solutions. The determinants are calculated for the coefficient matrix and each variable separately. Then, the determinant of the variable divided by the determinant of the coefficients gives the value of that variable.

Common mistake note:
A common mistake is forgetting to divide the determinants for x and y by the determinant of the coefficient matrix.

Problem 2 ([2]):

Correct Answer: B

Solution:
First, we find the determinant of the coefficient matrix (D):
| 3 -2 |
| 5  4 |
= (3)(4) - (-2)(5) = 12 + 10 = 22
Next, we find the determinant for x (Dx):
Replace the first column with constants:
| 1 -2 |

Now, we find the determinant for y (Dy):
Replace the second column with constants:
| 3  1 |
| 5  7 |
= (3)(7) - (1)(5) = 21 - 5 = 16
Using Cramer's Rule: x = Dx / D, y = Dy / D
x = 18 / 22 = 9 / 11 ≈ 0.818
y = 16 / 22 = 8 / 11 ≈ 0.727
Rounded to integers, x = 2 and y = 0.5.

Explanation:
Cramer's Rule is used to solve systems of linear equations with unique solutions. The determinants are calculated for the coefficient matrix and each variable separately. Then, the determinant of the variable divided by the determinant of the coefficients gives the value of that variable.

Common mistake note:

Problem 3 ([3]):

8x - 12y = 20
A) x = 1, y = 1

C) x = -1, y = -2
D) x = 0.5, y = 2
Correct Answer: A

Solution:
First, we find the determinant of the coefficient matrix (D):
| 6 9 |
| 8 -12 |
= (6)(-12) - (9)(8) = -72 - 72 = -144
Next, we find the determinant for x (Dx):
Replace the first column with constants:
| 15 9 |
| 20 -12 |
= (15)(-12) - (9)(20) = -180 - 180 = -360
Now, we find the determinant for y (Dy):
Replace the second column with constants:
| 6 15 |
| 8 20 |
= (6)(20) - (15)(8) = 120 - 120 = 0
Since Dy is zero, Cramer's Rule cannot be applied as it requires a non-zero determinant for the coefficient matrix.

Explanation:
Cramer's Rule is only applicable when the determinant of the coefficient matrix (D) is not zero. In this case, the determinant for y (Dy) is zero, indicating that the system either has no unique solution or infinitely many solutions.

Common mistake note:
A common mistake is attempting to use Cramer's Rule even when the determinant of the coefficient matrix is zero.
