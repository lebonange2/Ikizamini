Problem 1 (:1):
Sketch the graph of y = |2x - 3|.
A) [Insert a graph where the line y = 2x - 3 is reflected above the x-axis and below the x-axis, creating a V-shape centered at (1.5, 0)]
B) [Insert a graph where the line y = 2x - 3 is shifted to the right by 1.5 units and flipped vertically]
C) [Insert a graph where the line y = 2x - 3 is stretched horizontally by a factor of 2 and shifted up by 3 units]
D) [Insert a graph where the line y = 2x - 3 is reflected across the y-axis and shifted down by 3 units]
Correct Answer: A

Solution:
The absolute value function |2x - 3| reflects any input x-value less than 1.5 (the vertex of the original line) across the vertical line x = 1.5, while keeping values greater than or equal to 1.5 unchanged. This results in a V-shape centered at (1.5, 0).

Explanation:
The graph is created by reflecting the line y = 2x - 3 above and below the x-axis, which corresponds to choice A.

Common mistake note:
Common mistake: Choosing B, which reflects the original line vertically instead of horizontally across the vertical line x = 1.5.

Problem 2 (2):
What is the vertex of the graph of y = |3x + 4|?
A) ( -4/3, 0)
B) (4/3, 0)
C) (-1.5, 0)
D) (1.5, 0)
Correct Answer: A

Solution:
The vertex of an absolute value function in the form y = |ax + b| is at the point where the inside linear function crosses the x-axis, which occurs at x = -b/a.

Explanation:
For y = |3x + 4|, a = 3 and b = 4, so the vertex is at x = -4/3. The corresponding y-coordinate will be 0 because it's the x-intercept of the linear function inside the absolute value bars.

Common mistake note:
Common mistake: Choosing B, which is the result of dividing b by a without considering the negative sign.

Problem 3 (3):
Sketch the graph of y = |x| + 2.
A) [Insert a graph where the line y = x is shifted up by 2 units and mirrored horizontally around the y-axis, creating a square U-shape]
B) [Insert a graph where the line y = x is reflected across the y-axis and shifted down by 2 units]
C) [Insert a graph where the line y = x is stretched vertically by a factor of 2 and shifted up by 2 units]
D) [Insert a graph where the line y = x is reflected across the x-axis and shifted to the right by 2 units]
Correct Answer: A

Solution:
The absolute value function |x| shifts the linear function y = x up by 2 units, mirroring it horizontally around the y-axis. This results in a square U-shape.

Explanation:
The graph is created by shifting the line y = x up by 2 units and reflecting it across the y-axis, which corresponds to choice A.

Common mistake note:
Common mistake: Choosing B, which reflects the original line horizontally instead of mirroring it around the y-axis.

Problem 4 (4):
What is the range of the function y = |2x - 1|?
A) [0, ∞)
B) (-∞, ∞)
C) [-1, ∞)
D) [1, ∞)
Correct Answer: A

Solution:
The range of an absolute value function in the form y = |ax + b| is determined by the sign inside the absolute value bars. If a > 0, the range is [0, ∞).

Explanation:
For y = |2x - 1|, a = 2, which is positive, so the range is all non-negative numbers starting from 0.

Common mistake note:
Common mistake: Choosing B, which is the range of a linear function without an absolute value.

Problem 5 (5):
Find the equation of the line that forms the right side of the graph of y = |x - 3|.
A) y = x - 3
B) y = x + 3
C) y = -x - 3
D) y = -x + 3
Correct Answer: A

Solution:
The right side of the absolute value function y = |x - 3| is formed by the original linear function without reflection, which is y = x - 3.

Explanation:
For the graph y = |x - 3|, the right side follows the line y = x - 3 directly. Choice A represents this line.

Common mistake note:
Common mistake: Choosing B, which reflects the original line across the y-axis instead of keeping it unchanged.

Problem 6 (6):
Sketch the graph of y = |2(x - 1)| + 3.
A) [Insert a graph where the line y = 2x is shifted right by 1 unit, reflected horizontally around the vertical line x = 1, and then shifted up by 3 units, creating a square U-shape centered at (1, 3)]
B) [Insert a graph where the line y = 2x is stretched vertically by a factor of 2, shifted right by 1 unit, and then reflected across the x-axis, creating a V-shape centered at (1, 0)]
C) [Insert a graph where the line y = 2x is shifted up by 3 units, reflected horizontally around the vertical line x = 1, and then stretched vertically by a factor of 2, creating a square U-shape centered at (1, 6)]
D) [Insert a graph where the line y = 2x is shifted right by 1 unit, reflected across the x-axis, and then shifted up by 3 units, creating a V-shape centered at (1, 3)]
Correct Answer: A

Solution:
The function y = |2(x - 1)| + 3 shifts the line y = 2x right by 1 unit, reflects it horizontally around x = 1, and then shifts up by 3 units. This results in a square U-shape.

Explanation:
The graph is created by applying each transformation step-by-step: shift right by 1, reflect horizontally around x = 1 (which effectively multiplies the inside function by 2), and then shift up by 3 units. Choice A represents this process.

Common mistake note:
Common mistake: Choosing B, which reflects the original line across the x-axis instead of reflecting it horizontally.

Problem 7 (7):
What is the domain of the function y = |x + 2|?
A) (-∞, ∞)
B) [-2, ∞)
C) [0, ∞)
D) [-∞, -2]
Correct Answer: A

Solution:
The domain of an absolute value function in the form y = |ax + b| is all real numbers (-∞, ∞), as there are no restrictions on x.

Explanation:
For y = |x + 2|, there are no values of x that make the expression inside the absolute value bars undefined, so the domain is all real numbers.

Common mistake note:
Common mistake: Choosing B or D, which suggests a restricted domain based on the linear function inside the absolute value bars, but forgetting that the absolute value function makes all inputs non-negative.
