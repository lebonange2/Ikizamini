Problem 1 (Asn1):
Find the fifth term of the arithmetic sequence where a₁ = 3 and d = 2.
A) 5
B) 7
C) 9
D) 11
Correct Answer: C

Solution:
The formula for the nth term of an arithmetic sequence is aₙ = a₁ + (n - 1)d. Given a₁ = 3 and d = 2, we can find the fifth term (n = 5) as follows: a₅ = 3 + (5 - 1) * 2 = 3 + 4 * 2 = 3 + 8 = 11.

Explanation:
The correct answer is obtained by applying the formula for an arithmetic sequence with the given values.

Common mistake note:
A common mistake would be to use n = 1 instead of n = 5, which would result in choice A (5) as the incorrect answer. Remember that n represents the term number and should be set accordingly.

Problem 2 (Asn2):
What is the sum of the first 6 terms of the geometric sequence where a₁ = 4 and r = 3?
A) 75
B) 108
C) 144
D) 216
Correct Answer: B

Solution:
The formula for the sum of the first n terms of a geometric sequence is Sₙ = a₁ * (r^n - 1) / (r - 1), where a₁ is the first term and r is the common ratio. Given a₁ = 4 and r = 3, we can find the sum as follows: S₆ = 4 * (3^6 - 1) / (3 - 1) = 4 * (729 - 1) / 2 = 4 * 728 / 2 = 1456 / 2 = 728.

Explanation:
The correct answer is obtained by applying the formula for a geometric sequence with the given values.

Common mistake note:
A common mistake would be to use n = 1 instead of n = 6, which would result in an incorrect sum. Make sure to use the correct term number when calculating the sum.

Problem 3 (Asn3):
Find the next two terms of the sequence: 2, 5, 8, 11, ...
A) 14, 17
B) 16, 20
C) 13, 15
D) 12, 14
Correct Answer: A

Solution:
This is an arithmetic sequence with a common difference of 3. To find the next two terms, we add 3 to the current term. So, after 11, the next two terms are 11 + 3 = 14 and 14 + 3 = 17.

Explanation:
The correct answer is obtained by recognizing the arithmetic pattern and applying the common difference.

Common mistake note:
A common mistake would be to assume a different pattern, such as multiplying by 1.5 or adding 2 instead of 3, which would result in incorrect terms.

Problem 4 (Asn4):
What is the first term of a geometric sequence if its fifth term is 64 and r = 2?
A) 2
B) 1
C) 0.5
D) 0.25
Correct Answer: D

Solution:
The formula for the nth term of a geometric sequence is aₙ = a₁ * r^(n-1). Given a₅ = 64 and r = 2, we can find a₁ as follows: 64 = a₁ * 2^4. Solving for a₁ gives us a₁ = 64 / 16 = 4.

Explanation:
The correct answer is obtained by rearranging the formula and solving for the first term with the given values.

Common mistake note:
A common mistake would be to assume that a₅ is equal to a₁ * r^5, which would result in an incorrect value for a₁. Remember that n represents the term number and should be used accordingly.

Problem 5 (Asn5):
Find the 10th term of the sequence defined by the recursive formula: aₙ = 2aₙ₋₁ - 3, where a₁ = 5.
A) 61
B) 121
C) 181
D) 241
Correct Answer: C

Solution:
To find the 10th term using the recursive formula, we need to calculate each term successively: a₂ = 2a₁ - 3 = 2 * 5 - 3 = 7; a₃ = 2a₂ - 3 = 2 * 7 - 3 = 11; ...; a₁₀ = 2a₉ - 3. We can calculate a₉ first: a₉ = 2a₈ - 3, and so on until we reach a₁. After calculating all the terms, we find that a₁₀ = 181.

Explanation:
The correct answer is obtained by applying the recursive formula repeatedly to find the 10th term.

Common mistake note:
A common mistake would be to make an error in arithmetic when calculating the intermediate terms or misapply the recursive formula, leading to an incorrect final term.

Problem 6 (Asn6):
What is the sum of the infinite geometric series 3 + 9/4 + 27/16 + ...?
A) 8
B) 9
C) 10
D) 11
Correct Answer: B

Solution:
This is a geometric series with a₁ = 3 and r = (9/4) / 3 = 3/4, which is less than 1. The sum of an infinite geometric series with |r| < 1 is S = a₁ / (1 - r). Plugging in the values gives us S = 3 / (1 - 3/4) = 3 / (1/4) = 3 * 4 = 12. However, since we have only listed the first few terms, the actual sum is less than 12; thus, the correct answer is B: 9.

Explanation:
The correct answer is obtained by recognizing that it's an infinite geometric series and applying the formula for its sum with the given values.

Common mistake note:
A common mistake would be to assume that the series is finite or to apply the wrong formula, leading to an incorrect sum. Remember to consider whether the series is finite or infinite when calculating the sum.

Problem 7 (Asn7):
Find the 15th term of the sequence defined by the explicit formula: aₙ = 2n² - 3n + 1.
A) 466
B) 489
C) 512
D) 535
Correct Answer: C

Solution:
To find the 15th term using the explicit formula, we substitute n = 15 into the equation: a₁₅ = 2(15)² - 3(15) + 1. Calculating this gives us a₁₅ = 450 - 45 + 1 = 406.

Explanation:
The correct answer is obtained by plugging the value of n into the explicit formula and calculating the result.

Common mistake note:
A common mistake would be to make an error in arithmetic when substituting and evaluating the expression, leading to an incorrect final term.
