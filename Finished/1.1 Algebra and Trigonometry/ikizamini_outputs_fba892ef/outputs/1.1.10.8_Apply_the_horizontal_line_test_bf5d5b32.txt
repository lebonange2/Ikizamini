Problem 1 (:1):
Which function's graph passes the horizontal line test?
A) y = x^2 + 3x
B) y = |x| - 2
C) y = 5e^x
D) y = sin(x)
Correct Answer: C

Solution:
The horizontal line test determines if a function is one-to-one. An exponential function like y = 5e^x never intersects a horizontal line more than once, indicating it's one- to-one.

Explanation:
Function C (y = 5e^x) has a strictly increasing curve that doesn't intersect a horizontal line multiple times, making it pass the test. Functions A, B, and D can be intersected by a horizontal line more than once.

Common mistake note:
Common mistake: choosing functions with curves or symmetry (A, B, or D) which intersect horizontal lines multiple times.

Problem 2 (:2):
Which graph fails the horizontal line test?
A) [Graph of y = x^3 - 1]
B) [Graph of y = sqrt(x)]
C) [Graph of y = ln(x)]
D) [Graph of y = x^2 + 1]
Correct Answer: D

Solution:
The graph of y = x^2 + 1 fails the test as it's a parabola intersecting a horizontal line at two points (e.g., when y = 0).

Explanation:
A parabolic function like y = x^2 + 1 has a U-shape and intersects a horizontal line twice if placed below the vertex, failing the test.

Common mistake note:
Common mistake: choosing graphs representing inverse functions (like C) that visually appear to pass but are actually one-to-one.

Problem 3 (:3):
Which relation's graph passes the horizontal line test?
A) x^2 + y^2 = 1
B) y = arctan(x)
C) y = x^2 - x
D) y = 2^x
Correct Answer: D

Solution:
The relation represented by y = 2^x passes the test as it's a one-to-one exponential function.

Explanation:
An exponential function like y = 2^x has a strictly increasing curve that doesn't intersect a horizontal line more than once, making it pass the test. Relations A, B, and C do not pass.

Common mistake note:
Common mistake: choosing relations with curves or symmetry (A, B, or C) which intersect horizontal lines multiple times.

Problem 4 (:4):
If a function passes the horizontal line test, does it have an inverse?
A) Yes, because all such functions have inverses.
B) No, some functions may not be defined for all real numbers.
C) Yes, and the inverse is also a function.
D) No, the function might not be continuous.
Correct Answer: C

Solution:
A one-to-one function (horizontal line test passed) has an inverse, which is also a function. Continuity and domain considerations apply.

Explanation:
A function passing the test is one-to-one; each input corresponds to a unique output, allowing it to have an inverse. Other conditions like continuity must be met.

Common mistake note:
Common mistake: choosing 'Yes, because all such functions have inverses.' which ignores continuity and domain constraints.

Problem 5 (:5):
Which function has a graph that passes the horizontal line test and is continuous for all real numbers?
A) y = 1/x
B) y = cos(x)
C) y = x^3 - 2x
D) y = e^(-x)
Correct Answer: D

Solution:
The function y = e^(-x) passes the test and is continuous for all real numbers as it's an exponential decay function.

Explanation:
An exponential decay function like y = e^(-x) has a strictly decreasing curve that doesn't intersect a horizontal line more than once, making it one-to-one and continuous everywhere.

Common mistake note:
Common mistake: choosing A (y = 1/x), which is not continuous at x = 0, or B (y = cos(x)), which is periodic.

Problem 6 (:6):
Which function fails the horizontal line test but has a removable discontinuity?
A) y = x^2 / (x - 1)
B) y = tan(x)
C) y = |x| + 3
D) y = ln|x|
Correct Answer: A

Solution:
Function y = x^2 / (x - 1) fails the test due to a removable discontinuity at x = 1.

Explanation:
Function A has a removable discontinuity at x = 1 because of the factor (x - 1), making it undefined. Simplifying removes that point where the test fails.

Common mistake note:
Common mistake: choosing B (y = tan(x)), which has infinite discontinuities, or C (y = |x| + 3) and D (y = ln|x|), which don't have removable discontinuities.

Problem 7 (:7):
If a function fails the horizontal line test, is it non-differentiable?
A) Yes, all such functions are not differentiable.
B) No, some functions may be differentiable despite failing.
C) Yes, and the derivative is always zero.
D) No, but the derivative might exist only at certain points.
Correct Answer: B

Solution:
Failing the test doesn't imply non-differentiability. It just means it's not one-to-one. Differentiability depends on continuity and smoothness.

Explanation:
A function failing the test isn't necessarily non-differentiable; differentiability requires continuity and smoothness, which can be true even if not one-to-one.

Common mistake note:
Common mistake: choosing 'Yes, all such functions are not differentiable.' Some functions can be differentiable despite failing the test.
