Problem 1 (One):
Factor the expression: x^3 - 6x^2 + 9x
A) (x - 3)^3
B) (x - 3)(x^2 - 3)
C) (x - 3)(x - 1)^2
D) (x - 3)^2(x + 1)
Correct Answer: B

Solution:
The expression can be factored by taking out the greatest common factor (GCF) of x from each term. So we get: x(x^2 - 6x + 9). The remaining part is a perfect square trinomial, which factors as (x - 3)^2. Therefore, the correct factorization is (x - 3)(x^2 - 3).

Explanation:
The key to this problem is recognizing that x^2 - 6x + 9 is a perfect square trinomial and factoring it accordingly.

Common mistake note:
A common mistake would be to incorrectly factor the quadratic part as (x - 1)(x - 3), which would lead to choice C. This fails because the correct factorization must have an irreducible quadratic factor.

Problem 2 (Two):

A) (2y - 3)^2
B) (2y + 3)(2y + 3)
C) (2y + 3)^3
D) (2y + 6)^2
Correct Answer: B

Solution:
The expression is a perfect square trinomial, which can be factored directly as (2y + 3)(2y + 3).

Explanation:

Common mistake note:

Problem 7 (Seven):
Factor the expression: x^3 - 27x^2 + 189x - 405
A) (x - 9)^3
B) (x - 9)(x^2 - 18)
C) (x - 9)(x - 3)^2

Correct Answer: C

Solution:
First, factor out the GCF of x from each term: x(x^2 - 27x + 189). The remaining part is a quadratic trinomial that can be factored by grouping: (x^2 - 27x + 189) = (x^2 - 27x + 81) + (108 - 81) = (x - 9)^2 + 27. Since the second term is a constant, it cannot be factored further and must remain as part of the irreducible quadratic factor. So the correct factorization is (x - 9)(x - 3)^2.

Explanation:
The key here is recognizing that x^2 - 27x + 189 can be factored by grouping into a perfect square trinomial and a constant term.

Common mistake note:
A common mistake would be to incorrectly factor (x^2 - 27x + 189) as (x - 9)(x - 21), which would lead to choice D. This fails because the correct factorization must have an irreducible quadratic factor.
