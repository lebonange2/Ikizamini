Problem 1 (AsVjx7cN):
Solve and graph the inequality: |x - 3| < 4.
A) -1 < x < 7
B) x > 7 or x < -1
C) x = 3
D) No solution
Correct Answer: A

Solution:
To solve the inequality |x - 3| < 4, consider two cases: when (x - 3) is positive and when it's negative.

Case 1: x - 3 ≥ 0
(x - 3) < 4
x < 7
Combine with x ≥ 3 to get [3, 7).

Case 2: x - 3 < 0
-(x - 3) < 4
-x + 3 < 4
x > -1
Combine with x < 3 to get (-∞, 3).

The solution is -1 < x < 7.

Explanation:
Account for both cases where the absolute value expression can be positive or negative. Choice B assumes OR (incorrect), C only considers equality, and D misses the solution.

Common mistake note:
Not considering both cases in absolute value inequality.

Problem 2 (LXz2fTqP):
Solve and graph the inequality: |2x + 5| ≤ 10.
A) -7.5 ≤ x ≤ 2.5
B) x = -7.5 or x = 2.5
C) -∞ < x < ∞
D) No solution
Correct Answer: A

Solution:
Consider two cases: when (2x + 5) is positive and when it's negative.

Case 1: 2x + 5 ≥ 0
2x + 5 ≤ 10
2x ≤ 5
x ≤ 2.5
Combine with x ≥ -2.5 to get [-2.5, 2.5].

Case 2: 2x + 5 < 0
-(2x + 5) ≤ 10
-2x - 5 ≤ 10
-2x ≤ 15
x ≥ -7.5
Combine with x < -2.5 to get [-7.5, ∞).

The solution is -7.5 ≤ x ≤ 2.5.

Explanation:
Account for both cases and find the intersection of ranges. Choice B only considers equality, C misunderstands ≤, D misses solution.

Common mistake note:
Not considering both cases in absolute value inequality.

3x > 8 or 3x < -6

B) x = -1 or x = 4

4x - 6 ≥ 10
4x ≥ 16

-(4x - 6) ≥ 10
-4x + 6 ≥ 10
-4x ≥ 4
x ≤ -1
Combine with x < 1.5 to get (-∞, -1].

Solution is x ≤ -1 or x ≥ 4.

Explanation:
Account for both cases and find union of ranges. Choice B only considers equality, C misunderstands inequality symbol, D misses solution.

Problem 5 (z2nXKZuX):
Solve and graph the inequality: |x| < 3.
A) -3 < x < 3
B) x = -3 or x = 3
C) -∞ < x < ∞
D) No solution
Correct Answer: A

Solution:
|x| < 3 represents all x where |x| < 3. Range: (-3, 3).

Explanation:
Recognize numbers within 3 units of zero. Choice B only considers equality, C misunderstands strict inequality symbol, D misses solution.
