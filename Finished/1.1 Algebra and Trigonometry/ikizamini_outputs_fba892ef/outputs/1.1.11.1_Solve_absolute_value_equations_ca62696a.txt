Problem 1 (:1):
Solve the equation: |x - 3| = 7
A) -4
B) 4
C) 10
D) 10 or -4
Correct Answer: D

Solution:
To solve the absolute value equation |x - 3| = 7, we consider two cases:

Case 1: x - 3 is positive or zero
x - 3 = 7
x = 10

Case 2: x - 3 is negative
-(x - 3) = 7
-x + 3 = 7
-x = 4
x = -4

So, the solutions are x = 10 and x = -4.

Explanation:
The absolute value equation represents two scenarios: when the expression inside the absolute value is positive or zero, and when it's negative. We solve each case separately to find all possible solutions.

Common mistake note:
A common mistake is to assume that only one solution exists (either x = 10 or x = -4), forgetting that there can be two solutions for an absolute value equation.

Problem 2 (:2):
Solve the equation: |2x + 5| = 13
A) -9
B) 4
C) 4 or -9
D) 8
Correct Answer: C

Solution:
To solve the absolute value equation |2x + 5| = 13, we consider two cases:

Case 1: 2x + 5 is positive or zero
2x + 5 = 13
2x = 8
x = 4

Case 2: 2x + 5 is negative
-(2x + 5) = 13
-2x - 5 = 13
-2x = 18
x = -9

So, the solutions are x = 4 and x = -9.

Explanation:
Again, we solve for two separate cases: when the expression inside the absolute value is positive or zero, and when it's negative. Both cases lead to distinct solutions.

Common mistake note:
A common mistake here might be to divide by 2x directly without considering the sign of 2x + 5, which would result in a single incorrect solution.

Problem 3 (:3):
Solve the equation: |3 - x| = |2x + 1|
A) -4 or 1
B) 0 or 2
C) 1 or 2
D) No solution
Correct Answer: A

Solution:
To solve the equation |3 - x| = |2x + 1|, we can consider several cases:

Case 1: Both expressions are positive or zero
3 - x = 2x + 1
-x - 2x = 1 - 3
-3x = -2
x = 2/3

However, this solution doesn't satisfy the original equation because it makes one side of the equation negative and the other positive.

Case 2: One expression is positive and the other negative
We need to find values of x that make one side positive and the other negative. We can test different intervals for x to find such values.

For x < -1/2, both expressions are negative:
-x + 3 = -(2x + 1)
x + 2x = 4
3x = 4
x = 4/3 (not in the interval)

For -1/2 ≤ x < 3, 3 - x is positive and 2x + 1 is negative:
3 - x = -(2x + 1)
x + 2x = -4
3x = -4
x = -4/3
This solution satisfies the original equation.

For x ≥ 3, both expressions are positive:
-x + 3 = 2x + 1
-x - 2x = -2
-3x = -2
x = 2/3 (not in the interval)

So, the solution is x = -4/3.

Explanation:
In this case, we have to consider different intervals for x because the absolute values can change signs. We find a single solution that satisfies both expressions having opposite signs.

Common mistake note:
A common mistake would be assuming that there are no solutions or incorrectly identifying when the expressions inside the absolute values have the same sign.

Problem 4 (:4):
Solve the equation: |x + 2| = 0
A) -2
B) 0
C) No solution
D) 2
Correct Answer: A

Solution:
The absolute value of a number is zero if and only if the number itself is zero. Therefore, to solve |x + 2| = 0, we set x + 2 equal to zero:
x + 2 = 0
x = -2

Explanation:
For an absolute value equation to be equal to zero, the expression inside must be exactly zero.

Common mistake note:
A common mistake would be assuming that there are multiple solutions or choosing a non-zero value for x.

Problem 6 (:6):
Solve the equation: |x - 5| + |2x + 3| = 10
A) -4, 7/3
B) 0, 7/3
C) No solution
D) 7/3, 7
Correct Answer: A

Solution:
To solve the equation |x - 5| + |2x + 3| = 10, we need to consider different intervals for x because the absolute values can change signs. We'll test three intervals: x < -3/2, -3/2 ≤ x < 5, and x ≥ 5.

Interval 1: x < -3/2
Both expressions are negative:
-(x - 5) - (2x + 3) = 10
-x + 5 - 2x - 3 = 10
-3x + 2 = 10
-3x = 8
x = -8/3
This solution satisfies the original equation.

Interval 2: -3/2 ≤ x < 5
|x - 5| is negative, |2x + 3| is positive:
-(x - 5) + (2x + 3) = 10
-x + 5 + 2x + 3 = 10
x + 8 = 10
x = 2
This solution satisfies the original equation.

Interval 3: x ≥ 5
Both expressions are positive:
x - 5 + 2x + 3 = 10
3x - 2 = 10
3x = 12
x = 4
This value is not in the interval, so it's not a solution.

So, the solutions are x = -8/3 and x = 2.

Explanation:
We need to consider different intervals for x because the absolute values can change signs. We find two solutions that satisfy the equation.

Common mistake note:
A common mistake would be assuming that there is only one solution or not considering all possible cases for the signs of the expressions inside the absolute values.
