Problem 1 (?):
Find the period of the function f(x) = tan(4x).
A) π
B) π/2
C) π/4
D) 2π
Correct Answer: B

Solution:
The period of a tangent function is π divided by the absolute value of the coefficient inside the argument. For f(x) = tan(4x), the coefficient is 4, so the period is π / 4. Therefore, the correct answer is B: π/2.

Explanation:
The period of a trigonometric function like tangent is determined by the coefficient in front of x. The general form for the period of tan(kx) is π / |k|.

Common mistake note:
A common mistake is to forget that the period is affected by the absolute value of k, which can lead to choosing A (π) or D (2π).

Problem 2 (?):
Sketch the graph of y = cot(x) for one full period. Which of the following statements is true about the graph?
A) There are no vertical asymptotes.
B) The function has a maximum value of 1 at x = π/2.
C) The function has a minimum value of -1 at x = 3π/2.
D) The function is decreasing on the interval (0, π).
Correct Answer: D

Solution:
The graph of y = cot(x) has vertical asymptotes at x = kπ, where k is an integer. It does not have any maxima or minima but rather approaches infinity and negative infinity near the vertical asymptotes. The function is decreasing on (0, π) and increasing on (π, 2π). Therefore, the correct answer is D: The function is decreasing on the interval (0, π).

Explanation:
The cotangent function behaves similarly to the tangent function but with a phase shift of π/2. It has vertical asymptotes at multiples of π and oscillates between positive and negative infinity.

Common mistake note:
A common mistake is to confuse the behavior of cotangent with that of sine or cosine, which have maxima and minima rather than approaching infinity.

Problem 3 (?):
Find the domain of the function g(x) = cot(3x - π/2).
A) All real numbers
B) (π/6, 5π/6)
C) (-π/6, π/6)
D) R excluding (π/6 + kπ, 5π/6 + kπ), where k is an integer.
Correct Answer: D

Solution:
The domain of the cotangent function is all real numbers except for x values that make the argument equal to kπ, where k is an integer. For g(x) = cot(3x - π/2), we need to find when 3x - π/2 = kπ. Solving this equation gives us x = (π/6 + kπ)/3. Therefore, the domain excludes intervals of length π around π/6 and its integer multiples. The correct answer is D: R excluding (π/6 + kπ, 5π/6 + kπ), where k is an integer.

Explanation:
The domain of a cotangent function is determined by the restrictions imposed by the argument being equal to multiples of π.

Common mistake note:
A common mistake is to forget that the phase shift affects the location of the vertical asymptotes and thus the domain.

Problem 4 (?):
Sketch the graph of y = tan(x) - 2 for one full period. Which of the following statements is true about the graph?
A) The function has a minimum value of -3 at x = π/4.
B) The asymptotes are shifted to x = (π/2 + kπ)/2, where k is an integer.
C) The period remains π, but the amplitude is increased by 2.
D) The function is decreasing on the interval (-π/2, π/2).
Correct Answer: A

Solution:
The graph of y = tan(x) - 2 shifts the original tangent function down by 2 units. It still has a period of π and vertical asymptotes at x = kπ/2, where k is an integer. The minimum value occurs when tan(x) = -1, which happens at x = π/4 for one period. Therefore, the correct answer is A: The function has a minimum value of -3 at x = π/4.

Explanation:
When a constant is added to or subtracted from a tangent function, it shifts the graph vertically without changing the period or asymptotes.

Common mistake note:
A common mistake is to forget that adding a constant to the tangent function only affects its vertical position and not its period or asymptotes.

Problem 5 (?):
Find the derivative of f(x) = 2cot(3x).
A) -6csc^2(3x)
B) 6csc^2(3x)
C) -6sec^2(3x)
D) 6sec^2(3x)
Correct Answer: A

Solution:
The derivative of the cotangent function is -csc^2(x). To find the derivative of f(x) = 2cot(3x), use the chain rule: df/dx = -2csc^2(3x) * d/dx[3x] = -6csc^2(3x). Therefore, the correct answer is A: -6csc^2(3x).

Explanation:
The derivative of a cotangent function involves applying the chain rule to account for the inner function.

Common mistake note:
A common mistake is to forget to apply the chain rule or to use the wrong derivative of cotangent (csc^2 instead of -csc^2).

The function is increasing on the interval (-π/2, π/2) because the cotangent function is decreasing in that interval. Therefore, the correct answer is D: The function is increasing on the interval (-π/2, π/2).

Explanation:
When a constant is added to or subtracted from a cotangent function, it shifts the graph vertically without changing the period or asymptotes.

Common mistake note:

Problem 7 (?):
Find the zeros of the function h(x) = 3tan(2x) - 1.
A) x = (π/6 + kπ)/2, where k is an integer
B) x = (π/4 + kπ)/2, where k is an integer
C) x = (π/3 + kπ)/2, where k is an integer
D) x = (π/8 + kπ)/2, where k is an integer
Correct Answer: B

Solution:
To find the zeros of h(x) = 3tan(2x) - 1, set the equation equal to zero: 3tan(2x) - 1 = 0. Solving for tan(2x), we get tan(2x) = 1/3. The solutions for 2x are (π/6 + kπ)/2 and (5π/6 + kπ)/2, where k is an integer. Dividing by 2 gives us the zeros of x: x = (π/6 + kπ)/4 and x = (5π/6 + kπ)/4, which simplifies to x = (π/4 + kπ)/2. Therefore, the correct answer is B: x = (π/4 + kπ)/2, where k is an integer.

Explanation:
To find the zeros of a trigonometric function, set it equal to zero and solve for the angle inside the trigonometric function.

Common mistake note:
A common mistake is to forget to divide by the coefficient of tan(2x) or to use the wrong identity when solving for the zeros.
