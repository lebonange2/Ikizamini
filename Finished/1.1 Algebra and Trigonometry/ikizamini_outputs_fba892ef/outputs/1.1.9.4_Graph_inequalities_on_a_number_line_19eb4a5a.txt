Problem 1 (:Q1):
Graph the inequality: x > 3
A) [3, ∞)
B) (3, ∞)
C) (-∞, 3]
D) (-∞, 3)
Correct Answer: B

Solution:
The inequality x > 3 means 'x is greater than 3'. On a number line, this would be represented by an open circle at 3 (since x can't be exactly 3) and an arrow pointing to the right, indicating all values greater than 3. The correct graph is therefore '(3, ∞)' which denotes all real numbers greater than 3.

Explanation:
An open circle indicates that the value is not included in the solution set, while a closed circle means it is included. In this case, since x > 3, we use an open circle at 3.

Common mistake note:
Common mistake: Choosing 'A', which uses a closed circle at 3. This would indicate that x can be exactly 3, but the inequality states that x must be greater than 3.

Problem 3 (:Q3):
Graph the inequality: -2 < x < 5
A) (-∞, -2) U (5, ∞)
B) [-2, 5]
C) (2, 5)
D) (-2, 5)
Correct Answer: D

Solution:
The inequality -2 < x < 5 means 'x is greater than -2 and less than 5'. On a number line, this would be represented by open circles at -2 and 5 (since x can't be exactly -2 or 5) and a solid line connecting the two points, indicating all values between -2 and 5. The correct graph is therefore '(-2, 5)' which denotes all real numbers strictly between -2 and 5.

Explanation:
Open circles indicate that the value is not included in the solution set, while a solid line between them means all values within that range are included.

Common mistake note:
Common mistake: Choosing 'B', which uses closed circles at -2 and 5. This would indicate that x can be exactly -2 or 5, but the inequality states that x must be strictly between these values.

Problem 7 (:Q7):
Graph the inequality: -3 < x ≤ 2
A) (-∞, -3) U [2, ∞)
B) [2, ∞)
C) [-3, ∞)
D) (-3, 2]
Correct Answer: D

Solution:
The inequality -3 < x ≤ 2 means 'x is greater than -3 and less than or equal to 2'. On a number line, this would be represented by an open circle at -3 (since x can't be exactly -3) and a closed circle at 2 (since x can be exactly 2), with a solid line connecting the two points, indicating all values between -3 and 2. The correct graph is therefore '(-3, 2]' which denotes all real numbers strictly greater than -3 and less than or equal to 2.

Explanation:
An open circle indicates that the value is not included in the solution set, while a closed circle means it is included. In this case, since x < -3 and x ≤ 2, we use an open circle at -3 and a closed circle at 2.

Common mistake note:
Common mistake: Choosing 'C', which uses a closed circle at -3. This would indicate that x can be exactly -3, but the inequality states that x must be strictly greater than -3.
