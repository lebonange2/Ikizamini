Problem 1 (:1):
Solve the inequality: x^2 - 4x + 3 > 0
A) (x - 1)(x - 3) < 0
B) (x - 1)(x - 3) > 0
C) (x + 1)(x + 3) < 0
D) (x + 1)(x + 3) > 0
Correct Answer: B

Solution:
The inequality is in the form of a quadratic equation, x^2 - 4x + 3 > 0. To solve it, we factor the quadratic: (x - 1)(x - 3) > 0. The solution to this inequality occurs when both factors have the same sign, either both positive or both negative. Thus, the correct answer is B.

Explanation:
The inequality represents regions where the quadratic expression is greater than zero. Factoring helps identify those regions by determining the critical points (roots) and testing intervals.

Common mistake note:
A common mistake would be to assume that the inequality remains the same after factoring, forgetting that it only holds true when both factors have the same sign.

Problem 2 (2):
Solve the inequality: 3x^2 - 18x + 27 < 0
A) (x - 3)^2 < 0
B) (x - 3)(x - 9) < 0
C) (x + 3)^2 < 0
D) (x + 3)(x + 9) < 0
Correct Answer: A

Solution:
The inequality is already factored: 3(x - 3)^2 < 0. Since the square of a number is always non-negative, the only way for the entire expression to be less than zero is if the coefficient (3) is negative, which it isn't. Therefore, the solution is x does not exist or empty set. The correct answer choice represents this: (x - 3)^2 < 0.

Explanation:
The inequality involves a squared term, so it's important to recognize that the square of any number is non-negative. Thus, the only way for the entire expression to be negative is if the coefficient outside the square is negative.

Common mistake note:
A common mistake would be to think that since we have a quadratic inequality, we should look for roots and test intervals. However, in this case, the presence of a squared term changes the problem's nature.

Problem 3 (3):
Solve the inequality: x^2 - 6x + 9 ≤ 0
A) (x - 3)^2 ≤ 0
B) (x - 3)(x - 6) ≤ 0
C) (x + 3)^2 ≤ 0
D) (x + 3)(x + 6) ≤ 0
Correct Answer: A

Solution:
The inequality is already factored as (x - 3)^2 ≤ 0. The square of a number is zero when the number itself is zero, so x = 3 is the only solution to this inequality. The correct answer choice represents this: (x - 3)^2 ≤ 0.

Explanation:
The inequality involves a squared term that is less than or equal to zero. This means the expression inside the square must be zero, which occurs when x = 3.

Common mistake note:
A common mistake would be to think that we need to find two solutions for the quadratic equation and test intervals. However, in this case, the inequality is less than or equal to zero, so we only consider the value that makes the expression inside the square zero.

A) (2x + 8)^2 ≥ 0
B) (2x + 8)(2x + 16) ≥ 0
C) (2x - 8)^2 ≥ 0

Solution:
The inequality can be simplified by dividing both sides by 2: x^2 + 8x + 16 ≥ 0, which factors to (x + 4)^2 ≥ 0. Since the square of a number is always non-negative, this inequality holds true for all real numbers x. The correct answer choice represents this: (2x + 8)^2 ≥ 0.

Explanation:
The inequality involves a squared term that is greater than or equal to zero. This means the expression inside the square is never negative, so the inequality holds true for all real numbers.

Common mistake note:
A common mistake would be to think that we need to find roots and test intervals for this quadratic inequality. However, since it involves a squared term, the expression is always non-negative.

Solution:

Explanation:
The inequality involves a squared term that is greater than zero. This means the expression inside the square is never zero, so we can ignore it and focus on the other factor. The solution occurs when only one factor is negative, which happens between the roots of the quadratic.

Common mistake note:
