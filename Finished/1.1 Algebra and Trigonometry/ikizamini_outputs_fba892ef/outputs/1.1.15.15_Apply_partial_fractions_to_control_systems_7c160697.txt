Problem 1 (Inverse Laplace Transform of Partial Fractions A):
Find the inverse Laplace transform of the following function using partial fractions: F(s) = (s + 3)/(s^2 + 4s + 5)
A) e^{-2t}cos(t)
B) e^{-2t}sin(t)
C) e^{-t}cos(2t)
D) e^{-t}sin(2t)
Correct Answer: C

Solution:
The denominator factors as (s + 2)^2 + 1, which is a sum of squares. The partial fractions decomposition is F(s) = A/(s + 2) + B/((s + 2)^2 + 1). Solving for A and B gives A = -1, B = 1/2. Inverse Laplace transform: e^{-t}(-cos(2t) + (1/2)sin(2t)) = e^{-t}sin(2t)

Explanation:
Recognize the sum of squares in the denominator and decompose accordingly.

Common mistake note:
Not recognizing that (s + 2)^2 + 1 is a sum of squares leads to incorrect partial fraction decomposition.

Problem 3 (Partial Fractions with Constants C):
Find the partial fractions decomposition of the following function: H(s) = 4s/(s^2 + 4)
A) A/s + B/(s^2 + 4)
B) (2s - A)/(s^2 + 4) + B/s
C) (2s + A)/(s^2 + 4) + B/s
D) A/(s^2 + 4) + B/ s
Correct Answer: D

Solution:
The denominator is a quadratic with no real roots, so it cannot be factored into linear terms. The decomposition is H(s) = A/(s^2 + 4) + B/s. Solving for A and B gives A = 0, B = 2.

Explanation:
Recognize the irreducible quadratic denominator and decompose accordingly.

Common mistake note:
Attempting to factor the quadratic denominator into linear terms, which is not possible.

Problem 4 (Partial Fractions with Repeated Roots D):
Find the partial fractions decomposition of the following function: I(s) = (s + 2)/(s^3 + 6s^2 + 11s + 6)
A) (A/s + B/(s + 1) + C/(s + 2))^2
B) A/(s + 1)^2 + B/(s + 2)
C) A/(s + 1) + B/(s + 1)^2 + C/(s + 2)
D) A/(s + 1) + B/(s + 2)^2
Correct Answer: C

Solution:
The denominator factors as (s + 1)(s^2 + 5s + 6), which has a repeated root at s = -1. The decomposition is I(s) = A/(s + 1) + B/(s + 1)^2 + C/(s + 2). Solving for A, B, and C gives A = 1, B = -1, C = 0.

Explanation:
Account for the repeated root in the decomposition.

Common mistake note:
Not accounting for the repeated root leads to incorrect partial fraction decomposition.

Problem 5 (Partial Fractions with Linear Factors E):
Find the partial fractions decomposition of the following function: J(s) = (s + 1)/(s(s - 3)(s + 2))
A) A/s + B/(s - 3) + C/(s + 2)
B) (s + 1)/s + A/(s - 3) + B/(s + 2)
C) A/(s - 3)^2 + B/(s + 2)^2
D) A/ s + B/(s - 3)^2 + C/(s + 2)
Correct Answer: A

Solution:
The denominator is a product of linear factors, so the decomposition is J(s) = A/s + B/(s - 3) + C/(s + 2). Solving for A, B, and C gives A = -1, B = 1, C = -1.

Explanation:
Include all linear factors in the decomposition.

Common mistake note:
Not including all linear factors leads to incorrect partial fraction decomposition.

Problem 6 (Partial Fractions with Complex Roots F):
Find the partial fractions decomposition of the following function: K(s) = (s^2 + 1)/(s^3 - s)
A) (As + B)/(s - 1) + C/(s^2 + 1)
B) A/(s - 1)^2 + B/(s^2 + 1)
C) A/(s - 1) + (B + Cs)/(s^2 + 1)
D) (As + B)/(s - 1) + C/(s - i)(s + i)
Correct Answer: D

Solution:
The denominator factors as (s - 1)(s^2 + 1), where s^2 + 1 has complex roots. The decomposition is K(s) = (As + B)/(s - 1) + C/(s - i)(s + i). Solving for A, B, and C gives A = 0, B = 1, C = 1.

Explanation:
Account for the complex roots in the denominator.

Common mistake note:
Not accounting for the complex roots leads to incorrect partial fraction decomposition.

Problem 7 (Partial Fractions with Irreducible Quadratic G):
Find the partial fractions decomposition of the following function: L(s) = (s^2 + 1)/(s^3 + s)
A) (As + B)/(s - 1) + C/(s^2 + 1)
B) A/(s - 1)^2 + B/(s^2 + 1)
C) A/(s - 1) + (B + Cs)/(s^2 + 1)
D) (As + B)/(s - 1) + C/(s^2 + s + 1)
Correct Answer: D

Solution:
The denominator factors as (s - 1)(s^2 + s + 1), where the quadratic factor is irreducible. The decomposition is L(s) = (As + B)/(s - 1) + C/(s^2 + s + 1). Solving for A, B, and C gives A = 0, B = 1, C = 1.

Explanation:
Recognize the irreducible quadratic factor in the denominator and decompose accordingly.

Common mistake note:
Attempting to factor the quadratic factor leads to incorrect partial fraction decomposition.
