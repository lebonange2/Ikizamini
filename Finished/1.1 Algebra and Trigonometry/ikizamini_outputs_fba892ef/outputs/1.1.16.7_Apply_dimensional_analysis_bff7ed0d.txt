Problem 1 (OneMeterToInches):
Convert 1 meter to inches using dimensional analysis.
A) 39.37 inches
B) 52.80 inches
C) 60.00 inches
D) 3.28 feet
Correct Answer: A

Solution:
To convert meters to inches, we use the conversion factor 1 meter = 39.37 inches. We multiply the given value by the conversion factor.

Explanation:
Dimensional analysis involves using conversion factors to change units while keeping the quantity unchanged.

Common mistake note:
A common mistake is forgetting to multiply by the conversion factor or using the wrong conversion ratio.

Problem 5 (TemperatureConversion):
Convert 40 degrees Celsius to Fahrenheit using dimensional analysis.
A) 104 degrees Fahrenheit
B) 86 degrees Fahrenheit
C) 72 degrees Fahrenheit
D) 140 degrees Fahrenheit
Correct Answer: B

Solution:
To convert Celsius to Fahrenheit, we use the formula F = (C x 1.8) + 32. We plug in the given value and calculate.

Explanation:
Dimensional analysis can be applied to temperature conversions by using the appropriate conversion formula.

Common mistake note:
A common mistake is using the wrong conversion formula or forgetting to add 32 after multiplying by 1.8.

Problem 6 (SpeedKilometersToMiles):
Convert a speed of 60 kilometers per hour to miles per hour using dimensional analysis.
A) 37.28 miles per hour
B) 52.80 miles per hour
C) 40 miles per hour
D) 62.14 miles per hour
Correct Answer: B

Solution:
To convert kilometers per hour to miles per hour, we use the conversion factor 1 kilometer = 0.621371 miles and 1 hour = 1 hour (since hours are the same in both systems). We multiply the given value by the conversion factor for kilometers.

Explanation:
Dimensional analysis helps convert speeds between different measurement systems while preserving the actual speed.

Common mistake note:
A common mistake is using an incorrect conversion ratio or not converting to miles per hour.
