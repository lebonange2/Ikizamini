Problem 1 (One Absolute Value Equation):
Solve the equation: |3x - 5| = 7.
A) -4
B) 2
C) 4/3
D) 12
Correct Answer: B

Solution:
To solve an absolute value equation, consider two cases: one where the expression inside is positive and another where it's negative. For |3x - 5| = 7:

1) 3x - 5 = 7
2) 3x - 5 = -7

Solving case 1: x = 4 (not a valid solution)
Solving case 2: x = -2 (not a valid solution)

The correct solution is x = 2, as it satisfies |3(2) - 5| = 7.
The common mistake is assuming both solutions are correct.

Explanation:
We considered two cases and chose the valid solution.

Common mistake note:
Assuming both solutions are correct.

Problem 2 (Two Absolute Value Equations):
Solve the system of equations: |x - 1| = 3, |y + 2| = 4.
A) (1, 2)
B) (-2, -6)
C) (2, -2)
D) (-1, 6)
Correct Answer: C

Solution:
Solve each equation separately:

For |x - 1| = 3: x = 4 or x = -2
For |y + 2| = 4: y = 2 or y = -6

The solution that satisfies both equations is (2, -2). The common mistake is considering only one pair of solutions.

Explanation:
We solved each equation and found the simultaneous solution.

Common mistake note:
Considering only one pair of solutions.
------------------------------------------------------------------------------

Problem 3 (Three Absolute Value Equations):
Solve the system of equations: |2x - 1| = 5, |3y + 4| = 8, |5z - 7| = 12.
A) (3, -4, 5)
B) (-3, 0, -1)
C) (1, -4/3, 11/5)
D) (-1, 4/3, -11/5)
Correct Answer: A

Solution:
Solve each equation separately:

For |2x - 1| = 5: x = 3 or x = -2
For |3y + 4| = 8: y = 4/3 or y = -4
For |5z - 7| = 12: z = 5 or z = -1

The solution that satisfies all three equations is (3, 4/3, 5). The common mistake is overlooking the requirement for a simultaneous solution.

Explanation:
We solved each equation and found the solution valid for all three.

Common mistake note:
Overlooking the need for a solution in all equations.

Problem 4 (Absolute Value Inequality):
Solve the inequality: |2x - 3| < 5.
A) (1, 4)
B) (-∞, -1) U (4, ∞)
C) [-1, 4]
D) (-∞, -4) U (1, ∞)
Correct Answer: A

Solution:
For |2x - 3| < 5, consider two cases:

1) 2x - 3 < 5 => x < 4
2) -(2x - 3) < 5 => x > -1

The solution is x ∈ (-1, 4). The common mistake is not considering the strict inequality.

Explanation:
We considered two cases and combined the solutions.

Common mistake note:
Not considering the strict inequality '<'.

Problem 5 (Absolute Value Equation with Variables on Both Sides):
Solve the equation: |2x - 3| = |4 - x|.
A) 1
B) 2
C) 5/3
D) 3
Correct Answer: C

Solution:
Square both sides to eliminate absolute values:

(2x - 3)^2 = (4 - x)^2
Solve for x: x = 7 or x = -1/3
Check solutions in the original equation: x = 7 is valid, x = -1/3 is not.
The common mistake is assuming both solutions are valid.

Explanation:
We squared both sides, solved for x, and checked solutions.

Common mistake note:
Assuming both solutions are valid.

Problem 6 (Absolute Value Equation with Multiple Variables):
Solve the equation: |x + y| = 5, |x - y| = 3.
A) (2, 3)
B) (-2, -3)
C) (1, 4)
D) (-1, -4)
Correct Answer: C

Solution:
Consider cases for each absolute value equation:

For |x + y| = 5: x = 5 - y or x = -5 + y
For |x - y| = 3: y = x - 3 or y = x + 3

The solution that satisfies both equations is (1, 4). The common mistake is overlooking the requirement for a simultaneous solution.

Explanation:
We considered cases and found the simultaneous solution.

Common mistake note:
Overlooking the need for a solution in all equations.

Problem 7 (Absolute Value Equation with Fractions):
Solve the equation: |(x - 1)/2| = 3/2.
A) 0
B) 1
C) 2
D) -1
Correct Answer: B

Solution:
Multiply both sides by 2 to eliminate the fraction:

|x - 1| = 3
Solve for x: x = 4 or x = -2
Check solutions in the original equation: x = 1 is valid, x = 4 and x = -2 are not.
The common mistake is forgetting to check both solutions.

Explanation:
We multiplied by 2, solved for x, and checked solutions.

Common mistake note:
Forgetting to check both solutions.
