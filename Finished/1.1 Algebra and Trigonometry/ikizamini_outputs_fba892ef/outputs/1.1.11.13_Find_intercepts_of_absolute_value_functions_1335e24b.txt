Problem 1 (AslVZz2cN7KCyjWz):
What is the x-intercept of the function f(x) = |2x - 4|?
A) (0, 0)
B) (2, 0)
C) (4, 0)
D) (-2, 0)
Correct Answer: B

Solution:
To find the x-intercept of an absolute value function, set the expression inside the absolute value equal to zero and solve for x. For f(x) = |2x - 4|, we have 2x - 4 = 0, which leads to x = 2. So the x-intercept is at (2, 0).

Explanation:
The x-intercept occurs where the function crosses the x-axis, and for f(x) = |2x - 4|, this happens when x = 2.

Common mistake note:
A common mistake would be to select (0, 0) because it's a point on the graph of the function, but not an x-intercept since the function value is not zero at x = 0.

Problem 2 (nQz9xjWkZdFVHqLX):
What is the y-intercept of the function g(x) = |3x| + 1?
A) (0, 1)
B) (0, 4)
C) (0, -1)
D) (0, -2)
Correct Answer: A

Solution:
To find the y-intercept of a function, set x = 0 and evaluate the function at that point. For g(x) = |3x| + 1, when x = 0, g(0) = |3*0| + 1 = 1.

Explanation:
The y-intercept is found by evaluating the function when x = 0, which gives us (0, 1).

Common mistake note:
A common mistake would be to select (0, 4) because it's a point on the graph of the function, but not the y-intercept since we're looking for the value when x = 0.

Problem 3 (x7cGKZbEJfLXzr2v):
Find the x-intercept of h(x) = |x + 3| - 5.
A) (2, 0)
B) (-8, 0)
C) (-2, 0)
D) (8, 0)
Correct Answer: B

Solution:
Set the expression inside the absolute value equal to zero and solve for x: |x + 3| - 5 = 0. Add 5 to both sides: |x + 3| = 5. Then consider two cases: x + 3 = 5 or x + 3 = -5. Solving each case gives x = 2 or x = -8. Since we're looking for an x-intercept, we choose the negative value because it's where the function crosses the x-axis.

Explanation:
The x-intercepts of h(x) are (-8, 0) and (2, 0), but since we're asked for only one intercept, we select -8 as the correct answer. The function crosses the x-axis at x = -8.

Common mistake note:
A common mistake would be to select (2, 0) as the sole answer, overlooking that there are two x-intercepts for this function.
