Problem 1 (One):
Find the fifth term of the sequence defined by a_1 = 2 and a_n = 3a_{n-1} - 4.
A) Incorrect
B) Incorrect
C) 58
D) Incorrect
Correct Answer: C

Solution:
To find the fifth term, we start with a_1 and apply the recursive formula four times. Here's the calculation:
a_2 = 3a_1 - 4 = 3(2) - 4 = 6 - 4 = 2
a_3 = 3a_2 - 4 = 3(2) - 4 = 6 - 4 = 6
a_4 = 3a_3 - 4 = 3(6) - 4 = 18 - 4 = 14
a_5 = 3a_4 - 4 = 3(14) - 4 = 42 - 4 = **58**

Explanation:
The sequence increases with each iteration. By applying the correct recursive formula, we find the fifth term.

Common mistake note:
Applying the same term multiple times instead of iterating through the recursive formula.

Problem 2 (Two):
Find the eighth term of the sequence defined by a_1 = 5 and a_n = a_{n-1} + 3.
A) 29
B) 32
C) 38
D) 41
Correct Answer: D

Solution:
To find the eighth term, we start with a_1 and apply the recursive formula seven times. Here's the calculation:
a_2 = a_1 + 3 = 5 + 3 = 8
a_3 = a_2 + 3 = 8 + 3 = 11
... (continue this process)
a_8 = a_7 + 3 = 32 + 3 = **41**

Explanation:
The sequence increases by 3 with each iteration. By adding 3 to the previous term, we can find the eighth term.

Common mistake note:
Forgetting to add 3 each time or miscounting the number of iterations.

Problem 3 (Three):
Find the fourth term of the sequence defined by a_1 = 1 and a_n = 2a_{n-1} + 1.
A) 5
B) 9
C) 10
D) 18
Correct Answer: C

Solution:
To find the fourth term, we start with a_1 and apply the recursive formula three times. Here's the calculation:
a_2 = 2a_1 + 1 = 2(1) + 1 = 2 + 1 = 3
a_3 = 2a_2 + 1 = 2(3) + 1 = 6 + 1 = 7
a_4 = 2a_3 + 1 = 2(7) + 1 = 14 + 1 = **10**

Explanation:
The sequence doubles the previous term and adds one. By following this pattern, we can find the fourth term.

Common mistake note:
Multiplying by two instead of adding one or not doubling correctly.

Problem 4 (Four):
Find the sixth term of the sequence defined by a_1 = 3 and a_n = a_{n-1} / 2, if n is even; a_n = 3a_{n-1}, if n is odd.
A) 9
B) 18
C) 27
D) 54
Correct Answer: A

Solution:
Since we're looking for the sixth term, which is even, we'll use the rule a_n = a_{n-1} / 2. Here's the calculation:
a_2 = a_1 / 2 = 3 / 2 = 1.5
a_3 = 3a_2 = 3(1.5) = 4.5
a_4 = a_3 / 2 = 4.5 / 2 = 2.25
a_5 = 3a_4 = 3(2.25) = 6.75
a_6 = a_5 / 2 = 6.75 / 2 = **9**

Explanation:
We use the rule for even terms, dividing by two, to find the sixth term.

Common mistake note:
Using the wrong rule (multiplying by three) or not considering that n is even.

Problem 5 (Five):
Find the third term of the sequence defined by a_1 = 7 and a_n = -2a_{n-1} + 5.
A) 9
B) 13
C) 17
D) 21
Correct Answer: A

Solution:
To find the third term, we start with a_1 and apply the recursive formula twice. Here's the calculation:
a_2 = -2a_1 + 5 = -2(7) + 5 = -14 + 5 = -9
a_3 = -2a_2 + 5 = -2(-9) + 5 = 18 + 5 = **9**

Explanation:
The sequence multiplies the previous term by -2 and adds five. By following this pattern, we can find the third term.

Common mistake note:
Multiplying by two instead of multiplying by -2 or not negating correctly.

Problem 6 (Six):
Find the seventh term of the sequence defined by a_1 = 4 and a_n = a_{n-1} + 5 if n is odd; a_n = 2a_{n-1}, if n is even.
A) 39
B) 40
C) 41
D) 42
Correct Answer: C

Solution:
Since we're looking for the seventh term, which is odd, we'll use the rule a_n = a_{n-1} + 5. Here's the calculation:
a_2 = 2a_1 = 2(4) = 8
a_3 = a_2 + 5 = 8 + 5 = 13
a_4 = 2a_3 = 2(13) = 26
a_5 = a_4 + 5 = 26 + 5 = 31
a_6 = 2a_5 = 2(31) = 62
a_7 = a_6 + 5 = 62 + 5 = **41**

Explanation:
We use the rule for odd terms, adding five, to find the seventh term.

Common mistake note:
Using the wrong rule (multiplying by two) or not considering that n is odd.

Problem 7 (Seven):
Find the fifth term of the sequence defined by a_1 = 1 and a_n = -3a_{n-1} + 2, if n is even; a_n = a_{n-1} / 3, if n is odd.
A) -14
B) -17
C) -20
D) -23
Correct Answer: A

Solution:
Since we're looking for the fifth term, which is odd, we'll use the rule a_n = a_{n-1} / 3. Here's the calculation:
a_2 = -3a_1 + 2 = -3(1) + 2 = -3 + 2 = -1
a_3 = a_2 / 3 = (-1) / 3 = -1/3
a_4 = -3a_3 + 2 = -3(-1/3) + 2 = 1 + 2 = 3
a_5 = a_4 / 3 = 3 / 3 = **1**

Explanation:
We use the rule for odd terms, dividing by three, to find the fifth term.

Common mistake note:
Using the wrong rule (multiplying by -3) or not considering that n is odd.
