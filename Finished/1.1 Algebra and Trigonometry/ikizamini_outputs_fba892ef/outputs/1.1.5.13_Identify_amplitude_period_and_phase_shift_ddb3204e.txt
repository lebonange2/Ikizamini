Problem 1 (Asn001):
The function y = 4sin(2x - π/3) has an amplitude of:
A) 1
B) 2
C) 4
D) 8
Correct Answer: C

Solution:
Amplitude is the absolute value of the coefficient in front of the sine or cosine function. In this case, the amplitude is 4.

Explanation:
The amplitude determines how far the graph oscillates from its midline. For a general sine function y = a*sin(bx - c), 'a' represents the amplitude.

Common mistake note:
A common mistake would be to choose B (2) as it might seem like the coefficient of x, but remember that amplitude is only affected by the number outside the trigonometric function.
------------------------------------------------------------------------------

Problem 2 (Asn002):
The period of the function y = cos(πx + π/4) is:
A) π
B) 2π
C) 1
D) 4
Correct Answer: B

Solution:
The period of a cosine or sine function with an argument involving 'b', is given by 2π / |b|. In this case, b = π, so the period is 2π.

Explanation:
The period determines how often the function repeats itself. For a general cosine function y = cos(bx + c), the period is 2π / |b|.

Common mistake note:
A common mistake would be to choose A (π) because it's the coefficient inside the cosine, but remember that the period formula involves dividing by |b|.
------------------------------------------------------------------------------

Problem 3 (Asn003):
The phase shift of the function y = 2sin(x + π/2) is:
A) π/4
B) π/2
C) π
D) 3π/2
Correct Answer: B

Solution:
Phase shift is determined by the value inside the trigonometric function, but outside the argument. In this case, it's π/2.

Explanation:
The phase shift moves the graph horizontally without changing its shape. For a general sine function y = a*sin(bx + c), the phase shift is -c / b.

Common mistake note:
A common mistake would be to choose A (π/4) because it might seem like half of π/2, but remember that the phase shift formula involves dividing by 'b'.
------------------------------------------------------------------------------
