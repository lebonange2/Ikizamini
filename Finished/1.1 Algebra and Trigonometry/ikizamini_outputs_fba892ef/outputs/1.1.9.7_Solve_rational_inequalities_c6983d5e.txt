Problem 1 (One):
Solve the inequality: (2x + 3)/(x - 4) > 0
A) -3 < x < 4
B) x < -3 or x > 4
C) x > -3 and x ≠ 4
D) x < -3 and x ≠ 4
Correct Answer: C

Solution:
To solve the inequality (2x + 3)/(x - 4) > 0, we need to find where the expression is positive. First, we look for any values that make the denominator zero (this will give us vertical asymptotes), so x ≠ 4. Next, we set up intervals based on the roots of the numerator (2x + 3 = 0 gives x = -3/2) and test signs within each interval to determine where the expression is positive. Testing values, we find that the inequality holds true for x > -3/2 and x ≠ 4. Therefore, the correct answer is C: x > -3 and x ≠ 4.

Explanation:
The common mistake would be to forget about the restriction x ≠ 4 (when the denominator equals zero), which leads to choice A or D. This is incorrect because division by zero is undefined.

Common mistake note:
Forgetting to exclude values that make the denominator zero.

Problem 4 (Four):
Solve the inequality: (x^2 - 4)/(x + 2) < 0
A) -2 < x < 2
B) x < -2 or x > 2
C) x > -2 and x ≠ 2
D) x < -2 and x ≠ 2
Correct Answer: A

Solution:
To solve the inequality (x^2 - 4)/(x + 2) < 0, we first factor the numerator: (x - 2)(x + 2)/(x + 2). Since the denominator is never zero, we can ignore it for determining where the expression changes signs. The only root to consider is x = 2. Testing values, we find that the inequality holds true for -2 < x < 2. Therefore, the correct answer is A: -2 < x < 2.

Explanation:
The common mistake would be to forget about the restriction x ≠ -2 (which is not applicable in this case), which leads to choice B or C. This is incorrect because it creates an unnecessary restriction on the solution set.

Common mistake note:
Including a restriction that isn't needed.

Problem 5 (Five):

Testing values, we find that the inequality holds true for -2 < x < 1/2 and x ≠ 1 (since x = 1 makes the denominator zero). Therefore, the correct answer is B: -2 < x < 1/2 and x ≠ 1.

Explanation:
The common mistake would be to include x = 1 in the solution set, which leads to choice A or C. This is incorrect because the inequality does not hold true at x = 1 (it equals zero there).
