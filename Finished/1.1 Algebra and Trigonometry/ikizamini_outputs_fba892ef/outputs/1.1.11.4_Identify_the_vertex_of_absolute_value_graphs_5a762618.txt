Problem 1 (x1):
What is the vertex of the graph of |x - 3|?
A) (0, 3)
B) (3, 0)
C) (0, 0)
D) (-3, 0)
Correct Answer: B

Solution:
The vertex form of an absolute value equation is |x - h| = k, where (h, k) is the vertex. In this case, h = 3, so the vertex is at (3, 0).

Explanation:
The vertex is the point where the graph changes direction. Since the equation involves x - 3, the vertex occurs when the expression inside the absolute value is zero.

Common mistake note:
A common mistake is to confuse the vertex with a point on the graph. Choice A represents a point on the graph but not the vertex.

Problem 2 (x2):
What is the vertex of the graph of |2x + 4|?
A) (-2, 0)
B) (0, -2)
C) (0, 0)
D) (-1, 0)
Correct Answer: A

Solution:
To find the vertex, set the expression inside the absolute value to zero: 2x + 4 = 0. Solving for x gives x = -2, so the vertex is at (-2, 0).

Explanation:
Divide by the coefficient of x (2) to isolate x before finding the vertex.

Common mistake note:
A common mistake is to forget to divide by the coefficient of x when solving for the value of x that makes the expression inside the absolute value zero.
------------------------------------------------------------------------------

Problem 3 (x3):
What is the vertex of the graph of |x| + 5?
A) (0, -5)
B) (0, 5)
C) (-5, 0)
D) (5, 0)
Correct Answer: A

Solution:
The vertex form is |x - h| = k. In this case, there's no x inside the absolute value, so h = 0. The constant k is 5, which shifts the graph vertically. Thus, the vertex is at (0, -5).

Explanation:
When there's no linear term in the absolute value equation, the vertex lies on the y-axis.

Common mistake note:
A common mistake is to assume that the vertex will be at (0, 0) when there's no x inside the absolute value. However, the constant term outside influences the position of the vertex.
------------------------------------------------------------------------------

Problem 4 (x4):
What is the vertex of the graph of |3 - x|?
A) (3, 0)
B) (0, 3)
C) (3, 3)
D) (-3, 0)
Correct Answer: A

Solution:
The vertex form is |x - h| = k. In this case, h = 3, so the vertex is at (3, 0). The value inside the absolute value is subtracted from x, but it doesn't change the position of the vertex.

Explanation:
The vertex remains at the same horizontal position even if you switch x with a constant in the equation.

Common mistake note:
A common mistake is to think that switching x with 3 inside the absolute value would change the vertex. However, it only affects the way the graph looks but not its position.

Problem 6 (x6):
What is the vertex of the graph of |x + 2| - 3?
A) (2, -3)
B) (-2, -3)
C) (-2, 0)
D) (2, 0)
Correct Answer: B

Solution:
The vertex form is |x - h| = k. In this case, h = -2. The equation also shifts the graph vertically by subtracting 3, so the vertex is at (-2, -3).

Explanation:
When there's a constant term outside the absolute value, it shifts the graph vertically.

Common mistake note:
A common mistake is to forget that the vertical shift affects the y-coordinate of the vertex. Choice A neglects this shift.

Problem 7 (x7):
What is the vertex of the graph of |-2(x + 1)|?
A) (1, 0)
B) (-1, 0)
C) (-1, -2)
D) (1, -2)
Correct Answer: C

Solution:
The vertex form is |x - h| = k. In this case, setting the expression inside the absolute value to zero gives x = -1, so h = -1. The presence of -2 outside the absolute value compresses and reflects the graph across the y-axis. Thus, the vertex is at (-1, -2).

Explanation:
The negative sign outside the absolute value changes the direction of the graph but does not affect the position of the vertex.

Common mistake note:
A common mistake is to think that the negative sign would change the x-coordinate of the vertex. However, it only affects the shape of the graph.
