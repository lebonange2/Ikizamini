Problem 1 (Asdf):
What is the solution to the quadratic equation x^2 + 4x - 5 = 0 using the quadratic formula?
A) -5, 1
B) 2, 3
C) -2, 5
D) -1, 5
Correct Answer: A

Solution:
The quadratic formula is x = (-b ± √(b² - 4ac)) / (2a). For the equation x^2 + 4x - 5 = 0, a = 1, b = 4, and c = -5. Plugging these values into the formula gives us x = (-4 ± √(4² - 4(-5))) / 2 = (-4 ± √36) / 2 = (-4 ± 6) / 2. This results in two solutions: x = (2) / 2 = 1 and x = (-10) / 2 = -5.

Explanation:
The quadratic formula is used to find the roots of a quadratic equation, which are the values of x that make the equation true. In this case, we use the formula to find two solutions: x = 1 and x = -5.

Common mistake note:
A common mistake would be to incorrectly calculate the discriminant (b² - 4ac) or to misapply the quadratic formula, leading to incorrect solutions.

Problem 2 (Asdf2):
Solve the equation 3x^2 + 6x - 9 = 0 using the quadratic formula. Which of the following is a solution?
A) -1 + √3i
B) 2
C) -3
D) -1 - √3i
Correct Answer: A

Solution:
The quadratic formula is x = (-b ± √(b² - 4ac)) / (2a). For the equation 3x^2 + 6x - 9 = 0, a = 3, b = 6, and c = -9. Plugging these values into the formula gives us x = (-6 ± √(6² - 4(3)(-9))) / (2(3)) = (-6 ± √36) / 6 = (-6 ± 6i) / 6. This results in two complex solutions: x = -1 + √3i and x = -1 - √3i.

Explanation:
When the discriminant (b² - 4ac) is negative, the quadratic equation has complex roots. In this case, we find that both solutions are complex numbers.

Common mistake note:
A common mistake would be to assume that the solutions must be real numbers and overlook the possibility of complex roots.

Problem 5 (Asdf5):
Solve the equation 2x^2 + x - 3 = 0 using the quadratic formula. Which of the following is NOT a solution?
A) 1
B) -3/2
C) 1/2
D) 3
Correct Answer: D

Solution:
The quadratic formula is x = (-b ± √(b² - 4ac)) / (2a). For the equation 2x^2 + x - 3 = 0, a = 2, b = 1, and c = -3. Plugging these values into the formula gives us x = (-1 ± √((1)² - 4(2)(-3))) / (2(2)) = (-1 ± √13) / 4. This results in two solutions: x ≈ (-1 + √13) / 4 and x ≈ (-1 - √13) / 4, which are approximately equal to 0.68 and -1.38. The solution 3 is not among the actual roots.

Explanation:
The quadratic formula is used to find the roots of a quadratic equation, which are the values of x that make the equation true. In this case, we use the formula to find two solutions: approximately 0.68 and -1.38. The solution 3 does not satisfy the original equation.

Common mistake note:
A common mistake would be to overlook the possibility of irrational roots or to round the decimal values inaccurately, leading to incorrect identification of a non-existent integer solution.

Problem 6 (Asdf6):
What are the solutions to the quadratic equation 4x^2 - 12x + 9 = 0 using the quadratic formula?
A) 3/2, 3/2
B) 1, 3
C) 1, -3
D) -1, 3
Correct Answer: A

Solution:
The quadratic formula is x = (-b ± √(b² - 4ac)) / (2a). For the equation 4x^2 - 12x + 9 = 0, a = 4, b = -12, and c = 9. Plugging these values into the formula gives us x = (12 ± √((-12)² - 4(4)(9))) / (2(4)) = (12 ± √0) / 8 = (12) / 8 = 3/2. Since the discriminant is zero, there are two identical real solutions: x = 3/2.

Explanation:
The quadratic formula is used to find the roots of a quadratic equation, which are the values of x that make the equation true. In this case, we use the formula and find that the discriminant is zero, indicating two identical real solutions: x = 3/2.

Common mistake note:
A common mistake would be to assume that there must be two distinct solutions or to overlook the possibility of repeated roots when the discriminant is zero.

Problem 7 (Asdf7):
Solve the equation 6x^2 - 15x + 9 = 0 using the quadratic formula. Which of the following is a solution?
A) 1/2, 3
B) 1, 3/2
C) 1/2, 2
D) 1, 2
Correct Answer: B

Solution:
The quadratic formula is x = (-b ± √(b² - 4ac)) / (2a). For the equation 6x^2 - 15x + 9 = 0, a = 6, b = -15, and c = 9. Plugging these values into the formula gives us x = (15 ± √((-15)² - 4(6)(9))) / (2(6)) = (15 ± √225) / 12 = (15 ± 15) / 12. This results in two solutions: x = (30) / 12 = 5/2 and x = 0, which can be simplified to x = 2.5 and x = 0.

Explanation:
The quadratic formula is used to find the roots of a quadratic equation, which are the values of x that make the equation true. In this case, we use the formula to find two solutions: x = 2.5 (or 5/2) and x = 0. The simplified solution x = 1 is not among the actual roots.

Common mistake note:
A common mistake would be to overlook the possibility of non-integer solutions or to round decimal values inaccurately, leading to incorrect identification of a non-existent integer solution.
