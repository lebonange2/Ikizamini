Problem 1 (Ineq1):
Solve the inequality: |3x - 4| < 7.
A) -∞ < x < ∞
B) -< x < 5
C) &frac{3}{7} < x < &frac{11}{3}
D) x < -&frac{1}{3} or x > 5
Correct Answer: C

Solution:
To solve the inequality |3x - 4| < 7, we consider two cases: when 3x - 4 is positive and when it's negative.

Case 1: 3x - 4 ≥ 0
3x ≥ 4
x ≥ &frac{4}{3}

Case 2: 3x - 4 < 0
3x < 4
x < &frac{4}{3}

Now, solve for each case:

For Case 1: |3x - 4| < 7 becomes 3x - 4 < 7
3x < 11
x < &frac{11}{3}
Combining with x ≥ &frac{4}{3}, we get &frac{4}{3} ≤ x < &frac{11}{3}

For Case 2: |3x - 4| < 7 becomes -(3x - 4) < 7
-3x + 4 < 7
-3x < 3
x > -&frac{3}{3}
Combining with x < &frac{4}{3}, we get -&frac{3}{3} < x < &frac{4}{3}

The combined solution is: -&frac{1}{3} < x < &frac{11}{3}

Explanation:
Choice C correctly represents the interval where the inequality holds true.

Common mistake note:
A common mistake is to forget to consider both cases (when 3x - 4 is positive and negative), which leads to an incomplete or incorrect solution.
