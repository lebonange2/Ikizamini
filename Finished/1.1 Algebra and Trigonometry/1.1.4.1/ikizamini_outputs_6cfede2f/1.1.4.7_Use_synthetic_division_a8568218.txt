Problem 1 (:1):
Use synthetic division to determine the quotient and remainder when dividing the polynomial $x^3 - 2x^2 + x - 4$ by $x - 2$. What is the quotient?
A) $x^2 + 2x - 5$
B) $x^2 - 1$
C) $x^2 + 0x - 2$
D) $x^2 + x - 3$
Correct Answer: D

Solution:
The synthetic division for $x - 2$ is as follows:

```
  2  | 1  -2  1  -4
     |   2  0  -6
     -----------------
        1  0  -2  -6
```

Explanation:
The quotient is the polynomial above the horizontal line, which is $x^2 + x - 3$. The remainder is the last number in the bottom row, which is $-6$.

Common mistake note:
A common mistake would be to forget to include the missing powers of $x$ when writing the quotient. For example, choosing A ($x^2 + 2x - 5$) instead of D ($x^2 + x - 3$) because they forgot to subtract the product of the divisor and the current coefficient from the previous coefficient.

Problem 2 (2):
Use synthetic division to find the quotient and remainder when dividing $4x^3 + 5x^2 - 7x + 1$ by $x + 1$. What is the remainder?
A) $-10$
B) $-6$
C) $-3$
D) $-1$
Correct Answer: D

Solution:
The synthetic division for $x + 1$ is as follows:

```
  -1  | 4 5  -7  1
     |   -4  -9
     -----------------
        4  1  -6  1
```

Explanation:
The remainder is the last number in the bottom row, which is $-1$. The quotient is the polynomial above the horizontal line, but we are only interested in the remainder for this question.

Common mistake note:
A common mistake would be to confuse the remainder with the constant term of the dividend. For example, choosing B ($-6$) instead of D ($-1$), because they thought the last coefficient of the polynomial was the remainder.

Problem 3 (3):
Use synthetic division to determine the quotient and remainder when dividing $x^4 - 3x^2 + 5x - 7$ by $x + 1$. What is the degree of the quotient?
A) 0
B) 1
C) 2
D) 3
Correct Answer: C

Solution:
The synthetic division for $x + 1$ is as follows:

```
  -1  | 1  0  -3  5  -7
     |   -1  2
     -----------------
        1  -1  -1  4
```

Explanation:
The quotient is the polynomial above the horizontal line, which is $x^3 - x^2 - x + 4$. The degree of this polynomial is 3.

Common mistake note:
A common mistake would be to think that the degree of the quotient is the same as the degree of the divisor. For example, choosing B (1) instead of D (3), because they thought the degree was increased by one.

Problem 4 (4):
Use synthetic division to find the roots of $x^3 - 6x^2 + 9x - 4$ by dividing it by $(x - 1)$. Which root is found using synthetic division?
A) 0
B) 1
C) 2
D) 3
Correct Answer: B

Solution:
The synthetic division for $x - 1$ is as follows:

```
  1  | 1  -6  9  -4
     |   1  -5
     -----------------
        1  -5  4  0
```

Explanation:
Since the last number in the bottom row is 0, it means that $x - 1$ is a factor of the polynomial, and thus x = 1 is a root.

Common mistake note:
A common mistake would be to think that synthetic division only finds one root when dividing by a linear factor. For example, choosing C (2) or D (3), because they thought there was only one root.

Problem 5 (5):
Use synthetic division to determine the quotient and remainder when dividing $x^4 - 6x^3 + 11x^2 - 10x + 3$ by $x - 3$. What is the coefficient of the $x^2$ term in the quotient?
A) 1
B) 2
C) 3
D) 4
Correct Answer: C

Solution:
The synthetic division for $x - 3$ is as follows:

```
  3  | 1  -6  11  -10  3
     |   3  9  27
     -----------------
        1  -3  8  17  3
```

Explanation:
The quotient is the polynomial above the horizontal line, which is $x^3 - 3x^2 + 8x + 17$. The coefficient of the $x^2$ term is -3.

Common mistake note:
A common mistake would be to misread the sign of the coefficient. For example, choosing A (1) instead of C (3), because they read it as positive.

Problem 6 (6):
Use synthetic division to find the quotient and remainder when dividing $2x^4 - 5x^3 + 7x^2 - 9x + 1$ by $x - 2$. Which of the following is NOT a possible value for the constant term in the remainder?
A) 0
B) -1
C) -4
D) 6
Correct Answer: A

Solution:
The synthetic division for $x - 2$ is as follows:

```
  2  | 2  -5  7  -9  1
     |   4  -6
     -----------------
        2  -3  1  -5  1
```

Explanation:
The remainder is the last number in the bottom row, which can be any integer. However, since we are looking for a value that is NOT possible, the correct answer is 0.

Common mistake note:
A common mistake would be to choose a value that could actually be a remainder. For example, choosing B (-1) or C (-4), because they thought these were impossible.

Problem 7 (7):
Use synthetic division to determine the quotient and remainder when dividing $x^3 - 5x^2 + 6x - 2$ by $x - 1$. Which of the following is NOT a possible value for the quotient?
A) $x^2 - 4x + 5$
B) $x^2 - 4x + 6$
C) $x^2 - 5x + 6$
D) $x^2 - 6x + 7$
Correct Answer: D

Solution:
The synthetic division for $x - 1$ is as follows:

```
  1  | 1  -5  6  -2
     |   1  -4
     -----------------
        1  -4  2  -2
```

Explanation:
The quotient is the polynomial above the horizontal line, which can be any quadratic polynomial with these coefficients. However, since we are looking for a value that is NOT possible, the correct answer is $x^2 - 6x + 7$.

Common mistake note:
A common mistake would be to choose a value that could actually be a quotient. For example, choosing A ($x^2 - 4x + 5$) or B ($x^2 - 4x + 6$), because they thought these were impossible.
