Problem 1 (:1):
What is the solution to the equation x^2 - 4x + 3 = 0?
A) x = -1
B) x = 1
C) x = 3
D) x = -3
Correct Answer: B

Solution:
The equation can be factored as (x-1)(x-3) = 0. Setting each factor equal to zero gives us the solutions x=1 and x=3. Since we're looking for a single solution, the correct answer is x = 1.

Explanation:
Factoring quadratics helps find their roots. Here, factoring identified the solutions.

Common mistake note:
A common mistake would be to assume that only one of the factors (x-1) or (x-3) is the solution, but both need to be considered since either could equal zero.

Problem 2 (2):
Solve for x: 2x^2 + 5x - 3 = 0.
A) x = -3, x = 1/2
B) x = 3, x = -1/2
C) x = 1, x = -3
D) x = -1, x = 3
Correct Answer: A

Solution:
Using the quadratic formula, x = (-b ± √(b^2 - 4ac)) / (2a), where a=2, b=5, and c=-3. Plugging in these values gives us x = (-5 ± √(5^2 - 4*2*(-3))) / (2*2) = (-5 ± √25 + 24) / 4 = (-5 ± √49) / 4 = (-5 ± 7) / 4. This results in x = -3 and x = 1/2.

Explanation:
The quadratic formula is a general method for solving quadratic equations.

Common mistake note:
A common mistake would be to forget the plus or minus sign when applying the quadratic formula, leading to incorrect solutions.

Problem 3 (3):
What are the roots of the equation 3x^2 + 6x + 3 = 0?
A) x = -1
B) x = -2
C) x = 1, x = -2
D) No real solutions
Correct Answer: A

Solution:
The equation can be simplified by dividing all terms by 3: x^2 + 2x + 1 = 0. This is a perfect square trinomial that factors to (x+1)^2 = 0. The only solution is x = -1.

Explanation:
Perfect square trinomials can be easily factored and solved.

Common mistake note:
A common mistake would be to think there are two solutions because it's a quadratic equation, but in this case, the equation simplifies to a perfect square, which has only one solution.

Problem 4 (4):
Solve for x: x^3 - 6x^2 + 9x = 0.
A) x = 0, x = 3
B) x = 1, x = 2
C) x = -3, x = 3
D) x = -1, x = -2
Correct Answer: A

Solution:
The equation can be factored by pulling out x as a common factor: x(x^2 - 6x + 9) = 0. This gives us x=0 and (x-3)^2 = 0, which means x = 3. The solutions are x = 0 and x = 3.

Explanation:
Factoring by grouping helps find the roots of cubic equations.

Common mistake note:
A common mistake would be to think that only x=0 is a solution, but neglecting to consider the quadratic factor (x-3)^2 which also contributes a solution.

Problem 5 (5):
Find the solutions for the equation 4x^3 - 12x^2 + 9x = 0.
A) x = 0, x = 3/2
B) x = 1, x = 2
C) x = -3, x = 3
D) x = -1, x = -2
Correct Answer: A

Solution:
The equation can be factored by pulling out x as a common factor: x(4x^2 - 12x + 9) = 0. This gives us x=0 and (2x-3)^2 = 0, which means x = 3/2. The solutions are x = 0 and x = 3/2.

Explanation:
Factoring by grouping helps find the roots of cubic equations.

Common mistake note:
A common mistake would be to think that only x=0 is a solution, but neglecting to consider the quadratic factor (2x-3)^2 which also contributes a solution.

Problem 6 (6):
Solve for x: 2x^4 - 18x^2 + 27 = 0.
A) x = ±√3
B) x = ±3
C) x = ±√(3/2)
D) x = ±3√2
Correct Answer: A

Solution:
The equation can be factored by grouping: 2x^4 - 18x^2 + 27 = 2(x^4 - 9x^2 + 9) = 2(x^2 - 3)^2 = 0. This gives us (x^2 - 3)^2 = 0, which means x^2 = 3, so x = ±√3.

Explanation:
Factoring by grouping and using the square root property helps solve quartic equations.

Common mistake note:
A common mistake would be to try to factor the quadratic inside the parentheses without first factoring out the common coefficient, leading to incorrect solutions.

Problem 7 (7):
Solve for x: 5x^3 - 10x^2 + 5x = 0.
A) x = 0, x = 1
B) x = -1, x = -2
C) x = √5, x = -√5
D) x = 2, x = -2
Correct Answer: A

Solution:
The equation can be factored by pulling out x as a common factor: x(5x^2 - 10x + 5) = 0. This gives us x=0 and 5(x^2 - 2x + 1) = 0, which means 5(x-1)^2 = 0, so x = 1. The solutions are x = 0 and x = 1.

Explanation:
Factoring by pulling out a common factor helps find the roots of cubic equations.

Common mistake note:
A common mistake would be to think that only x=0 is a solution, but neglecting to consider the quadratic factor (x-1)^2 which also contributes a solution.
