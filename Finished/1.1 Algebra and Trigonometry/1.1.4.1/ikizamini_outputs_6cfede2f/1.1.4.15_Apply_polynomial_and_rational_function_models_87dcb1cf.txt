Problem 1 (:1):
What is the degree of the polynomial function f(x) = 3x^4 - 2x^2 + 7?
A) 1
B) 2
C) 3
D) 4
Correct Answer: D

Solution:
The degree of a polynomial is determined by the highest exponent of its variable. In this case, the term with the highest exponent is 3x^4, which has an exponent of 4. Therefore, the degree of the function f(x) = 3x^4 - 2x^2 + 7 is 4.

Explanation:
The degree helps identify a polynomial's overall shape and behavior as x approaches infinity or negative infinity.

Common mistake note:
A common mistake is selecting choice B (degree 2) because they only considered the term with the second-highest exponent. Remember, the degree is determined by the highest exponent.

Problem 2 (:2):
What is the vertical asymptote of the rational function g(x) = (x + 3)/(x^2 - 9)?
A) x = 0
B) x = 3
C) x = -3
D) x = ±3
Correct Answer: B

Solution:
The vertical asymptote of a rational function occurs where the denominator equals zero and the numerator does not. In g(x) = (x + 3)/(x^2 - 9), the denominator factors to (x - 3)(x + 3), which equals zero when x = 3 or x = -3. However, since the numerator also equals zero at x = -3, it's a hole in the graph rather than an asymptote. Therefore, the vertical asymptote is x = 3.

Explanation:
Vertical asymptotes represent values of x where the function approaches infinity or negative infinity; found by setting the denominator equal to zero.

Common mistake note:
A common mistake is selecting choice C (x = -3) as an asymptote, but it's not because there's a hole in the graph at that point due to the numerator also being zero.

Problem 3 (:3):
What is the y-intercept of the function h(x) = 2x^3 - x^2 + 4?
A) (0, 4)
B) (1, 5)
C) (0, 0)
D) (4, 0)
Correct Answer: A

Solution:
The y-intercept of a function is found by setting x = 0 and evaluating the expression for y. For h(x) = 2x^3 - x^2 + 4, when x = 0, we get y = 2(0)^3 - (0)^2 + 4 = 4. Thus, the y-intercept is at the point (0, 4).

Explanation:
The y-intercept occurs where the graph of a function crosses the y-axis, corresponding to setting x = 0.

Common mistake note:
A common mistake is selecting choice C (y-intercept at (0, 0)) because they forgot to evaluate the entire expression for y when x is set to 0.

Problem 4 (:4):
What is the domain of the function j(x) = √(x + 5)?
A) (-∞, ∞)
B) [5, ∞)
C) [-5, ∞)
D) (-5, ∞)
Correct Answer: C

Solution:
The domain of a function involving a square root is determined by the values for which the expression inside the square root is greater than or equal to zero. For j(x) = √(x + 5), the expression x + 5 must be greater than or equal to zero, so x ≥ -5. Therefore, the domain is [-5, ∞).

Explanation:
The domain represents the set of all possible input values (x-values) for which the function is defined.

Common mistake note:
A common mistake is selecting choice A (all real numbers) because they forgot to consider the restriction imposed by the square root.

Problem 5 (:5):
What is the x-intercept of the quadratic function k(x) = x^2 - 4x + 3?
A) (1, 0)
B) (3, 0)
C) (1, 3)
D) (3, 3)
Correct Answer: A

Solution:
The x-intercepts of a quadratic function are found by setting the equation equal to zero and solving for x. For k(x) = x^2 - 4x + 3, we set it to zero: x^2 - 4x + 3 = 0. Factoring gives us (x - 1)(x - 3) = 0, so x = 1 or x = 3. The x-intercept occurs at the point where y is zero, which in this case is when x = 1. Therefore, the x-intercept is at the point (1, 0).

Explanation:
The x-intercepts are points where the graph of a function crosses the x-axis, corresponding to setting the equation equal to zero and solving for x.

Common mistake note:
A common mistake is selecting choice B (x-intercept at (3, 0)) because they might have forgotten to check both solutions or considered only one solution.

Problem 6 (:6):
What is the equation of the line tangent to the function l(x) = x^3 - 2x^2 + x at the point (1, 0)?
A) y = x - 1
B) y = 2x - 2
C) y = 3x - 3
D) y = -x + 1
Correct Answer: A

Solution:
To find the equation of the tangent line, we need to calculate the derivative of l(x) and evaluate it at x = 1. The derivative of l(x) is l'(x) = 3x^2 - 4x + 1. Evaluating this at x = 1 gives us l'(1) = 3(1)^2 - 4(1) + 1 = 0, which is the slope of the tangent line. The point-slope form for a line given a slope m and a point (x1, y1) is y - y1 = m(x - x1). Plugging in m = 0, x1 = 1, and y1 = 0 gives us y - 0 = 0(1 - 1), or simply y = x - 1. Thus, the equation of the tangent line is y = x - 1.

Explanation:
The tangent line to a function at a point has a slope equal to the derivative of the function evaluated at that point. The equation of the tangent line can be found using the point-slope form.

Common mistake note:
A common mistake is selecting choice C (y = 3x - 3) because they might have forgotten to evaluate the derivative at x = 1, resulting in the wrong slope.

Problem 7 (:7):
What are the roots of the quadratic equation m(x) = 2(x - 2)^2 + 5 = 0?
A) (0, 5)
B) (2, 3)
C) (2, 5)
D) (4, 7)
Correct Answer: C

Solution:
The vertex form of a quadratic function is given by f(x) = a(x - h)^2 + k, where (h, k) is the vertex. For m(x) = 2(x - 2)^2 + 5, we can see that h = 2 and k = 5 directly from the equation. Therefore, the roots of the quadratic equation are x = h ± √(-k/a), which gives us x = 2 ± √((-5)/2). Since the square root term is imaginary, there are no real roots for this quadratic equation.

Explanation:
The vertex form of a quadratic function helps identify the coordinates of the vertex and can be used to find the roots if they exist.

Common mistake note:
A common mistake would be selecting choice A or B because they might have misinterpreted the h and k values in the vertex form, assuming there are real roots.
