Problem 1 (:1):
Find the vertical asymptote of the function f(x) = (3x + 6)/(2x - 4).
A) (x = -2)
B) (x = 0)
C) (x = 2)
D) (x = 4)
Correct Answer: C

Solution:
The vertical asymptote occurs where the denominator equals zero. Set the denominator equal to zero and solve for x: 2x - 4 = 0, which gives x = 2.

Explanation:
Vertical asymptotes occur when the function's denominator is zero.

Common mistake note:
A common mistake would be selecting A or D because they are factors of the linear term in the denominator. However, these values do not make the entire denominator zero.

Problem 2 (:2):
What is the horizontal asymptote of the function g(x) = (5x^2 + 3x - 1)/(2x^2 + x + 4)?
A) (y = 0)
B) (y = 1/2)
C) (y = 2.5)
D) (y = 5)
Correct Answer: B

Solution:
The horizontal asymptote of a rational function is determined by the ratio of the leading coefficients of the numerator and denominator. Here, the leading coefficient of the numerator is 5 and the denominator is 2, so the horizontal asymptote is y = 5/2 or y = 2.5.

Explanation:
Horizontal asymptotes represent the behavior of a function as x approaches infinity or negative infinity.

Common mistake note:
A common mistake would be selecting D because it's the coefficient of the highest power in the numerator. However, for horizontal asymptotes, you must consider both the numerator and denominator.

Problem 3 (:3):
Identify the x-intercept(s) of the function h(x) = (x - 1)(x + 2)/(x - 3).
A) (x = -2)
B) (x = 0)
C) (x = 1, x = 3)
D) (x = 1, x = -2)
Correct Answer: D

Solution:
To find the x-intercepts, set the numerator equal to zero: (x - 1)(x + 2) = 0. This gives x = 1 and x = -2.

Explanation:
X-intercepts occur where the function's value is zero.

Common mistake note:
A common mistake would be selecting C because it includes the values that make the denominator zero, but those points are not x- intercepts since they cause the function to be undefined.

Problem 4 (:4):
Find the domain of the function j(x) = (2x + 1)/(x^2 - 9).
A) (x ≠ -3, x ≠ 3)
B) (x ≠ 0)
C) (x ≠ -3)
D) (x ≠ 3)
Correct Answer: A

Solution:
The domain is all real numbers except those that make the denominator zero. Set the denominator equal to zero: x^2 - 9 = (x - 3)(x + 3) = 0, which gives x = -3 and x = 3.

Explanation:
The domain consists of values for x where the function is defined.

Common mistake note:
A common mistake would be selecting B because it omits one of the roots of the denominator. However, both roots must be excluded from the domain.

Problem 5 (:5):
Sketch the graph of k(x) = (x + 1)/(x - 2) and identify any vertical or horizontal asymptotes.
A) Vertical asymptote at x = 2, horizontal asymptote at y = 1
B) Vertical asymptote at x = -1, horizontal asymptote at y = 1
C) Vertical asymptote at x = 2, horizontal asymptote at y = -1
D) Vertical asymptote at x = -1, horizontal asymptote at y = -1
Correct Answer: A

Solution:
The vertical asymptote is at x = 2 because the denominator becomes zero there. The horizontal asymptote is at y = 1 since the function approaches this value as x goes to infinity or negative infinity.

Explanation:
Sketching a rational function involves identifying key features like intercepts, asymptotes, and any points where the function changes direction.

Common mistake note:
A common mistake would be selecting B because it reverses the location of the vertical asymptote. However, the correct location is based on the denominator.

Problem 6 (:6):
Solve for x in the equation m(x) = (4x - 5)/(3x + 2) = 1.
A) (x = 7/3)
B) (x = 3/4)
C) (x = 1)
D) (x = -1)
Correct Answer: A

Solution:
Set the equation equal to 1 and solve for x: (4x - 5)/(3x + 2) = 1. Multiply both sides by the denominator to get rid of it: 4x - 5 = 3x + 2, which gives x = 7/3.

Explanation:
To solve a rational equation, isolate the variable and then solve for it.

Common mistake note:
A common mistake would be selecting B because it results from subtracting 1 from both sides instead of multiplying by the denominator.

Problem 7 (:7):
Find the slant asymptote of the function n(x) = (x^3 - x^2 + 4)/(x - 1).
A) (y = x^2 + x + 4)
B) (y = x^2 - x + 4)
C) (y = x^2 + 2x + 3)
D) (y = x^2 - 2x + 3)
Correct Answer: B

Solution:
To find the slant asymptote, divide the numerator by the denominator. The quotient is x^2 - x + 4, so the slant asymptote is y = x^2 - x + 4.

Explanation:
A slant (or oblique) asymptote occurs when the degree of the numerator is one more than the degree of the denominator.

Common mistake note:
A common mistake would be selecting A because it omits the linear term in the quotient. The correct slant asymptote includes all terms from the quotient.
