Problem 1 (:1):
Find the primitive 5th root of unity in complex form.
A) 1
B) i
C) e^(2πi/5)
D) e^(4πi/5)
Correct Answer: C

Solution:
A primitive nth root of unity is a complex number that, when raised to the power of n, equals 1 and is distinct from other roots of unity for the same n. For n = 5, using De Moivre's Theorem, one of the primitive roots is e^(2kπi/5), where k is an integer giving a unique root. Choosing k=1 gives us e^(2πi/5).

Explanation:
Option A (1) is not primitive as it's the 1st root and not distinct. Option B (i) is the 4th root, not primitive for n = 5. Option D (e^(4πi/5)) is also a root but not primitive because it's a multiple of e^(2πi/5).

Common mistake note:
Common mistake: Choosing a non-primitive root or selecting an incorrect form.

Solution:

Problem 3 (3):
What is the smallest positive integer n for which 2 + i is a primitive nth root of unity?
A) 4
B) 6
C) 8
D) 10
Correct Answer: B

Solution:
To determine if 2 + i is a primitive nth root of unity, find the smallest n such that (2 + i)^n = 1. Convert to polar form: (2 + i) = √5 * (cos(θ) + i*sin(θ)), where θ = arctan(1/2). Then, calculate θ for which (cos(θ) + i*sin(θ))^n = 1.

Explanation:
For n = 4, 6, 8, or 10, check if (2 + i)^n equals 1. Only for n = 6 does this hold true: (2 + i)^6 = (√5 * e^(i*arctan(1/2)))^6 = 32 * 5 = 160 = 1 (mod 100).

Common mistake note:
Common mistake: Not converting to polar form or failing to recognize the modular arithmetic aspect.

Problem 4 (4):
Find a primitive 9th root of unity in rectangular form.
A) -1
B) 0
C) 1/2 + √3i/2
D) 1/2 - √3i/2
Correct Answer: C

Solution:
Using De Moivre's Theorem, we can find a primitive 9th root of unity by raising e^(2πi/9) to the power of 9. Let's choose k=1 for simplicity: (e^(2πi/9))^9 = 1.

Explanation:
Option A (-1) is not primitive as it's the 3rd root, and n = 9. Option B (0) is not a root of unity. Options C and D are both correct as they are the two primitive 9th roots of unity in rectangular form, but we only need one. Since it asks for a primitive root, we choose C.

Common mistake note:
Common mistake: Choosing a non-primitive root or failing to recognize that there are two primitive roots in this case.

Problem 5 (5):
Find the smallest positive integer n such that (1 + i)^n = 1.
A) 2
B) 4
C) 6
D) 8
Correct Answer: B

Solution:
Use De Moivre's Theorem to find the smallest n for which (1 + i) equals 1. In polar form, (1 + i) = √2 * (cos(π/4) + i*sin(π/4)). Find n such that cos(nπ/4) + i*sin(nπ/4) = 1.

Explanation:
For n = 2, 4, 6, or 8, check if (1 + i)^n equals 1. Only for n = 4 does this hold true: (1 + i)^4 = (√2 * e^(i*π/4))^4 = 4 = 1.

Common mistake note:
Common mistake: Not converting to polar form or failing to recognize the modular arithmetic aspect.
