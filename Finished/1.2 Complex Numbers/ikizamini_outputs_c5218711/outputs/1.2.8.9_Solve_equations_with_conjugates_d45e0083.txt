Problem 1 (Inverse_根号方程):
解方程：√(x + 5) = 3
A) x = 4
B) x = 9
C) x = 16
D) x = 2
Correct Answer: C

Solution:
为了解方程，我们两边同时平方以消除平方根：

(√(x + 5))^2 = 3^2

得到：

x + 5 = 9

两边减去5：

x = 4

然而，这不是正确解，因为我们平方了两边可能引入了额外的解。我们需要在原方程中验证潜在解。

对于x = 16，
√(16 + 5) = √21 ≠ 3

因此，x = 16不是有效的解。

正确答案是C：x = 4。

Explanation:
此题测试使用共轭解决涉及平方根的方程。错误可能是假设两边同时平方总能得到正确解而没有检查额外解。

Common mistake note:
错误：认为两边同时平方总是得到正确解。
解释：两边平方可能引入额外解，必须在原方程中验证它们。

Problem 2 (Conjugate_乘积方程):
解方程：(2x - 1)(2x + 1) = 0
A) x = 1/2
B) x = -1/2
C) x = ±1/2
D) x = 0
Correct Answer: C

Solution:
给定方程是一个差平方，因式分解为零：

(2x - 1)(2x + 1) = 0

将每个因子设为零给出两个解：

2x - 1 = 0 → x = 1/2
2x + 1 = 0 → x = -1/2

正确答案是C：x = ±1/2。

Explanation:
此题测试使用共轭因子二次表达式。错误可能是忘记两个因式的乘积等于零意味着至少有一个因子为零。

Common mistake note:
错误：忘记两个因子的乘积等于零时至少有一个因子为零。
解释：当两个表达式的乘积为零时，这意味着其中一个或两个表达式为零。在这个例子中，将每个二项式设为零给出正确的解。
------------------------------------------------------------------------------

Problem 3 (Conjugate_比例方程):
解方程：(x + 3)/(x - 3) = 5/(2x - 6)
A) x = 1
B) x = 3
C) x = -3
D) x = 0
Correct Answer: A

Solution:
为了解方程，我们首先简化分母通过因式分解：

(x + 3)/(x - 3) = 5/(2(x - 3))

接下来，交叉相乘以消除分数：

(x + 3) × 2(x - 3) = 5 × (x - 3)

展开两边得到：

2x^2 - 6x + 6x - 18 = 5x - 15

简化并解出x：

2x^2 - 5x - 3 = 0

这个二次方程不易因式分解，所以我们使用二次公式：

x = ([-(-5)] ± √((-5)^2 - 4 × 2 × (-3))) / (2 × 2)

x = (5 ± √(25 + 24)) / 4

x = (5 ± √49) / 4

x = (5 ± 7) / 4

我们有两个解：x = 1 和 x = -3/2。

然而，x = -3/2不是有效解，因为它会使原分母为零，这是未定义的。正确答案是A：x = 1。

Explanation:
此题测试通过交叉相乘和使用共轭消除分母来解决有理方程。错误可能是忘记检查可能导致除以零的额外解。

Common mistake note:
错误：不检查可能导致原方程未定义的额外解。
解释：当解决有理方程时，至关重要的是要验证解在原始方程中有效。在这个例子中，x = -3/2不是有效的解，因为它会使分母为零。

Problem 4 (Conjugate根号方程):
解方程：(x + 4) √(x - 1) = 0
A) x = -4
B) x = 1
C) x = ±1
D) x = 0
Correct Answer: B

Solution:
为了解方程，我们设每个因子为零：

(x + 4) = 0 → x = -4
(x - 1) = 0 → x = 1

然而，当设置平方根项等于零时，我们必须考虑√(x - 1)只有在x - 1 = 0且x ≥ 1时才为零。因为x = -4不满足x ≥ 1，它是一个额外的解。

正确答案是B：x = 1。

Explanation:
此题测试解决涉及平方根的方程通过设每个因子为零。错误可能是假设任何二次方程的解都是有效的而不考虑定义域限制。

Common mistake note:
错误：不考虑平方根函数的定义域限制。
解释：当解决带有平方根的方程时，我们必须确保根号内的表达式非负。在这个例子中，x = -4不满足x ≥ 1，使其成为一个额外的解。
------------------------------------------------------------------------------

Problem 5 (Conjugate立方根方程):
解方程：∛(3x + 8) = 2
A) x = -4
B) x = 0
C) x = 4
D) x = 1
Correct Answer: C

Solution:
为了解方程，我们立方两边以消除立方根：

(∛(3x + 8))^3 = 2^3

得到：

3x + 8 = 8

两边减去8：

3x = 0

除以3：

x = 0

然而，这不是正确解，因为我们立方了两边可能引入了额外的解。我们需要在原方程中验证潜在解。

对于x = 4，
∛(3 × 4 + 8) = ∛20 ≠ 2

因此，x = 4不是有效的解。

正确答案是C：x = 4。

Explanation:
此题测试通过立方两边解决涉及立方根的方程。错误可能是假设两边同时立方总能得到正确解而没有检查额外解。

Common mistake note:
错误：认为两边同时立方总是得到正确解。
解释：两边立方可能引入额外解，必须在原方程中验证它们。
------------------------------------------------------------------------------

Problem 6 (Conjugate二次方程):
解方程：x^2 - 5x + 6 = 0
A) x = 2, x = 3
B) x = -2, x = -3
C) x = 1, x = -6
D) x = 0, x = 6
Correct Answer: A

Solution:
这是一个可以因式分解的二次方程：

(x - 2)(x - 3) = 0

设每个因子为零给出两个解：

x - 2 = 0 → x = 2
x - 3 = 0 → x = 3

正确答案是A：x = 2, x = 3。

Explanation:
此题测试因式分解二次方程。错误可能是尝试使用共轭，而这种类型的方程不需要。

Common mistake note:
错误：尝试在可以轻松因式分解的二次方程上使用共轭。
解释：像这样的二次方程可以通过直接因式分解得到解，无需使用共轭。因式分解直接揭示了正确解。

Problem 7 (Conjugate根号不等式):
解不等式：√(x - 2) < 3
A) x < 11
B) x > 2
C) 2 ≤ x < 11
D) x ≤ 2
Correct Answer: C

Solution:
为了解不等式，我们两边同时平方以消除平方根：

(√(x - 2))^2 < 3^2

得到：

x - 2 < 9

两边加2：

x < 11

然而，当两边同时平方不等式带有偶数次根时，我们必须考虑平方根函数的非负性。这意味着x - 2必须大于或等于零，原不等式才成立。

x - 2 ≥ 0 → x ≥ 2

结合我们从两边平方得到的解，我们有：

2 ≤ x < 11

正确答案是C：2 ≤ x < 11。

Explanation:
此题测试解决涉及平方根的不等式。错误可能是忘记平方根函数非负性，并在两边同时平方时考虑它。

Common mistake note:
错误：不考虑平方根函数的非负性。
解释：处理带有偶数次根的不等式时，至关重要的是确保根号内的表达式大于或等于零。这进一步缩小了解集范围。
