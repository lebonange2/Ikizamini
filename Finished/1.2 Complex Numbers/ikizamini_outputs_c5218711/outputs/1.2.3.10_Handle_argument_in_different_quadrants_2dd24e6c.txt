Problem 1 (InQuadrant1):
Given the complex number z = 3 + 4i, which quadrant does it lie in?
A) First Quadrant
B) Second Quadrant
C) Third Quadrant
D) Fourth Quadrant
Correct Answer: A

Solution:
The first quadrant contains complex numbers with both positive real and imaginary parts. Since 3 is positive and 4 is also positive, z = 3 + 4i lies in the first quadrant.

Explanation:
In a complex plane, the quadrants are defined by the signs of the real (x) and imaginary (y) parts: 
- First Quadrant: x > 0, y > 0
- Second Quadrant: x < 0, y > 0
- Third Quadrant: x < 0, y < 0
- Fourth Quadrant: x > 0, y < 0

Common mistake note:
A common mistake is to misinterpret the signs of the real and imaginary parts. Make sure to check both the sign of the real part (3) and the imaginary part (4).

A) First Quadrant
B) Second Quadrant
C) Third Quadrant

Correct Answer: D

- First Quadrant: x > 0, y > 0
- Second Quadrant: x < 0, y > 0
- Third Quadrant: x < 0, y < 0
- Fourth Quadrant: x > 0, y < 0

Problem 3 (InQuadrant3):
What quadrant does the complex number z = 4i belong to?
A) First Quadrant
B) Second Quadrant
C) Third Quadrant
D) Fourth Quadrant
Correct Answer: B

Solution:
The second quadrant contains complex numbers with a negative real part and a positive imaginary part. Since 4i has no real part (x = 0) and a positive imaginary part, z = 4i lies in the second quadrant.

Explanation:
In a complex plane, the quadrants are defined by the signs of the real (x) and imaginary (y) parts: 
- First Quadrant: x > 0, y > 0
- Second Quadrant: x < 0, y > 0
- Third Quadrant: x < 0, y < 0
- Fourth Quadrant: x > 0, y < 0

Common mistake note:
A common mistake is to assume that the absence of a real part means it's in the first or fourth quadrant. Remember that zero is neither positive nor negative.
