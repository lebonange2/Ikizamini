Problem 1 (x1):
Solve the equation: (x + 3)(x - 4) = 0
A) x = 3
B) x = -3
C) x = 4
D) x = -4
Correct Answer: B

Solution:
The equation can be solved by setting each factor equal to zero: x + 3 = 0 or x - 4 = 0. Solving these equations gives x = -3 and x = 4, respectively. However, since we're looking for the value that makes both factors zero (as they are multiplied together), we only consider x = -3 as the correct solution.

Explanation:
The conjugate method is not directly applicable here; factoring the equation reveals the roots.

Common mistake note:
A common mistake would be to choose 'x = 4' because it's one of the factors, but that only makes one factor zero, not both. The correct solution requires setting the entire product equal to zero.

C) x = 0, x = 5
D) No solution
Correct Answer: C

Solution:
Use the conjugate method by expanding both sides: x^2 - x - 2 = x^2 + 6x + 9. Move all terms to one side and factor: 7x + 11 = 0, which gives x = -rac{11}{7}. However, this is not a valid solution since it makes the original equation's left side negative while the right side is positive. The correct solution is no solution.

Explanation:
The conjugate method is used here to expand and solve the equation.

Common mistake note:
A common mistake would be to think that x = -1 or x = 2 are solutions because they make one factor zero, but these values do not satisfy the original equation.

Problem 6 (x6):
Solve the equation: rac{(x + 4)(x - 3)}{(x + 4)^2} = 1
A) x = 3
B) x = -4
C) No solution
D) x = 3, x = -4
Correct Answer: A

Solution:
Simplify the equation by canceling out the common factor (x + 4): x - 3 = x + 4. Subtract x from both sides: -3 = 4, which is a contradiction. The correct solution is no solution.

Explanation:
The conjugate method is not used here; we simplify and find a contradiction.

Common mistake note:
A common mistake would be to think that x = -4 is a solution because it cancels out in the equation, but doing so leads to a false statement (-3 = 4).
