Problem 1 (Asdf):
Solve the inequality: x + 3 < 7
A) x < 4
B) x > 4
C) x ≤ 4
D) x ≥ 4
A) x < 4
B) x > 4
C) x ≤ 4
D) x ≥ 4
Correct Answer: A

Solution:
Subtract 3 from both sides to get x < 4. The correct answer is A.

Explanation:
Inequalities are solved by performing the same operation on both sides of the inequality sign. Here, subtracting 3 maintains the direction of the inequality.

Common mistake note:
A common mistake is to forget to change the direction of the inequality when multiplying or dividing by a negative number.

Problem 3 (Qwer):
Which graph represents the solution set for the inequality: -3x + 6 ≤ 12?
A) A line with shading on the right side
B) A line with shading on the left side
C) A shaded region above the line
D) A shaded region below the line
A) A line with shading on the right side
B) A line with shading on the left side
C) A shaded region above the line
D) A shaded region below the line
Correct Answer: D

Solution:
The inequality -3x + 6 ≤ 12 simplifies to x ≥ -2. The solution set is all values of x greater than or equal to -2, which corresponds to a shaded region below the line y = x + 2. The correct answer is D.

Explanation:
When graphing inequalities, shading above or below the line depends on whether the inequality involves '<' or '>=' (shading below) or '>' or '<=' (shading above).

Common mistake note:
A common mistake is to shade in the wrong direction based on the inequality sign.

Problem 4 (Tyui):
Solve and graph the solution set for the compound inequality: 4x - 5 < 11 or x + 2 > 7
A) x < 4, x > 5
B) x < 4, x < 5
C) x > 4, x < 5
D) x > 4, x > 5
A) x < 4, x > 5
B) x < 4, x < 5
C) x > 4, x < 5
D) x > 4, x > 5
Correct Answer: A

Solution:
Solve each inequality separately: 4x - 5 < 11 gives x < 4 and x + 2 > 7 gives x > 5. The compound solution set is x < 4 or x > 5, which graphically appears as two separate regions on the number line. The correct answer is A.

Explanation:
When solving compound inequalities with 'or', you find solutions for each inequality and combine them without overlapping regions.

Common mistake note:
A common mistake is to incorrectly combine the solution sets, assuming they should overlap.

Problem 5 (Poiu):
Sketch the solution set for the inequality: 3(x - 2) ≥ x + 6
A) A line with shading on the right side
B) A line with shading on the left side
C) A shaded region above the line
D) A shaded region below the line
A) A line with shading on the right side
B) A line with shading on the left side
C) A shaded region above the line
D) A shaded region below the line
Correct Answer: C

Solution:
Distribute and simplify: 3x - 6 ≥ x + 6, which gives 2x ≥ 12 or x ≥ 6. The solution set is all values of x greater than or equal to 6, which corresponds to a shaded region above the line y = x - 6. The correct answer is C.

Explanation:
When graphing inequalities, shading above or below the line depends on whether the inequality involves '<' or '>=' (shading below) or '>' or '<=' (shading above). Here, we first distribute and simplify before graphing.

Common mistake note:
A common mistake is to forget to distribute the 3 in the original inequality.
