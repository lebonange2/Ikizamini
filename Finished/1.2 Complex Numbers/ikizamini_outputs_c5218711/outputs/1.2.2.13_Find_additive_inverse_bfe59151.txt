Problem 1 (Asd1):
What is the additive inverse of -7?
A) -8
B) 8
C) 0
D) No unique inverse
Correct Answer: B

Solution:
The additive inverse of a number is the number that, when added to the original number, results in zero. The additive inverse of -7 is 7 because (-7) + 7 = 0.

Explanation:
Additive inverses are numbers that cancel each other out when added together.

Common mistake note:
A common mistake would be to choose 'A' (-8), which is the opposite sign but not the correct magnitude. Remember, the additive inverse has the same magnitude as the original number but with the opposite sign.

Problem 2 (Zxc1):
Find the additive inverse of 0.
A) 1
B) -1
C) No unique inverse
D) No inverse for zero
Correct Answer: C

Solution:
The additive inverse of 0 is 0 itself because 0 + 0 = 0. There is no other number that, when added to 0, would result in a different value.

Explanation:
Zero has a unique property: its own additive inverse is itself.

Common mistake note:
A common mistake might be to choose 'C' (0), assuming there is an additive inverse for all numbers. However, only zero has this special characteristic.

Problem 3 (Qwe1):
What is the additive inverse of 5/2?
A) -5/2
B) No unique inverse
C) No inverse for fractions
D) No inverse
Correct Answer: A

Solution:
The additive inverse of a fraction is found by changing its sign. The additive inverse of 5/2 is -5/2 because (5/2) + (-5/2) = 0.

Explanation:
Additive inverses apply to fractions as well, with the same principle: change the sign of the number.

Common mistake note:
A common mistake could be to choose 'B' (2/5), which is simply the reciprocal of 5/2 but not its additive inverse. Remember, the additive inverse changes the sign.
