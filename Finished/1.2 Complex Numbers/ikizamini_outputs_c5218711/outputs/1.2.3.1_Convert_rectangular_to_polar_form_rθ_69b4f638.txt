Problem 1 (Asdf):
Convert the rectangular coordinates (-3, 4) into polar form.
A) (5, π/4)
B) (5, -π/4)
C) (5, 3π/4)
D) (5, -3π/4)
Correct Answer: C

Solution:
(r, θ) = √((-3)^2 + 4^2), arctan(4/-3) = 5, -π/4. The correct answer is (5, -3π/4).

Explanation:
The polar form (r∠θ) represents the same point as rectangular coordinates (x, y), where r is the distance from the origin and θ is the angle formed with the positive x-axis. To convert (-3, 4) to polar form, we calculate r using the Pythagorean theorem: r = √(x^2 + y^2) and find θ using arctan(y/x).

Common mistake note:
A common mistake is to use the wrong quadrant for θ when calculating the arctangent. Since x < 0 and y > 0, we need to adjust the angle to account for the correct quadrant.

Problem 3 (Qwer):
Convert the rectangular coordinates (0, 5) into polar form.
A) (5, 0)
B) (5, π/2)
C) (5, π)
D) (5, 3π/2)
Correct Answer: A

Solution:
(r, θ) = √(0^2 + 5^2), arctan(5/0) = undefined, 0. The correct answer is (5, 0).

Explanation:
The polar form (r∠θ) represents the same point as rectangular coordinates (x, y), where r is the distance from the origin and θ is the angle formed with the positive x-axis. To convert (0, 5) to polar form, we calculate r using the Pythagorean theorem: r = √(x^2 + y^2) and find θ using arctan(y/x). Since x is zero, the angle θ becomes undefined. However, in this case, we know that the point lies on the positive y-axis, so θ is 0.

Common mistake note:
A common mistake is to assume that an undefined arctangent means there's no solution or to choose a random angle. In this case, the correct angle is 0 because the point lies on the positive y-axis.

Problem 5 (Bnml):

Common mistake note:
