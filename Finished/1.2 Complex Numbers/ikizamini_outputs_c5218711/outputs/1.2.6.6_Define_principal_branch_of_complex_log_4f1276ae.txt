Problem 1 (Asdf):
What is the principal branch of the complex logarithm function?
A) log(z) for all z in C
B) ln(|z|) + arg(z), where arg(z) is in [0, 2π)
C) ln(|z|) + i(arg(z)), where arg(z) is in [-π, π)
D) ln(|z|) + i(arg(z)), where arg(z) is in (-π, π]
Correct Answer: C

Solution:
The principal branch of the complex logarithm function, denoted as ln(z), has a range of (-π, π] for the imaginary part (argument) to ensure it's single-valued. Therefore, option C is correct.

Explanation:
The principal branch of the complex log function selects one value from the infinite set of values that satisfy the logarithm property.

Common mistake note:
A common mistake is to choose option A, which represents the natural logarithm for all complex numbers without considering the single-valued nature of the principal branch. Option B omits the imaginary part of the complex log, and option D uses an incorrect range for the argument.

Problem 2 (Asdf):
Which of the following expressions represents the principal value of the logarithm of z = 2 + 3i?
A) ln(2 + 3i)
B) ln(sqrt(13)) + i(arctan(3/2))
C) ln(sqrt(13)) + i(pi/4)
D) ln(sqrt(13)) + i(-pi/4)
Correct Answer: B

Solution:
The principal value of the logarithm of z = 2 + 3i can be found by calculating the modulus and argument. The modulus is sqrt(2^2 + 3^2) = sqrt(13), and the argument is arctan(3/2). Using option B with ln(sqrt(13)) + i(arctan(3/2)), we get the principal value.

Explanation:
The principal branch of the complex log function requires both modulus and argument to be within their respective ranges. In this case, the argument is in (-π, π].

Common mistake note:
A common mistake would be to choose option C or D, which represent other possible values for the logarithm but not the principal value.

Problem 4 (Asdf):
What is the value of the principal logarithm of -1?
A) 0
B) iπ
C) -iπ
D) ln(1) + i(π/2)
Correct Answer: B

Solution:
The principal logarithm of -1 can be found using Euler's formula, e^(iπ) = -1. Taking the logarithm of both sides gives us ln(-1) = iπ.

Explanation:
The principal branch ensures a single-valued result by restricting the argument to the range (-π, π]. In this case, the argument is π.

Common mistake note:
A common mistake would be to choose option C (-iπ), which is one of the many possible values for the logarithm of -1 but not the principal value. Option A and D represent other logarithmic expressions that do not correspond to the principal branch.

In polar form, a complex number can be written as r(cosθ + i sinθ), where r is the modulus and θ is the argument. The principal logarithm uses the natural logarithm of the modulus and the restricted argument.

Common mistake note:
