Problem 1 (:1):
What is the value of i²?
A) 0
B) 1
C) -1
D) i
Correct Answer: C

Solution:
The square of the imaginary unit i is -1. Thus, i² = -1.

Explanation:
This question tests understanding of a basic property of complex numbers.

Common mistake note:
A common mistake would be to select '0' or '1', which are incorrect because they do not satisfy the fundamental property of i.

Problem 2 (:2):
If z = 3 + 4i, what is the value of z²?
A) 9 - 16
B) 7 + 24i
C) -7 + 24i
D) -5 - 24i
Correct Answer: D

Solution:
z² = (3 + 4i)(3 + 4i) = 9 + 12i + 12i + 16i² = 9 + 24i - 16 = -7 - 24i.

Explanation:
This question tests the application of i² = -1 in a complex number multiplication problem.

Common mistake note:
A common mistake would be to forget to apply i² = -1, leading to an incorrect result.

Problem 3 (:3):
What is the square root of -9?
A) 3
B) -3
C) 3i
D) -3i
Correct Answer: C

Solution:
The square root of -9 can be written as √(-1 * 9) = √(-1) * √(9) = i * 3 = 3i.

Explanation:
This question tests understanding of taking the square root of a negative number using imaginary numbers.

Common mistake note:
A common mistake would be to select '-3', which is the square root of 9 but not -9. Another mistake could be forgetting to include i.
