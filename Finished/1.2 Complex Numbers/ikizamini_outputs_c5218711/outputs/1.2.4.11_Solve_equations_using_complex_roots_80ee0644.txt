Problem 1 (:1):
Find the solution to the equation: x^2 + 4 = 0
A) -2
B) 2
C) 2i
D) -2i
Correct Answer: C

Solution:
The given equation is a quadratic equation in the form of x^2 + 4 = 0. To solve it, we can use the quadratic formula: x = (-b ± √(b^2 - 4ac)) / (2a). In this case, a = 1, b = 0, and c = 4. Plugging these values into the formula gives us x = ±√(-4) / 2 = ±i√2. Simplifying further, we get x = ±2i. Therefore, the correct answer is C: 2i.

Explanation:
The quadratic equation has complex roots because the discriminant (b^2 - 4ac) is negative. Complex numbers have an imaginary part, denoted by 'i'.

Common mistake note:
A common mistake would be to choose A or B, which are real solutions for a different quadratic equation without the complex term. Remember that when the discriminant is negative, roots will be complex.

Problem 2 (:2):
Solve for x: (x - 3i)(x + 5i) = 0
A) 3i
B) -5i
C) 3i or -5i
D) 15i
Correct Answer: C

Solution:
The given equation is a product of two binomials, which can be solved by setting each factor equal to zero. So we have (x - 3i) = 0 or (x + 5i) = 0. Solving these equations gives us x = 3i and x = -5i. Therefore, the correct answer is C: 3i or -5i.

Explanation:
When multiplying binomials and setting the product to zero, we find roots by solving each factor separately. Complex numbers can be solutions in such equations.

Common mistake note:
A common mistake would be to multiply coefficients (3i * 5i), leading to an incorrect solution. Remember that we're looking for values of x that make each factor zero, not the product.

Problem 4 (:4):
Find the solution to the equation: 2x^2 + 8ix - 6 = 0
A) 1 + i
B) 1 - i
C) -1 + i
D) -1 - i
Correct Answer: C

Solution:
To solve the given quadratic equation, we can use the quadratic formula: x = (-b ± √(b^2 - 4ac)) / (2a). Here, a = 2, b = 8i, and c = -6. Plugging these values into the formula gives us x = (-8i ± √((-8i)^2 - 4(2)(-6))) / (2(2)). Simplifying further, we get x = (-8i ± √(-64 + 48)) / 4 = (-8i ± √16) / 4 = (-8i ± 4) / 4. This leads to two solutions: x = -2i + 1 and x = -2i - 1. Therefore, the correct answer is C: -1 + i.

Explanation:
When solving a quadratic equation with complex coefficients, use the quadratic formula and handle imaginary parts correctly.

Common mistake note:
A common mistake would be to mishandle the imaginary terms in calculation, leading to incorrect solutions. Remember to square the imaginary part (8i) and keep track of plus or minus sign when applying the quadratic formula.

A) -6 - 5i
B) -6 + 5i
C) -6 - 3i
D) -6 + 3i
Correct Answer: A

Solution:
To solve the given quadratic equation, we can use the quadratic formula: x = (-b ± √(b^2 - 4ac)) / (2a). Here, a = 1, b = 12, and c = 37. Plugging these values into the formula gives us x = (-12 ± √((12)^2 - 4(1)(37))) / (2(1)). Simplifying further, we get x = (-12 ± √(144 - 148)) / 2 = (-12 ± √(-4)) / 2 = (-12 ± 2i) / 2. This leads to two solutions: x = -6 + i and x = -6 - i. Therefore, the correct answer is A: -6 - 5i.

Explanation:
When solving a quadratic equation with real coefficients, use the quadratic formula and handle complex roots correctly.

Common mistake note:
