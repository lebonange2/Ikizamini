Problem 1 (:1):
Which regular expression represents a language containing strings of 0s and 1s with an equal number of 0s and 1s?
A) (0+1)*
B) (0+1)^*(01|10)*(0+1)^*
C) 0^*1^*
D) 0(0+1)^*1(0+1)^*
Correct Answer: D

Solution:
The correct regular expression is D, which represents strings starting with a 0, followed by any number of 0s or 1s, then a 1, and finally any number of 0s or 1s. This ensures an equal number of 0s and 1s in the string.

Explanation:
Regular expressions describe languages containing strings that meet specific criteria.

Common mistake note:
Choice A represents any combination of 0s and 1s, not necessarily with an equal number.
Choice B requires at least one pair of alternating 0s and 1s, which isn't necessary for equality.

Problem 2 (:2):
Which formal language notation describes a set of strings where each string has an even number of 'a's followed by an odd number of 'b's?
A) Context-free grammar (CFG)
B) Regular expression (regex)
C) Deterministic finite automaton (DFA)
D) Pushdown automaton (PDA)
Correct Answer: A

Solution:
The language described requires a context-sensitive rule, best represented by a Context-free grammar (CFG). Regular expressions and DFAs can't handle the specific ordering requirement.

Explanation:
Context-free grammars are used for languages with more complex structure than regular expressions or DFAs.

Common mistake note:
Choice B (regex) cannot enforce the exact order of 'a's and 'b's.
Choice C (DFA) is limited to finite state transitions, unable to handle the ordering.

Problem 3 (:3):
Which formal language model recognizes the language containing all strings ending with the substring 'ab'?
A) Regular expression (regex)
B) Deterministic finite automaton (DFA)
C) Non-deterministic finite automaton (NFA)
D) Pushdown automaton (PDA)
Correct Answer: A

Solution:
The language described can be recognized by a regular expression, designed to match specific patterns in strings. DFAs and NFAs can also recognize this language.

Explanation:
Regular expressions are used for pattern-matching tasks in strings.

Common mistake note:
Choice D (PDA) is unnecessary for this simple pattern matching task.

Problem 4 (:4):
Which formal language model describes the set of all palindromic strings over the alphabet {a, b}?
A) Regular expression (regex)
B) Deterministic finite automaton (DFA)
C) Non-deterministic finite automaton (NFA)
D) Context-free grammar (CFG)
Correct Answer: C

Solution:
Palindromic strings can be recognized by a non-deterministic finite automaton (NFA), which allows for multiple paths through the machine. DFAs and regular expressions cannot handle reading the string in both directions.

Explanation:
NFAs are used when there's a need for non-linear or parallel processing.

Common mistake note:
Choice A (regex) and B (DFA) are limited to linear progression through the string.

Problem 5 (:5):
Which formal language model best describes the set of all strings containing an equal number of 'a' and 'b', where 'a' appears before 'b'?
A) Regular expression (regex)
B) Deterministic finite automaton (DFA)
C) Non-deterministic finite automaton (NFA)
D) Context-sensitive grammar (CSG)
Correct Answer: D

Solution:
The language described requires context-sensitivity, as it involves the order of 'a' and 'b'. Regular expressions, DFAs, and NFAs are not context- sensitive.

Explanation:
Context-sensitive grammars handle languages with complex ordering requirements.

Common mistake note:
Choice A (regex) and B (DFA) are limited to pattern matching and finite state transitions, respectively.
Choice C (NFA) is also limited to finite state transitions.
