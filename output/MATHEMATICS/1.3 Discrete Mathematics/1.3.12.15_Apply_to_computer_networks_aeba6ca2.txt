Problem 1 (?):
What is the primary function of a router in a computer network?
A) To store and retrieve data from the network
B) To connect multiple devices on a network and forward data packets between them
C) To provide internet connectivity to the network
D) To secure the network by filtering incoming and outgoing traffic
Correct Answer: B

Solution:
A router connects multiple devices on a network and forwards data packets between them, enabling communication between different networks and managing network traffic.

Explanation:
Routers may contribute to security and provide internet connectivity, but their primary role is connecting devices and forwarding data.

Common mistake note:
Common mistake: Choosing A (store and retrieve data) typically involves servers or storage devices. Choosing C (internet connectivity) can be misleading as routers can function without internet access, focusing on local network communication.

A) To store and process data for multiple users
B) To provide services to other devices by running applications
C) To request resources or services from the server
D) To manage network traffic between devices
Correct Answer: C

Solution:

Explanation:
Clients initiate communication while servers handle requested tasks. A and B describe server roles, and D is typically the function of a router.

Problem 3 (?):
What is the main purpose of using firewalls in computer networks?
A) To increase network speed by optimizing data transmission
B) To provide remote access to devices on the network
C) To ensure secure communication by filtering unauthorized traffic
D) To distribute network load and balance resources
Correct Answer: C

Solution:
Firewalls primarily filter unauthorized traffic, ensuring secure communication between trusted internal networks and untrusted external networks.

Explanation:
Firewalls do not affect network speed, provide remote access, or distribute network load; these functions belong to other networking components.

Common mistake note:

Which protocol is used for file transfers in computer networks?
A) HTTP (Hypertext Transfer Protocol)
B) FTP (File Transfer Protocol)
C) SMTP (Simple Mail Transfer Protocol)

Problem 6 (?):
Which layer of the OSI (Open Systems Interconnection) model is responsible for routing data packets between networks?
A) Application Layer
B) Transport Layer
C) Network Layer
D) Data Link Layer
Correct Answer: C

Solution:
The Network Layer in the OSI model routes data packets between networks, using addressing information and protocols like IP.

Explanation:
The Application Layer deals with user applications, Transport Layer manages end-to-end communication, and Data Link Layer focuses on reliable transmission within a single network segment.

Common mistake note:
Common mistake: Choosing A (Application Layer) could混淆 with high-level services. Choosing B (Transport Layer) might happen when thinking about error-free data transfer.
