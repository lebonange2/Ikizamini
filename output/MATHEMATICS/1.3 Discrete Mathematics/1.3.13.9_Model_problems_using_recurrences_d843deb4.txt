Problem 1 (Asdf):
What is the recurrence relation for the number of ways to tile a 2xN chessboard with 2x1 dominoes?
A) T(n) = T(n-1) + T(n-2)
B) T(n) = 2 πn
C) T(n) = 2^N
D) T(n) = N!
Correct Answer: A

Solution:
The recurrence relation for tiling a 2xN chessboard with 2x1 dominoes is found by considering the last tile placed. If it covers the two leftmost cells, there are T(n-1) ways to tile the remaining board. If it covers the second and third cells from the left, then there are T(n-2) ways to tile the rest. Therefore, the recurrence relation is T(n) = T(n-1) + T(n-2).

Explanation:
This problem involves modeling a combinatorial situation with a recurrence relation.

Common mistake note:
A common mistake would be to choose C (T(n) = 2^N), which represents the number of subsets of size N from a set, not the number of ways to tile a board.

Correct Answer: A

Solution:
The Fibonacci sequence is defined by the recurrence relation F(n) = F(n-1) + F(n-2), where F(1) = 1 and F(2) = 1.

Explanation:

Problem 3 (Qwer):
What is the recurrence relation for the number of ways to climb n stairs if you can take 1 or 2 steps at a time?
A) C(n) = C(n-1) + C(n-2)
B) C(n) = 2^n
C) C(n) = n!
D) C(n) = C(n-1) × C(n-2)
Correct Answer: A

Solution:
The recurrence relation for this problem is found by considering the last step taken. If you take a single step, there are C(n-1) ways to climb the remaining stairs. If you take two steps, there are C(n-2) ways. Therefore, C(n) = C(n-1) + C(n-2).

Explanation:
This problem models a counting problem with a recurrence relation.

Common mistake note:
A common mistake would be to choose B (C(n) = 2^n), which represents the number of subsets of size n from a set, not the number of ways to climb stairs.

Problem 4 (Poiu):

B) T(n) = 2^n - 1
C) T(n) = n! / (n-2)!
D) T(n) = C(n, 2)
Correct Answer: C

Solution:
The number of binary trees with n nodes is given by the recurrence relation T(n) = n × T(n-1), with T(1) = 1. This can be simplified to T(n) = n! / (n-2)!.

Explanation:
This problem involves modeling a tree structure with a recurrence relation.

Common mistake note:
A common mistake would be to choose A (T(n) = T(n-1) + T(n-2)), which is the Fibonacci sequence, not the number of binary trees.

Problem 6 (Vbnm):
What is the recurrence relation for the number of strings of length n using only characters 'a' and 'b', where no two consecutive characters are the same?
A) S(n) = S(n-1) + S(n-2)
B) S(n) = 2^n
C) S(n) = n! / 2!
D) S(n) = S(n-1) + S(n-2) - S(n-3)
Correct Answer: D

Solution:
The recurrence relation for this problem is found by considering the last character added. If it's 'a', there are S(n-1) valid strings, and if it's 'b', there are also S(n-1) valid strings (since we can't have two consecutive 'a's or 'b's). However, we've counted the case where the last two characters are 'aa' or 'bb' twice, so we subtract S(n-3), which is the number of invalid strings ending in 'aaa' or 'bbb'. Thus, S(n) = S(n-1) + S(n-2) - S(n-3).

Explanation:
This problem models a string constraint with a recurrence relation.

Common mistake note:
A common mistake would be to choose A (S(n) = S(n-1) + S(n-2)), which is the Fibonacci sequence, not the number of strings satisfying this condition.

Problem 7 (Xzas):
What is the recurrence relation for the number of ways to arrange n distinct items into a circle?
A) C(n) = C(n-1) + C(n-2)
B) C(n) = (n-1)! / 2
C) C(n) = n!
D) C(n) = n × (n-1)
Correct Answer: B

Solution:
The number of ways to arrange n distinct items in a circle is given by C(n) = (n-1)! / 2, as rotations are considered equivalent.

Explanation:
This problem involves modeling a circular arrangement with a recurrence relation.

Common mistake note:
A common mistake would be to choose C (C(n) = n!), which represents the number of ways to arrange n items linearly, not in a circle.
