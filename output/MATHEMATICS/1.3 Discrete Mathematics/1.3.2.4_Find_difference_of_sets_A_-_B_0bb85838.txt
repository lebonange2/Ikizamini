Problem 1 (:1):
Given set A = {1, 2, 3, 4} and set B = {3, 4, 5}, what are the elements in the difference set (A - B)?
A) [1, 2]
B) [3, 4]
C) [5]
D) [1, 2, 3, 4, 5]
Correct Answer: A

Solution:
The difference of sets A and B (A - B) contains elements that are in set A but not in set B. From the given sets: A = {1, 2, 3, 4} and B = {3, 4, 5}, we can see that only 1 and 2 from set A are not in set B. So, the difference is {1, 2}.

Explanation:
The elements 3 and 4 are not included because they are part of both sets. Element 5 is not in set A, so it's not in the difference.

Common mistake note:
A common mistake would be to include elements that are in both sets B (like 3 and 4) or to add elements that are not in either set (like 5).

Problem 2 (2):
Set A contains {7, 10, 13, 16} and set B has {10, 15, 18}. What are the elements in the difference set (A - B)?
A) [7, 13, 16]
B) [10, 15, 18]
C) [15, 18]
D) [13]
Correct Answer: A

Solution:
The difference of sets A and B (A - B) consists of elements from set A that are not in set B. Given A = {7, 10, 13, 16} and B = {10, 15, 18}, only 7, 13, and 16 from set A are not in set B. So, the difference is {7, 13, 16}.

Explanation:
The element 10 is not included because it's in both sets. Elements 15 and 18 are not in set A, so they're not part of the difference.

Common mistake note:
A common mistake would be to include element 10 from set B or to add elements that are not in either set.

Problem 3 (3):
Set C = {2, 4, 6, 8} and set D = {5, 7, 9}. What is the difference set (C - D)?
A) [1, 3, 5, 6, 7, 8, 9]
B) [2, 4, 6, 8]
C) [5, 7, 9]
D) [2, 4]
Correct Answer: B

Solution:
The difference of sets C and D (C - D) contains elements from set C that are not in set D. Given C = {2, 4, 6, 8} and D = {5, 7, 9}, all elements in set C are unique and not in set D. So, the difference is {2, 4, 6, 8}.

Explanation:
No elements from set D are in set C, so there's no overlap to exclude. Elements outside of both sets (like 1 or 3) are not part of the difference.

Common mistake note:
A common mistake would be to include elements from set D or to add elements that are not in either set.
