Problem 1 (One):
Which graph represents a complete graph with 4 vertices?
A) [{'vertices': [0, 1]}, {'vertices': [0, 2]}, {'vertices': [0, 3]}, {'vertices': [1, 2]}, {'vertices': [1, 3]}, {'vertices': [2, 3]}]
B) [{'vertices': [0, 1]}, {'vertices': [0, 2]}, {'vertices': [1, 3]}, {'vertices': [2, 3]}]
C) [{'vertices': [0, 1]}, {'vertices': [0, 2]}, {'vertices': [1, 2]}]
D) [{'vertices': [0, 1], 'weight': 5}, {'vertices': [0, 2]}, {'vertices': [1, 3]}, {'vertices': [2, 3]}]
Correct Answer: A

Solution:
A complete graph has an edge between every pair of vertices. In this case, graph A has edges connecting all pairs of vertices (0-1, 0-2, 0-3, 1-2, 1-3, and 2-3), satisfying the definition of a complete graph with 4 vertices.

Explanation:
A complete graph must have an edge between every pair of vertices. Graph B is missing an edge (2-3), graph C is missing two edges (2-3 and 0-3), and graph D has a weighted edge which does not affect connectivity but might confuse the reader about the definition of a complete graph.

Common mistake note:
Common mistake: Choosing B or C because they lack an edge connecting two vertices. Remember that all pairs of vertices must be connected in a complete graph.

Problem 2 (Two):
Identify which graph represents a complete graph with 5 vertices.
A) [{'vertices': [0, 1]}, {'vertices': [0, 2]}, {'vertices': [0, 3]}, {'vertices': [0, 4]}, {'vertices': [1, 2]}, {'vertices': [1, 3]}, {'vertices': [1, 4]}, {'vertices': [2, 3]}, {'vertices': [2, 4]}, {'vertices': [3, 4]}]
B) [{'vertices': [0, 1]}, {'vertices': [0, 2]}, {'vertices': [0, 3]}, {'vertices': [0, 4]}, {'vertices': [1, 2]}, {'vertices': [1, 3]}, {'vertices': [2, 3]}]
C) [{'vertices': [0, 1]}, {'vertices': [0, 2]}, {'vertices': [0, 3]}, {'vertices': [0, 4]}, {'vertices': [1, 2]}, {'vertices': [1, 3]}, {'vertices': [1, 4]}]
D) [{'vertices': [0, 1], 'weight': 5}, {'vertices': [0, 2]}, {'vertices': [0, 3]}, {'vertices': [0, 4]}, {'vertices': [1, 2]}, {'vertices': [1, 3]}, {'vertices': [1, 4]}]
Correct Answer: A

Solution:
Graph A represents a complete graph with 5 vertices because it has an edge connecting every pair of vertices (0-1, 0-2, 0-3, 0-4, 1-2, 1-3, 1-4, 2-3, 2-4, and 3-4).

Explanation:
A complete graph must have an edge between every pair of vertices. Graph B is missing two edges (3-4 and 2-4), graph C is missing one edge (2-4), and graph D has a weighted edge which does not affect connectivity but might confuse the reader about the definition of a complete graph.

Common mistake note:
Common mistake: Choosing B, C, or D because they lack an edge connecting two vertices or include extra edges. Remember that a complete graph must connect every pair of vertices.

Problem 3 (Three):
Which of the following is NOT a complete graph?
A) [{'vertices': [0, 1]}, {'vertices': [0, 2]}, {'vertices': [1, 2]}]
B) [{'vertices': [0, 1]}, {'vertices': [0, 2]}, {'vertices': [0, 3]}, {'vertices': [1, 2]}, {'vertices': [1, 3]}, {'vertices': [2, 3]}]
C) [{'vertices': [0, 1]}, {'vertices': [0, 2]}, {'vertices': [0, 3]}, {'vertices': [1, 2]}, {'vertices': [1, 3]}, {'vertices': [2, 3]},  {'vertices': [0, 4]}]
D) [{'vertices': [0, 1]}, {'vertices': [0, 2]}, {'vertices': [0, 3]}, {'vertices': [1, 2]}, {'vertices': [1, 3]}, {'vertices': [2, 3]}, {'vertices': [3, 4]}]
Correct Answer: A

Solution:
Graph A is not a complete graph because it lacks an edge connecting vertex 1 and vertex 2.

Explanation:
A complete graph must have an edge between every pair of vertices. Graph A only has edges (0-1, 0-2, and 1-2), missing the connection between vertex 1 and vertex 2. The other options represent graphs with connections between all pairs of vertices.

Common mistake note:
Common mistake: Choosing B, C, or D because they have multiple edges or additional vertices. Remember that a complete graph must connect every pair of vertices, regardless of the number of edges or extra vertices.

Problem 4 (Four):
Which graph represents a complete graph with 3 vertices?
A) [{'vertices': [0, 1]}, {'vertices': [0, 2]}, {'vertices': [1, 2]}]

Correct Answer: A

Solution:
Graph A represents a complete graph with 3 vertices because it has an edge connecting vertex 0 and vertex 1, vertex 0 and vertex 2, and vertex 1 and vertex 2.

Explanation:
A complete graph must have an edge between every pair of vertices. Graph B is missing an edge (2-3), graph C includes an extra edge (1-3) that is not required for a complete graph with only 3 vertices, and graph D has a weighted edge which does not affect connectivity but might confuse the reader about the definition of a complete graph.

Common mistake note:
Common mistake: Choosing B or C because they lack an edge connecting two vertices or include extra edges. Remember that all pairs of vertices must be connected in a complete graph, and the number of vertices determines the required connections.
