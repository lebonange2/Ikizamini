Problem 1 (Asdf):
A tree diagram shows two branches, one with 3 outcomes and the other with 4 outcomes. How many total outcomes are there in the tree diagram?
A) 5
B) 7
C) 12
D) 16
Correct Answer: C

Solution:
To find the total number of outcomes in a tree diagram, multiply the number of outcomes at each branch. In this case, it's 3 (first branch) multiplied by 4 (second branch), which equals 12.

Explanation:
When counting outcomes in a tree diagram, remember to multiply the outcomes from each branch together.

Common mistake note:
A common mistake is adding the outcomes instead of multiplying them. Adding would result in 3 + 4 = 7, which is incorrect.

Problem 2 (Bghj):
In a tree diagram with three branches, there are 2 outcomes on the first branch, 3 on the second branch, and 4 on the third branch. How many total outcomes are there?
A) 9
B) 10
C) 18
D) 24
Correct Answer: D

Solution:
To find the total number of outcomes, multiply the outcomes from each branch: 2 (first branch) * 3 (second branch) * 4 (third branch) = 24.

Explanation:
Always multiply the outcomes at each branch to get the total number of possibilities in a tree diagram.

Common mistake note:
A common mistake is adding the products from each pair of branches, which would give 6 (2*3) + 8 (3*4) = 14, instead of multiplying all three outcomes together.

Problem 4 (Yuiop):
In a tree diagram with four branches, there are 3 outcomes on the first branch, 2 on the second branch, 4 on the third branch, and 5 on the fourth branch. How many total outcomes does this tree diagram represent?
A) 14
B) 20
C) 48
D) 120
Correct Answer: D

Solution:
To find the total number of outcomes, multiply the outcomes from each branch: 3 (first branch) * 2 (second branch) * 4 (third branch) * 5 (fourth branch) = 120.

Explanation:
When counting outcomes in a tree diagram, multiply the outcomes at each branch together.

Common mistake note:
A common mistake is adding the products from each pair of branches, which would give 6 (3*2) + 8 (2*4) + 20 (4*5) = 34, instead of multiplying all four outcomes together.
