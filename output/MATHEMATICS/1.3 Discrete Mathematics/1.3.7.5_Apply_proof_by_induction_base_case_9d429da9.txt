Problem 1 (One):
Prove that the sum of the first n positive integers is 
(n(1+1))/2
using mathematical induction. What is the base case for this proof?
A) n = 0
B) n = 1
C) n = -1
D) n = any integer
Correct Answer: B

Solution:
The base case for a proof by induction typically involves showing that the statement holds true for the smallest possible value of the variable. In this case, n represents the number of positive integers being summed, so the smallest possible value is 1. Thus, the base case is when n = 1.

Explanation:
The sum of the first positive integer (n=1) is 1 itself, which according to the formula 
(n(1+1))/2
equals 
(1(1+1))/2 = 1. Since this is true for n=1, we start with n=1 as our base case to show that the statement holds for at least one value.

Common mistake note:
A common mistake would be to choose 'n = 0' or 'n = -1', but these values are not part of the set of positive integers, which is the domain of this problem. Choosing 'n = any integer' is too broad and does not provide a specific starting point for the induction proof.

Problem 2 (Two):
To prove that 2^n > n^2 for all positive integers n greater than or equal to 3, what should be the base case in the proof by induction?
A) n = 0
B) n = 1
C) n = 2
D) n = 3
Correct Answer: D

Solution:
The base case for this proof should be the smallest value of n that is greater than or equal to the starting point specified in the problem statement, which is n = 3. This ensures we are demonstrating the inequality holds true for at least one integer within the given range.

Explanation:
For n = 3, 2^3 = 8 and 3^2 = 9. Since 8 > 9 does not hold, we must start with n = 3 as our base case to show that the statement holds for at least one value within the specified range (n >= 3).

Common mistake note:
A common mistake would be to choose 'n = 0', 'n = 1', or 'n = 2', but these values are outside the given range, which starts from n = 3. Choosing 'n = any integer' is too broad and does not provide a specific starting point for the induction proof.
