Problem 1 (:1):
Given the idempotent property for multiplication: a × a = a, which of the following expressions is NOT idempotent?
A) 2 × 2
B) 3^3
C) 4 + 4
D) 5!
Correct Answer: D

Solution:
The expression that is NOT idempotent is D, because 5! (5 factorial) is not equal to 5 when multiplied by itself. The correct idempotent expressions are A: 2 × 2 = 4, B: 3^3 = 27, and C: 4 + 4 = 8.

Explanation:
Idempotence refers to a property where applying an operation twice results in the same value as applying it once. In this case, we're looking at multiplication and addition operations.

Common mistake note:
A common mistake would be choosing C (4 + 4), which is idempotent for addition but not for multiplication. The key here is to understand that idempotence applies specifically to the operation given in the property.

Problem 2 (:2):
Which of the following binary operations is NOT idempotent?
A) a × a
B) a + a
C) a ∘ a (using AND logical operator)
D) a ∧ a (using OR logical operator)
Correct Answer: D

Solution:
The operation that is NOT idempotent is D, because the OR logical operator (a ∧ a) can result in True when applied twice to False, which is not equal to the original value. The correct idempotent operations are A: multiplication, B: addition, and C: AND logical operator.

Explanation:
Idempotence applies to binary operations where applying the operation multiple times does not change the result. In the context of logical operators, only the AND operator is idempotent.

Common mistake note:
A common mistake would be choosing C (a ∘ a), which is idempotent for the AND logical operator but might lead to confusion when considering other operations like multiplication and addition.

Problem 3 (:3):
Given the idempotent property for exponentiation: a^0 = 1, which of the following expressions is NOT idempotent?
A) 2^0
B) 3^0
C) 4^0
D) 5^1
Correct Answer: D

Solution:
The expression that is NOT idempotent is D, because 5^1 is not equal to 1 when raised to the power of 0. The correct idempotent expressions are A: 2^0 = 1, B: 3^0 = 1, and C: 4^0 = 1.

Explanation:
Idempotence for exponentiation states that any number raised to the power of 0 is equal to 1. This property applies only when the exponent is 0.

Common mistake note:
A common mistake would be choosing A, B, or C, which are all idempotent because they follow the rule a^0 = 1. The key here is to recognize that the property specifically mentions the power of 0.

Problem 4 (:4):
Which of the following statements about idempotence is FALSE?
A) Multiplication is an idempotent operation.
B) Addition is an idempotent operation.
C) The identity element for an idempotent operation is always 1.
D) A binary operation can be idempotent even if its identity element is not 1.
Correct Answer: C

Solution:
The false statement about idempotence is C, because the identity element for an idempotent operation does not have to be 1. For example, in addition, the identity element is 0, which makes it idempotent (a + 0 = a). The correct statements are A: multiplication, B: addition, and D: binary operations can be idempotent with different identity elements.

Explanation:
Idempotence does not mandate that the identity element must be 1; it depends on the specific operation being considered.

Common mistake note:
A common mistake would be choosing A or B, which are true statements about idempotence. The key is to understand that the identity element can vary depending on the operation.

Problem 5 (:5):
Given the matrix multiplication property: A × A = A, where A is an idempotent matrix, which of the following matrices is NOT idempotent?
A) [1 0; 0 1]
B) [2 0; 0 2]
C) [0 1; 1 0]
D) [1 1; 1 1]
Correct Answer: D

Solution:
The matrix that is NOT idempotent is D, because [1 1; 1 1] × [1 1; 1 1] = [2 2; 2 2], which is not equal to the original matrix. The correct idempotent matrices are A: identity matrix, B: a scalar multiple of the identity matrix, and C: a permutation matrix.

Explanation:
Idempotence for matrices means that multiplying a matrix by itself results in the same matrix. Matrices like A, B, and C satisfy this property, but D does not.

Common mistake note:
A common mistake would be choosing B or C, which are idempotent because they follow the rule of being scalar multiples or permutations of the identity matrix. The key here is to recognize that matrix D does not remain unchanged when multiplied by itself.

Problem 6 (:6):
Which of the following functions demonstrates idempotence?
A) f(x) = x^2
B) f(x) = 2x
C) f(x) = x + 1
D) f(x) = x × x
Correct Answer: D

Solution:
The function that demonstrates idempotence is D, because f(x) = x × x = x^2 will return the same value when applied twice (f(f(x)) = x^4). The other choices are not idempotent.

Explanation:
Idempotence for functions means applying the function multiple times to a value results in the same output as applying it once. In this case, only D satisfies that property.

Common mistake note:
A common mistake would be choosing A (f(x) = x^2), which is not idempotent because f(f(x)) = x^4, not x^2. The key is to understand the definition of idempotence for functions.

Correct Answer: D

Solution:
The operation that is NOT an example of idempotence is D, because x! (x factorial) does not remain the same when multiplied by itself. The correct examples are A: multiplication, B: addition, and C: exponentiation with 0 as the power.

Explanation:
Idempotence refers to operations where applying them multiple times results in the same output. In this context, only D (factorial) does not exhibit idempotence.

Common mistake note:
