Problem 1 (AsdFgHjK):
Find the intersection of sets A = {1, 2, 3, 4} and B = {3, 4, 5, 6}. Which set represents the correct result?
A) [1, 2, 3, 4]
B) [3, 4, 5, 6]
C) [3, 4]
D) [1, 2, 5, 6]
Correct Answer: C

Solution:
The intersection of sets A and B (A ∩ B) contains elements that are both in set A and set B. In this case, the common elements are 3 and 4.

Explanation:
To find the intersection, we look for elements that appear in both sets. Only option C includes these elements.

Common mistake note:
A common mistake is to choose option A, which contains all of set A but not the exclusive elements from B; or option D, which includes elements from neither A nor B.

Problem 2 (XyzPqRsT):
Given sets C = {2, 4, 6, 8} and D = {1, 3, 5, 7, 9}, what is the intersection of sets C ∩ D?
A) [1, 2, 3, 4, 5, 6, 7, 8, 9]
B) []
C) [2, 4, 6, 8, 1, 3, 5, 7, 9]
D) []
Correct Answer: B

Solution:
The intersection of sets C and D (C ∩ D) is an empty set because there are no common elements between the two sets.

Explanation:
Since sets C and D do not share any elements, their intersection is an empty set, denoted as [] or {}.

Common mistake note:
A common mistake is to think that the intersection would include all numbers from 1 to 9, which is incorrect because they are not shared between the two sets.
