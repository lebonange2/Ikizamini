Problem 1 (:1):
Which of the following is a proper subset of {1, 2, 3, 4}?
A) {1}
B) {1, 2}
C) {1, 2, 3}
D) {1, 2, 3, 4}
Correct Answer: B

Solution:
A proper subset contains all elements of the original set and at least one element is missing. In this case, {1, 2} is a proper subset of {1, 2, 3, 4}, as it has all elements from the original set but lacks 3 and 4.

Explanation:
Proper subsets exclude at least one element from the original set.

Common mistake note:
Common mistake: Choosing D, which is not a proper subset because it is identical to the original set.
------------------------------------------------------------------------------

Problem 2 (2):
Is {5, 6} a subset or a proper subset of {1, 2, 3, 4, 5, 6}? Explain.
A) Subset
B) Proper subset
C) Neither
D) Both
Correct Answer: A

Solution:
A subset contains all or some elements of the original set without excluding any. {5, 6} is a subset of {1, 2, 3, 4, 5, 6}, as it includes two elements from the original set.

Explanation:
Subsets can be proper (missing at least one element) or not (containing all elements).

Common mistake note:
Common mistake: Choosing B, which is incorrect because {5, 6} does not exclude any elements from the original set.

Problem 3 (3):
Which of the following sets is a proper subset of {a, b, c}? Select all that apply.
A) {a}
B) {b, c}
C) {a, b}
D) {a, b, c}
Correct Answer: A

Solution:
Proper subsets exclude at least one element from the original set. In this case, {a} is a proper subset of {a, b, c}, as it excludes b and c.

Explanation:
Proper subsets can have any combination of elements missing from the original set.

Common mistake note:
Common mistake: Choosing D, which is not a proper subset because it includes all elements from the original set.

Problem 4 (4):
Is {x, y} a proper subset of {x, y, z}? Explain.
A) Yes
B) No
C) Cannot be determined
D) Both A and B
Correct Answer: B

Solution:
A proper subset excludes at least one element from the original set. In this case, {x, y} is not a proper subset of {x, y, z}, because it includes all elements from the original set.

Explanation:
Proper subsets do not include all elements of the original set.

Common mistake note:
Common mistake: Choosing A, which is incorrect because {x, y} does not exclude any elements from the original set.

Problem 5 (5):
Which of the following sets is a subset of {m, n, o, p}? Select all that apply.
A) {n, o}
B) {p, m, n, o}
C) {m, n, o, p}
D) {o, p}
Correct Answer: A

Solution:
Subsets can include any combination of elements from the original set. In this case, {n, o} is a subset of {m, n, o, p}, as it includes two elements from the original set.

Explanation:
Subsets can have any number of elements from the original set.

Common mistake note:
Common mistake: Choosing C, which is not a proper subset but rather identical to the original set.
