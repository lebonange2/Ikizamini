Problem 1 (Asdf):
Which of the following best describes logical equivalence?
A) Two propositions are logically equivalent if they have different truth values.
B) Two propositions are logically equivalent if they are always true together and false together.
C) Logical equivalence means that one proposition implies the other.
D) Two propositions are logically equivalent if their negations are logically equivalent.
Correct Answer: B

Solution:
Logical equivalence (≡) holds between two propositions when both propositions have the same truth value in every possible scenario. This means they are true together and false together, making option B the correct answer.

Explanation:
Option A is incorrect because logically equivalent propositions must have the same truth values. Option C describes implication, not logical equivalence. Option D is a misinterpretation of logical equivalence; it's not about negations but rather the propositions themselves having identical truth values.

Common mistake note:
Common mistake: Confusing logical equivalence with implication.

Problem 2 (Bnmv):
If P ≡ Q, which of the following is also logically equivalent to P?
A) P ∨ Q
B) P ∧ Q
C) ¬Q
D) ¬P
Correct Answer: B

Solution:
Given that P ≡ Q, it means P and Q have the same truth value in all cases. Therefore, the conjunction (∧) of P and Q, denoted as P ∧ Q, will also be logically equivalent to P.

Explanation:
Option A represents disjunction, which is not equivalent but merely requires one proposition to be true. Option C negates Q, making it logically different from P. Option D negates P, which directly contradicts the given logical equivalence.

Common mistake note:
Common mistake: Not understanding that conjunction preserves truth value when propositions are equivalent.

Problem 3 (Cxyw):
Which of the following pairs of propositions is logically equivalent?
A) (P → Q) ∧ (Q → P)
B) (P ∨ Q) ∧ (¬P ∨ ¬Q)
C) (P ∧ Q) ↔ (P ∨ Q)
D) P ≡ ¬P
Correct Answer: A

Solution:
The pair (P → Q) ∧ (Q → P) is logically equivalent to (P ↔ Q), which means they are both true or false together. Therefore, option A represents logically equivalent propositions.

Explanation:
Option B represents the tautology (always true) known as 'contraposition'. Option C is not logically equivalent because it describes biconditional (↔), not equivalence (≡). Option D represents a self-contradiction (a proposition and its negation cannot be equivalent).

Common mistake note:
Common mistake: Confusing logical equivalence with other logical relationships like implication or biconditional.

Problem 5 (Ertg):
Which of the following is an example of logically equivalent propositions?
A) P ∨ Q and ¬(P ∧ Q)
B) P → Q and Q → P
C) P ↔ Q and (P ∧ Q) ∨ (¬P ∧ ¬Q)
D) P ≡ Q and P ∨ ¬Q
Correct Answer: B

Solution:
The pair (P → Q) and (Q → P) represents logically equivalent propositions because they are both true or false together, forming a biconditional relationship.

Explanation:
Option A represents the exclusive disjunction (XOR), which is not an equivalence. Option C represents the definition of biconditional, not logical equivalence. Option D shows a combination of equivalence and disjunction, which does not preserve equivalence for Q.

Common mistake note:
Common mistake: Confusing logically equivalent propositions with other logical relationships like implication or exclusive disjunction.

Problem 6 (Ftyu):
What is the truth value of (P ≡ Q) if P and Q are both true?
A) True
B) False
C) Indeterminate
D) Depends on the truth values of P and Q
Correct Answer: A

Solution:
(P ≡ Q) is true when P and Q have the same truth value. Since both P and Q are true in this case, their equivalence is also true.

Explanation:
Option B is incorrect because equivalent propositions have the same truth value. Option C is not applicable here as there's no uncertainty. Option D is redundant with the learning objective itself, which states that logical equivalence requires identical truth values.

Common mistake note:
Common mistake: Assuming truth values of P and Q do not matter for logical equivalence.
