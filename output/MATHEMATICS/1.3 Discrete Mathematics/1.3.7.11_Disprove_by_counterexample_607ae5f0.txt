Problem 1 (InequalityCounterexample):
Which of the following is a counterexample that disproves the statement: 'For all real numbers x and y, if x > y, then x^2 > y^2'?
A) (1, -1)
B) (0, 0)
C) (-1, 1)
D) (2, 1)
Correct Answer: B

Solution:
The statement 'For all real numbers x and y, if x > y, then x^2 > y^2' is disproved by a counterexample where x^2 is not greater than y^2 even though x is greater than y. In option B, (0, 0), both x and y are equal, so x^2 = y^2. This shows that the statement is not universally true.

Explanation:
A counterexample must show that a given statement does not hold in all cases. Since x > y for (0, 0) but x^2 = y^2, this demonstrates that the inequality does not always apply.

Common mistake note:
Common mistake is to choose an example where x and y have different signs, like A or C, which would actually satisfy the original statement because the square of a negative number is larger than the square of a smaller positive number.

Problem 2 (SetTheoryCounterexample):
Which of the following is a counterexample that disproves the statement: 'For all sets A and B, if A ∪ B = B ∪ A, then A = B'?
A) {1, 2} and {2, 3}
B) {1, 2, 3} and {2, 3}
C) {1, 2} and {1, 2, 3}
D) ∅ and {1}
Correct Answer: A

Solution:
The statement 'For all sets A and B, if A ∪ B = B ∪ A, then A = B' is disproved by a counterexample where the union of two sets is equal, but the sets themselves are not identical. In option A, {1, 2} ∪ {2, 3} = {1, 2, 3} and {2, 3} ∪ {1, 2} = {1, 2, 3}, yet {1, 2} ≠ {2, 3}.

Explanation:
A counterexample must show that a given statement does not hold in all cases. Since the union of sets A and B is equal to the union of sets B and A for option A, but A is not equal to B, this demonstrates that the equality of sets does not always follow.

Common mistake note:
Common mistake is to choose an example where the sets are identical, like D, which would satisfy the original statement because the union of a set with itself will always be the set itself.

Problem 3 (FunctionCounterexample):
Which of the following is a counterexample that disproves the statement: 'For all functions f(x) and g(x), if f(g( x)) = g(f(x)), then f(x) = g(x)'?
A) f(x) = x^2, g(x) = x^3
B) f(x) = x+1, g(x) = x-1
C) f(x) = sin(x), g(x) = cos(x)
D) f(x) = |x|, g(x) = |x|
Correct Answer: D

Solution:
The statement 'For all functions f(x) and g(x), if f(g( x)) = g(f(x)), then f(x) = g(x)' is disproved by a counterexample where the composition of two functions is equal, but the functions themselves are not identical. In option D, f(|x|) = |x| and g(|x|) = |x|, yet f(x) ≠ g(x).

Explanation:
A counterexample must show that a given statement does not hold in all cases. Since the composition of functions f and g is equal for option D, but f and g are not identical, this demonstrates that the equality of functions does not always follow.

Common mistake note:
Common mistake is to choose an example where the functions are identical, like C, which would satisfy the original statement because the composition of a function with itself will always be the same function.

Problem 4 (LogicCounterexample):
Which of the following is a counterexample that disproves the statement: 'If it is raining, then I am inside'.
A) It is raining and I am inside.
B) It is not raining and I am outside.
C) It is raining and I am outside.
D) It is not raining and I am inside.
Correct Answer: C

Solution:
The statement 'If it is raining, then I am inside' is disproved by a counterexample where it is raining but the consequent (I being inside) is false. In option C, it is raining, but I am outside, which shows that the conditional statement is not universally true.

Explanation:
A counterexample must show that a given statement does not hold in all cases. Since it is raining and I am outside for option C, this demonstrates that being inside is not always true when it is raining.

Common mistake note:
Common mistake is to choose an example where the conditional statement is true, like A or D, which would satisfy the original statement because if it is not raining, there is no requirement for me to be inside.

Problem 5 (GeometryCounterexample):
Which of the following is a counterexample that disproves the statement: 'All equilateral triangles are similar'?
A) Two equilateral triangles with sides 3 cm and 4 cm.
B) An equilateral triangle with side 5 cm and an isosceles triangle with equal sides 5 cm.
C) Two equilateral triangles with the same area.
D) Two equilateral triangles with the same perimeter.
Correct Answer: A

Solution:
The statement 'All equilateral triangles are similar' is disproved by a counterexample where two equilateral triangles have different side lengths. In option A, two equilateral triangles with sides 3 cm and 4 cm are not similar because their corresponding angles are the same, but their side ratios (3/4) are not equal.

Explanation:
A counterexample must show that a given statement does not hold in all cases. Since the ratio of sides is different for option A, this demonstrates that equilateral triangles with different side lengths are not similar.

Common mistake note:
Common mistake is to choose an example where the triangles have the same shape but different sizes, like C or D, which would satisfy the original statement because all equilateral triangles have the same angles and are thus similar.

Problem 6 (AlgebraCounterexample):
Which of the following is a counterexample that disproves the statement: 'For all real numbers x, if x^2 + 1 = 0, then x = 0'?
A) x = -1
B) x = 0
C) x = √(-1)
D) x = 1
Correct Answer: C

Solution:
The statement 'For all real numbers x, if x^2 + 1 = 0, then x = 0' is disproved by a counterexample where x^2 + 1 is equal to zero but x is not equal to zero. In option C, x = √(-1) (also known as i), which satisfies x^2 + 1 = 0, but x ≠ 0.

Explanation:
A counterexample must show that a given statement does not hold in all cases. Since x = √(-1) is a solution to x^2 + 1 = 0 for option C, this demonstrates that x being equal to zero is not the only solution.

Common mistake note:
Common mistake is to choose an example where x is indeed zero, like B, which would satisfy the original statement because if x^2 + 1 = 0 and x = 0, then x must be zero.

Problem 7 (ProbabilityCounterexample):
Which of the following is a counterexample that disproves the statement: 'If two events are independent, their probabilities multiply'?
A) Event A occurs with probability 0.5 and Event B occurs with probability 0.3.
B) Event A occurs with probability 1 and Event B occurs with probability 0.2.
C) Event A occurs with probability 0.4 and Event B does not occur at all (probability 0).
D) Event A occurs with probability 0.6 and Event B occurs with probability 0.6.
Correct Answer: C

Solution:
The statement 'If two events are independent, their probabilities multiply' is disproved by a counterexample where the second event has zero probability (impossible). In option C, if Event A occurs with probability 0.4 and Event B does not occur at all (probability 0), their joint probability is 0, which is not equal to the product of their individual probabilities.

Explanation:
A counterexample must show that a given statement does not hold in all cases. Since the joint probability for option C is zero, this demonstrates that multiplying independent probabilities does not always give the correct joint probability when one event has zero probability.

Common mistake note:
Common mistake is to choose an example where both events have non-zero probabilities, like A or D, which would satisfy the original statement because if two events are independent, their probabilities multiply.
