Problem 1 (:Q1):
Expand the binomial (x + 2)^3.
A) (x^3) + (6x^2) + (12x) + 4
B) (x^3) + (2x^2) + (4x) + 8
C) (x^3) + (3x^2) + (6x) + 12
D) (x^3) + (9x^2) + (18x) + 27
Correct Answer: A

Solution:
(x + 2)^3 = x^3 + 3(x^2 	imes 2) + 3(x 	imes 2^2) + 2^3 = x^3 + 6x^2 + 12x + 8

Explanation:
The binomial expansion of (a + b)^n is given by the formula: a^n + n*a^(n-1)*b + ... + n*a*b^(n-1) + b^n. In this case, a = x, b = 2, and n = 3.

Common mistake note:
A common mistake would be to forget to multiply the coefficients by the binomial coefficient (in this case, 3). For example, choosing B would be incorrect because it doesn't account for the correct coefficients.

Problem 2 (:Q2):
Expand the polynomial (x - 1)^4.
A) (x^4) - (4x^3) + (6x^2) - (4x) + 1
B) (x^4) - (4x^3) + (8x^2) - (12x) + 8
C) (x^4) - (6x^3) + (12x^2) - (8x) + 4
D) (x^4) - (8x^3) + (24x^2) - (32x) + 16
Correct Answer: A

Solution:
(x - 1)^4 = x^4 - 4(x^3 	imes 1) + 6(x^2 	imes 1^2) - 4(x 	imes 1^3) + 1^4 = x^4 - 4x^3 + 6x^2 - 4x + 1

Explanation:
The binomial expansion of (a - b)^n is similar to the one for positive exponents, but with alternating signs: a^n - n*a^(n-1)*b + ... + (-1)^(n-1)n*a*b^(n-1) + (-1)^n*b^n. In this case, a = x, b = 1, and n = 4.

Common mistake note:
A common mistake would be to forget the alternating signs in the expansion. For example, choosing B would be incorrect because it doesn't follow the correct pattern.

Problem 3 (:Q3):
Expand the trinomial (x + y - 1)^2.
A) (x^2) + (2xy) + (y^2) - (2x) - (2y) + 1
B) (x^2) + (2xy) + (y^2) + (2x) + (2y) - 2
C) (x^2) + (4xy) + (2y^2) - (2x) - (2y) + 1
D) (x^2) + (4xy) + (2y^2) + (2x) + (2y) - 2
Correct Answer: A

Solution:
(x + y - 1)^2 = (x + y - 1)(x + y - 1) = x^2 + xy + yx + y^2 - x - y - x - y + 1 = x^2 + 2xy + y^2 - 2x - 2y + 1

Explanation:
The expansion of a trinomial (a + b + c)^n can be done by multiplying the binomials formed by each pair of terms. In this case, we have (x + y - 1)(x + y - 1).

Common mistake note:
A common mistake would be to forget to multiply all pairs of terms or to incorrectly distribute the negative sign. For example, choosing C would be incorrect because it doubles the xy term and doesn't account for the correct distribution of signs.

Problem 5 (:Q5):
Expand the polynomial (x + 3)^2 - (x - 1)^2.
A) (2x^2) + (4x) + 8
B) (2x^2) + (4x) + 6
C) (2x^2) + (4x) + 4
D) (2x^2) - (4x) + 4
Correct Answer: C

Solution:
(x + 3)^2 - (x - 1)^2 = (x^2 + 6x + 9) - (x^2 - 2x + 1) = x^2 + 6x + 9 - x^2 + 2x - 1 = 8x + 8

Explanation:
To expand the difference of squares, we can use the identity: (a^2 - b^2) = (a + b)(a - b). In this case, a = x + 3 and b = x - 1.

Common mistake note:
A common mistake would be to incorrectly apply the difference of squares formula or to forget to distribute the negative sign in the subtraction. For example, choosing D would be incorrect because it doesn't follow the correct pattern.
