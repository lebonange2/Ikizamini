Problem 1 (One):
Which standard domain is used for representing geographical locations?
A) RGB color space
B) Mercator projection
C) Longitudinal-latitude coordinates
D) HSL color space
Correct Answer: C

Solution:
The correct answer is C, Longitudinal-latitude coordinates. This system uses pairs of longitude and latitude values to represent locations on Earth's surface, making it a standard for geographical mapping.

Explanation:
A and D are color spaces used in image processing, not geographical mapping. B, Mercator projection, is a specific map projection that distorts the size and shape of regions near the poles; it is not a standard domain for representing locations per se.

Common mistake note:
Common mistake: Choosing B (Mercator projection) because it's a familiar map type. However, remember that Mercator projection is a mapping technique, not a standard domain for geographical locations.

C) Longitudinal-latitude coordinates
D) HSL color space
Correct Answer: A

Solution:
The correct answer is A, URLs and HTML tags. Web pages are organized using URLs to identify their location on the internet and HTML tags to structure the content.

Common mistake note:
