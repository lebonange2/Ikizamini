Problem 1 (OnePlusOnePlusTwo):
What is the result of (1 + 1) + 2?
A) 3
B) 4
C) 5
D) 6
Correct Answer: A

Solution:
(1 + 1) + 2 = 2 + 2 = 4. The associative property states that the order in which numbers are grouped does not affect the sum, so (1 + 1) + 2 is equal to 1 + (1 + 2), which equals 4.

Explanation:
The associative property applies when adding multiple numbers together. It allows you to group the numbers differently without changing the final result.

Common mistake note:
A common mistake would be choosing 'B', 4, because some might think that each addition operation is performed separately (1 + 1 = 2, then 2 + 2 = 4), but forgetting that the property allows for grouping changes without affecting the sum.

Problem 2 (ThreePlusOnePlusTwo):
What is the result of 3 + (1 + 2)?
A) 5
B) 6
C) 7
D) 8
Correct Answer: A

Solution:
3 + (1 + 2) = 3 + 3 = 6. The associative property holds, so the order of grouping does not affect the sum.

Explanation:
Again, we apply the associative property when adding numbers together. Here, we first perform the operation inside the parentheses (1 + 2), then add the result to 3.

Common mistake note:
A common mistake would be choosing 'C', 7, if a student forgets to use the associative property and instead calculates each addition separately (3 + 1 = 4, then 4 + 2 = 6).
------------------------------------------------------------------------------

Problem 3 (MultiplicationAssociative):
What is the result of (5 × 2) × 3?
A) 10
B) 15
C) 20
D) 30
Correct Answer: D

Solution:
(5 × 2) × 3 = 10 × 3 = 30. The associative property of multiplication also holds, so the order of grouping does not affect the product.

Explanation:
The associative property applies to multiplication as well. Here, we first multiply 5 and 2, then multiply the result by 3.

Common mistake note:
A common mistake would be choosing 'B', 15, if a student forgets that the associative property also works for multiplication and calculates each multiplication separately (5 × 2 = 10, then 10 × 3 = 30).
------------------------------------------------------------------------------

Problem 4 (MixedOperationsAssociative):
What is the result of (4 + 6) × (2 + 3)?
A) 40
B) 50
C) 60
D) 70
Correct Answer: C

Solution:
(4 + 6) × (2 + 3) = 10 × 5 = 50. First, perform the operations inside each set of parentheses, then multiply the results.

Explanation:
When there are both addition and multiplication involved, use the order of operations: first perform the operations inside parentheses, then multiply. Here, we add within each set of parentheses (4 + 6 = 10, 2 + 3 = 5), then multiply the results.

Common mistake note:
A common mistake would be choosing 'D', 70, if a student forgets to apply the associative property and calculates the addition operations separately before multiplying (4 + 6 = 10, 2 + 3 = 5, then 10 × 5 = 50).
------------------------------------------------------------------------------

Problem 5 (AssociativePropertyWithFractions):
What is the result of (1/2 + 1/4) + 1/8?
A) 7/8
B) 9/8
C) 15/16
D) 17/16
Correct Answer: C

Solution:
(1/2 + 1/4) + 1/8 = (2/4 + 1/4) + 1/8 = 3/4 + 1/8 = (6/8 + 1/8) = 7/8. The associative property holds for fractions as well.

Explanation:
When adding fractions, first find a common denominator and then add the numerators. Here, we have a common denominator of 8 after simplifying 2/4 to 1/2. Then, we apply the associative property to group the fractions differently without changing the sum.

Common mistake note:
A common mistake would be choosing 'B', 9/8, if a student calculates each addition separately (1/2 + 1/4 = 3/4, then 3/4 + 1/8 = 7/8) without considering the associative property.
------------------------------------------------------------------------------

Problem 6 (AssociativePropertyWithNegativeNumbers):
What is the result of (-5 - 3) - (-2)?
A) -6
B) -7
C) -10
D) -14
Correct Answer: A

Solution:
(-5 - 3) - (-2) = -8 - (-2) = -8 + 2 = -6. The associative property applies to subtraction, but remember that subtracting a negative is the same as adding a positive.

Explanation:
When subtracting negative numbers, it's equivalent to adding positives. Here, we first perform the operation inside the parentheses and then apply the associative property.

Common mistake note:
A common mistake would be choosing 'C', -10, if a student forgets that subtracting a negative is addition and calculates each subtraction separately (-5 - 3 = -8, then -8 - (-2) = -6).
------------------------------------------------------------------------------

Problem 7 (AssociativePropertyWithMixedOperationsAndParentheses):
What is the result of ((-2 + 4) × 3) ÷ (1 + 1)?
A) 3
B) 4
C) 6
D) 12
Correct Answer: B

Solution:
((-2 + 4) × 3) ÷ (1 + 1) = (2 × 3) ÷ 2 = 6 ÷ 2 = 3. Apply the order of operations: parentheses first, then multiplication and division from left to right.

Explanation:
Remember the order of operations: perform operations inside parentheses first, followed by multiplication and division from left to right (no need for associative property here since there are no repeated operations).

Common mistake note:
A common mistake would be choosing 'C', 6, if a student forgets the order of operations and calculates the multiplication before the addition within the parentheses (2 + 4 = 6, then 6 × 3 = 18 ÷ 2 = 9).
