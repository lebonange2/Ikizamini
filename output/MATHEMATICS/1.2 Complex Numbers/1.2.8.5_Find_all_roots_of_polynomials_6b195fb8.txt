Problem 1 ([1-7][A-D]):
What are the roots of the polynomial f(x) = x^3 - 4x^2 + 5x - 2?
A) -2, 1, 1
B) 2, -1, -1
C) 2, 1, 1
D) -2, -1, -1
Correct Answer: C

Solution:
To find the roots of a cubic polynomial like f(x) = x^3 - 4x^2 + 5x - 2, we can try factoring or using numerical methods. Upon inspection, we see that (x - 1) is a factor because f(1) = 0. By performing polynomial division or synthetic division, we find the quotient to be x^2 - 3x + 2. Factoring this quadratic gives us (x - 2)(x - 1). So the roots are x = 1, x = 2, and x = 1. The correct answer is C: 2, 1, 1.

Explanation:
The common mistake would be to choose A or B because they have the same repeated root (1), but the coefficient of x^2 in the original polynomial is -4, which means one of the roots must be -1. The correct factorization shows that there are two distinct roots (1 and 2) and a repeated root at 1.

Common mistake note:
Choosing A or B because they have a repeated root without considering the coefficient of x^2.

Problem 2 ([1-7][A-D]):
Find the roots of the quadratic polynomial g(x) = 3x^2 - 5x - 2.
A) -2/3, 1
B) 2/3, -1
C) 3/2, -2
D) -3/2, 2
Correct Answer: B

Solution:
To find the roots of a quadratic polynomial like g(x) = 3x^2 - 5x - 2, we can use the quadratic formula: x = [-b ± sqrt(b^2 - 4ac)] / (2a). For this equation, a = 3, b = -5, and c = -2. Plugging these values into the formula gives us x = [5 ± sqrt((5)^2 - 4(3)(-2))] / (2(3)) = [5 ± sqrt(49)] / 6 = [5 ± 7] / 6. This results in two roots: x = 2/3 and x = -1. The correct answer is B: 2/3, -1.

Explanation:
The common mistake would be to choose A or C because they have the same sum (-2/3 + 3/2 = -1), but the product of the roots should equal c/a = -2/3, which rules out these choices. The correct application of the quadratic formula gives us the correct roots.

Common mistake note:
Choosing A or C based on the incorrect sum of roots without checking the product.

The correct answer is A: ±√2, ±1.

Explanation:

Problem 5 ([1-7][A-D]):
Find the zeros of the polynomial k(x) = x^3 - 9x + 8, using the rational roots theorem.
A) 2, -4, 1
B) 1, -1, 8
C) 1, 2, -4
D) -1, 1, 8
Correct Answer: C

Solution:
The rational roots theorem states that the possible rational roots of a polynomial are in the form p/q, where p divides the constant term and q divides the leading coefficient. For k(x) = x^3 - 9x + 8, the constant term is 8 and the leading coefficient is 1, so possible rational roots include ±1, ±2, ±4, and ±8. Testing these values, we find that x = 1 and x = -4 are zeros because k(1) = k(-4) = 0. The quotient after factoring becomes x^2 + 5x + 8, which does not have any linear factors with integer coefficients. Therefore, the zeros are x = 1, x = -4, and x = 1 (repeated). The correct answer is C: 1, 2, -4.

Explanation:
The common mistake would be to choose A or D because they include a repeated root at 1, but testing all possible rational roots shows that there are only two distinct real zeros. Using the rational roots theorem and factoring correctly reveals the zeros.

Common mistake note:
Choosing A or D due to misapplying the rational roots theorem and not recognizing the repeated root.

Problem 6 ([1-7][A-D]):
Find the zeros of the polynomial l(x) = 2x^3 - 5x^2 + 4x - 1, by factoring.
A) 1/2, 1, 2
B) -1/2, -1, -2
C) 1/2, -1, 2
D) -1/2, 1, -2
Correct Answer: A

Solution:
To find the zeros of l(x) = 2x^3 - 5x^2 + 4x - 1, we can try factoring by grouping. The polynomial can be rewritten as (2x^3 - 2x) + (-5x^2 + 4x) - 1. Factoring out x from each group gives us x(2x^2 - 2) - x(5x - 4) - 1. Simplifying further, we get x(2(2x^2 - 1)) - x(5x - 4) - 1 = x(2(2(x + 1)(x - 1))) - x(5x - 4) - 1. Factoring out an additional x gives us x[(2(2(x + 1)(x - 1))) - (5x - 4)] - 1 = x(4(x^2 - 1)) - x(5x - 4) - 1 = x(4(x + 1)(x - 1)) - x(5x - 4) - 1. Now, we can see that the quadratic inside the brackets does not factor easily with integer coefficients, but we can use the quadratic formula to find its roots: x = [6 ± sqrt((6)^2 - 4(2)(6))] / (2(2)) = [6 ± sqrt(36 - 48)] / 4 = [6 ± sqrt(-12)] / 4. Since we have imaginary roots, the only real root is x = 1/2. The correct answer is A: 1/2, 1, 2.

Explanation:
The common mistake would be to choose B or C because they include a repeated root at 1, but factoring by grouping and considering the quadratic formula for the remaining factor shows that there are only two distinct real zeros. Correctly applying factoring techniques reveals the zeros.

Common mistake note:
Choosing B or C due to misapplying factoring methods and not recognizing the imaginary roots.
