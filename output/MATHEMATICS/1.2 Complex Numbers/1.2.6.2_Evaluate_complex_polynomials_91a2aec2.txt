Problem 1 (:1):
What is the value of the polynomial (3x^2 - 4x + 5) at x = 2?
A) -7
B) 6
C) 9
D) 20
Correct Answer: C

Solution:
To evaluate the polynomial at x = 2, substitute 2 for x in the expression: (3(2)^2 - 4(2) + 5). Calculate the result: (3(4) - 8 + 5) = (12 - 8 + 5) = (4 + 5) = 9.

Explanation:
To evaluate a polynomial at a given value, substitute that value for the variable and perform the arithmetic operations.

Common mistake note:
A common mistake would be to incorrectly calculate the result or misinterpret the question. Some students might forget to square the x term or make errors in arithmetic.

A) -41

Problem 3 (:3):
What is the value of (2x^4 - 6x^2 + 9) at x = 1?
A) 5
B) 1
C) 9
D) 7
Correct Answer: A

Solution:
Substitute 1 for x in the expression: (2(1)^4 - 6(1)^2 + 9). Calculate the result: (2 - 6 + 9) = (-4 + 9) = 5.

Explanation:
To evaluate a polynomial at a given value, substitute that value for the variable and perform the arithmetic operations.

Common mistake note:
A common mistake would be to forget to raise x to the correct power or misinterpret the question. Some students might not recognize that x^4 means 1^4 when x is 1.

Problem 4 (:4):
Evaluate (x^3 - 2x^2 + 3x - 1) at x = 0.
A) -1
B) 0
C) 1
D) 3
Correct Answer: B

Solution:
When x is 0, all terms with x will be 0: (0^3 - 2(0)^2 + 3(0) - 1) = (-1).

Explanation:
To evaluate a polynomial at x = 0, set all terms with x to 0 and calculate the remaining constant term.

Common mistake note:
A common mistake would be to forget that any power of 0 is 0 or misinterpret the question. Some students might not realize that when x is 0, all terms involving x will disappear.
