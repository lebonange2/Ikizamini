Problem 1 (IncorrectParameters):
A function `draw_shape(x, y)` is used to draw a shape with parameters x and y. To draw the same shape at different positions, which of the following code snippets correctly parameterizes the position?
A) draw_shape(50, 100)
B) draw_shape(shape_x, 100)
C) draw_shape(x, shape_y)
D) draw_shape(position_x, position_y)
Correct Answer: D

Solution:
The correct answer is D. This snippet parameterizes the position by using variables `position_x` and `position_y`, allowing for different positions to be passed in when calling the function. The other options do not use variables or only use one variable, which would result in drawing the shape at a fixed position or along one axis.

Explanation:
To parameterize a complex path, you need to use variables that can hold different values for each instance of the path. Options A, B, and C either don't use variables for both dimensions or use only one variable, making them incorrect choices.

Common mistake note:
Common mistake: Not using two separate variables for both x and y coordinates.

Problem 2 (IncorrectPathFunction):
A program uses a function `draw_circle(radius, center_x, center_y) to draw circles. To create multiple circles with different radii at varying positions, which of the following code snippets correctly parameterizes the circle creation?
A) for i in range(5): draw_circle(i)
B) for i in range(5): draw_circle(radius=i, center=(0, 0))
C) for i in range(5): draw_circle(i, center_x=i*10, center_y=i*10)
D) for i in range(5): draw_circle(i, (i*10, i*10))
Correct Answer: C

Solution:
The correct answer is C. This snippet parameterizes the circle creation by using a loop and variables `i`, `center_x`, and `center_y`. The other options either don't vary the position or use incorrect variable assignments.

Explanation:
To parameterize the creation of multiple circles, you need to vary both the radius and the center coordinates. Option A only varies the radius but not the position, option B uses a fixed center, and option D assigns the same value for both `center_x` and `center_y`. Only option C correctly varies all parameters.

Common mistake note:
Common mistake: Not varying the center coordinates or using incorrect variable assignments.

Problem 3 (IncorrectPathData):
A program generates a complex path by concatenating multiple line segments. The function `draw_line(x1, y1, x2, y2) is used to draw each line segment. To create a parameterized version of the path, which of the following code snippets correctly uses arrays for the coordinates?
A) def draw_complex_path(points): for i in range(len(points)): draw_line(points[i])
B) def draw_complex_path(line_data): for i in range(len(line_data)): draw_line(line_data[ i][0], line_data[ i][1], line_data[ i][2], line_data[ i][3])
C) def draw_complex_path(lines): for line in lines: draw_line(line[0], line[1], line[2], line[3])
D) def draw_complex_path(path): for i in range(len(path)): draw_line(path[i][0], path[i][1], path[i][2], path[i][3])
Correct Answer: C

Solution:
The correct answer is C. This snippet correctly uses a 2D array `lines` to store the x and y coordinates for each line segment, allowing for easy manipulation of the path data. The other options either don't use arrays or have incorrect indexing.

Explanation:
To parameterize a complex path, you need to store the coordinates in an array format that can be easily modified. Option A doesn't use arrays at all, option B uses a 1D array with incorrect indexing, and option D has incorrect variable name. Only option C correctly uses a 2D array with proper indexing.

Common mistake note:
Common mistake: Not using a 2D array or incorrect indexing.
