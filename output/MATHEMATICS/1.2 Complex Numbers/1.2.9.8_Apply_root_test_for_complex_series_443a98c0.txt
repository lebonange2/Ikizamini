Problem 1 (One):
Determine the convergence of the series using the root test: Σ (3i)^n / n^2, where i is the imaginary unit.
A) Convergent
B) Divergent
C) Conditional convergence
D) Absolute convergence
Correct Answer: B

Solution:
The root test states that if |a_n|^(1/n) → L as n → ∞, then the series Σ a_n converges absolutely if L < 1, diverges if L > 1, and is inconclusive if L = 1. For the given series, a_n = (3i)^n / n^2, so |a_n|^(1/n) = |(3i)^n|^(1/n) / n^(2/n) = 3 / n^(2/n). As n → ∞, n^(2/n) approaches 1, so the limit becomes 3/1 = 3. Since L > 1, the series diverges.

Explanation:
The root test is applicable to complex series as well as real ones. By applying it correctly, we find that the limit leads to a value greater than 1, which indicates divergence.

Common mistake note:
A common mistake would be to assume that because i^2 = -1, the entire series would converge. However, the root test involves taking the absolute value of the terms, so the imaginary part does not affect the convergence.

Problem 2 (Two):
Use the root test to determine if the series Σ (-4)^n / (3^n + 2), where n is a positive integer, converges or diverges.
A) Convergent
B) Divergent
C) Conditional convergence
D) Absolute convergence
Correct Answer: A

Solution:
The root test gives us |a_n|^(1/n) = [(-4)^n / (3^n + 2)]^(1/n) = (-4) * [(3^n + 2)^(-1/ n)]. As n → ∞, (3^n + 2)^(-1/n) approaches 3^(-1) = 1/3. Thus, the limit becomes |-4| * (1/3) = 4/3 < 1. Since L < 1, the series converges absolutely.

Explanation:
The root test is applied correctly by considering the absolute value of the terms and taking the limit as n approaches infinity. The result shows convergence.

Common mistake note:
A common mistake would be to incorrectly simplify (3^n + 2)^(-1/n) or overlook the fact that we need to take the absolute value of the term.

Explanation:
The root test is applied correctly by considering the absolute value of the terms and taking the limit as n approaches infinity. The result shows divergence due to an unbounded limit.

Common mistake note:

Problem 4 (Four):
Determine whether the series Σ (1 + 2i)^n / n! converges or diverges using the root test.
A) Convergent
B) Divergent
C) Conditional convergence
D) Absolute convergence
Correct Answer: A

Solution:
The root test gives us |a_n|^(1/ n) = [(1 + 2i)^n / n!]^(1/ n) = (1 + 2)^(-1) * (n!)^(-1/ n). As n → ∞, (n!)^(-1/ n) approaches 0, so the limit becomes 3^(-1) = 1/3 < 1. Since L < 1, the series converges absolutely.

Explanation:
The root test is applied correctly by considering the absolute value of the terms and taking the limit as n approaches infinity. The result shows convergence.

Common mistake note:
A common mistake would be to overlook the factorial in the denominator or incorrectly simplify (1 + 2i)^n.

Explanation:
The root test is applied correctly by considering the absolute value of the terms and taking the limit as n approaches infinity. The result shows absolute convergence.

Common mistake note:
A common mistake would be to assume that because i^2 = -1, the series would converge conditionally. However, the root test involves taking the absolute value of the terms, so the imaginary part does not affect the convergence.

The root test is applied correctly by considering the absolute value of the terms and taking the limit as n approaches infinity. The result shows absolute convergence due to a limit approaching zero.
