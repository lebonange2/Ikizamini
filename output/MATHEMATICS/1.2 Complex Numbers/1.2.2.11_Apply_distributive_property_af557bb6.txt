Problem 1 (:Q1):
Simplify the expression: 3(4x + 5)
A) 12x + 8
B) 12x + 15
C) 15x + 8
D) 15x + 20
Correct Answer: B

Solution:
3(4x + 5) = 3 	imes 4x + 3 	imes 5 = 12x + 15

Explanation:
The distributive property states that a 	imes (b + c) = a 	imes b + a 	imes c. We apply this property to distribute the 3 across both terms inside the parentheses.

Common mistake note:
A common mistake is forgetting to multiply each term within the parentheses by the outside number.

Problem 2 (:Q2):
Simplify the expression: (5 - 2)(7x + 3)
A) 21x + 15
B) 21x - 9
C) 35x - 6
D) 35x + 6
Correct Answer: A

Solution:
(5 - 2)(7x + 3) = 3 	imes 7x + 3 	imes 3 = 21x + 9

Explanation:
We apply the distributive property twice, first distributing the (5 - 2) across the terms inside the second set of parentheses.

Common mistake note:
A common mistake is subtracting the numbers outside the parentheses before distributing.

Problem 3 (:Q3):
Simplify the expression: 7(4y - 6)
A) 28y - 14
B) 28y - 42
C) 28y + 42
D) 49y - 6
Correct Answer: B

Solution:
7(4y - 6) = 7 	imes 4y - 7 	imes 6 = 28y - 42

Explanation:
The distributive property is applied to distribute the 7 across both terms inside the parentheses.

Common mistake note:
A common mistake is adding the numbers outside the parentheses instead of multiplying.

Problem 4 (:Q4):
Simplify the expression: (2x + 3)(5 - x)
A) 10x - 2x^2 + 15 - 3x
B) 10x + 2x^2 + 15 - 3x
C) 10x - 2x^2 - 15 + 3x
D) 10x + 2x^2 - 15 + 3x
Correct Answer: A

Solution:
(2x + 3)(5 - x) = 2x 	imes 5 + 2x 	imes (-x) + 3 	imes 5 + 3 	imes (-x) = 10x - 2x^2 + 15 - 3x

Explanation:
We apply the distributive property twice, distributing each term in the first set of parentheses across both terms in the second set.

Common mistake note:
A common mistake is forgetting to multiply the negative sign when multiplying by -x.

Problem 5 (:Q5):
Simplify the expression: 4(3z + 2) - 2(6z - 1)
A) 12z + 8 - 12z + 2
B) 12z + 8 - 12z - 2
C) 12z + 8 + 12z - 2
D) 12z + 8 - 18z + 2
Correct Answer: D

Solution:
4(3z + 2) - 2(6z - 1) = (4 	imes 3z + 4 	imes 2) - (2 	imes 6z - 2 	imes 1) = 12z + 8 - 12z + 2

Explanation:
We apply the distributive property to each set of parentheses, then combine like terms.

Common mistake note:
A common mistake is not combining the like terms (12z and -12z) after distributing.

Problem 6 (:Q6):
Simplify the expression: 6(2w - 3) + 3(4w + 5)
A) 18w - 18 + 12w + 15
B) 18w - 18 + 12w - 15
C) 18w + 18 + 12w + 15
D) 18w + 18 + 12w - 15
Correct Answer: A

Solution:
6(2w - 3) + 3(4w + 5) = (6 	imes 2w - 6 	imes 3) + (3 	imes 4w + 3 	imes 5) = 18w - 18 + 12w + 15

Explanation:
We apply the distributive property to each set of parentheses, then combine like terms.

Common mistake note:
A common mistake is not combining the like terms (18w and 12w) after distributing.

Problem 7 (:Q7):
Simplify the expression: 3(5a - 4b) - 2(6a + 3b)
A) 15a - 12b - 12a - 6b
B) 15a - 12b - 12a + 6b
C) 15a + 12b - 12a - 6b
D) 15a + 12b - 12a + 6b
Correct Answer: A

Solution:
3(5a - 4b) - 2(6a + 3b) = (3 	imes 5a - 3 	imes 4b) - (2 	imes 6a + 2 	imes 3b) = 15a - 12b - 12a - 6b

Explanation:
We apply the distributive property to each set of parentheses, then combine like terms.

Common mistake note:
A common mistake is not combining the like terms (15a and -12a) or (-12b and -6b) after distributing.
