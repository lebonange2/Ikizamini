Problem 1 (One):
Find the exact value of sin(π/3) + cos(π/4).
A) 1/2  + √2/2
B) √3/2  + 1/√2
C) 1  + 1
D) √3/2  + √2/2
Correct Answer: D

Solution:
sin(π/3) = √3/2 and cos(π/4) = √2/2. Adding them together gives sin(π/3) + cos(π/4) = √3/2 + √2/2.

Explanation:
This question assesses the application of trigonometric functions to specific angles and combining their results.

Common mistake note:
A common mistake is to incorrectly evaluate one or both trigonometric functions, leading to an incorrect sum.

Problem 2 (Two):
Convert 5π/3 radians to degrees.
A) 150°
B) 240°
C) 300°
D) 360°
Correct Answer: B

Solution:
To convert radians to degrees, multiply the radian measure by (180°/π). So 5π/3 * (180°/π) = 300° / 3 = 100°. Adding 180° because 5π/3 is in the second quadrant gives us 240°.

Explanation:
This question tests understanding of converting between radians and degrees.

Common mistake note:
A common mistake is to forget to add or subtract multiples of 180° when converting angles from radians to degrees based on their quadrants.

Problem 3 (Three):
Find the exact value of tan(π/6) - cot(π/4).
A) 1/2  - √2
B) √3/3  - 1
C) 0
D) -1/2
Correct Answer: B

Solution:
tan(π/6) = √3/3 and cot(π/4) = 1. Subtracting them gives tan(π/6) - cot(π/4) = √3/3 - 1.

Explanation:
This question evaluates the application of trigonometric functions to specific angles and subtracting their results.

Common mistake note:
A common mistake is to incorrectly evaluate one or both trigonometric functions, leading to an incorrect difference.

Problem 4 (Four):
Simplify the expression cos²θ - sin²θ, given that θ is in the first quadrant.
A) cos(2θ)
B) sin(2θ)
C) 1
D) -1
Correct Answer: A

Solution:
(cos²θ - sin²θ) = cos(2θ), using the trigonometric identity for cosine of double angles.

Explanation:
This question assesses understanding of trigonometric identities and their application to simplify expressions.

Common mistake note:
A common mistake is to confuse the identity for sine of double angles (sin(2θ) = 2sinθcosθ) with the one for cosine.

Problem 5 (Five):
Find the exact value of sec(-π/6) * csc(π/3).
A) 1
B) √3
C) 2
D) -√3
Correct Answer: C

Solution:
sec(-π/6) = 2 and csc(π/3) = 2. Multiplying them gives sec(-π/6) * csc(π/3) = 4 / √3 * √3 = 4.

Explanation:
This question tests the application of trigonometric functions to specific angles, multiplying their results, and considering negative angles.

Common mistake note:
A common mistake is to forget that secant and cosecant are positive in all quadrants, even when the input angle is negative.

Problem 6 (Six):
Find the period of the function y = 3sin(2x + π).
A) π
B) 2π
C) π/2
D) π/4
Correct Answer: C

Solution:
The period of a sine function is given by 2π / |B|, where B is the coefficient of x inside the sine. In this case, B = 2, so the period is 2π / 2 = π/2.

Explanation:
This question tests understanding of the relationship between the coefficients in a trigonometric function and its period.

Common mistake note:
A common mistake is to forget to consider the absolute value of B when calculating the period.

Problem 7 (Seven):
Solve for x: 2cos(x) + √3 = 0, in the interval [0, 2π].
A) x = π/6
B) x = π/3
C) x = 5π/6
D) x = 7π/6
Correct Answer: D

Solution:
First, isolate cos(x): cos(x) = -√3 / 2. The solutions in the given interval are x = 2π - π/3 and x = π + π/3, which simplifies to x = 5π/6 and x = 4π/3. Since 4π/3 is outside the interval [0, 2π], the only valid solution is x = 5π/6.

Explanation:
This question tests the ability to solve trigonometric equations within a specified interval.

Common mistake note:
A common mistake is to forget to check if the solutions found are within the given interval.
