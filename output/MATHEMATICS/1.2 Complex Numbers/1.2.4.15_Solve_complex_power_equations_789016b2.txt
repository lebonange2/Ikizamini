Problem 1 (:1):
Find the value of (3 + 4i)^3.
A) (9 - 40i)
B) (81 + 216i)
C) (729 - 1944i)
D) (512 + 768i)
Correct Answer: A

Solution:
(3 + 4i)^3 = (3^3) + 3(3^2)(4i) + 3(3)(4i)^2 + (4i)^3
= 27 + 108i - 144 - 64i
= 9 - 40i

Explanation:
Apply the binomial theorem or expand the expression step by step.

Common mistake note:
A common mistake is forgetting to multiply all terms in the expansion, leading to an incorrect result.

Problem 2 (:2):
Simplify (2 - 3i)^4.
A) (16 + 72i)
B) (16 - 72i)
C) (256 - 768i)
D) (256 + 768i)
Correct Answer: B

Solution:
(2 - 3i)^4 = (2^4) - 4(2^3)(3i) + 6(2^2)(3i)^2 - 4(2)(3i)^3 + (3i)^4
= 16 - 96i - 216 + 216i - 81i^4
= 16 - 216 + 81
= 16 - 135
= 16 - 135(-1) (since i^2 = -1)
= 16 + 135
= 151

Explanation:
Apply the binomial theorem or expand the expression step by step, remembering that i^2 = -1.

Common mistake note:
A common mistake is not accounting for the powers of i correctly, leading to an incorrect result.

Problem 3 (:3):
Evaluate (5 + 2i)^(-2).
A) (25/29)
B) (29/25)
C) (25/169)
D) (169/25)
Correct Answer: A

Solution:
(5 + 2i)^(-2) = (1 / (5 + 2i))^2
= [(5 - 2i) / (5^2 + 2^2)]^2 (conjugate of the denominator)
= [(5 - 2i) / 29]^2
= (25/841) * (29/29)
= 25/841

Explanation:
To find the reciprocal, take the conjugate of the denominator and multiply. Then square the result.

Common mistake note:
A common mistake is not taking the conjugate when finding the reciprocal, leading to an incorrect result.

Problem 4 (:4):
Solve for x: (x + 1)^3 = -8.
A) -2
B) 1
C) 0
D) 2
Correct Answer: A

Solution:
(x + 1)^3 = -8
(x + 1) = (-8)^(1/3)
= -2 (since (-2)^3 = -8)
x = -2 - 1
x = -3

Explanation:
Take the cube root of both sides and solve for x, remembering that the principal cube root of -8 is -2.

Common mistake note:
A common mistake is not considering the negative cube root, leading to an incorrect solution.

Problem 5 (:5):
Find the real part of (3 + 4i)^6.
A) 177147
B) 177148
C) 196830
D) 196832
Correct Answer: A

Solution:
(3 + 4i)^6 = (3^6) + 6(3^5)(4i) + 15(3^4)(4i)^2 + 20(3^3)(4i)^3 + 15(3^2)(4i)^4 + 6(3)(4i)^5 + (4i)^6
= 729 + 7776i - 23328 - 34560i + 25920 + 13824i - 4096
= 729 - 4096
= -3367

Explanation:
Expand the expression and group real and imaginary parts. The real part is the sum of the real terms.

Common mistake note:
A common mistake is not separating the real and imaginary parts, leading to an incorrect result.

Problem 6 (:6):
Simplify (2i)^5 / (4 - 3i).
A) (16i + 32)
B) (16i - 32)
C) (8i + 16)
D) (8i - 16)
Correct Answer: B

Solution:
(2i)^5 / (4 - 3i) = (-32i) / (4 - 3i)
= (-32i)(4 + 3i) / (4 - 3i)(4 + 3i) (conjugate of the denominator)
= (-128i - 96i^2) / 25
= (-128i + 96) / 25
= (96 - 128i) / 25

Explanation:
Simplify the numerator, then multiply by the conjugate of the denominator and simplify.

Common mistake note:
A common mistake is not multiplying by the conjugate when simplifying the fraction, leading to an incorrect result.

Problem 7 (:7):
Find the absolute value of (1 - 2i)^3.
A) φ
B) 2φ
C) 4φ
D) 8φ
Correct Answer: C

Solution:
|(1 - 2i)^3| = |1 - 2i|^3
= φ(1^2 + (-2)^2)^(3/2)
= φ(5)^(3/2)
= 4φ

Explanation:
Find the absolute value by taking the modulus of each term, then raise to the power of the denominator of the exponent.

Common mistake note:
A common mistake is not applying the correct formula for the absolute value of a complex number, leading to an incorrect result.
