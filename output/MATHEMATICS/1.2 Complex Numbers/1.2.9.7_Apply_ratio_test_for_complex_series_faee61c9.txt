Problem 1 (?):
Determine the convergence of the series ∑(zn), where zn = (3i)^n.
A) Convergent by Ratio Test
B) Divergent by Ratio Test
C) Inconclusive by Ratio Test
D) Absolutely Convergent
Correct Answer: B

Solution:
The ratio test states that if |zn+1/zn| < 1, the series converges. Let's apply it to zn = (3i)^n.

Explanation:
Ratio Test: lim (n→∞) |(3i)^(n+1)/(3i)^n| = lim (n→∞) |3i| = 3 > 1, which means the series diverges by the ratio test.

Common mistake note:
A common mistake is to assume that since zn approaches zero as n increases, the series converges. However, this is not sufficient; we must consider the absolute value of the ratio.

Problem 2 (?):
Evaluate the convergence of the series ∑(n^2/(3+4i)^n).
A) Convergent by Ratio Test
B) Divergent by Ratio Test
C) Inconclusive by Ratio Test
D) Absolutely Convergent
Correct Answer: A

Solution:
Applying the ratio test, we have |(n+1)^2/(3+4i)^(n+1)/(n^2/(3+4i)^n)| = (n+1)^2 / |(3+4i)|^2.

Explanation:
lim (n→∞) [(n+1)^2 / |(3+4i)|^2] = lim (n→∞) [n^2/(9 + 16)] = 0 < 1, which means the series converges by the ratio test.

Common mistake note:
A common mistake is to forget that we must take the absolute value of the complex number in the denominator. Without it, the limit would be infinity and lead to a wrong conclusion.

Problem 3 (?):
Determine if the series ∑(e^(niπ)) converges using the ratio test.
A) Convergent by Ratio Test
B) Divergent by Ratio Test
C) Inconclusive by Ratio Test
D) Absolutely Convergent
Correct Answer: C

Solution:
The ratio test is inconclusive because the limit of |e^(n(iπ) + iπ)/e^(niπ)| does not exist.

Explanation:
lim (n→∞) |e^(n(iπ) + iπ)/e^(niπ)| = lim (n→∞) |e^(iπ)| = 1, but the limit does not provide enough information to determine convergence or divergence. The ratio test is inconclusive.

Common mistake note:
A common mistake is to assume that since e^(iπ) = -1 and the series seems to oscillate, it must converge. However, this is not sufficient; we need a limit strictly less than 1 for convergence.

Problem 4 (?):
Test the convergence of the series ∑((-2i)^n/ n).
A) Convergent by Ratio Test
B) Divergent by Ratio Test
C) Inconclusive by Ratio Test
D) Absolutely Convergent
Correct Answer: A

Solution:
The ratio test gives |((-2i)^(n+1)/(n+1))/((-2i)^n/ n)| = |-2i| < 1, which implies convergence.

Explanation:
lim (n→∞) |-2i| = 2 < 1, so the series converges by the ratio test. Since the terms are not all non-negative, we cannot conclude absolute convergence without further analysis.

Common mistake note:
A common mistake is to overlook that the limit of the ratio must be less than 1 for convergence; here, it's just 2, which is not enough.

Problem 5 (?):
Analyze the convergence of the series ∑((-3)^n/(4+5i)^n).
A) Convergent by Ratio Test
B) Divergent by Ratio Test
C) Inconclusive by Ratio Test
D) Absolutely Convergent
Correct Answer: B

Solution:
The ratio test gives |((-3)^(n+1)/(4+5i)^(n+1))/((-3)^n/(4+5i)^n)| = |-3| > 1, which implies divergence.

Explanation:
lim (n→∞) |-3| = 3 > 1, so the series diverges by the ratio test. No further analysis is needed for this conclusion.

Common mistake note:
A common mistake is to forget that we must take the absolute value of both the numerator and denominator in the ratio test.
