Problem 1 (IncrementBy5):
Given the linear transformation w = 5z + 2, what is the value of w when z is 3?
A) {10}
B) {17}
C) {15}
D) {8}
Correct Answer: C

Solution:
w = 5z + 2, substitute z with 3: w = 5 	imes 3 + 2 = 15

Explanation:
This question tests the application of a linear transformation by multiplying the input (z) by a constant (a) and adding a constant (b).

Common mistake note:
Common mistake is to forget to multiply z by 5 or add 2, resulting in answer A (10) or D (8).

Problem 2 (ScaleAndShift):
What is the linear transformation that maps input z to output w = 3z + 7?
A) {az + b, where a = 3, b = 7}
B) {az + b, where a = 7, b = 3}
C) {az + b, where a = z, b = 7}
D) {az + b, where a = 3z, b = 0}
Correct Answer: A

Solution:
The transformation is w = az + b with a = 3 and b = 7.

Explanation:
This question tests understanding of the linear transformation formula and identifying the correct values for a and b.

Common mistake note:
Common mistake is to switch the roles of a and b, resulting in answer B (a = 7, b = 3).

Solution:
