Problem 1 (:1):
Solve the inequality: |x - 3| < 5.
A) -8 < x < 2
B) 2 < x < 8
C) -2 < x < 8
D) 0 < x < 10
Correct Answer: C

Solution:
To solve the inequality |x - 3| < 5, we consider two cases: when (x - 3) is positive and when it's negative.

Case 1: x - 3 > 0
(x - 3) < 5
x < 8

Case 2: x - 3 < 0
-(x - 3) < 5
-x + 3 < 5
x > -2

Combining the two cases, we get -2 < x < 8.

Explanation:
The correct answer is when the absolute value of (x - 3) is less than 5, which means x can be between -2 and 8 but not including those values.

Common mistake note:
A common mistake is to forget considering both cases (positive and negative), leading to an incorrect solution.

Problem 2 (:2):
Solve the inequality: |2x + 1| ≤ 7.
A) -4 ≤ x ≤ 3
B) 0 ≤ x ≤ 4
C) -9 ≤ x ≤ 5
D) 1 ≤ x ≤ 6
Correct Answer: A

Solution:
To solve the inequality |2x + 1| ≤ 7, we again consider two cases: when (2x + 1) is positive and when it's negative.

Case 1: 2x + 1 ≥ 0
2x + 1 ≤ 7
2x ≤ 6
x ≤ 3

Case 2: 2x + 1 < 0
-(2x + 1) ≤ 7
-2x - 1 ≤ 7
-2x ≤ 8
x ≥ -4

Combining the two cases, we get -4 ≤ x ≤ 3.

Explanation:
The correct answer is when the absolute value of (2x + 1) is less than or equal to 7, which means x can be between -4 and 3 inclusive.

Common mistake note:
A common mistake is to forget that '≤' includes the endpoint values, so x can be -4 and 3.

Problem 3 (:3):
Solve the inequality: |3x - 6| > 9.
A) x < -1 or x > 5
B) x ≤ -1 or x ≥ 5
C) x ≠ -1 and x ≠ 5
D) No solution
Correct Answer: A

Solution:
To solve the inequality |3x - 6| > 9, we consider when (3x - 6) is positive and negative.

Case 1: 3x - 6 > 0
3x > 6
x > 2
Since x must be greater than 2, it must also be greater than 5 to satisfy the inequality.

Case 2: 3x - 6 < 0
-(3x - 6) > 9
-3x + 6 > 9
-3x > 3
x < -1
Since x must be less than -1, it must also be less than -1 to satisfy the inequality.

Combining the two cases, we get x < -1 or x > 5.

Explanation:
The correct answer is when the absolute value of (3x - 6) is greater than 9, which means x can be any number less than -1 or greater than 5.

Common mistake note:
A common mistake is to forget that '>' does not include the endpoint values.

Problem 4 (:4):
Solve the inequality: |x + 2| + |x - 3| < 7.
A) -1.5 < x < 4.5
B) 0 < x < 6
C) -4 < x < 5
D) No solution
Correct Answer: C

Solution:
To solve the inequality |x + 2| + |x - 3| < 7, we need to consider four cases due to the two absolute values:

Case 1: x ≤ -2 and x ≥ 3 (no overlap)
(x + 2) + (x - 3) < 7
2x - 1 < 7
2x < 8
x < 4
Since x must be greater than or equal to 3, there is no solution in this case.

Case 2: -2 < x < 3
(x + 2) + (-(x - 3)) < 7
x + 2 - x + 3 < 7
5 < 7
This case is always true for any x between -2 and 3.

Combining the solutions from Case 2, we get -2 < x < 3 or -4 < x < 5 (since x cannot be equal to -2 or 3 due to the inequality being strict).

Explanation:
The correct answer is when the sum of the absolute values of (x + 2) and (x - 3) is less than 7, which means x can be any number between -4 and 5 but not including those endpoints.

Common mistake note:
A common mistake is to forget that there are four cases to consider due to the two absolute values.

Combining the solutions from Case 2, we get -15 ≤ x < 1/2 or -5/3 ≤ x ≤ 7/2 (since x cannot be equal to -4/3 or 1/2 due to the inequality being weak).

Explanation:

Problem 7 (:7):
Solve the inequality: |3x - 2| - |x + 1| < 5.
A) -4/3 < x < 9/2
B) -1/3 < x < 7/2
C) -2 < x < 6
D) No solution
Correct Answer: C

Solution:
To solve the inequality |3x - 2| - |x + 1| < 5, we consider four cases due to the two absolute values:

Case 1: x ≤ -1 and x ≥ 2/3 (no overlap)
(3x - 2) - (x + 1) < 5
2x - 3 < 5
2x < 8
x < 4
Since x must be greater than or equal to 2/3, there is no solution in this case.

Case 2: -1 < x < 2/3
(3x - 2) - (-(x + 1)) < 5
3x - 2 + x + 1 < 5
4x - 1 < 5
4x < 6
x < 3/2
Since x must be less than 2/3, we have -1 < x < 3/2.

Combining the solutions from Case 2, we get -1 < x < 3/2 or -2 < x < 6 (since x cannot be equal to -1 or 2/3 due to the inequality being strict).

Explanation:
The correct answer is when the difference of the absolute values of (3x - 2) and (x + 1) is less than 5, which means x can be any number between -2 and 6 but not including those endpoints.

Common mistake note:
A common mistake is to forget that there are four cases to consider due to the two absolute values.
