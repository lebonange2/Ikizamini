Problem 1 (:1):
Find the square root of the complex number (3 + 4i) using completing the square method.
A) (2 + i)
B) (1 + 2i)
C) (1 - 2i)
D) (2 - i)
Correct Answer: B

Solution:
To find the square root of (3 + 4i), we first express it in the form (a + bi)² = c + di. Completing the square for the real part and the imaginary part separately, we get:

(1 + √2 + 2i)(1 - √2 + 2i)
= (1 - (√2)²) + (2√2)i + (2√2)i - (√2)²
= (1 - 2) + (4√2)i
= -1 + 4i

Now, we need to find the square root of this complex number. Since the coefficient of i is even, we can take the square root of both parts separately:

(1/2)(-1 ± √((-1)² - (4i)²))
= (1/2)(-1 ± √(1 + 16))
= (1/2)(-1 ± √17)

The square root of 17 is not a simple integer, so we need to consider the principal value. The principal square root of -1 is i. Therefore, the square root of -1 + 4i is:

(1/2)(-1 + √17)i
= (1/2)(-1 + 3.58113883008) * i
= (1/2)(2.58113883008)i
= 1.29056941504i

This corresponds to the choice B: (1 + 2i).

Explanation:
The correct answer is found by completing the square for the real and imaginary parts, then taking the principal square root of the result.

Common mistake note:
A common mistake would be to assume that the square root of a complex number with an even coefficient of i will have an integer value. In this case, the square root has a non-integer part due to the √17 term.

Problem 2 (:2):
Simplify (x + 3i)² using completing the square method.
A) (x + 6i)(x - 3i)
B) (x + 9)(x - 3)
C) (x + 3)^2
D) (x^2 + 9)
Correct Answer: D

Solution:
To simplify (x + 3i)² using completing the square, we first expand it and then group the terms:

(x + 3i)(x + 3i)
= x² + 3ix + 3ix + (3i)²
= x² + 6ix - 9

Now, to complete the square for the imaginary part, we add and subtract (6/2)² = 9 inside the expression:

x² + 6ix - 9 + 9 - 9
= x² + 6ix
= x² + (6i)^2
= x² - 36

Since i² = -1, we get:

x² - 36
= x² - 6²
= (x - 6)(x + 6)
= (x^2 - 36)

This corresponds to the choice D: (x^2 + 9).

Explanation:
The correct answer is found by expanding, grouping terms, and completing the square for the imaginary part. Then, factorizing the result gives us x² - 36.

Common mistake note:
A common mistake would be to forget that i² = -1 when simplifying (3i)², leading to an incorrect result.
