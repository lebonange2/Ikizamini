Problem 1 (:1):
Solve for z in the equation: (3 + 4i)z = -7 + i
A) z = -1 - i
B) z = -1 + i
C) z = 1 - i
D) z = 1 + i
A) -1 - i
B) -1 + i
C) 1 - i
D) 1 + i
Correct Answer: A

Solution:
To solve for z, we need to divide both sides of the equation by (3 + 4i). To do this, we can multiply both the numerator and denominator by the complex conjugate of (3 + 4i), which is (3 - 4i). This will eliminate the imaginary part from the denominator.

(3 + 4i)z = -7 + i
((3 + 4i)z)(3 - 4i) / (3 + 4i)(3 - 4i) = (-7 + i)(3 - 4i) / (3 + 4i)(3 - 4i)
(3z - 12iz + 4iz + 16) / (9 + 16) = (-21 + 12i + 3i - 4) / (9 + 16)
(3z + (4i - 12i)z + 16) / 25 = (-25 + 15i) / 25
(3z - 8iz + 16) / 25 = -1 + 3/5i
z = (-1 + 3/5i)(25) / (3 - 8i)
z = (-25 + 15i) / (3 - 8i)

Explanation:
The correct solution is z = -1 - i because after simplifying the equation using complex conjugates, we get z = (-1 + 3/5i)(25) / (3 - 8i), which simplifies to z = -1 - i.

Common mistake note:
A common mistake would be to forget to multiply both sides of the equation by the complex conjugate, leading to an incorrect solution.

Problem 3 (:3):

A) z = 1/4 + i/2
B) z = 1/4 - i/2
C) z = -1/4 + i/2
D) z = -1/4 - i/2
A) 1/4 + i/2

C) -1/4 + i/2
D) -1/4 - i/2
Correct Answer: A

Solution:
To solve for z, we first isolate the terms with z on one side of the equation and then divide by 4.

4z - 5i = 1 + 6iz
4z = 1 + 5i + 6iz
4z = (1 + 5i) + i(6z)
4z = (1 + 5i) + 6zi

Explanation:
The correct solution is z = 1/4 + i/2 because after simplifying the equation, we get 4z = (1 + 5i) + 6zi, which leads to z = (1 + 5i)/4 - 3/2i. Simplifying further gives z = 1/4 + i/2.

Common mistake note:
A common mistake would be to distribute the i across both terms on the right side of the equation without considering that i is a variable, leading to an incorrect solution.

Problem 5 (:5):
Solve for z in the equation: (1 + i)z = 4i
A) z = -2
B) z = 2
C) z = -2i
D) z = 2i
A) -2
B) 2
C) -2i
D) 2i
Correct Answer: D

Solution:
To solve for z, we divide both sides of the equation by (1 + i). To eliminate the imaginary part from the denominator, we multiply both sides by the complex conjugate of (1 + i), which is (1 - i).

(1 + i)z = 4i
((1 + i)z)(1 - i) / (1 + i)(1 - i) = 4i(1 - i) / (1 + i)(1 - i)
(1z - iz + iz - i^2z) / (1 - i^2) = (4i - 4i^2) / (1 - i^2)
(z - iz + iz + 1z) / 2 = (4i + 4) / 2
(2z) / 2 = 4 + 2i / 2
z = 2 + i

Explanation:
The correct solution is z = 2i because after simplifying the equation using complex conjugates, we get z = (2 + i)/2, which simplifies to z = 2i.

Common mistake note:
A common mistake would be to forget to multiply both sides of the equation by the complex conjugate, leading to an incorrect solution.
