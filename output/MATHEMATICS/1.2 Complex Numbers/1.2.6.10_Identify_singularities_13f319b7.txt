Problem 1 (Infinite__zeros):
Find the singularity of the function f(x) = (x^3 - 4x^2 + x) / (x - 1).
A) -1
B) 0
C) 1
D) 2
Correct Answer: C

Solution:
The singularity occurs where the denominator is zero. For f(x), the denominator is x - 1, which equals zero when x = 1.

Explanation:
Singularities are points where a function is undefined, typically due to division by zero. In this case, the only point that causes a division by zero is x = 1.

Common mistake note:
A common mistake would be to choose -1 or 2 as they are roots of the numerator, but they do not affect the singularity since they don't make the denominator zero.

Problem 2 (Removable_singularity):
Determine if the function g(x) = (x^2 + 3x + 2) / (x + 1) has a removable singularity at x = -1.
A) Yes
B) No
C) Cannot be determined without expanding
D) The singularity is not removable
Correct Answer: A

Solution:
The function g(x) can be simplified by factoring the numerator: (x + 1)(x + 2) / (x + 1). The (x + 1) term cancels out, leaving g(x) = x + 2. Thus, the singularity is removable.

Explanation:
A removable singularity occurs when a factor in the numerator and denominator cancel each other out, making the function defined at that point after simplification.

Common mistake note:
Choosing 'No' or 'Cannot be determined without expanding' would be a common mistake. Factoring the numerator reveals that the singularity is indeed removable.

Problem 3 (Essential_singularity):
Classify the singularity of h(x) = 1 / (x^2 - 1) at x = 1.
A) Removable
B) Pole of order 1
C) Essential
D) Not a singularity
Correct Answer: C

Solution:
The function h(x) does not have a removable singularity or a pole because the denominator does not factor to cancel out x = 1. It is an essential singularity.

Explanation:
An essential singularity occurs when the function approaches infinity or oscillates near the singular point without canceling factors in the numerator and denominator.

Common mistake note:
A common mistake would be to choose 'Removable' or 'Pole of order 1', but these do not apply because x = 1 is not a root of the denominator.

Problem 4 (Infinity_at_infinity):
Identify the singularity type for the function j(x) = (x^3 + 2x^2 + x) / e^x at x = ∞.
A) Removable
B) Pole of order 1
C) Essential
D) Not a singularity
Correct Answer: B

Solution:
As x approaches infinity, the numerator grows faster than the denominator (e^x grows exponentially). Thus, j(x) approaches infinity, indicating a pole of order 1.

Explanation:
A pole of order 1 occurs when the function approaches infinity as x approaches a singularity. In this case, the exponential growth of e^x is overcome by the faster polynomial growth in the numerator.

Common mistake note:
A common mistake would be to choose 'Essential' or 'Not a singularity'. The pole of order 1 indicates that the singularity is not essential and is caused by the denominator's inability to keep up with the numerator.

Problem 5 (Zero_at_origin):
Find the singularity type for k(x) = (x^2 + x - 6) / x at x = 0.
A) Removable
B) Pole of order 1
C) Essential
D) Not a singularity
Correct Answer: A

Solution:
The function k(x) can be simplified by factoring the numerator: (x + 3)(x - 2) / x. The x term cancels out, leaving k(x) = x + 3 for x ≠ 0. Thus, it's a removable singularity.

Explanation:
A removable singularity occurs when a factor in the numerator and denominator cancel each other out, making the function defined at that point after simplification.

Common mistake note:
Choosing 'Pole of order 1' or 'Essential' would be common mistakes. Factoring the numerator reveals that the singularity is removable.

Problem 6 (Nonremovable_singularity):
Classify the singularity of l(x) = (x^2 + 3x + 2) / (x^2 - 1) at x = 1.
A) Removable
B) Pole of order 1
C) Essential
D) Not a singularity
Correct Answer: C

Solution:
The function l(x) does not have a removable singularity because the denominator factors to (x - 1)(x + 1), but there is no corresponding factor in the numerator. It's an essential singularity.

Explanation:
An essential singularity occurs when the function approaches infinity or oscillates near the singular point without canceling factors in the numerator and denominator.

Common mistake note:
A common mistake would be to choose 'Removable' because x = 1 is a root of the denominator, but it's not canceled by a factor in the numerator.

Problem 7 (Nonisolated_singularity):
Identify the singularity type for m(x) = (x^2 + 3x + 2) / (x - 1)^2 at x = 1.
A) Removable
B) Pole of order 1
C) Essential
D) Nonisolated
Correct Answer: D

Solution:
The singularity is not isolated because the denominator has a higher power (x - 1)^2, making it a nonisolated singularity at x = 1.

Explanation:
A nonisolated singularity occurs when the denominator has a higher power than the corresponding factor in the numerator, resulting in an infinite number of singularities along a curve or line.

Common mistake note:
A common mistake would be to choose 'Removable' or 'Pole of order 1', but these do not apply because the singularity is not isolated.
