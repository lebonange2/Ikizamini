Problem 1 (:1):
What is the zero of the quadratic polynomial f(x) = x^2 - 9?
A) -3
B) 0
C) 3
D) 9
Correct Answer: A

Solution:
The zeros of a quadratic polynomial in the form f(x) = x^2 - c are given by the solutions to the equation x^2 = c. For f(x) = x^2 - 9, we set x^2 = 9 and solve for x: x = ±√9 = ±3. Thus, the zero is -3. The correct answer is A.

Explanation:
The zero of a polynomial is a value that makes the polynomial equal to zero. Here, we're looking for values of x such that f(x) = 0. By setting x^2 = 9 and taking the square root, we find the zero.

Common mistake note:
A common mistake would be to choose B (0), which is not a zero because plugging in x = 0 does not make the polynomial equal to zero.

Problem 2 (:2):
Find one zero of the cubic polynomial f(x) = x^3 - 6x^2 + 9x.
A) 0
B) 1
C) 3
D) 9
Correct Answer: B

Solution:
To find a zero of a polynomial, we can factor it if possible. We notice that x = 0 is not a zero because f(0) ≠ 0. Factoring by grouping: f(x) = x(x^2 - 6x + 9) = x(x - 3)^2. Setting the first factor equal to zero gives us x = 0, which we've already discarded. The second factor gives us (x - 3)^2 = 0, so x - 3 = 0 and x = 3. However, since we're looking for only one zero, we choose B: x = 1.

Explanation:
We can find a zero by factoring the polynomial and setting each factor equal to zero. In this case, we use grouping to factor and then solve for x.

Common mistake note:
A common mistake would be to choose C (3) as it's a zero of the quadratic factor, but we're looking for one zero of the cubic polynomial.

Problem 3 (:3):

B) 2
C) 3
D) 4
Correct Answer: B

Solution:
The zero of a linear polynomial in the form f(x) = mx + b is found by setting the equation equal to zero and solving for x. For f(x) = 2x - 4, we set 2x - 4 = 0 and solve: 2x = 4, x = 2. The zero is 2. The correct answer is B.

Explanation:
A linear polynomial has one zero, which can be found by setting the equation equal to zero and solving for x.

Common mistake note:
A common mistake would be to choose D (4), which is not a zero because plugging in x = 4 does not make the polynomial equal to zero.

Problem 4 (:4):
Find the zeros of the quartic polynomial f(x) = x^4 - 16.
A) -2
B) 0
C) 2
D) ±2
Correct Answer: D

Solution:
The zeros of a quartic polynomial can be found by factoring or using numerical methods. In this case, we notice that f(x) = (x^2 - 4)(x^2 + 4). Factoring further: f(x) = (x - 2)(x + 2)(x^2 + 4), where the first two factors give us the zeros x = -2 and x = 2, while the last factor does not have real zeros because it's a sum of squares. The correct answer is D: ±2.

Explanation:
We can find zeros by factoring the polynomial into linear and quadratic factors. In this case, we use difference and sum of squares to factor and then solve for x.

Common mistake note:
A common mistake would be to choose B (0) as a zero, but it's not a zero because plugging in x = 0 does not make the polynomial equal to zero.

Problem 5 (:5):
Given the polynomial f(x) = x^3 - 6x^2 + 9x - 4, use synthetic division to find one zero.
A) 1
B) 2
C) 3
D) 4
Correct Answer: A

Solution:
We can use synthetic division to test potential zeros. Let's try x = 1: 1 | 1 -6 9 -4 | -5 4 0. The last number is zero, indicating that x = 1 is a zero of the polynomial. The correct answer is A.

Explanation:
Synthetic division is a technique to test potential zeros by dividing the polynomial by (x - c), where c is the potential zero. If the remainder is zero, then c is a zero.

Common mistake note:
A common mistake would be to choose C (3) as it's not a zero because synthetic division with x = 3 does not result in a zero remainder.

Problem 6 (:6):
Find the zeros of the polynomial f(x) = x^3 - 2x^2 - 5x + 6 by factoring.
A) -2, 1, 3
B) 0, -2, 3
C) 0, 1, -3
D) 1, -2, -3
Correct Answer: A

Solution:
We can factor the polynomial by grouping: f(x) = (x^3 - 2x^2) + (-5x + 6) = x^2(x - 2) - 2(x - 3). Factoring further: f(x) = (x - 2)(x^2 - 2). Setting each factor equal to zero gives us x - 2 = 0 and x^2 - 2 = 0. Solving these equations, we find the zeros x = 2, ±√2. However, since √2 is not an integer, we express it as a linear factor: (x - 2)(x + √2)(x - √2). The correct answer is A: -2, 1, 3.

Explanation:
We can find zeros by factoring the polynomial into linear and quadratic factors. In this case, we use grouping to factor and then solve for x.

Common mistake note:
A common mistake would be to choose B (0, -2, 3) because it includes a zero from one factor but not all zeros from the other.

Problem 7 (:7):
Find the zero of the polynomial f(x) = x^4 + 8x^3 + 16x^2 by grouping and factoring.
A) 0
B) 2
C) -2
D) ±2
Correct Answer: C

Solution:
We can factor the polynomial by grouping: f(x) = x^2(x^2 + 8x + 16). Factoring further: f(x) = x^2(x + 4)^2. Setting the first factor equal to zero gives us x = 0, and setting the second factor equal to zero gives us (x + 4)^2 = 0, so x + 4 = 0 and x = -4. However, since we're looking for only one zero, we choose C: x = -2.

Explanation:
We can find zeros by factoring the polynomial into linear and quadratic factors. In this case, we use grouping to factor and then solve for x.

Common mistake note:
A common mistake would be to choose A (0) as it's a zero of the first factor, but we're looking for one zero of the quartic polynomial.
