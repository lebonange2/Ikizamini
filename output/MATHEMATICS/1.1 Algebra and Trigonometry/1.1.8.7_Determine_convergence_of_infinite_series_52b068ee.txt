Problem 1 (Asdf):
Does the series ∑(n / (n+1)) converge or diverge?
A) Converges
B) Diverges
C) Conditionally converges
D) Absolutely converges
Correct Answer: A

Solution:
The series can be rewritten as ∑((n+1 - 1) / (n+1)) = ∑(1 - 1/(n+1)). As n approaches infinity, the term 1/(n+1) approaches 0. Thus, the series becomes ∑(1), which is a harmonic series that diverges. However, since we're looking for convergence of the original series, we consider the limit of the terms as n approaches infinity, which goes to 1 - 0 = 1. Since the limit is finite, the series converges.

Explanation:
The key here is to recognize that the limit comparison test or direct comparison test cannot be applied directly because the series does not have a simple form like the p-series. Instead, we must manipulate the terms to understand their behavior as n grows large.

Common mistake note:
A common mistake would be to apply the limit comparison test with the harmonic series, which leads to a false conclusion about divergence.

Problem 2 (Bghj):
Does the series ∑((-1)^n / n) converge or diverge?
A) Converges
B) Diverges
C) Conditionally converges
D) Absolutely converges
Correct Answer: C

Solution:
This is an alternating series, specifically the alternating harmonic series. According to the Leibniz test, if the sequence of absolute values (|(-1)^n / n|) decreases monotonically to 0 as n approaches infinity and the limit of the first term is 0, then the series converges. In this case, both conditions are met, so the series conditionally converges.

Explanation:
The Leibniz test applies specifically to alternating series where the terms alternate in sign and decrease in absolute value. The test helps determine if the series converges, but not whether it's absolutely or conditionally convergent.

Common mistake note:
A common mistake would be to assume that because the harmonic series diverges, this alternating series must also diverge. However, the alternating nature changes the convergence properties.

Problem 3 (Qwer):
Does the series ∑(e^n / n!) converge or diverge?
A) Converges
B) Diverges
C) Conditionally converges
D) Absolutely converges
Correct Answer: A

Solution:
This is an example of the ratio test. The limit as n approaches infinity of |(e^(n+1) / (n+1)!)| / |(e^n / n!)| = e / (n+1). As n increases, this ratio approaches 0, which is less than 1. According to the ratio test, if the limit is less than 1, the series converges absolutely.

Explanation:
The ratio test compares the absolute values of consecutive terms in a series to determine convergence. If the limit is less than 1, the series converges; if greater than 1, it diverges; and if equal to 1, the test is inconclusive.

Common mistake note:
A common mistake would be to try using the root test instead of the ratio test, which may lead to confusion. The ratio test is more appropriate for this type of series.

Problem 4 (Yuiop):
Does the series ∑((-1)^n * n) converge or diverge?
A) Converges
B) Diverges
C) Conditionally converges
D) Absolutely converges
Correct Answer: B

Solution:
This is an example of the alternating series test. The terms do not decrease monotonically to 0, as |(-1)^n * n| alternates between positive and negative values that increase in absolute value. Therefore, the alternating series test does not apply, and we cannot conclude convergence or divergence based on it alone. However, since the limit of the absolute value of terms (|n|) approaches infinity as n approaches infinity, the series diverges.

Explanation:
The alternating series test requires that the sequence of absolute values decreases monotonically to 0. If this condition is not met, we must look at other tests or properties to determine convergence.

Common mistake note:
A common mistake would be to assume that because it's an alternating series, it must converge. The alternating series test has specific conditions that must be met for the conclusion to hold.

Problem 5 (Bvnmm):
Does the series ∑(1 / (n^2 + n)) converge or diverge?
A) Converges
B) Diverges
C) Conditionally converges
D) Absolutely converges
Correct Answer: A

Solution:
This is an example of the integral test. The function f(x) = 1 / (x^2 + x) is continuous, positive, and decreasing for x > 1. We can integrate it from 1 to infinity to determine convergence. ∫(1 / (x^2 + x)) dx from 1 to infinity converges because the integral evaluates to ln(x+1) | from 1 to infinity, which approaches a finite value as x approaches infinity. Thus, the series converges.

Explanation:
The integral test compares the sum of a series with an improper integral. If the integral converges, so does the series; if the integral diverges, so does the series.

Common mistake note:
A common mistake would be to try using the comparison test with a simpler function like 1/x^2, which may lead to confusion about the convergence properties of the original series.

Problem 6 (Xcxz):
Does the series ∑((-3)^n / n^2) converge or diverge?
A) Converges
B) Diverges
C) Conditionally converges
D) Absolutely converges
Correct Answer: A

Solution:
This is an example of the ratio test. The limit as n approaches infinity of |((-3)^(n+1) / (n+1)^2)| / |((-3)^n / n^2)| = |-3| < 1, which means the series converges absolutely.

Explanation:
The ratio test is useful for determining convergence when there's a variable base raised to a power and a polynomial in the denominator. If the limit is less than 1, the series converges; if greater than 1, it diverges; and if equal to 1, the test is inconclusive.

Common mistake note:
A common mistake would be to try using the root test instead of the ratio test, which may lead to confusion. The ratio test is more appropriate for this type of series.

Problem 7 (Vbnmm):
Does the series ∑(ln(n) / n^2) converge or diverge?
A) Converges
B) Diverges
C) Conditionally converges
D) Absolutely converges
Correct Answer: A

Solution:
This is an example of the limit comparison test. Compare this series to ∑(1 / n^2), which is a p-series with p = 2 > 1, and thus convergent. The limit as n approaches infinity of (ln(n) / n^2) / (1 / n^2) = ln(n) / 1 approaches 0, so the original series also converges.

Explanation:
The limit comparison test compares the behavior of two series term by term to determine convergence. If the limit is finite and non-zero or infinity, both series either converge or diverge together.

Common mistake note:
A common mistake would be to try using the ratio test directly on the original series, which may lead to difficulty simplifying the expression. The limit comparison test is more straightforward in this case.
