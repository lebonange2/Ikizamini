Problem 1 (Q1):
Evaluate: \(\log_{10}(0.01)\).
A) -2
B) -1
C) 2
D) 0.1
Correct Answer: A

Solution:
Let \(x=\log_{10}(0.01)\). Then \(10^x=0.01\).
Since \(0.01=10^{-2}\), we have \(10^x=10^{-2}\) so \(x=-2\).

Explanation:
A base-10 logarithm asks for the exponent on 10 that produces the given number. Because \(10^{-2}=0.01\), the value is \(-2\).

Common mistake note:
Choosing \(2\) by ignoring that the number is less than 1. Logs of numbers between 0 and 1 are negative.
------------------------------------------------------------------------------

Problem 2 (Q2):
Evaluate: \(\log_{2}(32)\).
A) 4
B) 5
C) 6
D) 32
Correct Answer: B

Solution:
Let \(x=\log_{2}(32)\). Then \(2^x=32\).
Because \(2^5=32\), \(x=5\).

Explanation:
\(\log_2(32)\) is the exponent on 2 needed to get 32, which is 5.

Common mistake note:
Answering 32 by confusing \(\log_b(a)\) with \(a\). The logarithm returns an exponent, not the original number.
------------------------------------------------------------------------------

Problem 3 (Q3):
Evaluate: \(\log_{3}\left(\frac{1}{27}\right)\).
A) -3
B) -1
C) 1
D) 3
Correct Answer: A

Solution:
Let \(x=\log_{3}(\tfrac{1}{27})\). Then \(3^x=\tfrac{1}{27}\).
Since \(27=3^3\), we have \(\tfrac{1}{27}=3^{-3}\). Thus \(3^x=3^{-3}\) so \(x=-3\).

Explanation:
Rewrite the argument as a power of the base: \(\tfrac{1}{27}=3^{-3}\). The logarithm then returns the exponent \(-3\).

Common mistake note:
Choosing \(3\) by using \(\log_3(27)=3\) and forgetting the reciprocal makes the exponent negative.
------------------------------------------------------------------------------

Problem 4 (Q4):
Evaluate: \(\log_{5}(125)\).
A) 2
B) 3
C) 5
D) 25
Correct Answer: B

Solution:
Let \(x=\log_{5}(125)\). Then \(5^x=125\).
Because \(125=5^3\), we get \(x=3\).

Explanation:
Identify 125 as a power of 5: \(5^3=125\). Therefore the log equals 3.

Common mistake note:
Choosing 25 by confusing exponentiation with logarithms (thinking \(\log_5(125)=125/5\)). Logs are not division; they represent exponents.
------------------------------------------------------------------------------

Problem 5 (Q5):
Evaluate: \(\log_{4}(\sqrt{2})\).
A) \(\tfrac{1}{8}\)
B) \(\tfrac{1}{4}\)
C) \(\tfrac{1}{2}\)
D) \(2\)
Correct Answer: B

Solution:
Let \(x=\log_{4}(\sqrt{2})\). Then \(4^x=\sqrt{2}\).
Write everything as powers of 2: \(4=2^2\) and \(\sqrt{2}=2^{1/2}\).
So \((2^2)^x=2^{1/2}\Rightarrow 2^{2x}=2^{1/2}\Rightarrow 2x=\tfrac{1}{2}\Rightarrow x=\tfrac{1}{4}.\)

Explanation:
Converting to a common base (2) allows matching exponents directly, giving \(x=\tfrac{1}{4}\).

Common mistake note:
Choosing \(\tfrac{1}{2}\) by incorrectly assuming \(\log_4(\sqrt{2})=\sqrt{\log_4(2)}\). Logarithms do not distribute over roots that way.
------------------------------------------------------------------------------

Problem 6 (Q6):
Evaluate: \(\log_{3}(81) + \log_{3}(\tfrac{1}{9})\).
A) 0
B) 1
C) 2
D) 3
Correct Answer: C

Solution:
Compute each term:
\(\log_3(81)=\log_3(3^4)=4\).
\(\log_3(\tfrac{1}{9})=\log_3(3^{-2})=-2\).
Sum: \(4+(-2)=2\).

Explanation:
Evaluating each logarithm by rewriting as powers of 3 gives 4 and −2, so the total is 2.

Common mistake note:
Adding the arguments instead (e.g., trying \(\log_3(81+1/9)\)). Log properties combine sums of logs as a product inside a single log, not as a sum of arguments.
------------------------------------------------------------------------------

Problem 7 (Q7):
Evaluate: \(\log_{1/2}(8)\).
A) -3
B) -2
C) 2
D) 3
Correct Answer: A

Solution:
Let \(x=\log_{1/2}(8)\). Then \((\tfrac{1}{2})^x=8\).
Rewrite in base 2: \((\tfrac{1}{2})^x=2^{-x}\) and \(8=2^3\).
So \(2^{-x}=2^3\Rightarrow -x=3\Rightarrow x=-3\).

Explanation:
Because the base is \(\tfrac12\), positive results require negative exponents to produce a number greater than 1. Solving \((1/2)^x=8\) gives \(x=-3\).

Common mistake note:
Choosing \(3\) by treating the base as 2 (confusing \(\log_{1/2}(8)\) with \(\log_2(8)\)). The reciprocal base flips the sign of the exponent.
