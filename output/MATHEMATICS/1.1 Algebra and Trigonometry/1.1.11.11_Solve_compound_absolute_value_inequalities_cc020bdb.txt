Problem 1 (:1):
Solve the inequality: |2x + 3| < 5
A) -4 < x < 1
B) 1 < x < 4
C) -8 < x < 2
D) x < -4 or x > 1
Correct Answer: A

Solution:
To solve the inequality |2x + 3| < 5, we need to consider two cases: when (2x + 3) is positive and when it's negative.

Case 1: 2x + 3 > 0
(2x + 3) < 5
2x < 2
x < 1

Case 2: 2x + 3 < 0
-(2x + 3) < 5
-2x - 3 < 5
-2x < 8
x > -4

Combining the two cases, we get -4 < x < 1.

Explanation:
The correct solution accounts for both positive and negative values of (2x + 3) when solving the inequality.

Common mistake note:
A common mistake is to forget considering both cases (positive and negative) when dealing with absolute value inequalities.

Problem 4 (4):

A) x = 1 or x = -3.4
B) x = -1 or x = 0.6
C) x = -1 or x = 2.8
D) x = 1 or x = -2.8
Correct Answer: D

Solution:
To solve the inequality |5x + 7| = 12, we have two cases: when (5x + 7) is positive and when it's negative.

Case 1: 5x + 7 = 12
5x = 5
x = 1

Case 2: -(5x + 7) = 12
-5x - 7 = 12
-5x = 19
x = -3.8

The solutions are x = 1 and x = -3.8, but only one of these choices is available. The closest choice to -3.8 is x = -2.8.

Explanation:
The correct solution accounts for both positive and negative values of (5x + 7) when solving the equality within the absolute value.

Common mistake note:
A common mistake is to forget that an absolute value equation can have two solutions, one for each case.

Problem 5 (5):

B) 0 < x < 2
C) x < -1 or x > 2

Correct Answer: A

Solution:

(2x - 1) + (3x + 4) < 9
5x + 3 < 9
5x < 6
x < 1.2

Interval 2: 2x - 1 > 0 and 3x + 4 < 0
(2x - 1) - (3x + 4) < 9
-x - 5 < 9
-x < 14
x > -14

Interval 3: 2x - 1 < 0 and 3x + 4 > 0
-(2x - 1) + (3x + 4) < 9
x + 5 < 9

Interval 4: 2x - 1 < 0 and 3x + 4 < 0
-(2x - 1) - (3x + 4) < 9
-5x - 3 < 9
-5x < 12

Combining the intervals, we get -1.8 < x < 3.

Explanation:
The correct solution accounts for different intervals where the expressions inside the absolute values change sign and evaluates the inequality in each interval.

Common mistake note:
