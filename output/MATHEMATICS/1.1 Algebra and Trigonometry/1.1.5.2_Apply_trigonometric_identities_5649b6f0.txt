Problem 1 (:Q1):
Simplify the expression: cos(x) * sin(x)
A) sin(2x)
B) cos(2x)
C) tan(x)
D) cot(x)
Correct Answer: A

Solution:
Using the double angle identity for sine, we know that sin(2x) = 2sin(x)cos(x). Since we have only cos(x) * sin(x), dividing both sides by 2 gives sin(x)cos(x) = 1/2*sin(2x). The simplified expression is sin(2x).

Explanation:
This question assesses the application of the double angle identity for sine.

Common mistake note:
A common mistake would be to select option B (cos(2x)), which relates to the cosine double angle identity. However, it does not match the given expression.

Problem 2 (:Q2):
Prove that: tan(x) = sin(x) / cos(x)
A) Given
B) Identity
C) Derivative
D) Integral
Correct Answer: B

Solution:
The identity tan(x) = sin(x) / cos(x) is a fundamental trigonometric relationship that connects the tangent function to sine and cosine. It can be derived from right triangle definitions or limit definitions of derivatives.

Explanation:
This question evaluates understanding of basic trigonometric identities.

Common mistake note:
A common error might be to choose option A (Given), suggesting it's a fact without proof. However, this identity requires derivation or acceptance as an established relationship between sine and cosine.

Problem 3 (:Q3):
Simplify the expression: 1 + tan^2(x)
A) sec^2(x)
B) csc^2(x)
C) cot^2(x)
D) tan^2(x)
Correct Answer: A

Solution:
Employing the Pythagorean identity for tangent, 1 + tan^2(x) = sec^2(x). This identity arises from the relationship between sine, cosine, and secant in a right triangle.

Explanation:
This question tests application of the Pythagorean identity for tangent.

Common mistake note:
A common error could be to select option C (cot^2(x)), which involves the cotangent function. However, it does not match the given expression.

Problem 4 (:Q4):
Find the exact value of sin(π/6) + cos(π/3):
A) 1
B) √2
C) √3
D) 2
Correct Answer: A

Solution:
sin(π/6) = 1/2 and cos(π/3) = 1/2. Adding these values results in 1/2 + 1/2 = 1.

Explanation:
This question tests recall of exact trigonometric values for common angles.

Common mistake note:
A typical mistake might be to choose option B (√2) or C (√3), which relate to other angle values. However, for π/6 and π/3, sine and cosine values are simple fractions.

Problem 5 (:Q5):
Simplify the expression: sec(x) - 1 / sec(x) + 1
A) tan^2(x)
B) cot^2(x)
C) sin^2(x)
D) cos^2(x)
Correct Answer: A

Solution:
Using the identity (a - 1)/(a + 1) = tan^2(x) for a = sec(x), we get (sec(x) - 1)/(sec(x) + 1) = tan^2(x).

Explanation:
This question assesses application of a trigonometric identity involving secant.

Common mistake note:
A common error could be to choose option B (cot^2(x)), which involves cotangent. However, it does not match the given expression.

Problem 7 (:Q7):
Simplify the expression: cos(2x) in terms of sin(x):
A) 1 - 2sin^2(x)
B) 2cos^2(x) - 1
C) sin^2(x) + cos^2(x)
D) tan^2(x)
Correct Answer: A

Solution:
The double angle identity for cosine gives cos(2x) = 1 - 2sin^2(x). This identity stems from the Pythagorean theorem applied to sine and cosine.

Explanation:
This question tests application of the double angle identity for cosine.

Common mistake note:
A common error could be to choose option B (2cos^2(x) - 1), which relates to the other double angle identity for cosine. However, it does not match the requested simplification in terms of sin(x).
