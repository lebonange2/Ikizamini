Problem 1 (?):
What is the smallest integer value among -3, 0, 2, and 5?
A) -3
B) 0
C) 2
D) 5
Correct Answer: A

Solution:
The smallest integer among the given numbers is -3.

Explanation:
When comparing integers, negative values are smaller than positive or zero values. Thus, -3 is the smallest value in this set.

Common mistake note:
Common mistake: Choosing 0 as the smallest integer. This fails because negative numbers are considered smaller than zero.

Problem 2 (?):
Find the maximum value from the following list of real numbers: 1.5, -2.7, 4.3, and -0.8.
A) 1.5
B) -2.7
C) 4.3
D) -0.8
Correct Answer: C

Solution:
The maximum value is 4.3.

Explanation:
When comparing real numbers, positive values are larger than negative or zero values. Thus, 4.3 is the largest number in this set.

Common mistake note:
Common mistake: Choosing a negative number as the maximum. This fails because negative numbers are considered smaller than positive numbers.

Problem 3 (?):
What is the smallest value among the following fractions: rac{1}{4}, rac{3}{8}, rac{5}{6}, and rac{7}{12}?
A) rac{1}{4}
B) rac{3}{8}
C) rac{5}{6}
D) rac{7}{12}
Correct Answer: A

Solution:
The smallest fraction is rac{1}{4}.

Explanation:
To compare fractions, we can either convert them to like denominators or cross-multiply. Here, rac{1}{4} = 0.25, rac{3}{8} = 0.375, rac{5}{6} = 0.833, and rac{7}{12} ≈ 0.583. Clearly, rac{1}{4} is the smallest.

Common mistake note:
Common mistake: Comparing numerators without considering denominators. This fails because different denominators can result in different relative sizes of fractions.

Problem 4 (?):
Find the minimum value from the set of complex numbers: 2 + 3i, -1 - 4i, 0 + 0i, and 5 + 2i.
A) 2 + 3i
B) -1 - 4i
C) 0 + 0i
D) 5 + 2i
Correct Answer: B

Solution:
The minimum value is -1 - 4i.

Explanation:
When comparing complex numbers, we typically compare their magnitudes. However, for this question, we're looking for the smallest value in terms of real part. Here, -1 is smaller than 0 and 2, so -1 - 4i is the minimum.

Common mistake note:
Common mistake: Comparing only the imaginary parts. This fails because complex numbers are compared based on both their real and imaginary parts.

Problem 5 (?):
What is the maximum value of the function f(x) = x^2 - 2x + 1 for x in the interval [0, 3]?
A) 0
B) 1
C) 2
D) 4
Correct Answer: D

Solution:
The maximum value is 4.

Explanation:
To find the maximum value of a quadratic function in an interval, we can use calculus or complete the square. Here, f(x) = (x - 1)^2. Since x is between 0 and 3, the minimum occurs at x = 1, so the maximum must occur at one of the endpoints. Evaluating f(0) and f(3), we get 1 and 4, respectively. Thus, the maximum is 4.

Common mistake note:
Common mistake: Choosing the vertex as the maximum value. This fails because the vertex represents the minimum or maximum for continuous functions, but not necessarily at the endpoints of an interval.

Problem 6 (?):
Find the smallest absolute value among the following numbers: -7, 3, 0, and 5.
A) -7
B) 3
C) 0
D) 5
Correct Answer: C

Solution:
The smallest absolute value is 0.

Explanation:
The absolute value of a number represents its distance from zero on the number line. Thus, 0 has the smallest distance (it's already at zero), making it the smallest absolute value in this set.

Common mistake note:
Common mistake: Choosing a negative number as the smallest absolute value. This fails because the absolute value of a negative number is always positive and thus larger than 0.

Problem 7 (?):
What is the maximum value of the function g(x) = 3sin(x) on the interval [0, π]?
A) -3
B) -1
C) 0
D) 3
Correct Answer: D

Solution:
The maximum value is 3.

Explanation:
The sine function has a range of [-1, 1]. When multiplied by 3, the range becomes [-3, 3]. Since x ranges from 0 to π on the interval, the maximum value occurs at x = π/2, where sin(π/2) = 1. Thus, multiplying by 3 gives us a maximum of 3.

Common mistake note:
Common mistake: Choosing -3 as the maximum value. This fails because the function is multiplied by 3, which changes the range to positive values only.
