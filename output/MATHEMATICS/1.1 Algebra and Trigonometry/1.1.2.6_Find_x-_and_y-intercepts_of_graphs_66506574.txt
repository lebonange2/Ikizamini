Problem 1 (Q1):
Find the x-intercept of the line given by the equation \(3x + 4y = 12\).
A) \(x = 4\)
B) \(x = 3\)
C) \(x = 0\)
D) \(x = -3\)
Correct Answer: A

Solution:
To find the x-intercept, set \(y = 0\) in the equation: \(3x + 4(0) = 12\). Simplifying gives \(3x = 12\), hence \(x = 4\).

Explanation:
The x-intercept occurs where the line crosses the x-axis, which is when \(y = 0\). Substitute \(y = 0\) into the equation and solve for \(x\).

Common mistake note:
A common mistake is setting \(x = 0\) instead of \(y = 0\) to find the x-intercept, leading to confusion.

Problem 2 (Q2):
What is the y-intercept of the line \(y = 5x - 7\)?
A) \(y = 5\)
B) \(y = -7\)
C) \(y = 0\)
D) \(y = 7\)
Correct Answer: B

Solution:
To find the y-intercept, set \(x = 0\): \(y = 5(0) - 7 = -7\). So the y-intercept is \(y = -7\).

Explanation:
The y-intercept is the value of \(y\) when \(x = 0\). Substitute \(x = 0\) into the equation to find \(y\).

Common mistake note:
A common mistake is substituting \(y = 0\) instead of \(x = 0\), which instead calculates the x-intercept.
------------------------------------------------------------------------------

Problem 3 (Q3):
For the graph of the equation \(2x - y = 6\), determine the y-intercept.
A) \(y = 6\)
B) \(y = -6\)
C) \(y = 2\)
D) \(y = -2\)
Correct Answer: B

Solution:
Set \(x = 0\): \(2(0) - y = 6\), which simplifies to \(-y = 6\), so \(y = -6\).

Explanation:
Find the y-intercept by setting \(x = 0\) and solving for \(y\).

Common mistake note:
Forgetting to change the sign when solving \(-y = 6\) can lead to incorrect answers.
------------------------------------------------------------------------------

Problem 4 (Q4):
Calculate the x-intercept for the equation \(4x + 5y = 20\).
A) \(x = 5\)
B) \(x = 4\)
C) \(x = -4\)
D) \(x = 0\)
Correct Answer: A

Solution:
Set \(y = 0\) in the equation: \(4x + 5(0) = 20\), thus \(4x = 20\), hence \(x = 5\).

Explanation:
For the x-intercept, set \(y = 0\) and solve the equation for \(x\).

Common mistake note:
Incorrectly solving \(4x + 5y = 20\) when \(x = 0\) instead leads to finding the y-intercept.

Problem 5 (Q5):
If the equation of a line is \(x + 2y = 8\), what is its x-intercept?
A) \(x = 8\)
B) \(x = 4\)
C) \(x = 5\)
D) \(x = 2\)
Correct Answer: A

Solution:
For the x-intercept, set \(y = 0\): \(x + 2(0) = 8\), thus \(x = 8\).

Explanation:
The x-intercept is found by setting \(y = 0\) and solving for \(x\).

Common mistake note:
Mistakenly setting \(x = 0\) would lead to calculating the y-intercept instead.

Problem 6 (Q6):
Given the line \(3x - 2y = 9\), what is the value of the y-intercept?
A) \(y = 9\)
B) \(y = -9\)
C) \(y = \frac{9}{2}\)
D) \(y = -\frac{9}{2}\)
Correct Answer: C

Solution:
To find the y-intercept, set \(x = 0\): \(3(0) - 2y = 9\), leading to \(-2y = 9\) thus \(y = \frac{9}{2}\).

Explanation:
By setting \(x = 0\), we solve for \(y\) to determine the y-intercept.

Common mistake note:
Failing to handle division by negative two correctly when solving can result in wrong answers.
------------------------------------------------------------------------------

Problem 7 (Q7):
Determine the y-intercept for the line \(y = -4x + 3\).
A) \(y = 3\)
B) \(y = -4\)
C) \(y = -3\)
D) \(y = 4\)
Correct Answer: A

Solution:
For the y-intercept, set \(x = 0\): \(y = -4(0) + 3 = 3\). So the y-intercept is \(y = 3\).

Explanation:
The y-intercept can be found by replacing \(x\) with zero in the equation, leaving only the constant term.

Common mistake note:
Misreading the formula may lead someone to incorrectly choose the coefficient of \(x\) rather than the constant.
