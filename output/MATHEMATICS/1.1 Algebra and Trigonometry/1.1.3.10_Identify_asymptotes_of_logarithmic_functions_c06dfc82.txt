Problem 1 (Q1):
Identify the vertical asymptote of the function \(f(x)=\log_2(x-5)\).
A) \(x=0\)
B) \(x=5\)
C) \(y=5\)
D) \(y=0\)
Correct Answer: B

Solution:
Set the logarithm’s argument to 0: \(x-5=0\Rightarrow x=5\).

Explanation:
A logarithmic function has a vertical asymptote where its argument approaches \(0^+\). Here, as \(x\to 5^+\), \(x-5\to 0^+\) and \(\log_2(x-5)\to -\infty\), so the vertical asymptote is \(x=5\).

Common mistake note:
Forgetting the horizontal shift and choosing \(x=0\). The parent \(\log_2(x)\) has asymptote \(x=0\), but \(x-5\) shifts it to \(x=5\).

Problem 2 (Q2):
Find the vertical asymptote of \(g(x)=\ln(3x+6)\).
A) \(x=-2\)
B) \(x=2\)
C) \(y=-2\)
D) \(y=0\)
Correct Answer: A

Solution:
Set the argument to 0: \(3x+6=0\Rightarrow x=-2\).

Explanation:
The domain requires \(3x+6>0\). The boundary occurs at \(x=-2\). As \(x\to -2^+\), \(3x+6\to 0^+\) and \(\ln(3x+6)\to -\infty\), giving a vertical asymptote at \(x=-2\).

Common mistake note:
Sign errors when solving \(3x+6=0\). Also, the asymptote is vertical (an \(x=\) line), not horizontal.
------------------------------------------------------------------------------

Problem 3 (Q3):
Determine the vertical asymptote of \(h(x)=\log_{10}(7-2x)\).
A) \(x=\tfrac{7}{2}\)
B) \(x=-\tfrac{7}{2}\)
C) \(y=\tfrac{7}{2}\)
D) No asymptote
Correct Answer: A

Solution:
Set the argument to 0: \(7-2x=0\Rightarrow x=\tfrac{7}{2}\).

Explanation:
Logs are defined only when the argument is positive. Here the domain is \(7-2x>0\Rightarrow x<\tfrac{7}{2}\). As \(x\to (7/2)^-\), \(7-2x\to 0^+\) and \(\log_{10}(7-2x)\to -\infty\), so the vertical asymptote is \(x=\tfrac{7}{2}\).

Common mistake note:
Choosing \(-\tfrac{7}{2}\) due to moving terms incorrectly. Solve \(7=2x\) to get \(x=\tfrac{7}{2}\).
------------------------------------------------------------------------------

Problem 4 (Q4):
Identify the vertical asymptote of \(p(x)=\log_5\big((x+1)^2\big)\).
A) \(x=-1\)
B) \(x=1\)
C) \(y=-1\)
D) There is no vertical asymptote because the square makes the argument nonnegative.
Correct Answer: A

Solution:
Set the argument to 0: \((x+1)^2=0\Rightarrow x=-1\).

Explanation:
Even though \((x+1)^2\ge 0\), a logarithm requires the argument be strictly positive, not merely nonnegative. As \(x\to -1\) (from either side), \((x+1)^2\to 0^+\) and \(\log_5((x+1)^2)\to -\infty\), so there is a vertical asymptote at \(x=-1\).

Common mistake note:
Thinking the square removes the issue. Squaring prevents negative values but still allows 0, and \(\log(0)\) is undefined (tends to \(-\infty\)).

Problem 5 (Q5):
Find the vertical asymptote of \(f(x)=2-\ln(x-4)\).
A) \(x=4\)
B) \(x=-4\)
C) \(y=2\)
D) \(y=-\infty\)
Correct Answer: A

Solution:
Set the ln argument to 0: \(x-4=0\Rightarrow x=4\).

Explanation:
Vertical asymptotes for logarithmic functions come from where the argument approaches \(0^+\). Adding/subtracting outside the log (like the \(+2\)) or multiplying by \(-1\) does not change the input value where the log’s argument is 0. Thus the vertical asymptote is \(x=4\).

Common mistake note:
Choosing \(y=2\) due to the vertical shift. Logarithmic asymptotes here are vertical lines determined by the log’s argument, not by outside shifts.

Problem 6 (Q6):
Determine the vertical asymptote(s) of \(q(x)=\log_3\left(\dfrac{x+2}{x-1}\right)\).
A) \(x=-2\) only
B) \(x=1\) only
C) \(x=-2\) and \(x=1\)
D) No vertical asymptote
Correct Answer: C

Solution:
First find where the log argument is positive: \(\frac{x+2}{x-1}>0\) gives intervals \(( -\infty,-2)\cup(1,\infty)\). Vertical asymptotes occur at domain boundaries where the argument \(\to 0^+\) or \(\to +\infty\) when approached from within the domain. As \(x\to -2^-\), \(\frac{x+2}{x-1}\to 0^+\) so \(\log_3\to -\infty\), giving \(x=-2\). As \(x\to 1^+\), \(\frac{x+2}{x-1}\to +\infty\) so \(\log_3\to +\infty\), giving \(x=1\).

Explanation:
A vertical asymptote can occur even if the function is only defined on one side of the boundary: it is enough that, from within the domain, the function values grow without bound. Here the domain is \(( -\infty,-2)\cup(1,\infty)\). Approaching \(x=-2\) from the left stays in the domain and forces the argument to \(0^+\), while approaching \(x=1\) from the right stays in the domain and forces the argument to \(+\infty\). Both produce unbounded logarithm values, so both \(x=-2\) and \(x=1\) are vertical asymptotes.

Common mistake note:
Requiring a two-sided approach for a vertical asymptote. For restricted domains (like rational expressions inside logs), one-sided approach from within the domain is sufficient (here, \(-2\) from the left and \(1\) from the right).

Problem 7 (Q7):
Identify the vertical asymptote(s) of \(r(x)=\log_2\big(x^2-9\big)\).
A) \(x=0\)
B) \(x=3\) only
C) \(x=-3\) and \(x=3\)
D) No vertical asymptotes
Correct Answer: C

Solution:
Set the argument to 0: \(x^2-9=0\Rightarrow (x-3)(x+3)=0\Rightarrow x=3\) or \(x=-3\).

Explanation:
The domain is \(x^2-9>0\Rightarrow |x|>3\). As \(x\to 3^+\) or \(x\to (-3)^-\) (approaching from within the domain), \(x^2-9\to 0^+\) and \(\log_2(x^2-9)\to -\infty\). Therefore, there are vertical asymptotes at \(x=-3\) and \(x=3\).

Common mistake note:
Keeping only \(x=3\) and forgetting \(x=-3\). Both zeros of the log’s argument create vertical asymptotes when they can be approached from within the domain.
