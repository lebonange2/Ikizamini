Problem 1 (Q1):
Solve the inequality: \(3x + 2y > 6\). Which of the following points is a solution?
A) (0, 2)
B) (1, 1)
C) (2, 1)
D) (0, 0)
Correct Answer: C

Solution:
Substitute each point into the inequality: \(3x + 2y > 6\). For point (2, 1): \(3(2) + 2(1) = 8\), satisfying the condition as 8 > 6.

Explanation:
Substitute x and y into the inequality to check if the condition is satisfied.

Common mistake note:
Choosing (0, 2) mistakenly assumes \(4 > 6\) after substitution.
------------------------------------------------------------------------------

Problem 2 (Q2):
Determine which region satisfies the inequality: \(x - 4y \leq 8\).
A) Above the line \(x = 4y + 8\)
B) Below the line \(x = 4y + 8\)
C) Exactly on the line \(x = 4y + 8\)
D) On the line when \(x > 8\)
Correct Answer: B

Solution:
Rewrite inequality as \(x \leq 4y + 8\). This represents the area below the line \(x = 4y + 8\).

Explanation:
The inequality suggests regions below or on the boundary line.

Common mistake note:
Misinterpretation of inequality signs often happens.

Problem 3 (Q3):
Identify which point is not a solution to \(2x - 3y < 9\).
A) (5, 0)
B) (3, 3)
C) (0, 3)
D) (2, 2)
Correct Answer: B

Solution:
Substitute point (3, 3) into \(2x - 3y\): \(2(3) - 3(3) = -3\), which is not \(< 9\).

Explanation:
Check each point by plugging into the inequality to find one that doesn't satisfy \(< 9\).

Common mistake note:
Incorrectly computing arithmetic within substituted values leads to errors.
------------------------------------------------------------------------------

Problem 4 (Q4):
For the inequality \(y \geq \frac{1}{2}x - 1\), what is the y-intercept?
A) -2
B) -1
C) 1
D) 0
Correct Answer: B

Solution:
Set \(x=0\) to find: \(y \geq \frac{1}{2}(0) - 1 = -1\). Therefore, the y-intercept is -1.

Explanation:
Y-intercept found by substituting \(x=0\) into \(y\) equation form.

Common mistake note:
Confusing setting \(x\) vs. \(y\) to zero affects finding intercepts.
------------------------------------------------------------------------------

Problem 5 (Q5):
Which statement is true for the inequality \(-3x + y < 7\)?
A) The inequality is equal when \(x = 0\)
B) The inequality holds for all positive x and y
C) The line \(-3x + y = 7\) forms boundary with all solutions below it
D) When x increases, y must also increase for the inequality to hold
Correct Answer: C

Solution:
Graph \(-3x + y = 7\); points below satisfy \(-3x + y < 7\).

Explanation:
Line describes boundary, and points below satisfy inequality.

Common mistake note:
Misunderstanding spatial placement relative to the boundary can cause incorrect answers.

Problem 6 (Q6):
Consider the inequality \(y < 2x + 3\). What happens to the inequality if it is multiplied through by \(-1\)?
A) It becomes \(-y < 2x + 3\)
B) The direction of the inequality changes
C) It becomes \(y < -2x - 3\)
D) It becomes \(-y > -2x - 3\)
Correct Answer: D

Solution:
Multiplying by \(-1\) reverses the inequality direction: \(-y > -2x - 3\).

Explanation:
Inequality reversal occurs when multiplied by a negative number.

Common mistake note:
Often neglecting to switch inequality direction results in incorrect solutions.

Problem 7 (Q7):
Find the slope of the boundary line for the inequality \(4x + 5y \leq 20\).
A) -4/5
B) 4/5
C) 5/4
D) -5/4
Correct Answer: A

Solution:
Convert \(4x + 5y = 20\) to slope-intercept form: \(y = -\frac{4}{5}x + 4\), revealing slope \(-4/5\).

Explanation:
Reform into \(y = mx + b\) to clearly identify slope \(m\).

Common mistake note:
Errors arise by misarranging or missing negative signs in conversions.
