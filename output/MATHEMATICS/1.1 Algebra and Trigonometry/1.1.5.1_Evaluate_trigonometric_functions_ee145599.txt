Problem 1 (:1):
Find the value of sin(π/6):
A) 0.5
B) 1
C) 0.8
D) 1.5
Correct Answer: A

Solution:
The sine function at π/6 (or 30°) is equal to 1/2 or 0.5.

Explanation:
sin(π/6) = 1/2

Common mistake note:
Common mistake: Choosing B (1), which is the value of cos(π/6) instead of sin(π/6).
------------------------------------------------------------------------------

Problem 2 (:2):
What is the value of cos(π)?
A) 0
B) 1
C) -1
D) 0.5
Correct Answer: C

Solution:
The cosine function at π is equal to -1.

Explanation:
cos(π) = -1

Common mistake note:
Common mistake: Choosing B (1), which is the value of cos(0).
------------------------------------------------------------------------------

Problem 3 (:3):
Simplify tan(π/4):
A) 0
B) 1
C) -1
D) undefined
Correct Answer: B

Solution:
The tangent function at π/4 (or 45°) is equal to 1.

Explanation:
tan(π/4) = 1

Common mistake note:
Common mistake: Choosing D (undefined), which is the value of tan(π/2).
------------------------------------------------------------------------------

Problem 4 (:4):
Find the value of cot(π/3):
A) √3
B) 1/√3
C) 1
D) 0
Correct Answer: B

Solution:
The cotangent function at π/3 (or 60°) is equal to 1/√3.

Explanation:
cot(π/3) = 1/√3

Common mistake note:
Common mistake: Choosing A (√3), which is the value of tan(π/3).
------------------------------------------------------------------------------

Problem 5 (:5):
Evaluate sec(-π/2):
A) 0
B) 1
C) -1
D) undefined
Correct Answer: D

Solution:
The secant function is undefined at -π/2.

Explanation:
sec(-π/2) = undefined (dividing by zero)

Common mistake note:
Common mistake: Choosing C (-1), which is the value of cos(-π/2).
------------------------------------------------------------------------------

Problem 6 (:6):
Find the value of csc(3π):
A) 1
B) -1
C) 0
D) undefined
Correct Answer: A

Solution:
The cosecant function at 3π is equal to 1.

Explanation:
csc(3π) = 1 (since sin(3π) = 0, csc is the reciprocal of sin)

Common mistake note:
Common mistake: Choosing D (undefined), which would be correct for sec(-π/2) but not for csc(3π).
------------------------------------------------------------------------------

Problem 7 (:7):
Simplify the expression cos(2x) when x = π/4:
A) -1
B) 0
C) 1
D) √2/2
Correct Answer: D

Solution:
The cosine of twice an angle is equal to 1 - 2sin^2(x). Plugging in x = π/4, we get cos(π/2) = 1 - 2(1/2)^2 = 1 - 1/2 = 1/2 or √2/2.

Explanation:
cos(2x) = 1 - 2sin^2(x), where x = π/4: cos(π/2) = 1 - 2(1/2)^2 = 1/2

Common mistake note:
Common mistake: Choosing C (1), which is the value of cos(0) and not for this specific case when x = π/4.
