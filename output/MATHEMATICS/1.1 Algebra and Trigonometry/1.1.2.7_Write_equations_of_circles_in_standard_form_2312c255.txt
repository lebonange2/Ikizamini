Problem 1 (Q1):
Write the equation of the circle with center (3, -2) and radius 5 in standard form.
A) (x - 3)^2 + (y + 2)^2 = 25
B) (x + 3)^2 + (y - 2)^2 = 25
C) (x - 3)^2 + (y - 2)^2 = 5
D) (x + 3)^2 + (y + 2)^2 = 5
Correct Answer: A

Solution:
Standard form: (x - h)^2 + (y - k)^2 = r^2. Here h=3, k=-2, r=5, so (x - 3)^2 + (y - (-2))^2 = 5^2 → (x - 3)^2 + (y + 2)^2 = 25.

Explanation:
In standard form, the center is (h,k) and the radius is r. Substitute h=3 and k=-2, and square the radius: r^2=25.

Common mistake note:
A common mistake is using (y - 2)^2 instead of (y + 2)^2 by forgetting that k=-2, so y - k = y - (-2) = y + 2.

Problem 2 (Q2):
Convert the circle equation x^2 + y^2 - 6x + 8y = 0 into standard form.
A) (x - 3)^2 + (y + 4)^2 = 25
B) (x + 3)^2 + (y - 4)^2 = 25
C) (x - 6)^2 + (y + 8)^2 = 0
D) (x - 3)^2 + (y + 4)^2 = 5
Correct Answer: A

Solution:
Group and complete squares:
(x^2 - 6x) + (y^2 + 8y) = 0
(x^2 - 6x + 9) + (y^2 + 8y + 16) = 0 + 9 + 16
(x - 3)^2 + (y + 4)^2 = 25.

Explanation:
Completing the square turns each quadratic expression into a perfect square trinomial. The constants added to complete squares must be added to the other side as well.

Common mistake note:
A common mistake is completing the square but forgetting to add the same constants (9 and 16) to the right-hand side, leading to an incorrect radius.
------------------------------------------------------------------------------

Problem 3 (Q3):
A circle has endpoints of a diameter at A(-2, 1) and B(6, 5). Write its equation in standard form.
A) (x - 2)^2 + (y - 3)^2 = 20
B) (x + 2)^2 + (y - 1)^2 = 20
C) (x - 2)^2 + (y - 3)^2 = 10
D) (x - 4)^2 + (y - 2)^2 = 20
Correct Answer: A

Solution:
Center is midpoint of diameter: ((-2+6)/2, (1+5)/2) = (2, 3).
Diameter length: AB = √((6-(-2))^2 + (5-1)^2) = √(8^2 + 4^2) = √80.
Radius r = √80 / 2 = √20.
So r^2 = 20, equation: (x - 2)^2 + (y - 3)^2 = 20.

Explanation:
The center is the midpoint of the diameter endpoints. The radius is half the distance between them; squaring the radius gives the right side of standard form.

Common mistake note:
A common mistake is using the full distance √80 as the radius (instead of halving it), which would incorrectly give r^2 = 80.
------------------------------------------------------------------------------

Problem 4 (Q4):
Write the equation of the circle in standard form: x^2 + y^2 + 4x - 10y + 13 = 0.
A) (x + 2)^2 + (y - 5)^2 = 16
B) (x - 2)^2 + (y + 5)^2 = 16
C) (x + 2)^2 + (y - 5)^2 = 4
D) (x - 2)^2 + (y - 5)^2 = 16
Correct Answer: A

Solution:
Move constant: x^2 + 4x + y^2 - 10y = -13.
Complete squares:
(x^2 + 4x + 4) + (y^2 - 10y + 25) = -13 + 4 + 25
(x + 2)^2 + (y - 5)^2 = 16.

Explanation:
For x^2+4x, add (4/2)^2=4. For y^2-10y, add (-10/2)^2=25. Add both to the right side to keep equality.

Common mistake note:
A common mistake is getting the center signs wrong, e.g., writing (y + 5)^2 from -10y; since y^2 - 10y completes to (y - 5)^2, the center’s y-coordinate is +5.
------------------------------------------------------------------------------

Problem 5 (Q5):
A circle has center (-1, 4) and passes through the point (2, 8). Write its equation in standard form.
A) (x + 1)^2 + (y - 4)^2 = 25
B) (x - 1)^2 + (y + 4)^2 = 25
C) (x + 1)^2 + (y - 4)^2 = 5
D) (x + 2)^2 + (y - 8)^2 = 25
Correct Answer: A

Solution:
Standard form: (x - h)^2 + (y - k)^2 = r^2 with (h,k)=(-1,4).
Compute r^2 using distance squared from center to point:
r^2 = (2 - (-1))^2 + (8 - 4)^2 = 3^2 + 4^2 = 25.
So (x + 1)^2 + (y - 4)^2 = 25.

Explanation:
When given a point on the circle, the radius is the distance from the center to that point. Using distance squared directly gives r^2.

Common mistake note:
A common mistake is computing r = 5 correctly but then putting 5 on the right side instead of r^2, yielding ... = 5 rather than ... = 25.

Problem 6 (Q6):
Write the equation of the circle in standard form: x^2 + y^2 - 2x + 12y + 20 = 0.
A) (x - 1)^2 + (y + 6)^2 = 17
B) (x + 1)^2 + (y - 6)^2 = 17
C) (x - 1)^2 + (y + 6)^2 = 57
D) (x - 2)^2 + (y + 12)^2 = 20
Correct Answer: A

Solution:
Group: (x^2 - 2x) + (y^2 + 12y) = -20.
Complete squares:
(x^2 - 2x + 1) + (y^2 + 12y + 36) = -20 + 1 + 36
(x - 1)^2 + (y + 6)^2 = 17.

Explanation:
Add (−2/2)^2=1 to complete the x-square and (12/2)^2=36 to complete the y-square; the right side becomes -20+37=17.

Common mistake note:
A common mistake is moving +20 incorrectly (e.g., leaving it on the left), which causes the right side to be wrong and can even produce a negative r^2.

Problem 7 (Q7):
The circle is tangent to the x-axis at the point (4, 0) and has center at (4, 3). Write its equation in standard form.
A) (x - 4)^2 + (y - 3)^2 = 9
B) (x - 4)^2 + (y - 3)^2 = 3
C) (x + 4)^2 + (y - 3)^2 = 9
D) (x - 3)^2 + (y - 4)^2 = 9
Correct Answer: A

Solution:
Standard form: (x - h)^2 + (y - k)^2 = r^2 with center (h,k)=(4,3).
Tangent to x-axis at y=0 means radius is vertical distance from center to x-axis: r = |3 - 0| = 3, so r^2=9.
Equation: (x - 4)^2 + (y - 3)^2 = 9.

Explanation:
A circle tangent to the x-axis has radius equal to the center’s distance to the x-axis (the absolute value of the y-coordinate).

Common mistake note:
A common mistake is using r=3 but writing r^2=3 on the right side, forgetting to square the radius in standard form.
