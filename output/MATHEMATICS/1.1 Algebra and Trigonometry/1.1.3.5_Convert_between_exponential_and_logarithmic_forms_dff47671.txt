Problem 1 (Q1):
Convert the exponential equation to logarithmic form: 3^4 = 81.
A) log_3(81) = 4
B) log_4(3) = 81
C) log_81(3) = 4
D) log_3(4) = 81
Correct Answer: A

Solution:
Use a^b = c ⇔ log_a(c) = b. Here 3^4 = 81, so log_3(81) = 4.

Explanation:
In exponential form, the base is 3, the result is 81, and the exponent is 4. The logarithmic form keeps base 3 and sets the logarithm equal to the exponent: log_3(81) = 4.

Common mistake note:
A common mistake is swapping the base and the result (e.g., writing log_81(3) = 4). That would correspond to 81^4 = 3, which is false.

Problem 2 (Q2):
Convert the logarithmic equation to exponential form: log_5(125) = 3.
A) 3^5 = 125
B) 5^3 = 125
C) 125^3 = 5
D) 5^125 = 3
Correct Answer: B

Solution:
Use log_a(c) = b ⇔ a^b = c. Here a = 5, b = 3, c = 125, so 5^3 = 125.

Explanation:
The base of the log is 5 and the log equals 3, meaning 5 raised to 3 gives 125.

Common mistake note:
A common mistake is reversing the exponent and base to get 3^5 = 125; this misreads the meaning of log_5(125) = 3.
------------------------------------------------------------------------------

Problem 3 (Q3):
Which logarithmic equation is equivalent to 10^(-2) = 0.01?
A) log_10(0.01) = -2
B) log_0.01(10) = -2
C) log_-2(10) = 0.01
D) log_10(-2) = 0.01
Correct Answer: A

Solution:
Use a^b = c ⇔ log_a(c) = b. Here 10^(-2) = 0.01, so log_10(0.01) = -2.

Explanation:
The base is 10, the result is 0.01, and the exponent is -2; the logarithmic form keeps base 10 and equals the exponent.

Common mistake note:
A common mistake is to swap base and argument and write log_0.01(10) = -2; that would mean 0.01^(-2) = 10, but 0.01^(-2) = 10000, not 10.

Problem 4 (Q4):
Convert the equation log_2(1/8) = -3 to exponential form.
A) 2^(1/8) = -3
B) (-3)^2 = 1/8
C) 2^(-3) = 1/8
D) (1/8)^2 = -3
Correct Answer: C

Solution:
Use log_a(c) = b ⇔ a^b = c. Here a = 2, b = -3, c = 1/8, so 2^(-3) = 1/8.

Explanation:
A logarithm equal to -3 indicates a negative exponent on base 2, producing the fraction 1/8.

Common mistake note:
A common mistake is to place the fraction as the exponent (2^(1/8) = -3), confusing the log argument with the exponent; the argument corresponds to the result, not the power.
------------------------------------------------------------------------------

Problem 5 (Q5):
Which exponential equation is equivalent to log_7(49) = 2?
A) 7^49 = 2
B) 49^7 = 2
C) 7^2 = 49
D) 2^7 = 49
Correct Answer: C

Solution:
Use log_a(c) = b ⇔ a^b = c. Here a = 7, b = 2, c = 49, so 7^2 = 49.

Explanation:
The base of the logarithm becomes the base of the exponential, and the logarithm value becomes the exponent.

Common mistake note:
A common mistake is to treat the log argument (49) as the exponent and write 7^49 = 2; that does not match the definition of logarithms.

Problem 6 (Q6):
Convert the exponential equation (1/3)^(-2) = 9 to logarithmic form.
A) log_(1/3)(9) = -2
B) log_9(1/3) = -2
C) log_(1/3)(-2) = 9
D) log_(-2)(1/3) = 9
Correct Answer: A

Solution:
Use a^b = c ⇔ log_a(c) = b. Here a = 1/3, b = -2, c = 9, so log_(1/3)(9) = -2.

Explanation:
Even with fractions and negative exponents, the conversion rule is the same: the log base is 1/3, the log argument is 9, and the log equals -2.

Common mistake note:
A common mistake is to swap base and argument (log_9(1/3) = -2). That would mean 9^(-2) = 1/3, but 9^(-2) = 1/81.

Problem 7 (Q7):
A student writes: log_4(64) = 4. Which exponential equation matches the student's statement?
A) 4^64 = 4
B) 4^4 = 64
C) 64^4 = 4
D) 64^4 = 16
Correct Answer: B

Solution:
Use log_a(c) = b ⇔ a^b = c. Here a = 4, c = 64, b = 4, so 4^4 = 64.

Explanation:
The logarithmic equation says the exponent needed on base 4 to get 64 is 4; that translates directly to 4^4 = 64.

Common mistake note:
A common mistake is to put the argument as the exponent (4^64 = 4), confusing c with b. In log form, the argument is the result, not the exponent.
