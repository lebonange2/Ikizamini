Problem 1 (One):
Given the function f(x) = |2x - 3|, what is the simplified form of f(x + 1)?
A) |2x - 5|
B) |2x - 1|
C) |4x - 6|
D) |2x + 1|
Correct Answer: B

Solution:
The function f(x) is shifted to the left by 1 unit, which means we replace x with (x + 1) inside the absolute value. So, f(x + 1) = |2(x + 1) - 3| = |2x + 2 - 3| = |2x - 1|. Since the coefficient of x inside the absolute value is positive (2), shifting left does not change the sign of the expression inside the absolute value. Thus, the correct answer is |2x - 1|.

Explanation:
When transforming an absolute value function by a horizontal shift, replace x with (x + h) or (x - h). The sign within the absolute value remains unchanged if the coefficient of x is positive.

Common mistake note:
A common mistake is to incorrectly change the sign inside the absolute value when shifting. Remember that only the position of the 'breakpoint' changes, not the signs within the absolute value.

Problem 2 (Two):
Given f(x) = |3x + 6| - 2, find the simplified form of f(-2x).
A) |-6x - 12| - 4
B) |6x + 12| - 2
C) |6x - 12| - 4
D) |-6x - 12| + 2
Correct Answer: A

Solution:
To find f(-2x), substitute -2x for x in the original function: f(-2x) = |3(-2x) + 6| - 2 = |-6x + 6| - 2. Since the absolute value of -6x + 6 is |-6(x - 1)|, and the absolute value of a negative number changes to its positive equivalent, we have |6 - 6x| - 2. Finally, multiplying the coefficient outside the absolute value by -2 gives us |-6(6 - x)| - 2 = |-6x + 6| - 2 = |-6x - 12| - 4.

Explanation:
When substituting a linear expression like -2x for x, distribute any coefficients. This can change the sign of the expression inside the absolute value if the coefficient of x is negative.

Common mistake note:
A common mistake is to forget that multiplying a linear expression by -1 changes signs within the absolute value. Remember to distribute when substituting -2x for x.

Problem 3 (Three):
Given f(x) = |4 - 3|x||, what is the simplified form of f(2x)?
A) |8 - 6|x||
B) |8 - 3|x||
C) |16 - 3|x||
D) |-8 + 6|x||
Correct Answer: B

Solution:
To find f(2x), substitute 2x for x in the original function: f(2x) = |4 - 3|2x||. Since the absolute value of 2x is |2(x)|, which simplifies to |2x|, we have |4 - 3|2x|| = |4 - 6|x||. Now, distribute the -3 across the absolute value: f(2x) = |4 - 18x| = |8 - 3|x||. Thus, the simplified form is |8 - 3|x||.

Explanation:
When substituting a linear expression like 2x for x, distribute any coefficients outside the absolute value across the entire expression inside the absolute value.

Common mistake note:
A common mistake is to forget to distribute the coefficient of x when substituting 2x for x. Remember to distribute -3 across |2x|.

Problem 4 (Four):
Given f(x) = |x + 1| + |x - 2|, find the simplified form of f(-x).
A) |-x + 1| + |-x - 2|
B) |-x + 1| + |x + 2|
C) |x - 1| + |-x - 2|
D) |x - 1| + |x + 2|
Correct Answer: A

Solution:
To find f(-x), substitute -x for x in the original function: f(-x) = |-x + 1| + |-x - 2|. Since absolute values are unchanged when their contents are negated, both parts of the expression remain the same. Therefore, f(-x) is equal to |-x + 1| + |-x - 2|.

Explanation:
When substituting -x for x in an absolute value function with two separate terms, each term will have its sign flipped inside the absolute value. However, since the absolute value function disregards the sign of its contents, the expressions inside remain unchanged.

Common mistake note:
A common mistake is to think that the signs inside the absolute values change when substituting -x for x. Remember that the absolute value function only cares about the magnitude of its contents.

Problem 5 (Five):
Given f(x) = |2x| + 3, find the simplified form of f(-2x).
A) |-4x| + 3
B) |4x| + 3
C) |-4x| - 3
D) |4x| - 3
Correct Answer: A

Solution:
To find f(-2x), substitute -2x for x in the original function: f(-2x) = |2(-2x)| + 3. Since multiplying a negative number by another negative number results in a positive product, we have |-4x| + 3. Thus, the simplified form is |-4x| + 3.

Explanation:
When substituting a linear expression like -2x for x, consider the effect of multiplication. This can change the sign of the expression inside the absolute value if the coefficient of x is negative.

Common mistake note:
A common mistake is to forget that multiplying a linear expression by -1 changes signs within the absolute value. Remember to distribute when substituting -2x for x.

Problem 6 (Six):
Given f(x) = |3x| - 5, find the simplified form of f(1/3x).
A) |x| - 5
B) |3x| - 15
C) |x| - 15
D) |9x| - 5
Correct Answer: A

Solution:
To find f(1/3x), substitute 1/3x for x in the original function: f(1/3x) = |3(1/3x)| - 5. Simplifying inside the absolute value gives us |x| - 5. Thus, the simplified form is |x| - 5.

Explanation:
When substituting a linear expression like 1/3x for x, distribute any coefficients outside the absolute value across the entire expression inside the absolute value. In this case, since the coefficient is 1/3, it cancels out with the 3 inside the absolute value.

Common mistake note:
A common mistake is to forget to cancel out the coefficient of x when substituting 1/3x for x. Remember to distribute 1/3 across |3x|.

Problem 7 (Seven):
Given f(x) = |2x - 4|, find the simplified form of f(2x + 2).
A) |4x - 8|
B) |4x| - 8
C) |4x - 12|
D) |-4x - 8|
Correct Answer: C

Solution:
To find f(2x + 2), substitute 2x + 2 for x in the original function: f(2x + 2) = |2(2x + 2) - 4|. Expanding and simplifying gives us |4x + 4 - 4| = |4x|, but since the coefficient of x inside the absolute value is positive (4), shifting right does not change the sign of the expression inside the absolute value. Thus, the correct answer is |4x - 12|.

Explanation:
When transforming an absolute value function by a horizontal shift, replace x with (x + h) or (x - h). The sign within the absolute value remains unchanged if the coefficient of x is positive.

Common mistake note:
A common mistake is to incorrectly change the sign inside the absolute value when shifting. Remember that only the position of the 'breakpoint' changes, not the signs within the absolute value.
