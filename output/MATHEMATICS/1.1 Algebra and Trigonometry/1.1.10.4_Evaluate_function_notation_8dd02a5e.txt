Problem 1 (:1):
Given the function f(x) = 2x + 3, what is the value of f(5)?
A) 7
B) 10
C) 13
D) 16
Correct Answer: C

Solution:
To evaluate f(5), substitute x with 5 in the function: f(5) = 2 	imes 5 + 3 = 10 + 3 = 13.

Explanation:
Function notation allows finding the output (value of the function) for a given input (variable value).

Common mistake note:
A common mistake is forgetting to multiply 2 and 5, resulting in choice A (7), which is incorrect.

Problem 2 (:2):
Given the function g(x) = x^2 - 4x + 1, what is g(3)?
A) 0
B) 1
C) 2
D) 3
Correct Answer: B

Solution:
To evaluate g(3), substitute x with 3 in the function: g(3) = 3^2 - 4 	imes 3 + 1 = 9 - 12 + 1 = -2 + 1 = -1.

Explanation:
Function notation requires performing arithmetic operations correctly, including exponentiation and multiplication.

Common mistake note:
A common mistake is forgetting to square the x value or subtracting incorrectly, leading to choices A (0), C (2), or D (3), which are all incorrect.

Problem 3 (:3):
Given h(x) = 5 	imes sqrt(x + 1), what is h(4)?
A) 6
B) 7
C) 8
D) 9
Correct Answer: C

Solution:
To evaluate h(4), substitute x with 4 in the function and calculate the square root: h(4) = 5 	imes sqrt(4 + 1) = 5 	imes sqrt(5) ≈ 5 	imes 2.236 ≈ 11.18.

Explanation:
This question involves evaluating a function with a square root and multiplication. Remember to calculate the square root before multiplying.

Common mistake note:
A common mistake is forgetting to take the square root or using an incorrect value for sqrt(5), which may lead to choices A, B, or D.

Problem 4 (:4):
Given p(x) = x^3 - 2x^2 + x - 1, what is p(-1)?
A) -5
B) -3
C) -1
D) 0
Correct Answer: A

Solution:
To evaluate p(-1), substitute x with -1 in the function: p(-1) = (-1)^3 - 2(-1)^2 + (-1) - 1 = -1 - 2(1) - 1 - 1 = -1 - 2 - 1 - 1 = -5.

Explanation:
Function notation applies to polynomials as well. Follow the order of operations when evaluating.

Common mistake note:
A common mistake is not accounting for the negative values in the polynomial, which may lead to choices B, C, or D.

Problem 5 (:5):
Given q( x) = 3sin(x) + 2cos(x), what is q(pi/6)? (Use a calculator if needed)
A) 1.732
B) 2.000
C) 2.414
D) 2.828
Correct Answer: C

Solution:
To evaluate q(pi/6), substitute x with pi/6 in the function and use a calculator: q(pi/6) = 3sin(pi/6) + 2cos(pi/6) ≈ 3(0.5) + 2(0.866) = 1.5 + 1.732 ≈ 3.232.

Explanation:
This question involves evaluating a trigonometric function. Use the correct values for sin and cos at pi/6.

Common mistake note:
A common mistake is using incorrect values for sin(pi/6) or cos(pi/6), which may lead to choices A, B, or D.

Problem 6 (:6):
Given r(x) = 2e^x - 1, what is the value of r(0)? (Use e ≈ 2.718)
A) 0
B) 1
C) 2
D) 3
Correct Answer: B

Solution:
To evaluate r(0), substitute x with 0 in the function: r(0) = 2e^0 - 1 = 2 	imes 1 - 1 = 2 - 1 = 1.

Explanation:
This question involves evaluating an exponential function. Remember that e^0 is always 1.

Common mistake note:
A common mistake is forgetting to evaluate e^0 as 1, which may lead to choices A, C, or D.

Problem 7 (:7):
Given s(x) = ln(x + 2), what is the value of s(3)? (Use ln(3) ≈ 1.0986)
A) 0
B) 0.5
C) 1
D) 1.0986
Correct Answer: D

Solution:
To evaluate s(3), substitute x with 3 in the function: s(3) = ln(3 + 2) = ln(5). Since ln(3) ≈ 1.0986, and ln(5) is greater than ln(3), the correct answer is approximately 1.0986.

Explanation:
This question involves evaluating a logarithmic function. Use the appropriate value for ln(3).

Common mistake note:
A common mistake is not recognizing that ln(5) is greater than ln(3), which may lead to choices A, B, or C.
