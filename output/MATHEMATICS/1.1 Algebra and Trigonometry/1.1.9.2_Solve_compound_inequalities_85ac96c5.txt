Problem 1 (Ineq1):
Solve the compound inequality: 3x - 4 < 10 and x + 5 > 2
A) x < 6 and x > -3
B) x > 6 and x < -3
C) x < 2 and x > 7
D) x > 2 and x < 7
Correct Answer: A

Solution:
First, solve each inequality separately:
1) 3x - 4 < 10 => 3x < 14 => x < 14/3 => x < 6
2) x + 5 > 2 => x > 2 - 5 => x > -3
Combine the solutions: x < 6 and x > -3

Explanation:
The solution to a compound inequality with 'and' is the intersection of the solutions for each individual inequality.

Common mistake note:
A common mistake is to combine the inequalities incorrectly, e.g., adding or multiplying both sides by the same number without considering the direction of the inequality sign.

Problem 2 (Ineq2):
Solve the compound inequality: -5 < 4x + 3 ≤ 17
A) -2 < x ≤ 3
B) 2 < x ≤ -3
C) -8 < x ≤ 14
D) x > -2 and x < 3
Correct Answer: A

Solution:
First, solve the inequality separately:
1) -5 < 4x + 3 => -5 - 3 < 4x => -8 < 4x => x > -8/4 => x > -2
2) 4x + 3 ≤ 17 => 4x ≤ 17 - 3 => 4x ≤ 14 => x ≤ 14/4 => x ≤ 3
Combine the solutions: -2 < x ≤ 3

Explanation:
The solution to a compound inequality with 'and' and '≤' is the intersection of the solutions for each individual inequality.

Common mistake note:
A common mistake is to forget that when dividing or multiplying by a negative number, the direction of the inequality sign changes.
------------------------------------------------------------------------------

Problem 3 (Ineq3):
Solve the compound inequality: 2(x - 1) > 5 and x/3 ≤ 4
A) x > 7/2 and x ≤ 12
B) x < 7/2 and x ≥ 12
C) x > 7/2 and x ≥ 12
D) x < 7/2 and x ≤ -12
Correct Answer: A

Solution:
First, solve each inequality separately:
1) 2(x - 1) > 5 => 2x - 2 > 5 => 2x > 5 + 2 => 2x > 7 => x > 7/2
2) x/3 ≤ 4 => x ≤ 4 * 3 => x ≤ 12
Combine the solutions: x > 7/2 and x ≤ 12

Explanation:
The solution to a compound inequality with 'and' is the intersection of the solutions for each individual inequality.

Common mistake note:
A common mistake is to forget to distribute the multiplication in the first inequality, leading to an incorrect solution.

Problem 5 (Ineq5):
Solve the compound inequality: 4x - 3 < 15 or x + 2 ≥ 0
A) x < 4 and x ≥ -2
B) x > 4 and x ≤ -2
C) x < 4 or x ≥ -2
D) x > 4 or x ≤ -2
Correct Answer: C

Solution:
First, solve each inequality separately:
1) 4x - 3 < 15 => 4x < 15 + 3 => 4x < 18 => x < 18/4 => x < 4
2) x + 2 ≥ 0 => x ≥ 0 - 2 => x ≥ -2
Combine the solutions using 'or': x < 4 or x ≥ -2

Explanation:
The solution to a compound inequality with 'or' is the union of the solutions for each individual inequality.

Common mistake note:
A common mistake is to combine the inequalities as if they were connected by 'and', leading to an incorrect solution.

Problem 6 (Ineq6):
Solve the compound inequality: -1 ≤ 2x + 1 < 5
A) -1 ≤ x < 2
B) 0 ≤ x < 3
C) -2 ≤ x < 4
D) x ≥ -1 and x < 2
Correct Answer: D

Solution:
First, solve the inequalities separately:
1) -1 ≤ 2x + 1 => -1 - 1 ≤ 2x => -2 ≤ 2x => x ≥ -2/2 => x ≥ -1
2) 2x + 1 < 5 => 2x < 5 - 1 => 2x < 4 => x < 4/2 => x < 2
Combine the solutions: x ≥ -1 and x < 2

Explanation:
The solution to a compound inequality with 'and' and '<=' is the intersection of the solutions for each individual inequality.

Common mistake note:
A common mistake is to forget that when dividing or multiplying by a negative number, the direction of the inequality sign changes.

2) x + 4 ≤ 6 => x ≤ 6 - 4 => x ≤ 2
Combine the solutions using 'or': x > 4 or x ≤ 2

Explanation:
The solution to a compound inequality with 'or' is the union of the solutions for each individual inequality.

Common mistake note:
A common mistake is to combine the inequalities as if they were connected by 'and', leading to an incorrect solution.
