Problem 1 (Q1):
Simplify: \(x^3 \cdot x^5\).
A) \(x^8\)
B) \(x^{15}\)
C) \(x^2\)
D) \(2x^8\)
Correct Answer: A

Solution:
\(x^3 \cdot x^5 = x^{3+5} = x^8\).

Explanation:
Product rule: when multiplying powers with the same base, add exponents: \(x^a x^b = x^{a+b}\).

Common mistake note:
A common error is multiplying exponents (getting \(x^{15}\)) instead of adding them.
------------------------------------------------------------------------------

Problem 2 (Q2):
Simplify: \(\dfrac{a^9}{a^4}\).
A) \(a^{13}\)
B) \(a^5\)
C) \(a^{-5}\)
D) \(\dfrac{1}{a^5}\)
Correct Answer: B

Solution:
\(\dfrac{a^9}{a^4}=a^{9-4}=a^5\) (for \(a\neq 0\)).

Explanation:
Quotient rule: when dividing same bases, subtract exponents: \(a^m/a^n=a^{m-n}\).

Common mistake note:
Adding exponents (\(a^{13}\)) is incorrect for division; division corresponds to subtracting exponents.
------------------------------------------------------------------------------

Problem 3 (Q3):
Simplify: \((2x^3)^2\).
A) \(2x^6\)
B) \(4x^5\)
C) \(4x^6\)
D) \(8x^6\)
Correct Answer: C

Solution:
\((2x^3)^2 = 2^2\,(x^3)^2 = 4x^{3\cdot 2} = 4x^6\).

Explanation:
Power of a product: \((ab)^n=a^n b^n\); power of a power: \((x^m)^n=x^{mn}\).

Common mistake note:
Forgetting to square the 2 (writing \(2x^6\)) is a common mistake.
------------------------------------------------------------------------------

Problem 4 (Q4):
Simplify and write with positive exponents: \(x^{-4}\).
A) \(-x^4\)
B) \(\dfrac{1}{x^4}\)
C) \(\dfrac{1}{x^{-4}}\)
D) \(x^4\)
Correct Answer: B

Solution:
\(x^{-4}=\dfrac{1}{x^4}\) (for \(x\neq 0\)).

Explanation:
Negative exponent rule: \(x^{-n}=\dfrac{1}{x^n}\).

Common mistake note:
Confusing \(x^{-4}\) with \(-x^4\) is incorrect; the negative sign is in the exponent, not in front of the base.
------------------------------------------------------------------------------

Problem 5 (Q5):
Simplify: \(\dfrac{3^5\cdot 3^{-2}}{3^1}\).
A) \(3^2\)
B) \(3^4\)
C) \(9\)
D) \(\dfrac{1}{9}\)
Correct Answer: C

Solution:
Numerator: \(3^5\cdot 3^{-2}=3^{5+(-2)}=3^3\). Then \(\dfrac{3^3}{3^1}=3^{3-1}=3^2=9\).

Explanation:
Use product rule to add exponents in the numerator, then quotient rule to subtract exponents when dividing by \(3^1\).

Common mistake note:
A common error is subtracting in the multiplication step (treating \(3^5\cdot 3^{-2}\) as \(3^{5-(-2)}\)); multiplication requires adding exponents.
------------------------------------------------------------------------------

Problem 6 (Q6):
Simplify: \(\left(\dfrac{x^4 y^{-2}}{x^{-1} y^3}\right)^2\).
A) \(x^{10}y^{-10}\)
B) \(x^{10}y^{10}\)
C) \(x^{5}y^{-5}\)
D) \(x^{-10}y^{10}\)
Correct Answer: A

Solution:
Inside the parentheses: \(\dfrac{x^4}{x^{-1}}=x^{4-(-1)}=x^5\) and \(\dfrac{y^{-2}}{y^3}=y^{-2-3}=y^{-5}\), so the inside is \(x^5y^{-5}\). Squaring gives \((x^5y^{-5})^2=x^{10}y^{-10}\).

Explanation:
Apply the quotient rule for each base when dividing, then apply the power rule to multiply each exponent by 2.

Common mistake note:
Common slips: using \(4-1\) instead of \(4-(-1)\), or failing to square both factors (squaring only \(x\) or only \(y\)).
------------------------------------------------------------------------------

Problem 7 (Q7):
Simplify completely with positive exponents: \(\dfrac{(x^2 y^{-3})^3}{x^{-1} y^2}\).
A) \(\dfrac{x^7}{y^{11}}\)
B) \(\dfrac{x^5}{y^7}\)
C) \(x^7 y^{11}\)
D) \(\dfrac{y^{11}}{x^7}\)
Correct Answer: A

Solution:
\((x^2 y^{-3})^3 = x^{2\cdot 3} y^{-3\cdot 3} = x^6 y^{-9}\). Then \(\dfrac{x^6 y^{-9}}{x^{-1}y^2}=x^{6-(-1)}y^{-9-2}=x^7 y^{-11}=\dfrac{x^7}{y^{11}}\).

Explanation:
Use power rule to multiply exponents in the numerator, quotient rule to subtract exponents when dividing, then rewrite negative exponents as reciprocals.

Common mistake note:
Mistakes include not distributing the exponent 3 to both factors (forgetting \(x^{2\cdot 3}\)), or adding exponents during division instead of subtracting.
