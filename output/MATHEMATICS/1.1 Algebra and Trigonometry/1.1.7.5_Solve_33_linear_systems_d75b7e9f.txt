Problem 1 (Q1):
Solve the following system of equations: \(2x + y - z = 3\), \(x - 2y + 3z = -1\), \(3x + 2y + z = 4\)
A) \(x = 1, y = -1, z = 2\)
B) \(x = 2, y = 1, z = -1\)
C) \(x = 1, y = 2, z = 1\)
D) \(x = -1, y = 0, z = 3\)
Correct Answer: A

Solution:
The correct solution is \(x = 1, y = -1, z = 2\).

Explanation:
To solve, subtract the second equation from the first to form a new equation, repeat with the other pairs to isolate one variable, solve for \(x\) and \(y\), and back-substitute to find \(z\).

Common mistake note:
Mistakes often arise from incorrect arithmetic during elimination.

Problem 2 (Q2):
Find the solution for: \(x + y + z = 6\), \(2x - y + z = 3\), \(3x + 2y - z = 8\)
A) \(x = 1, y = 2, z = 3\)
B) \(x = 2, y = 1, z = 3\)
C) \(x = 3, y = 1, z = 2\)
D) \(x = 1, y = 3, z = 2\)
Correct Answer: B

Solution:
The correct solution is \(x = 2, y = 1, z = 3\).

Explanation:
Start by expressing \(z\) from the first equation and substituting into the other two. Solve the resulting pairs of equations for \(x\) and \(y\). Back-substitute to find \(z\).

Common mistake note:
Arithmetic mistakes during substitution are a common error.

Problem 3 (Q3):
Determine the values of \(x, y, z\) for the system: \(2x + y + 2z = 10\), \(x + y + z = 6\), \(3x + 2y + z = 11\)
A) \(x = 1, y = 2, z = 3\)
B) \(x = 2, y = 1, z = 3\)
C) \(x = 0, y = 3, z = 3\)
D) \(x = 3, y = 1, z = 2\)
Correct Answer: C

Solution:
The solution is \(x = 0, y = 3, z = 3\).

Explanation:
Subtract the second equation from the first to form a simpler equation, then eliminate one variable using substitution. Solve for the remaining variables one by one.

Common mistake note:
Errors often occur from incorrect elimination or arithmetic.

Problem 4 (Q4):
Solve the system: \(x + 2y + 3z = 5\), \(2x - y + z = 1\), \(3x + y - z = 4\)
A) \(x = 1, y = 0, z = 1\)
B) \(x = 1, y = 2, z = 0\)
C) \(x = 0, y = 1, z = 1\)
D) \(x = 1, y = 1, z = 0\)
Correct Answer: A

Solution:
The solution is \(x = 1, y = 0, z = 1\).

Explanation:
Eliminate, by subtracting equation 2 and 3, the variable \(y\). Solve the remaining equations for \(x\) and \(z\), then substitute back to find \(y\).

Common mistake note:
Mistakes include losing variables during the elimination process.

Problem 5 (Q5):
For the system of equations \(x - y + z = 2\), \(2x + 3y - z = 5\), \(3x - y + 2z = 4\), determine \(x, y, z\).
A) \(x = 0, y = 1, z = 2\)
B) \(x = 1, y = -1, z = 2\)
C) \(x = 2, y = 1, z = 0\)
D) \(x = 1, y = 1, z = 1\)
Correct Answer: B

Solution:
The correct solution is \(x = 1, y = -1, z = 2\).

Explanation:
Begin by eliminating \(z\) using the first and second equations. Then solve the resulting two equations for \(x\) and \(y\) before back-substituting for \(z\).

Common mistake note:
Errors often stem from incorrect arithmetic operations.

Problem 6 (Q6):
What are the solutions for \(x, y, z\) in \(x + y - 2z = 1\), \(2x - 3y + z = 2\), \(3x + 4y + z = 14\)?
A) \(x = 2, y = 1, z = 1\)
B) \(x = 1, y = 2, z = 3\)
C) \(x = 3, y = 2, z = 1\)
D) \(x = 0, y = 1, z = 2\)
Correct Answer: C

Solution:
The correct solution is \(x = 3, y = 2, z = 1\).

Explanation:
Use elimination to remove \(z\) by combining equations 1 and 2. Solve for \(x\) and \(y\) from the derived equations, then substitute back for \(z\).

Common mistake note:
Incorrect or missing signs during the process can lead to errors.

Calculate the solution for \(x + y + z = 9\), \(x - y + 2z = 7\), \(2x + y + 3z = 15\).
A) \(x = 4, y = 1, z = 3\)
B) \(x = 2, y = 3, z = 4\)
C) \(x = 1, y = 2, z = 3\)
D) \(x = 3, y = 2, z = 1\)
Correct Answer: A

Solution:
The correct solution is \(x = 4, y = 1, z = 3\).

Explanation:
Begin by eliminating \(y\) using the first two equations. Solve the derived two-variable equations to determine \(x\) and \(z\), then substitute back to solve for \(y\).

Common mistake note:
Mistakes often occur when signs are inconsistent during elimination steps.
