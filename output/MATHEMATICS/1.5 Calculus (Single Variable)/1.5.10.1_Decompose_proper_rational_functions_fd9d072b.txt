Problem 1 ([1.5.10.1].1):
Factor the given rational function and state its decomposition:
A) (x + 2)(x - 2)/(x + 2)
B) (x - 2)^2/(x + 2)
C) x(x - 2)/(x + 2)
D) (x - 2)/(1)
Correct Answer: C

Solution:
f(x) = (x^2 - 4)/(x + 2) = (x + 2)(x - 2)/(x + 2) = x(x - 2)/(x + 2)

Explanation:
The numerator is a difference of squares, which factors to (x + 2)(x - 2). Since (x + 2) is in both the numerator and denominator, it can be cancelled out, leaving x(x - 2)/(x + 2).

Common mistake note:
Common mistake: Cancelling out (x - 2) instead of (x + 2). This would lead to an incorrect decomposition.

Problem 2 ([1.5.10.1].2):
Factor the given rational function and state its decomposition:
A) (3x)(x - 2)/(x + 3)(x - 3)
B) (3x - 6)(x - 1)/(x + 3)(x - 3)
C) 3(x - 2)/(x + 3)(x - 3)
D) 3(3x - 2)^2/(x + 3)(x - 3)
Correct Answer: C

Solution:
g(x) = (3x^2 - 6x)/(9 - x^2) = 3x(x - 2)/(3^2 - x^2) = 3(x - 2)/(x + 3)(x - 3)

Explanation:
The numerator factors to 3x(x - 2), and the denominator is a difference of squares, which factors to (x + 3)(x - 3). The common factor of 3 can be factored out from the numerator.

Common mistake note:
Common mistake: Factoring the denominator incorrectly as (x - 3)^2. This would lead to an incorrect decomposition.
------------------------------------------------------------------------------

Problem 3 ([1.5.10.1].3):
Factor the given rational function and state its decomposition:
A) 4x(x + 2)(x - 1)/(2x(x - 2))
B) 4x(3x - 2)^2/(2x(x - 2))
C) 4x(3x - 2)(x - 1)/(2x(x - 2))
D) 4x^2(3x - 2)/(2x(x - 2))
Correct Answer: C

Solution:
h(x) = (4x^3 - 8x^2)/(2x^2 - 4x) = 4x^2(3x - 2)/(2x(3x - 2)) = 4x(3x - 2)(x - 1)/(2x(3x - 2))

Explanation:
The numerator factors to 4x^2(3x - 2), and the denominator factors to 2x(3x - 2). The common factor of (3x - 2) can be cancelled out, leaving 4x(x - 1)/(2x).

Common mistake note:
Common mistake: Cancelling out x instead of (3x - 2). This would lead to an incorrect decomposition.
------------------------------------------------------------------------------

Problem 4 ([1.5.10.1].4):
Factor the given rational function and state its decomposition:
A) 6x(x + 3)(x - 1)/(3x(x + 2))
B) 6x(3x - 3)^2/(3x(x + 2))
C) 6x(3x - 3)(x - 1)/(3x(x + 2))
D) 6x^2(3x - 3)/(3x(x + 2))
Correct Answer: C

Solution:
j(x) = (6x^3 - 9x^2)/(3x^2 - 6x) = 3x^2(2x - 3)/(3x(2x - 3)) = 6x(2x - 3)(x - 1)/(3x(2x - 3))

Explanation:
The numerator factors to 3x^2(2x - 3), and the denominator factors to 3x(2x - 3). The common factor of 3x can be cancelled out, leaving 6x(x - 1)/(3x).

Common mistake note:
Common mistake: Factoring the numerator incorrectly as 6x^2(x + 3). This would lead to an incorrect decomposition.

Problem 5 ([1.5.10.1].5):
Factor the given rational function and state its decomposition:
A) 8x^3(3x - 2)/(16x(3x - 2))
B) 8x^3(3x - 2)^2/(16x(3x - 2))
C) 8x^3(3x - 2)(x - 1)/(16x(3x - 2))
D) 8x^2(3x - 2)^2/(16x(3x - 2))
Correct Answer: A

Solution:
k(x) = (8x^4 - 16x^3)/(16x^2 - 32x) = 8x^3(3x - 2)/(16x(3x - 2)) = 8x^3(3x - 2)/(16x(3x - 2))

Explanation:
The numerator factors to 8x^3(3x - 2), and the denominator factors to 16x(3x - 2). The common factor of (3x - 2) can be cancelled out, leaving 8x^3.

Common mistake note:
Common mistake: Cancelling out x instead of (3x - 2). This would lead to an incorrect decomposition.
