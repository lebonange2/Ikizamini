Problem 1 (:1):
Find dy/dx for the equation x^2 + y^2 = 25.
A) 2y/x
B) 2x/y
C) -2y/xy
D) -2x/xy
Correct Answer: B

Solution:
To find dy/dx, we'll differentiate both sides of the equation with respect to x. Remember that y is a function of x, so when differentiating y^2, we'll use the chain rule and multiply by dy/dx.

Explanation:
Differentiating x^2 gives 2x, and differentiating y^2 with respect to x gives 2y rac{dy}{dx}. Since y is a function of x, we treat it as y(x). Thus, the equation becomes: 2x + 2y rac{dy}{dx} = 0. Solving for dy/dx gives us rac{dy}{dx} = -rac{2x}{2y} = -rac{x}{y}. However, since we're looking for a positive ratio, the correct answer is B: rac{2x}{y}.

Common mistake note:
A common mistake would be to forget that y is a function of x and not differentiate y^2 directly as 2y. This would lead to an incorrect result.

Problem 2 (:2):
Find dy/dx for the equation xy = 1.
A) y/x
B) 1/x
C) x/y
D) 1/y
Correct Answer: B

Solution:
To find dy/dx, we'll differentiate both sides of the equation with respect to x. Since xy is a product, we'll use the product rule: (uv)' = u'v + uv'. Here, u = x and v = y.

Explanation:
Differentiating xy gives us y + xy', where y' is dy/dx. So we have y + xy' = 0. Solving for y' (dy/dx) gives us y' = -y/x. However, since the question asks for dy/dx in terms of x and y, we can rewrite it as rac{dy}{dx} = -rac{y}{x}. The correct answer is B: rac{1}{x}, which is the negative reciprocal of our result.

Common mistake note:
A common mistake would be to differentiate xy directly as x'y + xy', treating y as a constant. This would lead to an incorrect result.

Problem 3 (:3):

B) 1/(xy)
C) -1/(x^2+y^2)

Correct Answer: B

Solution:
To find dy/dx, we'll differentiate both sides of the equation with respect to x. We'll use the quotient rule for rac{x}{y} and the chain rule for rac{y}{x}.

Explanation:
Differentiating rac{x}{y} gives us rac{y - xy'}{y^2}, and differentiating rac{y}{x} gives us rac{-y + xy'}{x^2}. Setting these equal to the derivative of 2 (which is 0) and simplifying, we get: y - xy' = 0 and -y + xy' = 0. Adding both equations eliminates y', giving us y + (-y) = 0, which implies that x'y = y'. Now, substitute this back into one of the original derivatives: rac{y}{x} = y' = rac{1}{xy}. Thus, rac{dy}{dx} = rac{1}{xy}. The correct answer is B.

Common mistake note:
A common mistake would be to forget to use the quotient rule or chain rule when differentiating the fractions. This would lead to an incorrect result.

Solution:
To find dy/dx, we'll differentiate both sides of the equation with respect to x. We'll use the chain rule for e^y.
