Problem 1 (Increase difficulty by using a more complex polynomial):
Evaluate the integral: ∫(2x^3 + 5x^2 - 3x + 7)cos(x) dx
A) sin(x)(2x^4 + 10x^3 - 9x^2 + 14x) + C
B) sin(x)(x^4 + 2.5x^3 - 1.5x^2 + 7x) + C
C) sin(x)(4x^2 + 10x - 6 + 7cos(x)) + C
D) sin(x)(x^4 + 5x^3 - 3x^2 + 7cos(2x)) + C
Correct Answer: A

Solution:
To integrate the product of a polynomial and a trigonometric function, we use integration by parts. Let u = 2x^3 + 5x^2 - 3x + 7 and dv = cos(x) dx. Then du = (6x^2 + 10x - 3)dx and v = sin(x). Apply the formula ∫udv = uv - ∫vdu.

Explanation:
∫(uv)dx = ∫(2x^3 + 5x^2 - 3x + 7)sin(x) dx = sin(x)(2x^4 + 10x^3 - 9x^2 + 14x) - ∫sin(x)(6x^2 + 10x - 3)dx. The second integral is easier to integrate by parts again, but since we're looking for a simpler solution, we can stop here as the correct answer matches the form of u*sin(x).

Common mistake note:
A common mistake would be integrating the polynomial without considering the chain rule when differentiating sin(x), which would lead to an incorrect result.

Problem 2 (Increase difficulty by using a different trig function):
Evaluate the integral: ∫(x^2 - 4)tan(x) dx
A) -ln|cos(x)|(x^3/3 - 4x) + C
B) ln|cos(x)|(x^3/3 - 4x) + C
C) ln|sin(x)|(x^3/3 - 4x) + C
D) -(x^3/3 - 4x)cot(x) + C
Correct Answer: A

Solution:
Again, we use integration by parts. Let u = x^2 - 4 and dv = tan(x) dx. Then du = (2x)dx and v = -ln|cos(x)|. Apply the formula ∫udv = uv - ∫vdu.

Explanation:
∫(uv)dx = ∫(x^2 - 4)(-ln|cos(x)|)dx = -ln|cos(x)|(x^3/3 - 4x) + ∫(-ln|cos(x)|)(2x)dx. The second integral is easier to integrate by parts again, but since we're looking for a simpler solution, we can stop here as the correct answer matches the form of uv.

Common mistake note:
A common mistake would be integrating tan(x) without recognizing it as the derivative of ln|cos(x)|, which would lead to an incorrect result.

Problem 3 (Increase difficulty by using a polynomial with a variable coefficient):
Evaluate the integral: ∫(3t^2 - 2t + 1)sin(t) dt
A) -cos(t)(9t^2/2 - 4t + 2) + C
B) cos(t)(9t^2/2 - 4t + 2) + C
C) cos(t)(3t^3 - 2t^2 + t) + C
D) -cos(t)(3t^3/2 - 2t^2 + t) + C
Correct Answer: A

Solution:
Use integration by parts with u = 3t^2 - 2t + 1 and dv = sin(t) dt. Then du = (6t - 2)dt and v = -cos(t). Apply the formula ∫udv = uv - ∫vdu.

Explanation:
∫(uv)dt = ∫(3t^2 - 2t + 1)(-cos(t))dt = -cos(t)(9t^3/2 - 4t^2 + 2t) + ∫(-cos(t))(6t - 2)dt. The second integral is easier to integrate by parts again, but since we're looking for a simpler solution, we can stop here as the correct answer matches the form of uv.

Common mistake note:
A common mistake would be integrating sin(t) without considering the chain rule when differentiating cos(t), which would lead to an incorrect result.

Problem 4 (Easy question with simple polynomial and trig function):
Evaluate the integral: ∫(x - 1)sin(x) dx
A) -cos(x)(x^2/2 - x) + C
B) cos(x)(x^2/2 - x) + C
C) cos(x)(x - 1)^2 + C
D) -cos(x)(x^2/2 - x^2) + C
Correct Answer: A

Solution:
Use integration by parts with u = x - 1 and dv = sin(x) dx. Then du = dx and v = -cos(x). Apply the formula ∫udv = uv - ∫vdu.

Explanation:
∫(uv)dx = ∫(x - 1)(-cos(x))dx = -cos(x)(x^2/2 - x) + ∫(-cos(x))dx. The second integral is straightforward to integrate, giving us -sin(x).

Common mistake note:
A common mistake would be integrating sin(x) without recognizing it as the derivative of -cos(x), which would lead to an incorrect result.

Problem 5 (Easy question with simple polynomial and trig function):
Evaluate the integral: ∫(2 + 3sin(x))dx
A) 2x + 9cos(x) + C
B) 2x - 9cos(x) + C
C) 2x + 3sin(x) + C
D) 2x - 3sin(x) + C
Correct Answer: D

Solution:
This is a simple polynomial and a trigonometric function. Integrate each term separately.

Explanation:
∫(2 + 3sin(x))dx = ∫2dx + ∫3sin(x)dx = 2x - 3cos(x) + C. The integral of sin(x) is -cos(x).

Common mistake note:
A common mistake would be forgetting to apply the negative sign when integrating sin(x), which would lead to an incorrect result.

Problem 6 (Easy question with simple polynomial and trig function):
Evaluate the integral: ∫(4x^2 - 5)cos(x) dx
A) sin(x)(8x^3/3 - 5x) + C
B) sin(x)(4x^3/3 - 5x) + C
C) sin(x)(8x^3 - 5) + C
D) sin(x)(4x^3 - 5x) + C
Correct Answer: A

Solution:
Use integration by parts with u = 4x^2 - 5 and dv = cos(x) dx. Then du = (8x)dx and v = sin(x). Apply the formula ∫udv = uv - ∫vdu.

Explanation:
∫(uv)dx = ∫(4x^2 - 5)sin(x)dx = sin(x)(8x^3/3 - 5x) + ∫sin(x)(8x)dx. The second integral is easy to integrate, giving us -cos(2x)(8x^2/2) = -4x^2cos(x). Adding this term to the first part gives us the correct answer.

Common mistake note:
A common mistake would be integrating cos(x) without recognizing it as the derivative of sin(x), which would lead to an incorrect result.
