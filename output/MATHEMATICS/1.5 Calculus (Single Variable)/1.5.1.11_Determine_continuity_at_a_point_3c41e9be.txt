Problem 1 (Asdf):
Is the function f(x) = x^2 continuous at x=2?
A) Yes
B) No
C) Cannot be determined without more information
D) The function is not defined at x=2
Correct Answer: A

Solution:
To determine continuity at a point, we need to check if the following three conditions are met: 1) The function is defined at that point, 2) The limit exists at that point, and 3) The limit value equals the function value. At x=2, f(x) = (2)^2 = 4, which is defined. The limit as x approaches 2 of x^2 is also 4 because polynomial functions are continuous everywhere. Since all three conditions are met, the function is continuous at x=2.

Explanation:
The continuity test was successfully applied to the given point.

Common mistake note:
A common mistake would be to think that since the function is not defined at x=2 (which is not the case for f(x) = x^2), it must not be continuous. However, this is incorrect because the question specifically asks about continuity at x=2, and in this case, the function is indeed continuous.

Problem 2 (Bvcx):
Is the function g(x) = |x| continuous at x=0?
A) Yes
B) No
C) Cannot be determined without more information
D) The function is not defined at x=0
Correct Answer: A

Solution:
For the absolute value function g(x) = |x|, we can evaluate it at x=0 directly: g(0) = |0| = 0. The limit as x approaches 0 from both sides is also 0 because |x| becomes arbitrarily close to 0 as x approaches 0. Since all three conditions for continuity are met, the function is continuous at x=0.

Explanation:
The continuity test was correctly applied to the given point.

Common mistake note:
A common mistake would be to think that because |x| changes its sign at x=0 (from negative to positive), it must not be continuous. However, this is a misunderstanding of the definition of continuity; as long as the limit exists and equals the function value, continuity is maintained.

Problem 3 (Zxcv):
Is the function h(x) = 1/x continuous at x=3?
A) Yes
B) No
C) Cannot be determined without more information
D) The function is not defined at x=0
Correct Answer: B

Solution:
The function h(x) = 1/x is undefined at x=0, but the question asks about continuity at x=3. At x=3, h(3) is well-defined and equal to 1/3. However, as x approaches 0 from either side, the limit of 1/x goes to infinity or negative infinity, so it does not exist. Since the limit does not exist at x=3, the function is not continuous at that point.

Explanation:
The continuity test was correctly applied and revealed that the function is discontinuous at x=3.

Common mistake note:
A common mistake would be to focus on the behavior of the function near x=0 instead of x=3, which is what the question asks about. The key here is to recognize that the limit must exist at the specific point in question.

Problem 4 (Qwerty):
Is the function j(x) = x^3 - 6x^2 + 9x continuous at x=3?
A) Yes
B) No
C) Cannot be determined without more information
D) The function is not defined at x=0
Correct Answer: A

Solution:
For the polynomial function j(x) = x^3 - 6x^2 + 9x, we can evaluate it at x=3 directly: j(3) = (3)^3 - 6(3)^2 + 9(3) = 27 - 54 + 27 = 0. The limit as x approaches 3 is also 0 because polynomial functions are continuous everywhere. Since all three conditions for continuity are met, the function is continuous at x=3.

Explanation:
The continuity test was correctly applied to the given point.

Common mistake note:
A common mistake would be to think that since there's a change in the degree of the polynomial at x=3 (from cubic to quadratic), it might affect continuity. However, this is not the case; polynomials are continuous everywhere.

Problem 5 (Poiuyt):
Is the function k(x) = 2sin(x) continuous at x=π/2?
A) Yes
B) No
C) Cannot be determined without more information
D) The function is not defined at x=0
Correct Answer: A

Solution:
The sine function is continuous for all real numbers, including x=π/2. Thus, the composite function k(x) = 2sin(x) is also continuous at x=π/2. Evaluating k(π/2) gives us 2sin(π/2) = 2(1) = 2, which matches the limit as x approaches π/2.

Explanation:
The continuity of the sine function was correctly recognized and applied to the given point.

Common mistake note:
A common mistake would be to think that because sin(x) changes its value at different points (e.g., sin(π/2) = 1, but sin(-π/2) = -1), it might not be continuous. However, sine is a continuous function over its entire domain.

Problem 6 (Bnml):
Is the function l(x) = x^2sin(1/x) continuous at x=0?
A) Yes
B) No
C) Cannot be determined without more information
D) The function is not defined at x=0
Correct Answer: B

Solution:
The limit of l(x) = x^2sin(1/x) as x approaches 0 does not exist because the sine function oscillates between -1 and 1, while x^2 approaches 0. Therefore, the overall limit does not approach a single value, making the function discontinuous at x=0.

Explanation:
The continuity test was correctly applied and revealed that the function is discontinuous at x=0.

Common mistake note:
A common mistake would be to think that since x^2 approaches 0 as x approaches 0, the entire function must approach 0. However, the oscillating nature of sin(1/x) prevents this from happening.

Problem 7 (Njhg):
Is the function m(x) = [x] continuous at x=3?
A) Yes
B) No
C) Cannot be determined without more information
D) The function is not defined at x=0
Correct Answer: B

Solution:
The function m(x) = [x], the greatest integer function, is discontinuous at every integer value because it jumps from one integer to the next. At x=3, m(3) = 3, but as x approaches 3 from either side, the function value changes abruptly between 2 and 3, indicating a lack of continuity.

Explanation:
The discontinuity of the greatest integer function was correctly identified at the given point.

Common mistake note:
A common mistake would be to think that since m(x) is defined for all real numbers, it must be continuous everywhere. However, this function has jumps (discontinuities) at every integer value.
