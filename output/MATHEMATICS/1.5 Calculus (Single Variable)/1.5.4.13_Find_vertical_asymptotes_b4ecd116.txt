Problem 1 (One):
What is the equation of the vertical asymptote for the function f(x) = (x + 2)/(x^2 - 4)?
A) (x + 2)
B) (x - 2)
C) (x^2 - 4)
D) There are no vertical asymptotes.
Correct Answer: B

Solution:
The function has a rational expression with a denominator of x^2 - 4. To find the vertical asymptote, set the denominator equal to zero and solve for x: x^2 - 4 = 0 factors into (x + 2)(x - 2) = 0, giving x = -2 and x = 2 as potential vertical asymptotes. However, since f(x) is undefined only when x = 2 (not when x = -2 because the numerator also equals zero there), x = 2 is the equation of the vertical asymptote.

Explanation:
Vertical asymptotes occur where a function's denominator equals zero and the numerator does not.

Common mistake note:
A common mistake is to choose A, which is the numerator. The numerator has no impact on vertical asymptotes; only the zeros of the denominator matter.

Problem 3 (Three):
What is the equation of the vertical asymptote for f(x) = (x^2 + 9)/(x - 3i)?
A) (x - 3)
B) (x + 3)
C) (x^2 + 9)
D) There are no real vertical asymptotes.
Correct Answer: D

Solution:
The function has a denominator of x - 3i, which is a complex number. Since there are no real numbers that make a complex number zero, there are no real vertical asymptotes. The function may have vertical asymptotes in the complex plane, but this question asks for real vertical asymptotes.

Explanation:
Vertical asymptotes only occur where a rational function's denominator equals zero and the numerator does not.

Common mistake note:
A common mistake is to choose A or B, assuming that the imaginary part doesn't matter. In this case, it does; there are no real vertical asymptotes.
