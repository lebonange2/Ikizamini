Problem 1 (One-sided limit at infinity):
Find the limit as x approaches infinity for the function f(x) = (3x^2 + 5x - 7)/(4x^2 + 9).
A) -3/4
B) 3/4
C) 1
D) Does not exist
Correct Answer: B

Solution:
Using L'Hôpital's rule, we differentiate the numerator and denominator with respect to x. The derivative of 3x^2 + 5x - 7 is 6x + 5, and the derivative of 4x^2 + 9 is 8x. Now we have the limit as x approaches infinity for (6x + 5)/(8x). Dividing both terms by x gives us (6 + 5/x)/(8), which simplifies to 6/8 when x approaches infinity, or 3/4.

Explanation:
L'Hôpital's rule is applied when the limit results in an indeterminate form like 0/0 or ∞/∞. In this case, both the numerator and denominator approach infinity as x increases, so L'Hôpital's rule can be used.

Common mistake note:
A common mistake would be to directly compare the highest powers of the numerator and denominator without applying L'Hôpital's rule. This would lead to the incorrect conclusion that the limit is 3/4 by comparing 3x^2 and 4x^2, which is not correct because we need to apply L'Hôpital's rule first.

Problem 2 (Two-sided limit at a point):
Evaluate the limit as x approaches 0 for the function g(x) = sin(5x)/x.
A) 0
B) 1
C) 5
D) Does not exist
Correct Answer: C

Solution:
Applying L'Hôpital's rule, we differentiate both the numerator and denominator with respect to x. The derivative of sin(5x) is 5cos(5x), and the derivative of x is 1. So the limit becomes (5cos(5x))/1. As x approaches 0, cos(5x) approaches 1, so the limit simplifies to 5.

Explanation:
L'Hôpital's rule can be applied here because the limit results in the indeterminate form 0/0 when x approaches 0. After applying L'Hôpital's rule, we find that the limit is 5.

Common mistake note:
A common mistake would be to assume that sin(5x) behaves like 5x near 0 and conclude that the limit is 5 without using L'Hôpital's rule. This is incorrect because we need to apply L'Hôpital's rule to handle the indeterminate form.

Problem 3 (Infinite discontinuity):
Find the limit as x approaches 2 for the function h(x) = (x^3 - 8)/(x - 2).
A) -12
B) 0
C) 4
D) Does not exist
Correct Answer: D

Solution:
The function has a removable discontinuity at x = 2, but we can still use L'Hôpital's rule to evaluate the limit. The numerator simplifies to (x - 2)(x^2 + 2x + 4), which becomes 0 when x approaches 2. The denominator is (x - 2), which also becomes 0. This gives us an indeterminate form of 0/0, so we can apply L'Hôpital's rule. Differentiating both numerator and denominator with respect to x, we get 3x^2 + 4x + 4 and 1, respectively. The limit then becomes (3(2)^2 + 4(2) + 4)/1 = 24/1 = 24. However, since the function is undefined at x = 2, the limit does not exist.

Explanation:
L'Hôpital's rule can be applied here because of the indeterminate form 0/0 when x approaches 2. The limit does not exist due to the discontinuity in the function.

Common mistake note:
A common mistake would be to cancel out (x - 2) terms without considering that this would eliminate the singularity at x = 2, leading to an incorrect conclusion about the limit.

Problem 4 (Zero over zero indeterminate form):
Evaluate the limit as x approaches 1 for the function j(x) = (x^3 - 1)/(x - 1).
A) 0
B) 1
C) 2
D) 3
Correct Answer: D

Solution:
The limit results in an indeterminate form of 0/0 when x approaches 1. Applying L'Hôpital's rule, we differentiate both the numerator and denominator with respect to x. The derivative of x^3 - 1 is 3x^2, and the derivative of x - 1 is 1. So the limit becomes (3(1)^2)/1 = 3.

Explanation:
L'Hôpital's rule can be applied here because of the indeterminate form 0/0 when x approaches 1. After applying L'Hôpital's rule, we find that the limit is 3.

Common mistake note:
A common mistake would be to factor out (x - 1) and cancel it without considering the indeterminate form, leading to an incorrect conclusion about the limit.

Correct Answer: D

Solution:
The limit results in an indeterminate form of ∞/0 when x approaches 0. However, since the denominator approaches infinity faster than the numerator approaches zero, the limit is actually infinite. L'Hôpital's rule does not apply here because it can only be used for 0/0 or ∞/∞ forms.
