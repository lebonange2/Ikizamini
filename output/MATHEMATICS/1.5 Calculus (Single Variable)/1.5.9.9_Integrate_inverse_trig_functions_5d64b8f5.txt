Problem 1 (InverseTrig1):
Evaluate the integral: ∫(arcsin(x))^2 dx
A) (x(arcsin(x))  - (1/2)sin(2arcsin(x))) + C
B) (x^2)/2 + C
C) (x^2)(arcsin(x))  + (1/6)x^3 + C
D) x(arcsin(x))  + (1/4)x^2  - (1/2)sin(2arcsin(x)) + C
Correct Answer: A

Solution:
To integrate ∫(arcsin(x))^2 dx, use integration by parts. Let u = (arcsin(x))^2 and dv = dx. Then du = 2arcsin(x) * (1/sqrt(1 - x^2)) dx and v = x. Apply the integration by parts formula: ∫udv = uv - ∫vdu.

Explanation:
uv = x(arcsin(x))^2, and ∫vdu = ∫x * 2arcsin(x) * (1/sqrt(1 - x^2)) dx. Use substitution: let w = arcsin(x), so dw = (1/sqrt(1 - x^2))dx. The integral becomes ∫2w * x dw = x^2 * w - ∫x^2dw.

Common mistake note:
A common mistake is to forget the chain rule when differentiating (arcsin(x))^2, leading to du = 2arcsin(x) dx. This results in an incorrect antiderivative.

Problem 2 (InverseTrig2):
Evaluate the integral: ∫(cos(x)) / sqrt(1 - sin^2(x)) dx
A) arctan(sin(x)) + C
B) arcsin(sin(x)) + C
C) arccos(sin(x)) + C
D) sin(arcsin(sin(x))) + C
Correct Answer: A

Solution:
The integral ∫(cos(x)) / sqrt(1 - sin^2(x)) dx simplifies to ∫dx by recognizing that 1 - sin^2(x) = cos^2(x). The antiderivative of x is x.

Explanation:
Alternatively, use substitution: let w = sin(x), so dw = cos(x)dx and the integral becomes ∫dw / sqrt(1 - w^2), which is arctan(w) + C. Substituting back in w = sin(x) gives us arctan(sin(x)) + C.

Common mistake note:
A common mistake is to think that 1 - sin^2(x) simplifies to sin(x), leading to ∫(cos(x)) / sin(x) dx, which would result in ln|sin(x)| + C. However, this is incorrect because the correct simplification results in a simpler integral.

Problem 3 (InverseTrig3):
Evaluate the integral: ∫(arctan(x))^3 dx
A) (1/4)(x^2)(arctan(x))^2  - (1/6)x^3 + C
B) (1/2)(x^2)(arcsin(x))^2 + C
C) x(arctan(x))^2  - x + C
D) (1/4)(x^2)(arctan(x))^2  + (1/2)x^2 + C
Correct Answer: C

Solution:
Use integration by parts to integrate ∫(arctan(x))^3 dx. Let u = (arctan(x))^2 and dv = arctan(x)dx. Then du = 2arctan(x)/(1+x^2) dx and v = x(arctan(x)). Apply the integration by parts formula: ∫udv = uv - ∫vdu.

Explanation:
uv = x(arctan(x))^3, and ∫vdu = ∫x * 2arctan(x)/(1+x^2) dx. Use substitution: let w = arctan(x), so dw = (1/(1+x^2))dx. The integral becomes ∫2w * xdw = x^2 * w - ∫x^2dw.

Common mistake note:
A common mistake is to forget the chain rule when differentiating (arctan(x))^2, leading to du = 2arctan(x)/(1+x^2). This results in an incorrect antiderivative.

Problem 4 (InverseTrig4):
Evaluate the integral: ∫(sin(x)) / sqrt(1 + cos^2(x)) dx
A) arcsinh(sin(x)) + C
B) arctan(cos(x)) + C
C) arccos(cos(x)) + C
D) arcsin(cos(x)) + C
Correct Answer: B

Solution:
The integral ∫(sin(x)) / sqrt(1 + cos^2(x)) dx simplifies to ∫sin(x)dx by recognizing that 1 + cos^2(x) = 1. The antiderivative of sin(x) is -cos(x).

Explanation:
Alternatively, use substitution: let w = cos(x), so dw = -sin(x)dx and the integral becomes ∫-dw / sqrt(1 + w^2), which is -arcsinh(w) + C. Substituting back in w = cos(x) gives us -arcsinh(cos(x)) + C, but since arcsinh and arctan are related by a constant (arcsinh(c) = arctan(1/c)), we can rewrite it as arctan(sin(x)) + C.

Common mistake note:
A common mistake is to think that 1 + cos^2(x) simplifies to cos(x), leading to ∫sin(x)/cos(x) dx, which would result in ln|sec(x)| + C. However, this is incorrect because the correct simplification results in a simpler integral.

Problem 5 (InverseTrig5):
Evaluate the integral: ∫(arccos(x))^2 dx
A) (1/3)(x^3)(arccos(x))  - (1/4)x^4 + C
B) (1/2)(x^2)(arcsin(x))^2 + C
C) x(arccos(x))^2  - x + C
D) (1/3)(x^3)(arccos(x))  + (1/2)x^2 + C
Correct Answer: C

Solution:
Use integration by parts to integrate ∫(arccos(x))^2 dx. Let u = (arccos(x))^2 and dv = arccos(x)dx. Then du = -2arccos(x)/(1-x^2) dx and v = x(arccos(x)). Apply the integration by parts formula: ∫udv = uv - ∫vdu.

Explanation:
uv = x(arccos(x))^3, and ∫vdu = ∫x * -2arccos(‌x)/(1-x^2) dx. Use substitution: let w = arccos(x), so dw = -1/(1-x^2)dx. The integral becomes ∫-2w * xdw = -x^2 * w + ∫x^2dw.

Common mistake note:
A common mistake is to forget the chain rule when differentiating (arccos(x))^2, leading to du = -2arccos(‌x)/(1-x^2). This results in an incorrect antiderivative.
