Problem 1 (:Q1):
Simplify the expression: (3x^2)^3
A) (9x^5)
B) (27x^6)
C) (81x^5)
D) (81x^6)
Correct Answer: D

Solution:
To simplify (3x²)^3, apply the power rule for exponents: (a^n)^m = a^(n*m). So, we have (3x²)^3 = 3^3 * (x²)^3 = 27 * x^6 = 81x^6.

Explanation:
The power rule states that when you raise a power to another power, multiply the exponents. Common mistake: Forgetting to multiply the exponents (e.g., 3^3 * x² instead of 3^3 * x^6)

Common mistake note:
Common mistake: Forgetting to multiply the exponents

Problem 2 (:Q2):
Evaluate the expression when x = 2: (2x + 1)^4
A) 729
B) 81
C) 256
D) 49
Correct Answer: B

Solution:
Substitute x with 2 in the expression: (2(2) + 1)^4 = (4 + 1)^4 = 5^4. Calculate 5^4: 5 * 5 * 5 * 5 = 625. The closest power of 5 less than or equal to 625 is 81 (5^4 = 625, 5^3 = 125).

Explanation:
Substitute x with the given value and calculate the exponentiation. Common mistake: Directly multiplying choices without substituting x first.

Common mistake note:
Common mistake: Directly multiplying choices by 2 instead of substituting x = 2
------------------------------------------------------------------------------

Problem 3 (:Q3):
Simplify the expression: (4a^3b)^{-2}
A) (1/16a^-6b^2)
B) (1/16a^6b^-2)
C) (1/8a^6b^2)
D) (1/8a^-6b^-2)
Correct Answer: A

Solution:
Apply the power rule for exponents with a negative exponent: (a^n)^{-m} = 1/a^(n*m). So, we have (4a^3b)^{-2} = 1/(4^2 * (a^3)^2 * b^2) = 1/(16a^6b^2) = (1/16a^-6b^2)

Explanation:
When raising to a negative exponent, take the reciprocal of the base and multiply exponents. Common mistake: Incorrect handling of negative exponents.

Common mistake note:
Common mistake: Not understanding how to handle negative exponents
------------------------------------------------------------------------------

Problem 4 (:Q4):
Simplify the expression: (x + 3)^0
A) x
B) 3
C) 1
D) 0
Correct Answer: C

Solution:
(x + 3)^0 is equal to any number raised to the power of 0, which is always 1.

Explanation:
Any non-zero number raised to the power of 0 equals 1. Common mistake: Not applying the property for 0 powers.

Common mistake note:
Common mistake: Not understanding the property of exponents for 0 powers

Problem 5 (:Q5):
Simplify the expression: 2^(x+2) * 2^(x-1)
A) 4^x
B) 2^(2x+1)
C) 2^(2x-1)
D) 2^(x^2)
Correct Answer: B

Solution:
When multiplying powers with the same base, add exponents: 2^(x+2) * 2^(x-1) = 2^(x+2+x-1) = 2^(2x+1)

Explanation:
Combine exponents when multiplying powers with the same base. Common mistake: Incorrect coefficient multiplication or exponent addition.

Common mistake note:
Common mistake: Multiplying coefficients instead of adding exponents
------------------------------------------------------------------------------

Problem 6 (:Q6):
Simplify the expression: (5a^2b)^{-1} / (10ab)^{-3}
A) (1/2a)
B) (5/8a^4b^2)
C) (5/8a^3b)
D) (1/2a^4b^2)
Correct Answer: B

Solution:
Simplify each term: (5a^2b)^{-1} = 1/(5a^2b) and (10ab)^{-3} = 1/(1000a^3b^3). Divide simplified terms: (1/(5a^2b)) / (1/(1000a^3b^3)) = 1000a * b^2 / 5a^2b = 200a^(1-2)b^(3-1) = 200ab. Simplify further: 200ab = (5/8)a^4b^2.

Explanation:
Subtract exponents when dividing powers with the same base. Common mistake: Incorrect handling of negative exponents or coefficient division.

Common mistake note:
Common mistake: Not handling negative exponents in division
------------------------------------------------------------------------------

Problem 7 (:Q7):
Simplify the expression: (3x)^{-1} * (9x^{-2})
A) (1/27x)
B) (1/27x^3)
C) (27/ x^3)
D) (27/ x)
Correct Answer: A

Solution:
Simplify each term: (3x)^{-1} = 1/(3x) and (9x^{-2}) = 9/x^2. Multiply simplified terms: (1/(3x)) * (9/x^2) = 9 / (3x * x^2) = 9 / (3x^3) = (1/3)(1/x^3) = (1/27x).

Explanation:
Apply rules for each base separately when multiplying powers with different bases. Common mistake: Incorrect handling of separate bases.

Common mistake note:
Common mistake: Combining exponents across different bases
