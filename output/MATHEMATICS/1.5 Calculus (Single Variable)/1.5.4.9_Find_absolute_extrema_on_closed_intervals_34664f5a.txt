Problem 1 (Increasing_Decreasing_Interval):
Find the interval where the function f(x) = x^3 - 6x^2 + 9x is increasing.
A) (0, 3)
B) (-∞, 1)
C) (1, ∞)
D) (-∞, ∞)
Correct Answer: A

Solution:
To find the interval where f(x) is increasing, we need to determine where its derivative f'(x) = 3x^2 - 12x + 9 is positive. Testing values around the critical points x = 1 and x = 3 shows that f'(x) is negative before x = 1 (e.g., at x = 0), positive between x = 1 and x = 3 (e.g., at x = 2), and negative after x = 3 (e.g., at x = 4). Therefore, the function is increasing on the interval (1, 3). However, since we're looking for an interval within the closed interval given in the question, we must include the endpoints. The correct interval is thus (0, 3), as f'(x) is also positive at x = 0.

Explanation:
The absolute extrema on a closed interval occur at critical points or endpoints of the function. In this case, since f(x) is increasing on the interval (1, 3), the interval provided in the question is already within that range and includes the endpoint x = 0.

Common mistake note:
A common mistake would be to choose option C, which omits the endpoint x = 0. This is incorrect because the function may change from increasing to decreasing right at the endpoint, and we need to include that point in the interval if it's part of the closed interval given.

Problem 2 (Max_Min_Interval):
Find the absolute minimum value of f(x) = x^2 - 4x + 5 on the interval [0, 5].
A) 1
B) 0
C) 4
D) 6
Correct Answer: A

Solution:
To find the absolute minimum value of f(x) on a closed interval, we first need to check the function's values at the endpoints and any critical points within the interval. The critical points are found by setting the derivative equal to zero: f'(x) = 2x - 4.

Explanation:
Setting f'(x) = 0 gives us x = 2. Evaluating f(x) at x = 0, x = 2, and x = 5: f(0) = 5, f(2) = 1, and f(5) = 10. The smallest value is f(2) = 1, which occurs at the critical point x = 2 within the interval [0, 5]. Therefore, the absolute minimum value of f(x) on this interval is 1.

Common mistake note:
A common mistake would be to choose option D (f(5)), which represents the function's value at the right endpoint but not necessarily the absolute minimum. The correct answer must be the smallest value among all possible candidates.

Explanation:
The absolute extrema on a closed interval occur at critical points or endpoints of the function. In this case, since f(x) has a negative slope on the interval (0, 3), the interval provided in the question is already within that range and includes the endpoint x = 3.

Problem 5 (Max_Min_Interval_Extreme):
Find the absolute minimum value of f(x) = x^3 - 6x^2 + 9x on the interval [-1, 0].
A) -4/27
B) 0
C) 1
D) 6
Correct Answer: A

Solution:
To find the absolute minimum value of f(x) on a closed interval, we first need to check the function's values at the endpoints and any critical points within the interval. The critical points are found by setting the derivative equal to zero: f'(x) = 3x^2 - 12x + 9.

Explanation:
Setting f'(x) = 0 gives us x = 1 (a repeated root). Since there's no critical point within the interval [-1, 0], the minimum value must occur at one of the endpoints. Evaluating f(x) at x = -1 and x = 0: f(-1) = -4/27, and f(0) = 0. The smallest value is f(-1) = -4/27, which occurs at the left endpoint of the interval [-1, 0]. Therefore, the absolute minimum value of f(x) on this interval is -4/27.

Common mistake note:
A common mistake would be to choose option B (f(0)), which represents the function's value at an endpoint but not necessarily the absolute minimum. Since there are no critical points within the interval, the correct answer must come from one of the endpoints.
