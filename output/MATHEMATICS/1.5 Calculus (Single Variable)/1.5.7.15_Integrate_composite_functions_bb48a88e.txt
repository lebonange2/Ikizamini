Problem 1 (:1):
Find the integral of the function f(x) = (2x + 3)(x^2 - 4x + 5):
A) (x^3 + x^2)/3 - (8x^2 + 20x)/4 + C
B) (x^4 - 6x^3 + 17x^2 - 20x + 15)/4 + C
C) (x^4 - 6x^3 + 19x^2 - 28x + 30)/4 + C
D) (x^3 - 3x^2 + 7x - 15)/4 + C
Correct Answer: C

Solution:
To integrate the composite function f(x) = (2x + 3)(x^2 - 4x + 5), multiply the polynomials and integrate term by term. The integral is (x^4 - 6x^3 + 19x^2 - 28x + 30)/4 + C. Answer: C.

Explanation:
Use polynomial multiplication and term-by-term integration. Common mistake: Incorrect coefficient distribution when multiplying polynomials.

Common mistake note:
A common error is forgetting to distribute the coefficient 2 in front of x^3, leading to A. Another issue might be combining like terms improperly after integration, causing B or D.

Problem 2 (:2):
Evaluate ∫(sin(x)cos(x))dx from 0 to π/2:
A) -1
B) 1/2
C) 1
D) π/4
Correct Answer: B

Solution:
The integral of sin(x)cos(x) is (1/2)sin^2(x) + C. Evaluate at limits: [(-1/2)sin^2(π/2)] - [(-1/2)sin^2(0)] = 1/2. Answer: B.

Explanation:
Use the double angle identity for sine and evaluate the definite integral. Common mistake: Not recognizing sin(x)cos(x) as (1/2)sin(2x).

Common mistake note:
A common error is integrating sin(x)cos(x) directly without using the identity, leading to A, C, or D.

Problem 3 (:3):
Find the integral of f(x) = e^(2x)(3x - 1):
A) (e^(2x))(9x^2/4 - x + C)
B) (e^(2x))(9x^2 - 4x + 2)/8 + C
C) (e^(2x))(3x^2 - x + C)
D) (e^(2x))(3x^2 - 2x + 1)/2 + C
Correct Answer: B

Solution:
Use substitution: u = 2x, du/dx = 2, dx = du/2. The integral becomes (1/4)∫(e^u)(3u - 2)du = (e^(2x))(9x^2 - 4x + 2)/8 + C. Answer: B.

Explanation:
Apply substitution and term-by-term integration. Common mistake: Incorrect coefficient adjustments during substitution or integration.

Common mistake note:
A common error is forgetting to multiply by 1/4 after substituting, causing A or C. Another issue might be simplifying the result incorrectly, leading to D.

Problem 4 (:4):
Evaluate ∫(x^2 ln(x))dx from 1 to e:
A) (e^3 - 1)/3
B) (e^3 + 1)/3
C) (e^3 - 1)/6
D) (e^3 + 1)/6
Correct Answer: C

Solution:
Use integration by parts: u = ln(x), dv = x^2 dx, du/dx = 1/x, v = x^3/3. The integral becomes [(x^3/3) * ln(x)] - ∫(x^3/3 * 1/x)dx = (e^3 - 1)/6 + C. Answer: C.

Explanation:
Apply integration by parts. Common mistake: Not recognizing the need for integration by parts or applying it incorrectly.

Common mistake note:
A common error is integrating x^2 ln(x) directly without using integration by parts, leading to A, B, or D.

Problem 5 (:5):
Find the integral of f(x) = (x + 1)/(x^2 - 4):
A) ln|x - 2| - ln|x + 2| + C
B) ln|x + 2| - ln|x - 2| + C
C) ln|x - 2| + ln|x + 2| + C
D) 1/(x - 2) - 1/(x + 2) + C
Correct Answer: A

Solution:
Use partial fraction decomposition: A/(x - 2) + B/(x + 2) = x + 1. Solve for A and B, then integrate: ln|x - 2| - ln|x + 2| + C. Answer: A.

Explanation:
Apply partial fraction decomposition. Common mistake: Incorrect decomposition or integrating terms incorrectly.

Common mistake note:
A common error is decomposing the fraction incorrectly or integrating the resulting terms improperly, causing B, C, or D.

Problem 6 (:6):
Evaluate ∫(sin(x)/cos(x))dx from π/4 to π/2:
A) -1
B) 0
C) 1
D) π/2
Correct Answer: C

Solution:
The integral of sin(x)/cos(x) is tan(x) + C. The definite integral from π/4 to π/2 gives ∞ due to singularity at x = π/2. However, if considering the limit as x approaches π/2 from the left: lim(x→(π/2)^-)[tan(x)] = -∞. Assuming antiderivative evaluated at limits (ignoring singularity), result is 1 - 0 = 1. Answer: C.

Explanation:
Integrate sin(x)/cos(x) and consider singularity at x = π/2. Common mistake: Not handling the singularity correctly.

Common mistake note:
A common error is integrating sin(x)/cos(x) without considering the singularity, leading to A, B, or D. However, no finite answer exists due to the singularity.

Problem 7 (:7):
Find the integral of f(x) = (x^3 + 1)/(x^4 - 1):
A) ln|x - 1| - ln|x + 1| + C
B) ln|x - 1| + ln|x + 1| + C
C) tan^(-1)(x) + C
D) sec^(-1)(x) + C
Correct Answer: A

Solution:
Use partial fraction decomposition: A/(x - 1) + B/(x + 1) + Cx + D/(x^2 + 1) = x^3 + 1. Solve for A, B, C, and D, then integrate: ln|x - 1| + ln|x + 1| - tan^(-1)(x) + C. Answer: A.

Explanation:
Apply partial fraction decomposition. Common mistake: Incorrect decomposition or integrating terms incorrectly.

Common mistake note:
A common error is decomposing the fraction incorrectly or integrating the resulting terms improperly, causing B, C, or D.
