Problem 1 (Infinite limit with direct substitution):
Find the limit as x approaches 3 of the function f(x) = (x^2 - 9)/(x - 3).
A) -6
B) 0
C) ∞
D) Does not exist
Correct Answer: C

Solution:
f(x) = (x+3)(x-3)/(x-3) = x+3. As x approaches 3, f(x) approaches 3+3 = 6. Since the limit becomes unbounded as x gets closer to 3, the limit is infinity.

Explanation:
Direct substitution shows that the function simplifies to x+3, and since x approaches 3, the limit becomes unbounded.

Common mistake note:
A common mistake would be to cancel out (x-3) in the numerator and denominator, which is not allowed when x = 3.

Problem 2 (Zero in the denominator):
Evaluate the limit as x approaches 0 of the function g(x) = (2x^2 + x)/x.
A) 0
B) 1
C) 2
D) Does not exist
Correct Answer: D

Solution:
The function simplifies to g(x) = 2x + 1. As x approaches 0, the limit becomes 2(0) + 1 = 1. However, since there is a hole at x=0 (due to division by zero), the limit does not exist.

Explanation:
Direct substitution shows that the function simplifies to 2x+1, but there's a discontinuity at x=0 due to division by zero.

Common mistake note:
A common mistake would be to cancel out x in the numerator and denominator, which is only valid if x≠0. Since the limit involves x approaching 0, this method leads to an incorrect conclusion.

Problem 3 (Polynomial with removable discontinuity):
Find the limit as x approaches -2 of the function h(x) = (x^3 + 8)/(x+2).
A) -16
B) 0
C) 4
D) Does not exist
Correct Answer: A

Solution:
The function can be factored as h(x) = (x+2)(x^2 - 2x + 4)/(x+2), which simplifies to x^2 - 2x + 4 when x≠-2. As x approaches -2, the limit becomes (-2)^2 - 2(-2) + 4 = 16.

Explanation:
Direct substitution after factoring shows that there's a removable discontinuity at x=-2, and the limit is found by evaluating the simplified function at x=-2.

Common mistake note:
A common mistake would be to cancel out (x+2) in the numerator and denominator without considering the discontinuity at x=-2. This leads to an incorrect conclusion.

Problem 4 (Quotient of linear functions):
Evaluate the limit as x approaches 1 of the function j(x) = (3x - 2)/(5x - 4).
A) 0.6
B) 0.8
C) 1
D) Does not exist
Correct Answer: B

Solution:
The limit is found by direct substitution: j(1) = (3(1) - 2)/(5(1) - 4) = 1/1 = 1. However, the limit exists even though the function is undefined at x=1.

Explanation:
Direct substitution shows that the limit is 1, and it's important to remember that limits can exist even when the function is undefined at a specific point.

Common mistake note:
A common mistake would be to think that because the function is undefined at x=1, the limit does not exist. This is incorrect; the limit can still be found by evaluating the function as x approaches 1.

Problem 5 (Rational function with a hole):
Find the limit as x approaches 2 of the function k(x) = (x^2 - 4)/(x - 2).
A) 0
B) 2
C) 4
D) Does not exist
Correct Answer: C

Solution:
The function can be factored as k(x) = (x-2)(x+2)/(x-2), which simplifies to x+2 when x≠2. As x approaches 2, the limit becomes 2+2 = 4.

Explanation:
Direct substitution after factoring shows that there's a removable discontinuity at x=2, and the limit is found by evaluating the simplified function at x=2.

Common mistake note:
A common mistake would be to cancel out (x-2) in the numerator and denominator without considering the discontinuity at x=2. This leads to an incorrect conclusion.

Problem 6 (Limit of a constant):
Find the limit as x approaches 4 of the function l(x) = 7.
A) 0
B) 3
C) 7
D) 10
Correct Answer: C

Solution:
The limit is found by direct substitution: l(4) = 7. Since the function is constant, its value does not change as x approaches any point.

Explanation:
Direct substitution shows that the limit is equal to the constant value of the function, regardless of the input value.

Common mistake note:
A common mistake would be to think that the limit depends on the behavior of x as it approaches 4. However, since the function is a constant, its limit is simply the value of the function.

Problem 7 (Limit of a trigonometric function):
Find the limit as x approaches 0 of the function m(x) = sin(x)/x.
A) 0
B) 1
C) π/2
D) Does not exist
Correct Answer: B

Solution:
The limit is found using L'Hopital's rule or by recognizing the limit as x approaches 0 of sin(x)/x is equal to the derivative of sine evaluated at 0, which is cos(0) = 1.

Explanation:
Direct substitution does not work here because it leads to an indeterminate form (0/0). However, the limit can be found using other techniques like L'Hopital's rule or recognizing a known limit.

Common mistake note:
A common mistake would be to attempt direct substitution and conclude that the limit does not exist. This is incorrect; the limit exists and can be found using alternative methods.
