Problem 1 (One):
Simplify the expression: (x + 2)(x - 2)
A) (x^2 + 4)
B) (x^2 - 4x + 4)
C) (x^2 - 4)
D) (x + 4)^2
Correct Answer: C

Solution:
The sum and difference rule states that (a + b)(a - b) = a^2 - b^2. Applying this to the given expression, we get (x + 2)(x - 2) = x^2 - 2^2 = x^2 - 4.

Explanation:
The sum and difference rule is used to expand expressions like (a + b)(a - b).

Common mistake note:
A common mistake would be to add the terms inside the parentheses, which would result in choice A. This error occurs because the student misunderstands the rule for multiplying binomials.

Problem 2 (Two):
Simplify the expression: (3a + 4)(3a - 4)
A) (9a^2 + 12a)
B) (9a^2 - 16)
C) (9a^2 - 12a + 16)
D) (3a + 8)^2
Correct Answer: B

Solution:
Using the sum and difference rule, we have (3a + 4)(3a - 4) = (3a)^2 - 4^2 = 9a^2 - 16.

Explanation:
The sum and difference rule is applied to binomials where the terms are multiples of a single number.

Common mistake note:
A common mistake would be to multiply the coefficients outside the parentheses, which would result in choice A. This error occurs when students forget that only the squares inside the parentheses are squared.
