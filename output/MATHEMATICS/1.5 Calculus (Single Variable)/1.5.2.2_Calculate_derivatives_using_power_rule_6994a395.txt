Problem 1 (Unique ID):
Find the derivative of f(x) = x^3.
A) 3x^2
B) x^2
C) 3x^4
D) x^3
Correct Answer: A

Solution:
The power rule states that if f(x) = x^n, then the derivative f'(x) = nx^(n-1). For f(x) = x^3, n = 3. Applying the power rule gives us f'(x) = 3x^(3-1) = 3x^2.

Explanation:
The power rule is a fundamental tool for differentiating polynomials. In this case, we simply apply the rule to find the derivative of x^3.

Common mistake note:
A common mistake would be forgetting to reduce the exponent by 1 when applying the power rule. For example, choosing B (x^2) instead of A (3x^2).

Problem 2 (Unique ID):
Find the derivative of g(x) = 5x^7.
A) 35x^6
B) 14x^6
C) 35x^8
D) 14x^7
Correct Answer: A

Solution:
The power rule states that if f(x) = x^n, then the derivative f'(x) = nx^(n-1). For g(x) = 5x^7, n = 7. Applying the power rule gives us g'(x) = 5 * 7x^(7-1) = 35x^6.

Explanation:
The constant multiple rule can be applied before using the power rule. Here, we first multiply the constant (5) by the coefficient from the power rule (7), then reduce the exponent by 1.

Common mistake note:
A common mistake would be forgetting to multiply the constant factor (5) with the resulting coefficient from the power rule.

Problem 3 (Unique ID):
Find the derivative of h(x) = x^(-2).
A) -2x^(-3)
B) 2x^(-1)
C) -2x^(-2)
D) 2x^(-3)
Correct Answer: A

Solution:
The power rule states that if f(x) = x^n, then the derivative f'(x) = nx^(n-1). For h(x) = x^(-2), n = -2. Applying the power rule gives us h'(x) = (-2)x^((-2)-1) = -2x^(-3).

Explanation:
When dealing with negative exponents, remember to apply the power rule as usual and adjust for the negative sign.

Common mistake note:
A common mistake would be forgetting that the exponent becomes negative when applying the derivative to a negative exponent function.

Problem 4 (Unique ID):
Find the derivative of p(x) = (2x + 1)^4.
A) 8(2x+1)^3
B) 8x^3
C) 8(2x+1)^2
D) 8x^2
Correct Answer: A

Solution:
To find the derivative of a composite function like p(x) = (2x + 1)^4, we can use the chain rule. The outer function is f(u) = u^4 and the inner function is g(x) = 2x + 1. Applying the chain rule gives us p'(x) = 4(2x+1)^3 * 2 = 8(2x+1)^3.

Explanation:
The chain rule is used when differentiating a composite function. Here, we first find the derivative of the outer function (u^4), then multiply it by the derivative of the inner function (2x + 1).

Common mistake note:
A common mistake would be applying the power rule directly to p(x) without considering it as a composite function.

Problem 5 (Unique ID):
Find the derivative of q(x) = x^2 sin(x).
A) 2x sin(x) + x^2 cos(x)
B) 2x cos(x)
C) x^2 sin(x)
D) 2x^2 sin(x)
Correct Answer: A

Solution:
To find the derivative of a product like q(x) = x^2 sin(x), we can use the product rule. The first function is f(x) = x^2 and the second function is g(x) = sin(x). Applying the product rule gives us q'(x) = (2x)(sin(x)) + (x^2)(cos(x)) = 2x sin(x) + x^2 cos(x).

Explanation:
The product rule is used when differentiating a product of two functions. Here, we find the derivative of each function and multiply them together, then add the results.

Common mistake note:
A common mistake would be forgetting to multiply the derivatives from the product rule by their respective functions.

Problem 6 (Unique ID):
Find the derivative of r(x) = e^x cos(x).
A) e^x cos(x) - e^x sin(x)
B) e^x sin(x)
C) e^x cos(x)
D) e^x (sin(x) + cos(x))
Correct Answer: A

Solution:
To find the derivative of a product like r(x) = e^x cos(x), we can use the product rule. The first function is f(x) = e^x and the second function is g(x) = cos(x). Applying the product rule gives us r'(x) = (e^x)(cos(x)) + (e^x)(-sin(x)) = e^x cos(x) - e^x sin(x).

Explanation:
The product rule is used when differentiating a product of two functions. Here, we find the derivative of each function and multiply them together, then add the results.

Common mistake note:
A common mistake would be forgetting to apply the chain rule to e^x when differentiating it.

Problem 7 (Unique ID):
Find the derivative of s(x) = ln(x).
A) 1/x
B) x
C) ln(x)
D) x^2
Correct Answer: A

Solution:
The derivative of the natural logarithm function, ln(x), is given by f'(x) = 1/x. Thus, the derivative of s(x) = ln(x) is s'(x) = 1/x.

Explanation:
The derivative of the natural logarithm function is a standard result that should be memorized. It does not involve the power rule directly but can be derived using other techniques like implicit differentiation or the inverse function theorem.

Common mistake note:
A common mistake would be applying the power rule to ln(x), which is incorrect since it's not in the form x^n.
