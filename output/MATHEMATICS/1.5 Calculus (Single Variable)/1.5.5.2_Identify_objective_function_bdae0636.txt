Problem 1 (AsdFg67h):
What is the objective function in the following linear programming problem?
Maximize: 3x + 4y
Subject to:
x + y ≤ 10
2x - y ≤ 8
x, y ≥ 0
A) x + y
B) 2x - y
C) 3x + 4y
D) x
Correct Answer: C

Solution:
The objective function is the expression that we want to maximize in a linear programming problem. In this case, it is '3x + 4y'. The other expressions are constraints.

Explanation:
The objective function defines what we want to optimize in a linear programming problem.

Common mistake note:
A common mistake would be to choose one of the constraint inequalities (A or B), which represent the limits on the variables, rather than the actual target to optimize.
