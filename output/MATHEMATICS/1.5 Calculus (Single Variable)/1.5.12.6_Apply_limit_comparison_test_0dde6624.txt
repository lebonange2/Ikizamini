Problem 1 (One):
Evaluate the limit using the Limit Comparison Test: lim x → ∞ (3x^2 + 4x - 1) / (5x^2 + 7x)
A) (A) 0
B) (B) 1/3
C) (C) 3/5
D) (D) ∞
Correct Answer: C

Solution:
The Limit Comparison Test compares the limit of two functions. To apply it, we choose a simpler function to compare with, typically one that is easier to evaluate the limit for. In this case, let's compare our function with 3x^2 / 5x^2 = 3/5. Since both functions have x^2 in the numerator and denominator, they will grow at the same rate as x approaches infinity. The limit of 3/5 is 3/5, so by the Limit Comparison Test, the limit of (3x^2 + 4x - 1) / (5x^2 + 7x) is also 3/5.

Explanation:
The Limit Comparison Test compares the behavior of two functions as x approaches infinity. If the limit of the ratio of their absolute values is a finite, non-zero value, then both limits either exist and are equal or do not exist.

Common mistake note:
A common mistake would be to directly evaluate the limit without using the Limit Comparison Test. This test is useful when direct substitution doesn't lead to an easy solution.

Problem 2 (Two):
Evaluate the limit using the Limit Comparison Test: lim x → ∞ (sin(x) / x)^(1/x)
A) (A) 0
B) (B) 1
C) (C) e
D) (D) Does not exist
Correct Answer: B

Solution:
The Limit Comparison Test is not directly applicable to this problem because the function involves an exponent with x. Instead, we can use L'Hopital's Rule or recognize that (sin(x) / x) approaches 1 as x approaches infinity. Taking the limit of the logarithm first: lim x → ∞ ln((sin(x) / x)^(1/x)) = lim x → ∞ (1/x) * ln(sin(x) / x). The first term goes to 0, and the second term oscillates between -∞ and ∞. Therefore, the overall limit does not exist.

Explanation:
The Limit Comparison Test is designed for comparing series or functions with similar growth rates. This problem involves a more complex function that requires different techniques like L'Hopital's Rule or recognizing special limits.

Common mistake note:
A common mistake would be to try applying the Limit Comparison Test without realizing it's not suitable for this type of limit. It is essential to recognize when other methods, such as L'Hopital's Rule, are more appropriate.

Problem 3 (Three):
Evaluate the limit using the Limit Comparison Test: lim x → ∞ (2^x + 3^(x+1)) / (4^x)
A) (A) 0
B) (B) 1/2
C) (C) 1
D) (D) ∞
Correct Answer: B

Solution:
The Limit Comparison Test can be applied by comparing the given function with 3^(x+1) / 4^x = (3/4)^x. As x approaches infinity, (3/4)^x approaches 0 because 3/4 is less than 1. Since the limit of (3/4)^x is 0 and both functions grow at the same rate, the limit of (2^x + 3^(x+1)) / (4^x) is also 0.

Explanation:
The Limit Comparison Test helps to determine the behavior of a function by comparing it with another simpler function. In this case, we chose a function that grows at a similar rate and has an easily determined limit as x approaches infinity.

Common mistake note:
A common mistake would be to compare with 2^x / 4^x instead, which would lead to the incorrect conclusion that the limit is 1/2. It's important to choose a comparison function that reflects the dominant term in the original expression.

Since the limit of (1/e)^x is 0 and both functions grow at the same rate, the limit of (e^(2x) - 1) / (e^(3x) + 2) is also 0.

Explanation:
The Limit Comparison Test helps to determine the behavior of a function by comparing it with another simpler function. In this case, we chose a function that grows at a similar rate and has an easily determined limit as x approaches infinity.

Problem 6 (Six):

C) (C) 1
D) (D) ∞
Correct Answer: A

Solution:
The Limit Comparison Test can be applied by comparing the given function with ln(x) / x^2. As x approaches infinity, ln(x) grows much slower than x^2, so the limit of ln(x) / x^2 approaches 0.

Explanation:
