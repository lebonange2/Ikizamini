Problem 1 (SimplifiedQuestion1):
Simplify the expression (x+2)/(x-3) when x = 5.
A) (5+2)/(5-3)
B) 7/2
C) 3/2
D) 1
Correct Answer: B

Solution:
Substitute x = 5 into the expression: (5+2)/(5-3) = 7/2.

Explanation:
We substitute the value of x into the expression and simplify. The correct result is 7/2.

Common mistake note:
A common mistake is to forget to substitute x with 5, resulting in an incorrect answer.

Problem 2 (SimplifiedQuestion2):
Evaluate the function f(x) = 3x - 1 at x = 4.

D) 1
Correct Answer: C

Solution:

Problem 4 (SimplifiedQuestion4):
Evaluate the equation 4x + 7 = 15 for x.
A) (15 - 7)/4
B) 2
C) 8
D) 0
Correct Answer: B

Solution:
Subtract 7 from both sides and divide by 4: (15 - 7)/4 = 2.

Explanation:
We solve for x by isolating it on one side of the equation. The correct result is x = 2.

Common mistake note:
A common mistake is to forget to subtract 7 from both sides, resulting in an incorrect value for x.
