Problem 1 (:1):
Evaluate the limit as x approaches 0 for the function: (x^2 - 4)/(x - 2)
A) (0)^2 - 4 = -4
B) (0) - 2 = -2
C) lim(x->0)[(2x)/(1)] = 0
D) lim(x->0)[(2x)/(1)] = 0
Correct Answer: D

Solution:
L'Hôpital's rule is applicable because the limit results in the indeterminate form 0/0. Differentiating both the numerator and denominator, we get (2x)/(1). Evaluating this at x=0 gives us 0.

Explanation:
Choice A is incorrect because it evaluates the function at x=0 without applying L'Hôpital's rule. Choice B incorrectly applies the limit to the original function instead of differentiating.

Common mistake note:
A common mistake is to apply the limit directly to the original function without recognizing that L'Hôpital's rule is needed.

Problem 2 (:2):
Evaluate the limit as x approaches infinity for the function: (3x^2 + 5)/(7x^2 - 4)
A) (3∞^2 + 5)/(7∞^2 - 4) = ∞/∞
B) lim(x->∞)[(3/(7))] = 3/7
C) lim(x->∞)[(6x)/(14x)] = 6/14
D) lim(x->∞)[(3/(7))] = 0
Correct Answer: B

Solution:
The limit results in the indeterminate form ∞/∞, so L'Hôpital's rule applies. Differentiating both numerator and denominator, we get (6x)/(14x), which simplifies to 3/7 as x approaches infinity.

Explanation:
Choice A correctly identifies the indeterminate form but does not apply L'Hôpital's rule. Choice C incorrectly simplifies the fraction before applying L'Hôpital's rule, while choice D incorrectly sets the limit to zero without considering the correct application of L'Hôpital's rule.

Common mistake note:
A common mistake is to simplify the function before applying L'Hôpital's rule or not recognizing that ∞/∞ is an indeterminate form.
