Problem 1 (OneStepSubstitutionEasy1):
Solve for x: 2x + 3 = 7
A) x = 1
B) x = 2
C) x = 3
D) x = 4
Correct Answer: B

Solution:
Subtract 3 from both sides: 2x = 4. Divide by 2: x = 2.

Explanation:
This question tests the basic skill of solving a simple linear equation using substitution.

Common mistake note:
A common mistake is to forget to divide by 2, resulting in the incorrect answer A.

Problem 3 (MultiStepSubstitutionMedium1):
Solve for z: 3z + 2 = 4(z - 1)
A) z = 0
B) z = 1
C) z = 2
D) z = 3
Correct Answer: A

Solution:
Expand: 3z + 2 = 4z - 4. Move terms to one side: z = 6.

Explanation:
This question tests the skill of solving a linear equation with multiple steps using substitution.

Common mistake note:
