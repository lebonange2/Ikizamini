Problem 1 (One):
Find the axis of symmetry for the quadratic equation: f(x) = x^2 + 4x + 3.
A) (1, 0)
B) (-2, 0)
C) (0, -2)
D) (-1, 0)
Correct Answer: B

Solution:
The axis of symmetry for a quadratic equation in the form f(x) = ax^2 + bx + c is given by x = -b / (2a). For the equation f(x) = x^2 + 4x + 3, a = 1 and b = 4. Plugging these values into the formula gives us x = -4 / (2 * 1) = -2. Therefore, the axis of symmetry is at x = -2, which corresponds to the line x = -2 or (x - (-2))^2 = 0, or B: (-2, 0).

Explanation:
The axis of symmetry divides the parabola into two mirror images and can be found using the formula. The common mistake is not applying the formula correctly.

Common mistake note:
Common mistake: Forgetting to divide by 2 when calculating x = -b / (2a).

Problem 2 (Two):

Problem 3 (Three):
Find the axis of symmetry for the quadratic equation: f(x) = 2x^2 - 12x + 9.
A) (3, 0)
B) (-3, 0)
C) (6, 0)
D) (-6, 0)
Correct Answer: A

Solution:
Using the formula x = -b / (2a), for f(x) = 2x^2 - 12x + 9, a = 2 and b = -12. Plugging these values gives us x = -(-12) / (2 * 2) = 3. Therefore, the axis of symmetry is at x = 3, which corresponds to choice A: (3, 0).

Explanation:
The formula for the axis of symmetry applies regardless of the coefficient of x^2. The common mistake would be not accounting for the different coefficient.

Common mistake note:
Common mistake: Dividing by 1 instead of 2 when calculating x = -b / (2a) due to a misunderstanding of the formula.

Problem 4 (Four):
Find the axis of symmetry for the quadratic equation: f(x) = -3x^2 + 6x - 2.
A) (1, 0)
B) (-1, 0)
C) (2, 0)
D) (-2, 0)
Correct Answer: A

Solution:
Using the formula x = -b / (2a), for f(x) = -3x^2 + 6x - 2, a = -3 and b = 6. Plugging these values gives us x = -6 / (2 * -3) = 1. Therefore, the axis of symmetry is at x = 1, which corresponds to choice A: (1, 0).

Explanation:
The formula remains valid even when a is negative. The common mistake would be not considering the sign of a.

Common mistake note:
Common mistake: Neglecting the negative sign in front of b when calculating x = -b / (2a) due to oversight.

Problem 6 (Six):
Find the axis of symmetry for the quadratic equation: f(x) = x^2 - 8x + 15.
A) (4, 0)
B) (-4, 0)
C) (-2, 0)
D) (2, 0)
Correct Answer: A

Solution:
Using the formula x = -b / (2a), for f(x) = x^2 - 8x + 15, a = 1 and b = -8. Plugging these values gives us x = -(-8) / (2 * 1) = 4. Therefore, the axis of symmetry is at x = 4, which corresponds to choice A: (4, 0).

Explanation:
The formula for the axis of symmetry applies regardless of the constant term. The common mistake would be trying to factor out a coefficient from the equation.

Common mistake note:
Common mistake: Attempting to factor the quadratic equation instead of using the formula.
