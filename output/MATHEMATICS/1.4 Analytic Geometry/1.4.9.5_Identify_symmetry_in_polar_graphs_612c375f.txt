Problem 1 (:1):
The polar graph of r = cos(2θ) exhibits which type of symmetry?
A) No symmetry
B) Reflectional symmetry about the horizontal axis
C) Reflectional symmetry about the vertical axis
D) Rotational symmetry of order 4
Correct Answer: C

Solution:
The function r = cos(2θ) has reflectional symmetry about the vertical axis because cosine is an even function. When plotted, it appears symmetrical with respect to the line θ = π/2.

Explanation:
Even functions exhibit reflectional symmetry about the y-axis in rectangular coordinates, which translates to reflectional symmetry about the vertical axis (θ-axis) in polar coordinates.

Common mistake note:
Students may mistakenly choose A (No symmetry), thinking that cosine's periodic nature eliminates overall symmetry. However, recognizing that even functions have reflectional symmetry is key.

Problem 2 (2):
The polar equation r = 3sin(θ) has what type of symmetry?
A) Reflectional symmetry about both axes
B) Rotational symmetry of order 3
C) Reflectional symmetry about the horizontal axis
D) Reflectional symmetry about the vertical axis
Correct Answer: B

Solution:
The function r = 3sin(θ) has rotational symmetry of order 3 because sine is a periodic function with period 2π, and multiplying by 3 makes its graph repeat every π/3 radians.

Explanation:
Rotational symmetry in polar graphs occurs when the angle between successive points on the graph is a fraction of 2π. Here, sin(θ) has period 2π; multiplying by 3 results in a period of 2π/3, indicating rotational symmetry of order 3.

Common mistake note:
Students might choose A (Reflectional symmetry about both axes),混淆sine的周期性与反射对称性。实际上，sine仅在直角坐标中关于原点对称，而非同时关于两轴。

Problem 3 (3):
The polar equation r = 2 - 4cos(θ) exhibits which type of symmetry?
A) Reflectional symmetry about the horizontal axis
B) Reflectional symmetry about the vertical axis
C) Rotational symmetry of order 2
D) No symmetry
Correct Answer: B

Solution:
The function r = 2 - 4cos(θ) has reflectional symmetry about the vertical axis because cosine is an even function and the entire equation shifts vertically. The negative sign before cos(θ) does not affect overall symmetry.

Explanation:
Even functions retain their reflectional symmetry about the vertical axis when combined with linear transformations like shifting or stretching. In this case, shifting up by 2 and stretching by -4 do not change cosine's even property.

Common mistake note:
Students may select C (Rotational symmetry of order 2)，误以为cosine的周期性导致旋转对称。然而，是偶函数和位移的组合决定了整体对称性。

Problem 4 (4):
The polar graph of r = 5sin(2θ) + 3cos(θ) exhibits which type of symmetry?
A) Reflectional symmetry about the horizontal axis
B) Reflectional symmetry about the vertical axis
C) Rotational symmetry of order 4
D) No symmetry
Correct Answer: D

Solution:
The function r = 5sin(2θ) + 3cos(θ) has no symmetry because it combines sine and cosine functions with different periods, resulting in an asymmetrical graph.

Explanation:
When combining trigonometric functions with distinct periods or harmonics (like sin(2θ)), the resulting graph typically lacks specific symmetries. Here, the combination of 5sin(2θ) and 3cos(θ) creates a complex shape without recognizable symmetries.

Common mistake note:
Students might choose B (Reflectional symmetry about the vertical axis)，仅关注其中一个函数（cosine）的反射对称性。然而，与sine和不同谐波的组合消除了整体对称性。

Problem 5 (5):
The polar equation r = 2sin(θ) - cos(θ) exhibits which type of symmetry?
A) Reflectional symmetry about both axes
B) Rotational symmetry of order 3
C) Reflectional symmetry about the horizontal axis
D) Reflectional symmetry about the vertical axis
Correct Answer: A

Solution:
The function r = 2sin(θ) - cos(θ) has reflectional symmetry about both axes because it combines sine and cosine functions, which individually have symmetries that combine to form symmetry about both axes.

Explanation:
Sine exhibits reflectional symmetry about the origin in rectangular coordinates, as does cosine. When combined this way, the graph displays reflectional symmetry around both horizontal and vertical axes.

Common mistake note:
Students may select C (Reflectional symmetry about the horizontal axis) or D (Reflectional symmetry about the vertical axis)，仅关注单个函数的对称性。实际上，sine和cosine的组合在极坐标中形成关于两轴的对称性。
