Problem 1 (AsdFgHjK):
Find the rotation matrix that rotates a vector by 90 degrees counterclockwise around the z-axis.
A) [[1, 0, 0], [0, -1, 0], [0, 0, 1]]
B) [[-1, 0, 0], [0, 1, 0], [0, 0, 1]]
C) [[0, 1, 0], [1, 0, 0], [0, 0, 1]]
D) [[0, -1, 0], [-1, 0, 0], [0, 0, 1]]
Correct Answer: D

Solution:
The rotation matrix for a counterclockwise rotation of 90 degrees around the z-axis is given by the identity matrix with the first and second columns negated. The correct matrix is thus [[0, -1, 0], [-1, 0, 0], [0, 0, 1]].

Explanation:
A counterclockwise rotation around the z-axis results in a swap of the x and y components with a change of sign on one of them.

Common mistake note:
Common mistake: Choosing A or B, which represent clockwise rotations. Remember that counterclockwise rotations result in negative signs for the off-diagonal elements.

Problem 2 (ZxvBnMlP):
Given a rotation matrix R = [[cosθ, -sinθ], [sinθ, cosθ]], what is the angle of rotation θ if R represents a 180-degree rotation?
A) -π
B) π/2
C) π
D) 3π/2
Correct Answer: C

Solution:
A 180-degree rotation is equivalent to π radians. In the given rotation matrix, when θ = π, we have cosθ = -1 and sinθ = 0, resulting in the matrix [[-1, 0], [0, -1]] which represents a 180-degree rotation.

Explanation:
The rotation matrix for an angle θ is defined as [[cosθ, -sinθ], [sinθ, cosθ]]. For a 180-degree rotation, θ = π.

Common mistake note:
Common mistake: Choosing B or D, which represent quarter turns. Remember that a full turn is π radians.

Problem 4 (BvnMlPqRs):
Given a vector v = [1, 0, 0] and a rotation matrix R = [[cosθ, -sinθ, 0], [sinθ, cosθ, 0], [0, 0, 1]], what is the rotated vector after a 90-degree counterclockwise rotation around the y-axis?
A) [0, 1, 0]
B) [-1, 0, 0]
C) [1, 0, 0]
D) [0, -1, 0]
Correct Answer: A

Solution:
The rotation matrix for a counterclockwise rotation of θ degrees around the y-axis is given by [[cosθ, 0, sinθ], [0, 1, 0], [-sinθ, 0, cosθ]]. For θ = 90 degrees or π/2 radians, we have cosθ = 0 and sinθ = 1. The rotated vector v' is thus Rv = [0, 1, 0].

Explanation:
The rotation matrix around the y-axis only affects the x and z components of the vector.

Common mistake note:
Common mistake: Choosing C or D, which represent no rotation or a clockwise rotation. Remember that counterclockwise rotations change the x component.

Problem 5 (XcvBnMlP):
Find the angle θ in radians for which the rotation matrix R = [[cosθ, -sinθ], [sinθ, cosθ]] represents a 45-degree clockwise rotation.
A) -π/4
B) π/4
C) 3π/4
D) 5π/4
Correct Answer: C

Solution:
A 45-degree clockwise rotation is equivalent to -45 degrees or -π/4 radians. In the given rotation matrix, when θ = -π/4, we have cosθ = cos(-π/4) = √2 / 2 and sinθ = sin(-π/4) = -√2 / 2.

Explanation:
The rotation matrix for an angle θ is defined as [[cosθ, -sinθ], [sinθ, cosθ]]. For a clockwise rotation of 45 degrees, θ = -π/4.

Common mistake note:
Common mistake: Choosing A or B, which represent counterclockwise rotations. Remember that clockwise rotations have negative angles.

Problem 6 (GhjKlMnO):
Given a rotation matrix R = [[cosθ, -sinθ, 0], [sinθ, cosθ, 0], [0, 0, 1]], what is the rotated vector after a 360-degree rotation around the z-axis?
A) [1, 0, 0]
B) [-1, 0, 0]
C) [0, 1, 0]
D) [0, -1, 0]
Correct Answer: A

Solution:
The rotation matrix for a full 360-degree (2π radians) rotation around the z-axis is the identity matrix [[1, 0, 0], [0, 1, 0], [0, 0, 1]], which does not change the vector. Thus, the rotated vector remains as v = [1, 0, 0].

Explanation:
A full rotation around any axis returns the original orientation.

Common mistake note:
Common mistake: Choosing B, C, or D, which represent rotations around other axes. Remember that a full rotation around the z-axis does not change the vector.
