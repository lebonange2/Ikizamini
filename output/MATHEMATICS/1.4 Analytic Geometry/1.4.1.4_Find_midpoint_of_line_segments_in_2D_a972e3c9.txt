Problem 1 (AndrewMidpoint):
What is the midpoint of a line segment with endpoints A(2, 3) and B(8, 9)?
A) (5, 6)
B) (10, 12)
C) (2, 9)
D) (8, 3)
Correct Answer: A

Solution:
The midpoint formula is (x1 + x2) / 2, (y1 + y2) / 2. Plugging in the coordinates of A and B: (2 + 8) / 2 = 5, (3 + 9) / 2 = 6. So the midpoint is (5, 6).

Explanation:
The midpoint formula helps find the middle point on a line segment by averaging the x- and y-coordinates of the endpoints.

Common mistake note:
A common mistake would be to incorrectly average one or both coordinates, such as using (2 + 9) / 2 for the x-coordinate or (3 + 8) / 2 for the y-coordinate.

Problem 2 (SarahMidpoint):
Find the midpoint of a line segment with endpoints C(-4, -1) and D(6, 7).
A) (1, 3)
B) (-1, 2)
C) (4, 3)
D) (10, 8)
Correct Answer: A

Solution:
Using the midpoint formula: (x1 + x2) / 2 = (-4 + 6) / 2 = 1, (y1 + y2) / 2 = (-1 + 7) / 2 = 3. The midpoint is (1, 3).

Explanation:
The midpoint formula applies universally to any line segment in a Cartesian coordinate system.

Common mistake note:
A common mistake would be to transpose the coordinates when calculating the average, like using (-4 + 7) / 2 for the x-coordinate or (-1 + 6) / 2 for the y-coordinate.

Problem 3 (EmilyMidpoint):
What is the midpoint of a line segment connecting E(0, 5) and F(-3, -2)?
A) (-1.5, 1.5)
B) (1.5, 3.5)
C) (-1.5, 3.5)
D) (1.5, 1.5)
Correct Answer: C

Solution:
Applying the midpoint formula: (x1 + x2) / 2 = (-3 + 0) / 2 = -1.5, (y1 + y2) / 2 = (-2 + 5) / 2 = 3.5. The midpoint is (-1.5, 3.5).

Explanation:
The formula remains the same regardless of whether the coordinates are positive or negative.

Common mistake note:
A common mistake would be to forget to consider the signs when averaging the coordinates, like using (0 - 3) / 2 for the x-coordinate or (-2 + 5) / 2 for the y-coordinate.

B) (-3, -2)

Correct Answer: A

Solution:

Explanation:
The formula works for any line segment in a Cartesian plane.

Common mistake note:
