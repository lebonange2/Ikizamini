Problem 1 (Asdf):
Reflect the point (3, 4) across the line y = x. Which of the following is the correct reflected point?
A) (4, 3)
B) (3, -4)
C) (-4, -3)
D) (-3, -4)
Correct Answer: A

Solution:
The reflection across the line y = x swaps the x and y coordinates of a point. So, if we start with (3, 4), the reflected point will have its x-coordinate as the original y-coordinate and vice versa: (4, 3).

Explanation:
Reflection across the line y = x is a common transformation in geometry that swaps the x and y values of each coordinate.

Common mistake note:
A common mistake would be to choose option B, which reflects the point along the x-axis instead of the line y = x. Remember that reflection across y = x only swaps coordinates.

Problem 3 (Asdf3):
Reflect the equation y = 2x + 1 across the line y = x. Which of the following is the correct reflected equation?
A) x = 2y + 1
B) x = -2y - 1
C) y = -2x - 1
D) y = -2x + 1
Correct Answer: A

Solution:
Reflecting the equation across y = x means swapping x and y. So, y becomes x and vice versa: x = 2y + 1.

Explanation:
When reflecting an equation, treat it as a point (slope-intercept form) or line and apply the reflection rule accordingly.

Common mistake note:
A common mistake would be to choose option C, which reflects the slope incorrectly. Remember that the slope changes sign when reflecting across y = x.

Problem 4 (Asdf4):

A) x = (y - 2)^2 + 3
B) x = -(y - 2)^2 - 3
C) y = -(x - 2)^2 - 3
D) y = -(x - 2)^2 + 3
Correct Answer: A

Solution:
Reflecting the parabola across y = x means swapping x and y: x = (y - 2)^2 + 3.

Explanation:
When reflecting a more complex function, like a parabola, apply the reflection rule to each term in the equation.

Common mistake note:
A common mistake would be to choose option C, which reflects the vertex incorrectly. Remember that only the x and y values change; the structure of the equation remains the same.
