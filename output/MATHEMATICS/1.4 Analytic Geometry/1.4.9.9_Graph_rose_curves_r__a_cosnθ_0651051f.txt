Problem 1 (:Q1):
Sketch the graph of the polar equation r = 2 cos(3θ). Which of the following best describes the curve?
A) A circle with radius 2.
B) A cardioid.
C) A three-leafed rose curve.
D) A six-leafed rose curve.
Correct Answer: C

Solution:
The equation r = 2 cos(3θ) represents a rose curve with n = 3, which means it will have 3 petals. Thus, the correct answer is C: A three-leafed rose curve.

Explanation:
Rose curves are formed when n is an odd number; they have n petals. When n is even, the graph forms a petal-reflected curve (like a circle or cardioid). In this case, n = 3, which is odd.

Common mistake note:
Common mistake: Choosing A (circle) because of the radius 2. The presence of 'cos(3θ)' indicates that it's not a simple circle but a more complex rose curve.

Problem 2 (:Q2):
Sketch the graph of r = 4 sin(6θ). Which type of polar curve does this equation represent?
A) A cardioid.
B) A six-leafed rose curve.
C) An Archimedean spiral.
D) A circle.
Correct Answer: B

Solution:
The equation r = 4 sin(6θ) represents a rose curve with n = 6, which means it will have 6 petals. Therefore, the correct answer is B: A six-leafed rose curve.

Explanation:
Rose curves are formed when n is an odd number for cos or even for sin; they have n petals. In this case, n = 6, which is even, and since it's 'sin', it forms a rose curve.

Common mistake note:
Common mistake: Choosing A (cardioid) because of the sine function. The presence of '6θ' indicates that it's not a cardioid but a six-leafed rose curve.

Problem 3 (:Q3):
Sketch the graph of r = 3 cos(4θ). Which of the following best describes the symmetry of the curve?
A) Symmetric about both the polar axis and the vertical line θ = π/2.
B) Symmetric only about the polar axis.
C) Symmetric only about the vertical line θ = π/2.
D) No symmetry.
Correct Answer: B

Solution:
The equation r = 3 cos(4θ) represents a rose curve with n = 4, which is even. Even values of n result in symmetry only about the polar axis (θ-axis). So, the correct answer is B: Symmetric only about the polar axis.

Explanation:
Rose curves with even n are symmetric about the polar axis but not about any vertical line. In this case, n = 4, which is even.

Common mistake note:
Common mistake: Choosing C (symmetric about θ = π/2) because of the cosine function. Even values of n for cos or odd values of n for sin result in symmetry only about the polar axis.
