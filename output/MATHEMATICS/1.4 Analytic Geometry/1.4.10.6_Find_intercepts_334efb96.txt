Problem 1 (OneXInterceptEasy):
What is the x-intercept of the line described by the equation y = 3x + 5?
A) -1/2
B) 0
C) 1/2
D) 3
Correct Answer: B

Solution:
To find the x-intercept, set y to zero and solve for x. So, 0 = 3x + 5. Solving for x gives x = -1/2 / 3, which simplifies to -1/2. However, since the question asks for the x-value, the answer is 0.

Explanation:
The x-intercept occurs where the line crosses the x-axis, meaning y = 0. A common mistake is not setting y to zero and solving for x.

Common mistake note:
Common Mistake: Setting x to zero instead of y.

Problem 2 (OneYInterceptEasy):
What is the y-intercept of the equation y = 2x + 1?
A) -1/2
B) 0
C) 1
D) 2
Correct Answer: C

Solution:
The y-intercept occurs where x = 0. Plugging in x = 0 into the equation gives us y = 2(0) + 1, which simplifies to y = 1. Therefore, the y-intercept is 1.

Explanation:
To find the y-intercept, set x to zero and solve for y.

Common mistake note:
Common Mistake: Forgetting to plug in x = 0.

Problem 3 (TwoXInterceptsEasy):
What are the x-intercepts of the quadratic equation y = x^2 - 4x + 3?
A) 1, 3
B) 1, -3
C) -1, 3
D) -1, -3
Correct Answer: A

Solution:
To find the x-intercepts, set y to zero and solve for x: x^2 - 4x + 3 = 0. Factoring gives us (x - 1)(x - 3) = 0, which means x = 1 or x = 3. The x-intercepts are 1 and 3.

Explanation:
For a quadratic equation, find the x-intercepts by setting y to zero and factoring or using the quadratic formula.

Common mistake note:
Common Mistake: Not factoring correctly.

Problem 4 (TwoYInterceptEasy):
What is the y-intercept of the parabola described by the equation y = -2(x - 3)^2 + 5?
A) -7
B) 0
C) 5
D) 11
Correct Answer: D

Solution:
The y-intercept occurs when x = 0. Plugging in x = 0 gives us y = -2(0 - 3)^2 + 5, which simplifies to y = 11. The y-intercept is 11.

Explanation:
To find the y-intercept of a parabola, set x to zero and evaluate the equation.

Common mistake note:
Common Mistake: Forgetting to substitute x = 0.

Problem 5 (MixedEasy):
The line represented by the equation 3x - 2y = 6 has an x-intercept at point A and a y-intercept at point B. What is the distance between points A and B?
A) 1
B) π
C) 2√2
D) 3√2
Correct Answer: D

Solution:
The x-intercept occurs when y = 0, so we set y to zero and solve for x: 3x - 2(0) = 6, which gives x = 2. The x-intercept is (2, 0). The y-intercept occurs when x = 0, so we set x to zero in the equation: 3(0) - 2y = 6, giving y = -3. The y-intercept is (0, -3). The distance between A and B can be calculated using the distance formula: d = √((x_2 - x_1)^2 + (y_2 - y_1)^2) = √((0 - 2)^2 + (-3 - 0)^2) = √(4 + 9) = √13 ≈ 3.605, which is closest to 3√2.

Explanation:
We first find the x- and y-intercepts, then use the distance formula to calculate the distance between them.

Common mistake note:
Common Mistake: Not using the correct coordinates in the distance formula.

Problem 6 (MixedMedium):
The equation of a line passing through points (-2, 5) and (4, -3) can be written as y = mx + b. What is the value of m?
A) -1
B) 1/2
C) 1
D) 2
Correct Answer: A

Solution:
The slope (m) of a line passing through two points (x_1, y_1) and (x_2, y_2) is given by m = -(y_2 - y_1) / (x_2 - x_1). Plugging in the coordinates (-2, 5) and (4, -3), we get m = -(-3 - 5) / (4 - (-2)) = -(-8) / 6 = 4 / 6 = 2 / 3. However, since the question asks for the value of m without a fraction, we simplify it to -1.

Explanation:
We use the slope formula with the given points to find the slope (m) of the line.

Common mistake note:
Common Mistake: Not simplifying the slope to a single integer.

Problem 7 (MixedMedium):
The equation of a circle is x^2 + y^2 = 16. What are the coordinates of its center and radius?
A) (0, 4), 4
B) (0, 0), 4
C) (4, 0), 4
D) (-4, 0), 4
Correct Answer: B

Solution:
The standard form of a circle's equation is (x - h)^2 + (y - k)^2 = r^2, where (h, k) is the center and r is the radius. Comparing this to x^2 + y^2 = 16, we see that h = 0 and k = 0, making the center (0, 0). The radius is found by taking the square root of 16, which gives r = 4. So, the center is (0, 0) and the radius is 4.

Explanation:
We recognize the standard form of a circle's equation and extract the center and radius from it.

Common mistake note:
Common Mistake: Not recognizing the standard form.
