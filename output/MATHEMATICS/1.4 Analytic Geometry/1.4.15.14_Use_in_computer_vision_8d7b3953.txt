Problem 1 (:1):
What is a common use of computer vision in self-driving cars?
A) Detecting traffic lights
B) Calculating fuel efficiency
C) Analyzing engine performance
D) Predicting weather conditions
Correct Answer: A

Solution:
Computer vision helps self-driving cars detect objects like traffic lights, pedestrians, and other vehicles on the road. Calculating fuel efficiency and analyzing engine performance are related to car mechanics, not computer vision. Predicting weather conditions is not directly related to the primary function of self-driving cars.

Explanation:
In self-driving cars, computer vision plays a crucial role in perception and decision-making by recognizing elements in the environment.

Common mistake note:
Common mistake: Choosing B or C, which are related to car performance rather than perception.

Problem 2 (:2):
Which of the following is an application of computer vision in security systems?
A) Facial recognition
B) Analyzing financial data
C) Translating languages
D) Playing chess
Correct Answer: A

Solution:
Facial recognition uses computer vision algorithms to identify or verify a person's identity based on their facial features. Analyzing financial data, translating languages, and playing chess are not directly related to computer vision.

Explanation:
Computer vision is widely used in security systems for tasks like access control and surveillance through facial recognition.

Common mistake note:
Common mistake: Choosing B, C, or D, which are unrelated fields that may involve AI but not specifically computer vision.

Problem 3 (:3):
What technology powers the object detection feature in smartphone cameras?
A) Image compression
B) Optical character recognition (OCR)
C) Machine learning algorithms
D) GPS
Correct Answer: C

Solution:
Object detection in smartphone cameras relies on machine learning algorithms that can identify and label objects within an image. Image compression reduces file size, OCR reads text from images, and GPS is used for location tracking.

Explanation:
Smartphone cameras use computer vision to enhance user experience by detecting objects and applying filters or features accordingly.

Common mistake note:
Common mistake: Choosing A or B, which are unrelated technologies; choosing D, which is a positioning system rather than an image analysis tool.

Problem 4 (:4):
Which computer vision technique is used for identifying handwritten digits?
A) Image segmentation
B) Feature extraction
C) Deep learning neural networks
D) Edge detection
Correct Answer: C

Solution:
Handwritten digit recognition typically employs deep learning neural networks, such as convolutional neural networks (CNNs), to classify and interpret the patterns in handwritten digits. Image segmentation separates an image into meaningful regions, feature extraction isolates important aspects of an image, and edge detection highlights boundaries.

Explanation:
Deep learning algorithms are particularly effective at recognizing complex patterns like those found in handwritten digits.

Common mistake note:
Common mistake: Choosing A or D, which are techniques for image processing but not specifically designed for digit recognition; choosing B, which is a step in the process but not the primary method for this task.

Problem 6 (:6):
Which computer vision application helps with autonomous navigation in drones?
A) Scene understanding
B) Image compression
C) Image stitching
D) Video stabilization
Correct Answer: A

Solution:
Scene understanding, a subfield of computer vision, enables drones to interpret their surroundings and make decisions for autonomous navigation. Image compression reduces file size, image stitching combines multiple images, and video stabilization ensures smooth footage.

Explanation:
Autonomous drones rely on scene understanding to avoid obstacles, follow routes, and perform tasks like aerial photography or inspection.

Common mistake note:
Common mistake: Choosing B, C, or D, which are unrelated technologies; they do not directly contribute to drone navigation.
